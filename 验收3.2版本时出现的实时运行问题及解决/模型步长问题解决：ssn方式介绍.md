# 模型步长问题解决：SSN 方式介绍

---

## 结论

你现在的模型是**普通单核电气求解结构**，还没有使用 SSN。即使许可证有 4 个 CPU 核，也不能把一个完整电气网络自动平均分给 4 个核。

我们现在准备做的是：

```
把一个"大电气计算题"
→ 用 SSN 划分成几个"小电气计算题"
→ 让多个 CPU 核同时计算
→ 每 100 μs 再汇总一次结果
```

SSN 支持把同一电气系统的不同计算组分配给多个处理器，并且在支持的 RT-LAB / ARTEMiS 版本中可以做到**不额外增加一个仿真步长的延迟**。

---

## 一、你现在的模型是怎么计算的

当前大致是：

```
PV 逆变器
ESS 逆变器
EV 逆变器
电网、线路、母线、负荷
        ↓
组成一个完整电气网络
        ↓
由一个 CPU 核顺序计算
```

可以把它理解为：

> 有 4 名工人，但整份任务被装订成一本不能拆开的文件，只能交给其中 1 个人从头算到尾。

所以你虽然有 4 核许可，当前 Monitoring 仍主要显示一个 `sm_circuit` 计算任务，平均需要约 **785 μs**，而允许时间只有 **100 μs**。

---

## 二、ARTEMiS 到底是什么

当前模型中的逆变器、线路、电网、变压器等共同构成一个电气网络。普通情况下，Simulink Specialized Power Systems 会把它转换成一个大型状态空间计算问题，由 CPU 逐步求解。

**ARTEMiS** 的作用是把这种电力系统模型改造成更适合实时仿真的计算形式。

它主要处理：

- 开关状态发生变化时怎样更新电气方程
- 电感、电容等动态元件怎样离散化
- 电气网络矩阵怎样求解
- 不同电气计算组怎样协调
- 怎样利用多核 CPU

ARTEMiS 通常**不负责**：

- AGC 如何分配功率
- PLL 如何控制
- PWM 如何生成
- Modbus 如何通信
- V3.2 状态机如何判断

所以它优化的是"同一个电气模型在 CPU 里怎么算"，而不是改变你的控制目标。

### ARTEMiS 与 RT-LAB / SSN 的关系

```
RT-LAB：负责整个实时模型运行
    ↓
ARTEMiS：负责优化电气网络怎么计算
    ↓
SSN：ARTEMiS 中的网络分组求解方法
    ↓
多个 CPU 核：同时计算不同 SSN 组
```

你当前打开的 **ARTEMiS GUIde** 就是这套求解方法的总设置模块。现在先保持截图中的默认参数，不要自行调整求解器或迭代次数。

---

## 三、SSN 到底是什么

SSN 全称 **State-Space Nodal（状态空间节点法）**。

现在的模型相当于：

```
PV + ESS + EV + 母线 + 电网
→ 组成一个很大的计算题
→ 一个 CPU 核顺序计算
```

加入 SSN Interface Block 后，可以形成：

```
PV 电气组
ESS 电气组
EV 电气组
公共电网组
```

这些组通过 SSN 节点保持电气连接，然后由 ARTEMiS 统一求解。

**SSN Interface Block** 不是实际电阻、电感或断路器，而是一个**计算分界面**。它代表 SSN 节点，用于连接不同状态空间计算组。

最终目的不是改变电路，而是：

```
同一个电路
→ 换一种分组求解方式
→ 尝试让多个 CPU 核同时计算
```

### NIB 模块

NIB（Nodal Interface Block）不是普通的 Simulink 信号线，也不是把电压、电流通过 OpComm 传出去。它更像电气网络内部的**"计算连接点"**：

```
电气组 A
  ↓
NIB 节点
  ↓
电气组 B
```

- **SSN 关闭时**：NIB 相当于不改变系统的零电压 / 零电流接口，便于与普通 SPS 结果对比。
- **SSN 开启时**：它们才作为网络分组节点参与求解。

理想上可能分成：

| 组 | 内容 |
|----|------|
| 组 1 | PV 逆变器和 PV 滤波支路 |
| 组 2 | ESS 逆变器和 ESS 滤波支路 |
| 组 3 | EV 逆变器和 EV 滤波支路 |
| 组 4 | 公共母线、电网和负荷 |

> 注意：这只是方便理解的初步设想，最终分界不能随便放，要根据实际电气拓扑确定。

## 四、ARTEMiS GUIde 与 SSN Interface Block 的区别

### ARTEMiS GUIde

它是**全局设置模块**，作用类似"总控制台"：

- 选择求解器
- 设置固定步长
- 设置矩阵求解方式
- 设置迭代方式
- 检查 SSN 节点是否合法

一个模型一般**只需要一个**。

### SSN Interface Block

它是真正放进电气线路中的**分组接口**。例如三相系统使用 `SSN Interface Block (3ph)`。

可能的结构为：

```
PV 支路 ── 三相 SSN 接口 ── 公共母线
ESS 支路 ─ 三相 SSN 接口 ── 公共母线
EV 支路 ── 三相 SSN 接口 ── 公共母线
```

**一句话区分：**

> ARTEMiS GUIde 告诉软件"**怎样计算**"，SSN Interface Block 告诉软件"**在哪里分组**"。

---

## 五、分配 4 核是什么意思

模型有了多个 SSN 计算组后，才能在 RT-LAB 核分配页面给包含 SSN 网络的 `sm_circuit` 分配**多个核心**。

例如：

| CPU 核 | 计算内容 |
|--------|----------|
| 核 1 | PV 组 |
| 核 2 | ESS 组 |
| 核 3 | EV 组 |
| 核 4 | 母线和电网组 |

实际分配不一定严格一组对应一核，RT-LAB 和 SSN 会根据组计算安排并行执行。

所以**正确顺序**是：

```
先建立 SSN 分组
→ 再给 sm_circuit 分配多个核
```

而不是：

```
直接选择 4 核
→ 普通模型自动加速
```

官方文档明确说明：SSN 并行只有在对应子系统分配多个核心后才会启用；标准 SSN 组**不需要**拆成多个 `SS_` 子系统。
