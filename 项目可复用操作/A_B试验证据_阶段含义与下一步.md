# A/B试验证据、阶段含义与下一步

## 先给结论

**低频问题不是现在才发现的。现有两轮试验取得了新的排除和比较证据，但没有把某个控制模块的错误唯一锁定。上轮把“低阻尼”“时间尺度没有分开”“最后一次试验即可锁定”写得过于肯定，必须收回这些强结论。**

目前最可靠的事实是：A全功能配置的后期平缓没有维持到30秒；B中央积分增益设零后，主机记录仍显示大幅电压往复。因而不能继续沿着“只要删除中央无功偏置就解决”的方向改模。

但是，B上轮上传包尚没有B的五组原始记录或B计算结果，且关键偏置量没有在主机上取得。因此参数隔离证据和实际施加量隔离证据必须分开，不能声称两者都已全速率通过。

**当前不立即改模型结构、不提前改0.02/0.14、不先删低频支撑。先把已完成B的原始/计算结果补齐；需要进一步验证有功慢修正时，优先在B配置上只把该积分增益设零、仍正常进入阶段3，而不是先改变全局阶段号。**

这份文件纠正上轮《A/B 30秒根因锁定与下一版最终规划》中越过证据的结论；不否定其引用的实际A电压统计。

## 一、低阻尼、慢状态迁移和根因，分别指什么？

### 1. 已经观测到的现象

A在12～25秒较平缓，25～30秒重新出现大幅电压往复。A原速率计算表给出25～30秒约0.8824～1.2830标幺。这直接证明：**之前末段平缓不能外推成后续持续稳定。**[1]

B主机记录也有先较平缓、随后再出现较大变化的过程。这是B在约100毫秒主机监督分辨率上的观察，不能据此报B原速率的精确峰值或所有首发时刻。[2]

### 2. 对现象的一种解释

低阻尼，通俗说是偏离以后没有足够强、方向及时的作用把摆动消下去。慢状态迁移，是积分修正、功率分配等内部量仍在改变，电压暂时平缓不代表所有影响电压的工作状态都不再变化。

这些可以解释现象，但**不是看到波形就已经计算出阻尼或定位到内部某个状态。**

一段安静后再摆动，也可能受到限幅/死区状态变化、持续的工作点调整、已经存在的扰动等影响。仅靠输出形状，不能唯一地区分这些机制；本轮没有新测得特征值，也没有在B中重建全部内部状态。[1][2]

上轮将其直接称作已经锁定的“典型低阻尼再激发”，强度过高。现在应写成：

> 当前输出未持续收敛；低阻尼及慢状态作用是需要验证的机制解释。

### 3. 根因和连锁反应不是二选一

要落实到可修改的根因，至少需要说明：哪条路径、哪种状态/增益/符号/限制处理，在怎样的工作条件下造成了不合格响应，针对它的改变是否产生预期改善。

例如“先有电压变化，后来电流命令碰限”可以排除这次后发生的碰限是最早事件，但不能由此排除电流环的正常区动态、固定前馈或网络参数对整个闭环的作用。它们没有报故障也仍是对象的一部分。

因此，本轮仍需区分：最初激励、后续放大、最终饱和或恢复。**不能用某个环节没有报错来证明它永远与慢动态无关。**

## 二、历史上到底有没有发现？

**发现过。**

9月2日的《Mode7后第二层慢电压塌陷》已经区分快速前馈问题与慢电压问题，并列出低频支撑不足、功率外环和六机相互作用等候选。9月3日的N2/N3方案已提出把储能1、五台设备、网络与数字延迟放进同一个模型，用已有试验校准。9月4日版本4.6针对当时约0.25赫兹现象增加了低频无功阻尼，并保留了约1赫兹本地慢支撑。[3][4][5]

因此，不能把“一台储能与五台设备的低频交互”包装成本轮首次发现。它实际上仍是一个很大的系统范围，不是具体到可立即替换模块的定位结果。

### 之前修改有没有针对性？

已有局部修复具有各自依据：真实直流源、方向解释、执行限制反馈、交接等。它们的保留理由应分别来自接口审计和对应试验，不取决于最终整次是否通过。

但不能因为多个局部修复有理由，就把其组合在当前版本上的全部动态宣布正确。反过来，也不能因为当前仍波动，就断定历史每一项修复无效。

尤其版本4.8到4.9同时改了几个环节，且当前记录窗口更长。**两版的波形差别不能唯一归因于某一项修复，也不能确认当前慢摆动就是旧版同一个内部机制。**

当前可以确认的是：电流曾在异常后恢复正常跟踪，系统能完成真实离网；仍未完成的是在当前运行条件下持续维持合格输出。[1]

## 三、时间尺度重叠本身是不是确定的设计缺陷？

**不是。多个环节影响同一频段，并不自动等于冲突；设置不同截止频率，也不自动等于闭环已经分层稳定。**

上轮把0.18～0.35赫兹低频支路、1赫兹慢支撑和电压积分环列在一起，就把重叠说成已锁定的设计遗漏，推断过强。滤波器截止频率不是整条闭环的实测带宽；符号、增益、对象、延迟和工作点共同影响结果。

当前有证据支持的表述是：

> 没有在本轮材料中取得能够复现当前A/B行为、验证闭环稳定裕度、并预测某项候选修改效果的完整结果，因此不能凭历史参数表或频带名称直接选出最终修改。

这不等于宣布历史上从未做过模型分析。历史文件的确有相关计划和局部计算；需要的是它们能否解释和预测当前版本，而不是把以前的计划再次列一遍。[4][8]

**因此现在不默认删除低频支路，不默认把两条支撑合成一条，不默认改电压环，更不因为“更简单”就忽略以前消除过的振荡。**

## 四、阶段2和阶段3到底有什么区别？

这两个编号是现有运行流程中的控制阶段，不是又新增两项独立策略。

| 保留/投入的内容 | 阶段2：一次孤岛控制 | 阶段3：增加慢速恢复 |
|---|---|---|
| 储能1构网、电压/电流闭环 | 保留 | 保留 |
| 五台设备在线，原基础功率工作点 | 保留 | 保留 |
| 五台局部电压支撑、方向与限制处理 | 保留 | 保留 |
| 依据频率即时偏差形成的一次有功修正 | 保留 | 保留 |
| 把频率偏差逐渐积累成有功修正的慢积分 | 不积累，状态归零 | 按当前增益0.8工作 |
| 中央新增无功偏置 | 状态/请求为零 | A增益0.3；B增益0 |
| 原旧版公共电压恢复积分 | 当前配置关闭 | 当前配置关闭 |

中央协调器的继承代码明确分别计算一次修正和二次修正：阶段2只分配一次修正；阶段3分配一次修正加慢积分修正。阶段2使慢有功状态归零，阶段3按频率误差累加。当前A、B清单均读回有功二次增益0.8，旧公共电压恢复增益及上限仍为零。[2][6][7]

### B到底关了什么？

B仅关中央新增无功偏置积分，没有关闭依据频率误差调整五台功率的慢积分。

这在B设计时就是保留项，不是试验结束后突然新增。前面没有把两种慢恢复分清，导致“中央偏置已隔离”听起来像“全部二次控制已关闭”，这是解释不完整。

## 五、为什么电压问题还要看有功和频率？

### 1. 两个频率不是同一个量

- 约50赫兹：交流电网的运行频率。
- 约0.4～0.6赫兹：电压有效值等慢变量来回变化的速率，约1.7～2.5秒一轮。

后一项不表示电网从50赫兹掉到0.5赫兹，也不自动证明频率调节失效。上轮没有把这两个概念分开，是表达错误。

### 2. 有功慢恢复会实际改变设备电流

现有结构不是用频率偏差只画一条曲线，而是据此改变五台设备的有功指令。指令经各台功率环变成电流参考，再影响与储能1之间的功率分担和网络状态。[6][7]

本轮从A现有10毫秒表复核，二次有功总修正的均值约为：

| 离网后窗口 | 二次有功修正均值，标幺 |
|---|---:|
| 12～15秒 | -0.2967 |
| 15～20秒 | -0.3080 |
| 20～25秒 | -0.2451 |
| 25～30秒 | -0.1065 |

这证明它实际在改变工作点。**但变化不小仍不等于它变化错误，也不等于它就是起振源。**它可能是合理地响应前面的功率/频率变化，或与其他动态共同影响后续响应。

### 3. 电压环输出慢变同样不能直接叫积分饱和

比例积分控制器在误差尚未消除时继续调整，是正常行为的一种。现有表中记录的电压环总输出变化，不应直接称作内部积分状态异常。是否积累错误、是否被限制阻止兑现、是否迟滞过大，需要结合参考、实测和限幅证据判断。

## 六、为什么少了二次功能也可能稳定？

一次控制负责维持一个可运行状态，二次恢复用于逐渐减少一次控制留下的偏差、调整分担。它们不等同于有没有构网电源。[6][9]

所以取消某个慢积分，不等于把储能1构网电压、电流闭环关闭；系统有可能在带一定静差的状态下稳定。也可能因缺少有用的调节而偏差变大。

**诊断中必须分开看：摆动是否衰减、均值是否合适、设备是否仍在能力范围内。**

例如诊断配置中电压较低但很平，不能简单写成一次控制动态失败；若去掉慢积分以后设备进入功率极限，其波形也不能当成与原工作点等价的小信号稳定性比较。

B去掉无功慢积分没有稳定，并不能推出再隔离另一条仍在工作的慢积分一定也没有影响。这两次干预改变的是不同作用。

## 七、是否需要下一轮？怎样比上轮说法更严谨？

### 1. 上轮提出“阶段2保持30秒”的目的有意义，结论承诺没有依据

其目的：判断在没有慢速恢复积分的情况下，当前六机一次控制是否还出现相似的反复电压变化。

但它不能保证是最后一次试验。无论稳定或不稳定，都不能自动锁定某一组比例积分参数；工作点变化、能力限制和多个环节共同作用仍需要解释。

上轮“稳定就只改阶段3，不稳就重构低频支撑”的二选一太粗，应撤回。

### 2. 更小的实际干预：保持阶段3，只再关有功慢积分

**我建议下一轮使用B作为直接基线：保持同样的阶段3时序、同样的中央零偏置，只将现有有功二次积分增益从0.8改为0，并从零初值重新运行。**

| 配置 | 阶段3照常进入 | 中央无功积分增益 | 有功二次积分增益 |
|---|---|---:|---:|
| 已做A | 是 | 0.30 | 0.80 |
| 已做B | 是 | 0 | 0.80 |
| 建议的下一轮，尚未运行 | 是 | 0 | 0 |

这样B到下一轮只有一个新增的控制干预，不更换全局阶段编号，也不同时改变路由、阶段定时器或仅在阶段3计算的其他量。

可调入口是现有中央协调器的 `AA15_P_KI_F_SECONDARY（有功二次积分增益）`。不是把整个有功控制关掉：一次有功修正、五台基础功率环、构网下垂仍然保留。

这里恢复阶段3不是新的物理控制方案，只是让诊断干预更小。上轮“阶段2保持”表达的是验证目的，本轮把实现收窄到对应状态增益。

在生成可执行脚本前仍必须核验当前版本的该参数唯一作用路径、零初值及其他消费者，不能只套用旧版本函数就宣称完全等价。[6][7]

### 3. 结果只解释到实际能支持的范围

| 与B比较的结果 | 允许的判断 | 不允许的判断 |
|---|---|---|
| 反复摆动显著减少，设备可持续工作 | 有功慢恢复闭环或其造成的工作点迁移，对B的摆动具有重要作用；优先检查这条作用链 | 功率积分器算法本身一定错；只需延迟投入即可根治 |
| 相似摆动仍存在 | 两种中央慢恢复都不是该摆动出现的必要条件；集中核对现行一次控制、前馈/固定状态、网络共同响应 | 一定是低频阻尼支路错；直接删除该支路；0.02/0.14必然错 |
| 动态变平但均值偏离 | 稳定性与恢复精度出现取舍；保留这一诊断价值 | 缺功能配置直接作为正式通过 |
| 出现新的能力耗尽/保护变化 | 本次干预改变了可行工作状态，比较必须限于相同拓扑及有效能力区间 | 把其全部后期差异归为纯动态增益效应 |

这轮值得做，是因为它能影响下一步先检查哪条作用链，**不是因为我已提前认定有功有错。**

## 八、A/B取得了什么新结论？哪些尚未取得？

### 已取得

1. A本工况15秒平缓不能当成后续持续收敛，延长至30秒已经实测出现再度大摆动。
2. B在中央积分增益为零的配置下仍有大幅电压变化，不能把永久删除中央偏置作为现成解决方案。
3. A/B预开断参数差异只有已指定的中央增益，开断前工作点及主机早期响应接近。
4. A/B都保留有功慢积分；A记录表明它对长期功率工作点有实际作用。

### 尚未取得

1. 当前B五台实际新增偏置全速率始终为零的完整核验。
2. 某个内环或支撑支路为当前全部振荡唯一根因的证明。
3. 当前振荡等同历史同一模态的证明。
4. 仅更改投入时刻、某个滤波频率或某组增益就一定能通过的参数方案。
5. 原末段平缓平台是某个稳定平衡点的证明。

## 九、我们现在究竟改不改模型？

**现在不提交结构补丁，不先改增益。**

确定保留已证实修复：真实直流源、实际电压方向、完整执行限制反馈、现有交接和全部六台设备。0.02/0.14继续作为当前对照基线，不凭低频波形否定其历史高频改善。

之后的设计必须落到具体链条：

- 若证据指向有功慢恢复，核对频率输入、积分更新、实际功率分配、各台参考和实测、储能1分担；正确实现但响应过慢/耦合过强时，才依据对象调整参数。不能看到慢积分就直接加死区或把增益缩十倍。
- 若无两种中央慢恢复仍摆动，就核对电压误差、各支撑参考、最终电流和实测响应，包含固定前馈工作点及数字延迟。保留已有快速修复，不因一次关闭试验就直接删除历史低频支撑。
- 对任何拟改参数，在当前工作点附近和较晚工作点验证趋势，随后回到原全功能工况验证。不能只让一个短窗口好看。

现有物理模型是验证对象；若使用简化/线性模型选择参数，必须先检查它能否复现当前可观测响应。没有验证的模型参数预测不能冒称已解决。这是历史已有要求，不是另起一个无限扩张的任务。[4][8]

### 不能提前冻结的两种修法

**“延后进入阶段3”**：可能改善切换暂态，但当前25秒后还会再起振，仅延后可能只是把问题推迟；不能预先保证。

**“把低频支撑合成一个模块”**：可以作为候选简化，但模块数量少不等于稳定。没有明确动态证据时不能删除历史有作用的支路。

## 十、怎样才算该项策略正常实现？

用户要求的是15项策略之一正常运行，不是每次切换都理想无扰，也不是现在证明全部未来工况。

本轮沿用已讨论的宽松末段电压/频率范围作观察；暂态允许有有限变化，但不能把后期反复大摆动称为单次切换过程。阶段性通过至少需要真实断开、设备模式正确、持续供电、变化能衰减并保持、实际执行不过度持续受限。
