## 1. Layer-2 Patch 连续维度失败必须交接

V1.0：真实模型编译时 `AA15_L2_IREF_CORE/icandidate` 维度欠定。

V1.1：Scratch 编译时 `VFF/AA15_VFF_CORE/v_mode7` 维度欠定。

根因不是 MATLAB Function 被禁用，而是：

```text
CompiledPortWidth=2
不等于
vector shape 已唯一确定
```

最终修复原则：

```text
新 dq/IdIq MATLAB Function
→ Demux成scalar d/q
→ scalar-only Function
→ Mux回width2
```

并且 Layer-2 不再重写已经正式运行验证过的 Mode7 Shaper，而是在 trusted Mode7 后追加 wrapper。
