# 设置固定回调

## 一、用命令固定 InitFcn 并保存

执行：

```matlab
mdl = bdroot(gcs);

set_param(mdl, 'InitFcn', sprintf([ ...
    'Ts = 1e-4;\n' ...
    'Vgrid_line = 10000;\n' ...
]));

save_system(mdl);

disp(get_param(mdl,'InitFcn'));
```

应显示：

```text
Ts = 1e-4;
Vgrid_line = 10000;
```

`InitFcn` 会在模型编译初始化时执行，适合定义这类模型参数。

然后：

```text
关闭模型
→ 重新打开原始SLX
→ Ctrl+D
```

再执行：

```matlab
Ts
Vgrid_line
```

应分别得到：

```text
1.0e-4
10000
```

---

## 二、若重新打开后仍然消失

说明旧模型或RT-LAB工程有其他回调在覆盖 `InitFcn`。这时不要继续与回调覆盖机制冲突，直接将 `Vgrid_line` 固定在模型工作区：

```matlab
mdl = bdroot(gcs);
mw = get_param(mdl,'ModelWorkspace');

assignin(mw,'Vgrid_line',10000);

if strcmpi(mw.DataSource,'Model File')
    save_system(mdl);
else
    saveToSource(mw);
end
```

模型工作区变量会随模型或其指定数据源加载，并优先供本模型内模块解析。

验证：

```matlab
mw = get_param(bdroot(gcs),'ModelWorkspace');
evalin(mw,'Vgrid_line')
```

应返回：

```text
10000
```

---

**优先先执行第 2 步**（`InitFcn` 方案）。若仍被清除，再使用第 3 步的模型工作区方案。
