# 8.6 拆分模型波形不符发现问题

## 结论

**应当统一修改。**

本项目的任务是把老师搭建的旧单核模型拆分到多个实时子系统，原则上只改变计算分区，不应改变：

* 一次电气拓扑；
* PCC测量边界；
* 线路连接关系；
* PCC功率正负方向；
* 原有负荷相对于PCC的位置。

因此，**K5当前的负荷位置和六设备并联拓扑都应恢复为旧模型的结构**。旧模型没有证据表明搭建错误；相反，旧模型已经得到稳定且符合命令的结果，应作为基准。

我前面说"K5当前边界可能更接近最终PCC定义"，这个判断不应作为本次改模依据，应撤回。当前目标不是重新设计微电网，而是忠实拆分旧模型。

---

## 一、为什么两边Load都画在测量块右侧，测量边界却不同

关键不在图形上的"左、右"，而在于：

> **测量块两端分别接了哪些电气节点。**

### 旧模型 `shiyansan`

实际电气关系是：

```text
六台设备侧网络
        │
        ▼
PCC V-I Measurement
        │
        ├── Load1
        ├── Load2
        ├── Variable load
        ├── PCC断路器
        └── 公共电网
```

展开为：

```text
设备公共母线
→ PCC测量块
→ Load1、Load2、动态负荷、断路器、电网
```

因此，旧模型中：

* 六台设备位于PCC测量块一侧；
* Load1、Load2和电网位于另一侧；
* PCC测量值不包含Load1、Load2；
* PCC主要反映六台设备向外部网络交换的功率。

这正是为什么：

```text
PV1、PV2、ESS1、ESS2 = 0
EV1、EV2 = -0.6 pu
```

旧模型测得：

```text
PCC ≈ -120 kW
```

两台EV各充电约60 kW，结果完全对应。

---

### 当前K5

实际电气关系是：

```text
公共电网
→ 电网阻抗
→ PCC断路器
→ PCC V-I Measurement
→ Load1、Load2和六台设备公共母线
```

即：

```text
电网侧
→ PCC测量块
→ Load1、Load2、六台设备
```

因此，当前K5的PCC测量包含：

```text
Load1 约600 kW
+ Load2 约300 kW
+ 两台EV约120 kW
+ 损耗
```

所以得到约1 MW是可以解释的。

---

### 为什么视觉上都在右侧

两个模型的电网方向正好相反：

#### 旧模型

```text
设备在左
PCC测量在中
Load和电网在右
```

#### K5

```text
电网和断路器在左
PCC测量在中
Load和设备在右
```

所以Load虽然都画在测量块右边，但：

* 旧模型中，Load与电网同侧；
* K5中，Load与设备同侧。

这就是测量边界不同的原因。

## 二、旧模型的PCC边界是不是正确的

对于所有微电网，并不存在唯一绝对正确的PCC负荷边界，取决于Load1、Load2被定义成：

* 微电网内部负荷；
* 还是外部配电网负荷。

但是对于**当前项目和老师的基准模型**，旧模型的定义就是正确基准，因为：

1. 老师的标准模型采用该边界；
2. 原来的PCC波形稳定；
3. 原AGC工况和目标值均建立在该PCC定义上；
4. 以前的通信异常试验、AGC结果和约`-40 kW`目标也都使用该信号；
5. 当前任务是分核，不是改变微电网边界定义。

因此应继续沿用旧模型的PCC边界：

```text
设备侧
→ PCC测量
→ Load1、Load2、断路器、电网
```

还要保持PCC测量块的端口方向一致，否则即使边界位置一致，P、Q正负号也可能反过来。

## 三、旧模型六台设备的准确拓扑

你说：

> PV1没有支路，剩下五台都接了支路。

这个判断总体正确。

但ESS1和EV1不是各自独立并联的一条支路，而是共用一条径向链。

旧模型的准确结构是：

```text
                         ┌── PV1（直接连接，无线路）
                         │
                         ├── Line_PV2 ── PV2
                         │
设备公共母线 ────────────┼── Line_ESS2 ─ ESS2
                         │
                         ├── Line_EV2 ── EV2
                         │
                         └── Branch1 ── 节点A
                                          ├── ESS1
                                          │
                                          └── Branch2 ── EV1
```

也就是说：

### PV1

```text
公共母线 → PV1
```

没有线路块。

### ESS1与EV1

```text
公共母线
→ Branch1
→ ESS1接入节点
→ Branch2
→ EV1
```

ESS1位于第一段线路末端，EV1位于第二段线路末端。

### 另外三台

```text
公共母线 → Line_PV2  → PV2
公共母线 → Line_ESS2 → ESS2
公共母线 → Line_EV2  → EV2
```

因此旧模型共有五个线路块：

```text
Branch1
Branch2
Line_PV2
Line_ESS2
Line_EV2
```

而不是六台设备各自一条并联线路。

## 四、K5当前拓扑具体哪里不同

K5当前是六条完全并联的馈线：

```text
公共母线 → Line_EV2   → EV2
公共母线 → Line_EV1   → ESS1
公共母线 → Line_EV2_3 → PV1
公共母线 → D4_Line    → EV1
公共母线 → E5_Line    → ESS2
公共母线 → F6_Line    → PV2
```

同时Load1和Load2也挂在这个公共设备母线上。

这与旧模型有三项实质区别：

1. PV1在旧模型中直接接母线，K5中经过了`Line_EV2_3`；
2. ESS1和EV1在旧模型中是串联径向结构，K5中变成两条独立并联支路；
3. Load1、Load2在旧模型中位于PCC外侧，K5中位于PCC内侧。

这些都会改变：

* PCC有功；
* PCC无功；
* 各设备端电压；
* 线路压降；
* 控制器之间的耦合；
* 系统阻尼和动态波形。

所以不能只修改PCC信号的Gain来解决，必须恢复一次拓扑。

## 五、K5应该恢复成什么结构

当前的变压器、Stubline和三个SS不需要推翻。主要修改SM中的10 kV高压侧连接。

### 目标结构

```text
设备公共母线
│
├── prim_PV1                 直接连接
│
├── F6_Line ── prim_PV2
│
├── E5_Line ── prim_ESS2
│
├── Line_EV2 ─ prim_EV2
│
└── Line_EV1 ─ 节点A
                 ├── prim_ESS1
                 └── D4_Line ── prim_EV1
```

可以直接复用K5已有线路块，因为我核对过这些线路的R、L参数与旧模型五条线路一致。

具体对应关系可以定为：

| 旧模型线路     | K5保留使用          |
| --------- | --------------- |
| Line_PV2  | F6_Line         |
| Line_ESS2 | E5_Line         |
| Line_EV2  | Line_EV2        |
| Branch1   | Line_EV1        |
| Branch2   | D4_Line         |
| PV1直连     | 旁路或删除Line_EV2_3 |

`Line_EV2_3`不再作为PV1支路使用。

## 六、Load和PCC应恢复成什么结构

目标是：

```text
设备公共母线
→ PCC V-I Measurement
→ Load1、Load2、PCC断路器
→ 电网阻抗
→ 公共电网
```

旧模型还有一个`Variable load`，它也位于Load1、Load2同一侧。

当前稳态试验中动态负荷输入可能为0，因此它暂时不影响`-120 kW`结果；但为了完整恢复旧模型，后续也应恢复。

Load参数本身目前已经一致：

```text
Load1：
P = 200e3 × 3 = 600 kW
Q = 100 kvar

Load2：
P = 100e3 × 3 = 300 kW
Q = 0
```

本次不修改数值，只修改接入节点。

---

## 七、PCC测量块还要保持方向一致

旧模型中：

```text
PCC测量块左侧电气端口 → 设备母线
PCC测量块右侧电气端口 → Load和电网
```

K5当前正好相反：

```text
左侧端口 → 断路器和电网
右侧端口 → Load和设备
```

因此，恢复时不能只把Load挪过去，还要把`Three-Phase V-I Measurement3`的方向同步恢复。

否则可能出现：

```text
旧模型PCC = -120 kW
K5恢复后PCC = +120 kW
```

物理边界相同，但功率方向相反。

最稳妥的目标是直接保持旧模型的端口关系：

```text
lconn：设备公共母线
rconn：Load1、Load2、断路器、电网
```

---

## 八、修改顺序

不要一次同时改所有问题。

第一步只处理：

```text
PCC测量方向
Load1、Load2接入位置
```

建立副本：

```text
K5_DIAG_01_PCC_BOUNDARY
```

目标变为：

```text
设备和六条当前支路
→ PCC测量
→ Load1、Load2、断路器和电网
```

暂时不改六设备馈线结构。

这一步成功Build后，PCC均值应从"约1 MW总电网输入功率"转变为"主要反映六台设备净交换功率"。随后再进行第二步，将六条并联支路恢复成旧模型的五段线路拓扑。
