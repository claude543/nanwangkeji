4\. 正式写入点表：

40001 / offset0 Ppv1_pu INT16 0.0001 pu/count

40002 / offset1 Ppv2_pu INT16 0.0001 pu/count

40003 / offset2 Pess1_pu INT16 0.0001 pu/count

40004 / offset3 Pess2_pu INT16 0.0001 pu/count

40005 / offset4 Pev1_pu INT16 0.0001 pu/count

40006 / offset5 Pev2_pu INT16 0.0001 pu/count

40007 / offset6 agc_status INT16 1/count

40008 / offset7 dP INT16 0.1 kW/count

40009 / offset8 remain UINT16 0.1 kW/count

5\. 符号和范围约定：

PV：正值表示发电，范围 0～1 pu

ESS：正值表示放电，负值表示充电，范围 -1～1 pu

EV：负值表示充电，0 表示停止充电，范围 -1～0 pu

PCC_P：正值表示从大电网购电，负值表示向大电网反送

dP：dP = P_target - P_PCC

remain：始终为非负值

agc_status 需要支持：-2、-1、0、1、2

8.数据转换规则

读取时：读取16位raw→ 根据点表解释为INT16或UINT16→ 乘缩放系数→ 得到工程量

写入时：测试工程量→ 合法范围限幅→ 除以缩放系数→ 四舍五入→ 转为INT16或UINT16→ 写入寄存器

输出限幅要求：

Ppv1/Ppv2：0～1 pu

Pess1/Pess2：-1～1 pu

Pev1/Pev2：-1～0 pu

agc_status：-2～2

remain：不得小于0
