## 2.2 工程推理原则

冻结如下：

### 原则A：结构事实 > 名称猜测

不能因为模块叫 `Power Control Loop` 就推测某一路一定是 P/Q；
必须看：
- 精确端口；
- 精确连线；
- 参数；
- 运行数据。

### 原则B：模型静态结构、RT-LAB编译结果、运行数据是三层证据

```text
Simulink里存在参数
≠ RT-LAB Build一定在线暴露这个参数
```

今天 C1 第一次 Python 被拦截就是这个教训。

### 原则C：一次只改一个关键变量

A0/P0成功的根本原因是：

```text
A0：P OFF / Q OFF
P0：只增加 P ON，Q仍OFF
```

所以能做因果判断。

禁止下一步一次同时：
- 改 Kp；
- 改 Ki；
- 改 PLL；
- 改 P filter；
- 改 support。

### 原则D：正式试验每轮 fresh Reset → Load

不能：

```text
A0跑完
→ 在线改参数
→ 接着当P0
```

因为积分器、母线、电气状态都已经改变。

正式 A/B 必须：

```text
Reset
→ Load once
→ t≈0 PAUSED
→ t=0写本轮全部参数并readback
→ Execute
```

### 原则E：第一次 Execute 后正式 Runner 不再改控制参数

这不是“RT-LAB不能在线调参数”，而是**正式因果试验纪律**。

### 原则F：普通电气波动是证据，不应被 Runner 过早判失败

在 BASETEST 正式诊断中：
- V；
- f；
- I；
- P；
- CurrentLimit；
- ModHeadroom；
等普通电气量应记录，不应把诊断试验本身挡掉。

真正立即停止的是：
- NaN/Inf；
- 配置合同错误；
- 结构非法；
- 禁止的控制接管；
- 模型状态机明确结构失败；
等。

### 原则G：状态45 = 计划观察结束，不等于电气PASS

不要再把：
```text

```
解释成：

### 原则H：MAT 后处理错误不等于需要重跑 RT-LAB

### 为什么必须在共同分配前清零

错误做法：

```text
最后 FinalIref - support
```

不成立，因为：
- support 和 base current 已经共同限幅；
- 可能互相抵消；
- 限幅后相减不能还原原始基础电流；
- 甚至可能产生超限残量。

正确做法：

```text
support request
↓
BASETEST selector
↓
0
↓
原共同分配/限幅
```

这样：
- 必要 base current 算法保持；
- limit保持；
- 后台 raw support 仍可计算、记录；
- 但实际允许 support = 0。

这后来由 MAT 直接验证：
- Raw support 可以非零；
- Allowed support / TotalSupport / Envelope = 0。

## 6.4 P/Q 外环开关怎么实现

不改 PI 本体。

```text

Q error × RestoreAlpha → Q PI
```

```text
P effective alpha = RestoreAlpha × P_LOOP_ENABLE_EFF
Q effective alpha = RestoreAlpha × Q_LOOP_ENABLE_EFF
```

```text

```

所以：
- P off = P PI输入误差被门控；
- Q off = Q PI输入误差被门控；
- 原PI结构/状态/限值没被重写。

# 12. 为什么说“负阻尼”，物理上是什么

在强网里通常近似：

```text
Id改变
→ 主要改变ESS2自身P
→ 母线V/f/θ基本不动
```

但当前孤岛：

```text
ESS1是唯一GFM
ESS2是GFL
```

真实闭环是：

```text
Pmeas摆动
↓
P error = Pref - Pmeas
↓
P PI生成d轴电流参考
↓
ESS2电流变化
↓
孤岛功率平衡改变
↓
ESS1 GFM改变母线V/f/θ
↓
ESS2 PLL重新跟踪
↓
dq坐标和Pmeas再次改变
↓
P PI继续动作
```

A0证明这个孤岛本身存在约0.7~1 Hz自然慢摆，但会衰减。

P0证明加入P外环后，每轮控制动作的增益/相位关系使控制器在这个频段反而向振荡补能量，于是：
- 电压摆幅增大；
- P摆幅增大；
- PLL频率摆幅增大；
- 实际电流摆幅也增大。

这就是这里说的 `negative damping（负阻尼）`。
