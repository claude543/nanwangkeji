## 3.1 LFQ固定q轴注入问题

旧做法：

```text
LFQ scalar
→ 固定q轴
```

但实际电压方向会转动。

正确二维无功方向：

```text
u = [ud, uq]
n = [-uq, ud]
```

LFQ必须沿：

```text
n
```

形成二维电流请求。

最终改法：

```text
FinalLimit增加lfq_req输入
↓
在当前udn/uqn基础上
damp_d_total = dampd_req + n1*lfq_req
damp_q_total = dampq_req + n2*lfq_req
```

五台均修。

## 3.2 fixed-d role preclip问题

旧 `StateCore` 在固定d轴提前：

```text

→ dd=min/max(...)
```

这在电压坐标转动时不是物理有功方向。

补丁删除固定d轴预裁剪，角色约束留到下游沿真实电压方向的 limiter 中。

# 13. 五台接回前是否需要ΔV/Δf/Δθ重同步

和 J1 重同步不同。

J1两侧：

```text

+
上级电网电压源
```

是两个独立电压源，所以必须同期。

五台非主设备：

```text
ESS2/PV1/PV2/EV1/EV2
```

都应维持 GFL，不是第二个独立电压源。

因此不需要完全照搬：

```text
ΔV + Δf + Δθ
```

的电源同期合闸。

但必须做：

```text
母线V/f健康
+
设备保持GFL
+
PLL ready / 电压测量有效
```
