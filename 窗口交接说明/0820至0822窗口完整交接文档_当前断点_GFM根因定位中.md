# 0. 后续窗口先读这一页：五条最高优先级结论

1. **不要重新推翻整个项目结构。**  
   六逆变器、1SM+3SS、100 μs、Modbus、V5 板端 AGC、LOCAL15→BOARD15 的总体路线仍然成立。当前只是暴露了 GFM/孤岛物理执行链的模型问题。

   原先 S13 的确接错到了参考区域的 `Three-Phase Breaker`，但现在已改为真实 `J1_PCC_Breaker`，并在其执行边界加入了 100 μs `Z^-1`。Rebuild All 已成功，S5 已通过真实 J1 离网验证。

3. **不要再把当前塌压简单归因于“一台 ESS 功率不够”。**  
   已经把离网前 PCC 有功交换调到接近 0 kW，J1 打开后仍在几十毫秒内从约 10 kV 塌到低电压，因此原始 `-100 kW` 工况过重不是首因。

4. **不要再把 55–65 Hz 限幅当作唯一根因。**

5. **当前下一步不是再改 S5/S13/S15 状态机，而是看 ESS1 GFM 内部信号。**  
   最新真解耦试验已做到：ESS1 先进入 GFM 5 s、真实 J1 保持闭合，PCC 仍稳定约 10 kV；5 s 后才打开 J1，电压立即崩塌。这说明问题发生在 **失去强电网支撑以后 GFM 自身不能建立/维持孤岛电压**。


# 28. 当前 GFL/GFM 结构必须记住的技术事实

Control System 中：

```text
GridOn = 1
→ GFL
→ PLL + Power Control Loop
→ IdIq_refF
→ Current Regulator
→ PWM

GridOn = 0
→ GFM
→ Droop
→ Voltage Regulators
→ IdIq_ref
→ Current Regulator
→ PWM
```

`Droop_On`：

```text
只控制Droop P/Q下垂是否参与
≠
GFL/GFM模式开关
```

`GridOn` 才是真正模式选择。

Supervisor：

```text
二次频率/电压恢复
↓
Fref / Vref
```

GFM 电压环由：

```text
Droop Vout
+ measured Vdq
↓
Voltage Regulators
↓
IdIq_ref
```

构成。

当前 GFM `Vref Generation` 使用：

```text
Vnom_dc
```

而不是明确的真实 DC 测量，这是一个模型局限，但目前还不是已经证明的首因。
