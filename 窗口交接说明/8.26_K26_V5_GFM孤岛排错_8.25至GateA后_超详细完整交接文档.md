# 1. 当前最强的根因位置：Voltage Regulator dq轴映射

对最新模型重新沿线审计，当前最强、最具体的结构错误指向：

# `ESS1_Control/Voltage Regulators` 的两个Voltage PI输出到 `Id/Iq_ref` 的dq映射。

当前Voltage Regulators输入：

```text
Vq
Vq_ref
On
Vd
Vd_ref
```

内部实际关系：

```text
PI1 input:
Vq_ref - Vq

PI2 input:
Vd - Vd_ref
```

然后当前Mux：

```text
Mux input1 = PI1
Mux input2 = PI2
```

输出名：

```text
IdIq_ref
```

Current Regulator后级又明确把：

```text
input vector output1
当作Id_ref

output2
当作Iq_ref
```

所以当前实际控制律是：

```text
Id_ref = PIq(Vq_ref - Vq)

Iq_ref = PId(Vd - Vd_ref)
```

但在当前已经被MAT验证的q轴电压定向下，direct-axis Voltage Loop的PI correction应该是：

```text
Id correction
由Vd误差产生

Iq correction
由Vq误差产生
```

定义当前两个PI raw输出：

```text
u1 = PI(Vq_ref - Vq)

u2 = PI(Vd - Vd_ref)
```

当前：

```text
legacy vector = [u1, u2]
```

更合理的direct-axis mapping应为：

```text
corrected PI vector = [-u2, +u1]
```

也就是：

# 交换dq通道，并把原d误差PI输出翻转符号。

这不是“继续猜Kp/Ki”，而是控制向量的基本坐标映射问题。

# 2. 为什么这个dq mapping判断有物理依据，不只是看名字猜

B2已经非常强地验证了当前local capacitor的dq物理关系。

当前ESS1 C1：

```text
Bc≈0.05 pu
```

在q-axis voltage orientation下，稳态capacitor synchronous current：

```text
iC_sync,d = -Bc * Vq

iC_sync,q = +Bc * Vd
```

B2中F8 CAP项设置：

```text
[-0.05*Vq, +0.05*Vd]
```

MAT中：

```text
F8 final - Voltage PI raw
```

与理论CAP项达到数值精度一致。

所以：

```text
当前dq方向
当前Vd/Vq定义
当前capacitor current符号
```

已经不是猜测。

这也说明Voltage Regulator输出若要成为正常direct-axis current reference correction，应按：

```text
Id ← d-axis voltage error
Iq ← q-axis voltage error
```

而当前却是交叉映射。
