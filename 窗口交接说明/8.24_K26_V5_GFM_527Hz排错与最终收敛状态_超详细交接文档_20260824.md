# 0. 新窗口必须先读的结论

截至 2026-08-24 当前轮测试结束，问题已经从最初的“孤岛后 500+ Hz 不明高频振荡”收敛到两个层次，而且必须严格区分：

## 0.1 原始 527 Hz 高频自激问题

**已经得到非常强的解决证据，但尚未在完全健康、无饱和的最终孤岛工况下做最后封板验证。**

当前最强证据：

- 最新正确 local frame、Voltage PI 改为 `Kp_V=0.02, Ki_V=0.14` 后：
  - `515–535 Hz` 频带 RMS 从上一轮约 `7.72 kV` 降至约 `0.226 kV`；
  - 降幅约 `97.1%`；
  - `300–700 Hz` 总高频 RMS 从约 `10.39 kV` 降至约 `1.43 kV`；
  - 降幅约 `86.2%`；
  - `45–55 Hz` 基波频带重新成为绝对主导，约 `11.99 kV RMS`。
- 旧失稳模态的典型特征是：
  - J1 断开后从约 `300–400 Hz` 开始；
  - 随时间演化 `456 → 474 → 494 → 506 → 514 → 522 Hz`；
  - 最终逼近理论 `527.4 Hz`。
- 最新测试中没有再出现这种“持续向 527 Hz 漂移并增长”的行为。
- 最新剩余明显高频峰约为 `550 Hz` 与 `650 Hz`，分别几乎严格等于 `11×Fout` 与 `13×Fout`，属于控制器/调制长期饱和下的整数次谐波，不应再解释成原 527 Hz LC 自激。

因此当前应冻结：

> **“Voltage outer loop 带宽过高导致 LC 模态附近负阻尼”是原 527 Hz 问题的主因，这一判断已经被数学分析和最新 MAT 强烈验证。**

---

## 0.2 整个孤岛 GFM 是否已经最终 PASS

**没有。**

最新测试仍有：

- PCC 电压约 `12.16 kV RMS`，而目标约 `10 kV`；
- `ModIndex = 1` 大量/长期饱和；
- `Vd_conv / Vq_conv` 大量触顶；
- `Id_ref` 大面积限幅；
- 说明系统进入了另一个错误的非线性工作点。

但这个剩余问题已经不再是“未知高频不稳定”，而是非常具体：

> **GFL → GFM 切换时，Voltage PI 的内部积分状态没有 reset / bumpless initialization，导致新的低带宽 Voltage PI 带着 GFL 阶段积累的错误历史状态进入 GFM。**

这是当前**唯一明确暴露、且与最新失败现象完整对应的剩余主阻碍**。

---

## 0.3 能否说“只剩最后一个问题，而且一次能解决”

必须严谨表述：

### 可以高置信度确认的：

1. **当前最新 31 s 工况中，唯一明确暴露的主阻碍已经收敛到 Voltage PI 的 GFL→GFM 状态切换管理。**
2. 这个问题不是推测：
   - 模型结构上明确存在；
   - PI 有 external reset，但顶层 `Vreg_on` 长期为 1；
   - GFL 与 GFM 使用不同 feedback frame；
   - 最新 MAT 中 20–25 s 的 Id/Iq_ref 轨迹与“旧积分状态缓慢释放”完全一致。
3. 这比此前 527 Hz 问题更容易结构性修复：
   - 不需要重新推翻 local vC / iL；
   - 不需要改 30°；
   - 不需要重新扫 Current PI；
   - 不需要继续试裸 `iC` AD；
   - 核心是正确处理 Voltage PI 的 enable/reset/初始化时序。
4. 因此**有较大把握通过一次设计完善的结构 Patch 解决当前剩余主阻碍**。

### 不能绝对承诺的：

不能在还没跑过“状态切换修复后的健康 31 s”之前说：

> “整个六机孤岛系统绝对不存在任何二级问题。”

原因是当前最新测试后半段已经进入饱和，饱和会掩盖一些次级动态。  
正确工程结论应为：

> **当前主问题链已经高度收敛，只剩一个明确的模式切换状态管理问题；对此可以有很大把握一次性设计正确。修复后先用同一 31 s 工况确认无过压、无长期饱和、无 527 Hz 增长，再进入 66 s 最终验收。**

# 5. 527 Hz 理论来源

ESS1 L1：

```text
R = 0.003456 Ω
L = 0.000916732472209 H
```

在 50 Hz / 100 kVA / 480 V 基准下：

```text
Rpu ≈ 0.0015
X_L1,50 ≈ 0.125 pu
```

C1：

```text
480 V
50 Hz
P ≈ 100 W
Qc ≈ 5000 var
```

约：

```text
C ≈ 69.1 μF
B_C ≈ 0.05 pu
```

Transformer：

```text
约0.03 pu leakage
```

Differential Stubline：

```text
约0.03 pu leakage
```

换算到同一基准，线路很小，总等效：

```text
X_L,total ≈ 0.17976 pu
B_C ≈ 0.05 pu
```

理想 LC 模态：

```text
f_r ≈ 50 / sqrt(X_L,total * B_C)
    ≈ 527.4 Hz
```

因此：

> 527 Hz 是真实电气网络的自然模态，不是虚假的 PLL 频率、采样别名或绘图伪影。

真正需要解决的是：

```text
为什么孤岛后这个物理模态获得了负阻尼/不足阻尼
```

而不是“如何删除这个自然频率”。

# 43. 当前结论的最终版本

## 原527 Hz

> 物理 LC 网络确实存在约527.4 Hz自然模态。此前local GFM的Voltage outer loop仍沿用Kp=2、Ki=14，对Cpu≈0.05 pu的本地电容Plant等效要求约2 kHz外环带宽，远高于约118 Hz的Current inner loop；在800 Hz测量滤波和100 μs执行延时共同作用下，实际Voltage-loop unity crossover落到约470 Hz dq，恰与实测dq≈470–473 Hz、abc≈520–527 Hz重合，形成负阻尼。将Voltage PI按20 Hz目标降至0.02/0.14以后，515–535 Hz能量下降约97.1%，原持续向527 Hz爬升的模态不再出现，强烈证明这一根因判断正确。

## 当前唯一明确剩余主阻碍

> Voltage PI在GFL阶段一直处于active状态，而GFL和GFM使用不同的fast-feedback frame；进入GFM时没有reset或bumpless initialization。原Ki=14能够较快冲掉错误历史状态，新Ki=0.14则不能，因此25 s开J1时Id/Iq_ref仍严重偏离正确GFM强网工作点，随后将Current Regulator、Vd/Vq_conv和ModIndex推入饱和，形成约12.16 kV过压和11/13次谐波。

## 对“一次性解决”的置信度

> 当前证据已经足够支持把下一次结构修改集中在Voltage PI状态切换管理，而不是继续大范围排错。对“当前暴露的剩余问题”有较高把握可以一次性设计正确；但在修复后31 s健康工况真正跑通之前，不应做“系统绝对再无任何次级问题”的100%承诺。
