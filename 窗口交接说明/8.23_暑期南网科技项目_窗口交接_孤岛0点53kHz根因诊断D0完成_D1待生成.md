# 13. 当前几个频率的唯一正确解释

这部分新窗口必须严格使用，避免重新混淆。

| 数字 | 正确含义 | 是否正常 |
|---|---|---|
| **50 Hz** | 微网正常三相基波 | 应该存在 |
| **55 Hz** | 严重畸变后PLL/外部测频撞上限的表现 | 异常症状，不是根因 |
| **约527.4 Hz** | ESS1相关LC/网络理论自然模态 | 这个数学模态存在本身可以正常 |
| **约530～532 Hz** | abc真实三相电压实测快速失稳模态 | 不正常 |
| **约480～482 Hz** | 同一530 Hz正序型模态进入50 Hz同步dq坐标后的表现 | 不正常，不是第二个故障 |
| **500 Hz** | 正式V/I/P/Q测量二阶低通 `fn_Filter` | 正常设计参数，但目前高度可疑 |
| **4 kHz** | PWM开关频率 | 正常参数，目前次级候选 |

# 15. 527、530、480、500之间的逻辑

正确链：

```text
LC/网络数学上存在
约527 Hz自然模态
↓
J1打开后模态失去阻尼
↓
abc实际振成约530 Hz
↓
控制器使用约50 Hz同步dq
↓
同一正序模态在dq里约：
530 - 50
≈ 480 Hz
↓
而正式反馈低通：
fn_Filter = 500 Hz
```

所以真正值得怀疑的是：

```text
dq异常模态 ≈480 Hz
```

恰好落在：

```text
500 Hz低通滤波器
```

的强动态区域。

> **系统本来存在约527 Hz的LC/网络自然模态；并网时强网把它压住，J1打开以后ESS1独立构网时，这个模态没有获得足够阻尼，于是实际在约530 Hz持续振起来。现在又有证据表明逆变桥交流端也参与这个振荡，因此问题是GFM控制—PWM—Converter—LC—网络之间的闭环稳定性，而不是PCC或某一个测量块单独坏了。**

---

# 83. 用户对500 Hz滤波器的默认解释

简化：

> **500 Hz不是另一个振荡，而是控制器低通滤波器参数。530 Hz异常进入50 Hz dq坐标后大约变成480 Hz，因此这个480 Hz模态刚好处在500 Hz滤波器很敏感的频段。滤波器可能造成很大相位滞后，使本来应该“刹车”的控制器反应太晚，从而降低阻尼。但目前还没有证明它就是唯一根因，D1就是要直接测滤波前后。**
