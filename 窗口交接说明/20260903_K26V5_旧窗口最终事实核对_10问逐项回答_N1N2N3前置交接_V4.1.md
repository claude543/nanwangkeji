# 10. ESS1 GFM 内部 dq：历史上是 q-axis voltage orientation

ESS1 Voltage Regulator 原型历史结构：

```text
Vd_ref = 0
Vq_ref ≈ 1 pu
```

其物理分析长期使用：

```text
Vd ≈ 0
Vq ≈ V*
```

例如 capacitor synchronous current：

```text
iC_d = -Bc * Vq
iC_q = +Bc * Vd
```

F9 期间正是基于这个 q-axis voltage orientation 修正 Voltage PI 到 Id/Iq_ref 的映射。

因此：

> **不能把 ESS1 内部 GFM `theta_out` 直接假设成与五台 GFL `theta_PLL` 完全同零相位定义。**

# 52. 条件积分逻辑

当 PI 未试图越界，或误差方向有利于从饱和区退回时：

```text
Switch
→ Ki * error
→ integrator继续积分
```

当：

```text
PI 已到 / 超过 UpperLimit
AND
error 仍为正
```

或者：

```text
PI 已到 / 低于 LowerLimit
AND
error 仍为负
```

则逻辑：

```text
Logical AND
→ Logical OR
→ Switch控制
```

让：

```text
integrator input = 0
```

也就是：

> **conditional integration / integrator clamping 类型 anti-windup。**

同时：

```text
Discrete-Time Integrator
LimitOutput = on
```

最终输出再有：

```text
Saturation2
```
