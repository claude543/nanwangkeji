## 5.1 基础AGC方向逻辑

```text

```

若：

```text
dP > 0
```

```text

→ ESS放电

```

若：

```text

```

资源调用顺序：

```text
EV增加充电
→ ESS充电
→ PV降低
```

同类两台资源本来就按当前剩余余量比例分配。

# 28. isolated的准确含义

非常重要：

```text
isolated = 1
```

不是：

```text
打开断路器
PWM停机
物理切除设备
```

而是：

> **监督层/调度层隔离：该资源本次运行不再具有AGC协调调节资格。**

最终：

```text
isolated_i = 1
↓
trust_i = 0
↓
eff_i = 0
↓
AGC不再给该资源分配新的调节任务
```

设备物理上仍然接在微电网中，并可能继续执行其异常功率。

# 29. V0.3为什么必须有latch？

如果只写：

```text
state=3 → trust=0
```

后续state边缘变化可能让设备自动重新加入。

当前V5前本地阶段不能可靠定义：

```text
重新加入条件
```

所以：

```text
isolate_latch(i)=true
```

后，本次运行一直保持。

只有：

```text
enable=0
或模型重启
```

才清除。

资源重新加入留给V5真实语义后设计。
