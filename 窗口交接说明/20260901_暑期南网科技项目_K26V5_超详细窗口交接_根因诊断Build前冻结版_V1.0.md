```text

↓
```

F21 用于：

```text

```

当前结论：

> F21 已完成它应承担的第一层状态转移问题。普通六机失稳不能无证据重新归罪 F21。

# 4.2 F22——为什么 J1 边沿要处理 Voltage PI

```text

```


# 4.3 旧 F20 / F20V2——为什么输出电流前馈成为关键

ESS1 Voltage Loop 最终 current reference 不是单纯 Voltage PI。

F8 控制结构：

```text
Voltage PI
+
effective IOUT contribution
+
CAP compensation
↓
final Id/Iq_ref
↓
±1.25 pu saturation
↓
Current Regulator
```

其中 `IOUT contribution` 的物理意义非常重要：

```text
并网时：
上级电网承担部分瞬时输出电流责任

J1 OPEN：
这部分责任不能继续来自 Grid
↓
ESS1 必须快速接手
```

旧 Legacy F20：

```text
某时刻 capture raw IOUT
↓
固定 hold
```

问题是：

```text
pre-island old IOUT
≠
post-island ESS1 真正需要承担的 IOUT
```

因此 J1 后 stale IOUT 会导致 ESS1 current reference responsibility 缺口。

# 4.4 为什么不能改成 continuous raw IOUT

历史已经试过：

```text
continuous raw IOUT → Iref
```

虽然能提供快速支撑，但长期会改变 GFM 动态输出阻抗，并出现约：

```text
~3.4 Hz negative damping
```

所以最终不能用：

```text
永远 raw tracking
```

必须是：

```text
短时 FAST bridge
+
稳定后退出
```

这就是 F25 的设计原理。

---

# 4.5 F23——为什么不是最终第一毫秒方案

F23 使用：

```text
20 ms local mean/std/drift
```

对 quasi-steady working point 有价值。

但：

```text
J1 后 0~20 ms
```

正是第一层 responsibility transfer 最关键的时间。

所以：

> 20 ms estimator 可以负责“最终工作点候选”，不能负责“J1 第一拍快速接管”。

这就是为什么 F25 同时需要：

```text
FAST path
+
post estimator / candidate / commit
```

# 4.6 F24 V3.1——为什么要独立处理 F/V reference handover

切岛不只是电流状态变化，还有：

```text
Frequency reference
Voltage reference
```

并网阶段如果直接在瞬时值上取 target：

```text
PLL / voltage instantaneous ripple
→ READY 条件抖动
→ target本身不稳定
```

所以 F24 V3.1 改成 quasi-steady estimator：

```text
local windows
↓
mean
↓
two-window stability
↓
candidate
↓
PREALIGN / READY
↓
J1 edge HOLD
```

F24 的正式责任：

```text
在 planned islanding 前准备 F/V reference
J1 edge 后 HOLD 正确 reference
```

当前 F24 V3.1 已成熟。

重要：

```text
F24 RELEASE OFF
```

当前根因诊断阶段不允许随意启用 RELEASE。

# 5.2 FAST 为什么必须快

默认：

```text
alpha = 0.10
slew  = 0.005 pu / 100 μs
mag   = 0.60 pu
```

历史责任差约：

```text
~0.18 pu
```

理论 slew 时间：

```text
0.18 / 0.005 = 36 samples
≈ 3.6 ms
```

所以 FAST 不是为了 100 ms 后才工作，而是：

```text
J1 第一拍立即开始
3~5 ms 尺度接手责任
```

```text
→ bus
→ IOUT
```

```text

↓
candidate成熟
↓
退出FAST
↓
hold
```

# 11. PCC 测量语义——新窗口必须知道

PCC 正式测点位于：

```text

```

不是 Grid-side measurement。

`Freq_Hz`：

```text

```

变量名：

```text

```

实际上不是 broadband True RMS，而是：

```text
raw PCC Vabc
→ Va-Vb
→ Fundamental (PLL-Driven)
→ magnitude × 1/sqrt(2)
```

即：

> **PCC fundamental Vab RMS**

所以深度塌压时 PCC PLL frequency 可靠性下降。

高速模态分析优先：

```text

ESS1 Droop Fout/theta
Group29
```

```text

```

只证明：


不代表孤岛内部功率平衡健康。
