# K26_V5｜N1 编译态审计后最终重构启动与总体设计 V1.0

> 日期：2026-09-03  
> 当前基线：最新 V2 模型 + V1/V2 正式运行数据 + V4.0/V4.1 交接 + N1 编译态只读审计  
> 本文用途：冻结“为什么现在可以进入架构级重构、当前模型缺陷在哪里、最终六机应该怎样运行、重构后怎样验证和继续定位”。

---

# 0. 结论

K26_V5 已经走到**可以开始架构级重构**的阶段。

这里的“开始重构”分成两层：

1. **现在立即开始最终结构设计、接口设计、参数建模和改模脚本设计。**
2. **在关键参数稳定域和设备能力边界没有核清前，不直接对正式模型执行最终改模。**

当前已经锁定的不是一个孤立参数错误，而是：

```text
五台跟网逆变器仍按强电网下的高刚度功率跟踪方式运行
+
离岛后只有 ESS1 提供有限带宽、有限输出阻抗的构网电压
+
快速端口电压直接前馈削弱了系统自然阻尼
+
低频层又缺少完整的频率响应、功率平衡和限流反馈
```

V2 已经证明：把快速和慢速端口电压前馈、功率误差动态全部强行关闭，也不能自动形成正确孤岛。这说明 V2 第二阶段是有效诊断状态，不是最终控制器。

因此下一版不是继续修改一个 `Kslow`（慢电压前馈比例），而是重构整个“一台构网主机 + 五台跟网从机”的孤岛控制职责。

# 2. 当前模型已经确认的主要结构缺陷

## 2.1 五台设备虽然有角色参数，但角色参数没有参与控制

五台管理模块都包含：

```text
AA15_P_ROLE
（设备角色参数）
```

当前数值：

```text
PV1/PV2：1
ESS2：2
EV1/EV2：3
```

但是 V2 改模脚本把该参数直接接到：

```text
AA15_ROLE_TERM
（终止模块）
```

也就是说，当前五台实际执行的控制律完全相同，差别主要只有电压支撑电流上限。

这与最终要求不符：

```text
PV：
发电资源，欠频时是否能增发取决于可用余量，过频时可以削减发电。

ESS2：
双向储能，是五台中最适合承担快速双向有功支撑的设备。

EV：
当前只按可调充电负荷设计，欠频时减少充电，不能默认反向放电。
```

下一版必须让角色参数真正进入有功频率响应、功率上下限和电流优先级。

---

## 2.2 当前第二阶段是“诊断隔离”，不是最终孤岛状态

当前五台管理模块的实际阶段逻辑：

```text
阶段0：
原并网控制完全旁路

阶段1：
慢电压前馈目标 = 0
快速电压前馈目标 = 0
原有功/无功误差动态 = 0

阶段2：
慢电压前馈 = 参数 Kslow_stab
快速电压前馈 = 参数 Kfast_island
原有功/无功误差动态仍然 = 0

阶段3：
满足本机健康条件后
才逐步恢复原有功/无功误差动态

阶段4：
逐步恢复原并网控制
```

V2 正式试验中：

```text
Kslow_stab = 0
Kfast_island = 0
阶段3没有进入
```

因此本轮只是验证极端隔离条件，不是完整岛态控制。

下一版必须取消“阶段2长期冻结主要功能”的设计，改为：

```text
J1 打开第一拍：
维持孤岛所需的一次控制全部有效

J1 打开后较短时间：
岛态慢速功率协调逐步进入
```

---

## 2.3 当前没有真正的岛态有功频率响应

当前五台管理模块没有输入 ESS1 构网频率，也没有按频率偏差改变有功目标。

所以 J1 打开以后：

```text
ESS1 承担瞬时功率不平衡
但五台设备不会因为频率下降或升高而主动改变净有功
```

这不是完整的一主五从孤岛。

下一版必须新增：

\[
P_{i,\mathrm{ref}}^{\mathrm{isl}}
=
P_{i,0}
+
\Delta P_{f,i}
+
\Delta P_{\mathrm{sec},i}
\]

其中：

- \(P_{i,0}\)：切岛前捕获的本机有功工作点；
- \(\Delta P_{f,i}\)：本机根据 ESS1 构网频率产生的快速有功响应；
- \(\Delta P_{\mathrm{sec},i}\)：主任务中的岛态慢速协调修正。

---

## 2.4 当前“恢复功率”仍是恢复原并网功率目标

当前阶段3只是在本机健康后把：

```text
Pref_eff = Pmeas + g(Pref - Pmeas)
```

中的 \(g\) 从 0 恢复到 1。

这意味着它最终恢复的是原来的有功/无功命令，不是新设计的岛态调度目标。

下一版应取消这种“恢复原功率误差”的中心地位，直接形成岛态有功目标：

```text
切岛工作点
+
频率一次响应
+
岛态慢速协调
```

原 PCC（公共连接点）功率协调在 J1 打开后退出；其资源余量、SOC（荷电状态）和斜率限制思想可以复用，但控制误差必须改为岛内频率和 ESS1 长期功率负担。

---

## 2.5 当前电压支撑只有统一 q 轴电流通道

当前五台都使用：

```text
本机端口电压幅值误差
→ 一阶滤波
→ q轴电流支撑
```

该结构可以保留为基础，但仍存在三项不足：

1. 五台使用相同控制律，仅支撑上限不同；
2. 支撑参考只是在切岛时冻结本机电压，没有跟随 ESS1 构网电压目标；
3. 当前限流始终让电压支撑优先，再同比缩小原有功/无功电流，不区分 PV、ESS2、EV 的资源职责。

下一版应形成：

```text
ESS1 全局电压目标
+
每台切岛前本地线路压降偏置
→ 每台自己的本地电压参考
```

并按资源类型确定电流优先级。

---

## 2.6 当前总电流限制没有反馈给上层功率积分器

当前链路：

```text
原功率控制器
→ 原始电流参考
→ 五台管理模块
→ 总电流矢量限制
→ 最终电流参考
→ 电流调节器
```

原功率控制器只知道自己内部是否饱和，不知道下游总电流限制是否削小了指令。

当前 V2 本轮总电流限制没有动作，所以这不是本轮首发原因；但在最终全功能控制中，一旦频率支撑、电压支撑和慢速调度同时要求电流，就必须增加：

```text
总电流限制结果
→ 上层有功/无功控制器
→ 暂停继续向饱和方向积分，或进行反算修正
```

---

## 2.7 当前五台阶段由五个常数分别写入

目前每台都有：

```text
AA15_ENG_STAGE
（本机工程阶段常数）
```

由 Host（上位机）分别写入。

最终应改成一个主任务内的统一系统状态：

```text
SM_Master 中央状态机
→ 一个统一阶段信号
→ 分发给 PV组、ESS组、EV组
```

本机只保留健康状态和是否可参与，不自行决定整个系统何时恢复功率。

---

## 2.8 当前没有把 ESS1 构网频率和电压真正用于五台控制

N1 审计确认，ESS1 的：

```text
Fout
（构网频率）

Vout
（构网电压目标）
```

已经存在于 ESS1 的 26 维诊断尾部，并通过现有 30 维 ESS 返回向量进入 SM_Master：

```text
SS_Slave2/ESS1_Control
→ AA15_D1_FAST_DIAG_MUX18
→ SS_Slave2/Mux
→ ESS_Pmeas_vec2_to_SM
→ SM_Master/Demux1
→ AA15_D1_FAST_DEMUX18
```

按当前排列：

```text
AA15_D1_FAST_DEMUX18 第17路：Fout
AA15_D1_FAST_DEMUX18 第18路：Vout
```

因此：

```text
ESS1 → SM_Master
无需扩大现有30维返回向量
```

五台设备原有 12 维输入中已经包含：

```text
Fref
Vref
Pref
Qref
GridOn
```

所以可以复用现有 Fref、Vref、Pref、Qref 通道，把主机频率、电压目标和岛态功率命令送到五台。

当前只需要额外增加一个明确的组级系统阶段信号：

```text
PV组：24 → 25
ESS组：24 → 25
EV组：24 → 25
```

每组新增 1 个阶段标量，由组内两台设备共用。

# 3. 第一版最终重构是否使用 ESS1 公共相角

结论：

```text
第一版最终重构暂不把五台全部切换到 ESS1 公共相角。
```

原因：

1. 五台跟网坐标已确认是 `Vd≈1 pu、Vq≈0`；
2. ESS1 构网电压环历史上是 q 轴电压定向；
3. ESS1 自身还存在 F4 的 -120° 同步补偿和 Vref Generation 的 -30° 执行相位补偿；
4. 当前没有完成每台设备从 ESS1 构网角到本机测量点、PWM 执行点的精确固定偏置证明；
5. B1 已经证明本地 PLL（锁相环）不是原始快速失稳的必要根因。

因此第一版最稳妥的处理是：

```text
五台继续使用本机执行锁相坐标
+
保留 AA15_PLL_EXEC_FRAME_HOLD
（低压时的本机坐标保持）
+
使用 ESS1 Fout 作为五台有功频率响应的公共频率
```

这样直接处理已经锁定的端口和功率控制问题，不额外引入一个尚未证明的坐标改造。

公共相角作为后续可选增强项；只有在新一次控制已经稳定、数据仍明确显示五个本地锁相坐标造成问题时，再做精确偏置审计和公共相角切换。

# 4. 最终六机控制架构

## 4.1 ESS1：唯一构网主机

ESS1 继续负责：

```text
形成电压
形成频率
形成相角
承担切岛瞬间的剩余有功/无功不平衡
```

第一版不改：

```text
F21
F24
F25
ESS1现有构网电压环、电流环和下垂主参数
```

但要把其：

```text
Fout
Vout
Pmeas
Qmeas
```

送入主任务，供五台一次控制和岛态慢速协调使用。

---

## 4.2 PV1/PV2：跟网型发电从机

孤岛有功行为：

```text
过频：
允许削减发电

欠频：
只有存在已证明的可用功率余量时，才允许增加发电
否则向上调节能力按0处理
```

孤岛电压行为：

```text
在总电流允许时提供无功/电压支撑
若电流达到上限，可削减有功，释放电流能力
```

---

## 4.3 ESS2：最主要的双向支撑从机

孤岛有功行为：

```text
欠频：
增加放电或减少充电

过频：
减少放电或增加充电
```

ESS2 是五台中优先承担快速双向有功支撑和慢速功率转移的资源。

其动作必须受：

```text
SOC
有功上下限
总电流限制
充放电斜率
```

约束。

---

## 4.4 EV1/EV2：可调充电负荷

当前控制合同只支持：

```text
-1 pu：最大充电
0：停止充电
```

不按 V2G（车辆向电网反向放电）设计。

孤岛行为：

```text
欠频或明显欠压：
减少充电，等价于减轻岛内负荷

过频或功率过剩：
在允许范围内增加充电
```

# 6. 两频带电压前馈的最终处理

保留结构：

\[
V_{\mathrm{ff}}
=
V_{\mathrm{anchor}}
+
K_{\mathrm{slow}}(V_{\mathrm{slow}}-V_{\mathrm{anchor}})
+
K_{\mathrm{fast}}(V_{\mathrm{raw}}-V_{\mathrm{slow}})
\]

当前可以冻结：

```text
Kfast：
第一版保持0
因为10～17 Hz快速必要路径已经由历史因果试验锁定
```

暂不能冻结：

```text
Kslow
分界频率
```

这两个参数必须在完整一次控制中，与：

```text
电流环
本地电压支撑
ESS2有功频率响应
EV减充电响应
ESS1输出阻抗
```

一起计算稳定区域。

下一版准备阶段应直接把 Kslow 平滑到最终值，不再使用：

```text
先降到0
J1打开后再恢复
```

的 V2 逻辑。

# 7. 主任务中的岛态慢速协调

原 PCC AGC（公共连接点自动功率协调）在 J1 打开后退出，因为 PCC 已断开。

新的岛态协调使用：

```text
ESS1构网频率偏差
+
ESS1长期承担的有功偏差
+
五台设备上调/下调余量
```

形成总慢速修正，再分配给五台。

建议总误差结构：

\[
e_f=f_{\mathrm{nom}}-f_{\mathrm{ESS1}}
\]

\[
e_P=P_{\mathrm{ESS1}}-P_{\mathrm{ESS1,bias}}
\]

协调器输出：

\[
\Delta P_{\mathrm{sec,total}}
=
C_f(s)e_f + C_P(s)e_P
\]

再依据各资源实际余量分配。

该协调不把 ESS1 当普通分配对象；ESS1继续承担瞬时剩余量，协调器逐步让其回到合理储备附近。

岛态协调进入条件不是“孤岛已经稳定”，而是：

```text
J1已经确认打开
ESS1构网频率和功率信号有效
完成短暂切换隔离时间
没有数值错误
```

之后从0缓慢爬升。

# 8. 中央状态机

建议在：

```text
K26_V5/SM_Master/AA15_LOCAL_CONTROL_STACK
```

新增统一状态管理器。

状态建议：

```text
0 正常并网
1 计划离岛准备
2 孤岛一次控制
3 孤岛一次+慢速协调
4 重同步
5 合闸保持
6 并网控制恢复
```

它与已有：

```text
AA15_S15_Recovery_Manager
AA15_S15_Master_Fref_Router
```

配合，不重复实现重同步。

五台本机只根据统一状态执行，并根据本机健康状态决定“可用/不可用”，不再自行决定系统阶段。

# 9. 通信和端口设计

## 9.1 ESS1 到主任务

不扩大当前 30 维返回向量。

直接复用：

```text
SM_Master/AA15_D1_FAST_DEMUX18/17
→ ESS1 Fout

SM_Master/AA15_D1_FAST_DEMUX18/18
→ ESS1 Vout
```

P_ESS1、P_ESS2 已经是 Demux1 的前两路。

如果未来需要 ESS1 相角，再在现有 26 维诊断尾部中重新分配两路为：

```text
sin(theta_ESS1)
cos(theta_ESS1)
```

不直接传原始角度，避免0/2π跳变。

第一版不使用公共相角，所以暂不改。

## 9.2 主任务到五台

继续复用每台12维输入中的：

```text

Vref：
孤岛时传 ESS1 构网电压目标

Pref：
传并网功率命令，或岛态基础+慢速协调命令

Qref：
传并网无功命令，或岛态无功基准
```

每个设备组增加1个组级状态：

```text
PV_Group：24→25
ESS_Group：24→25
EV_Group：24→25
```

# 11. 模块删除策略

不在第一次最终功能补丁中同时大规模删除历史模块。

原因：

```text
功能重构
与
历史清理
同时进行
会让失败后难以判断是新控制错误还是误删旧依赖
```

第一次补丁：

```text
替换五台V2管理模块
替换五个独立阶段常数
新增中央状态机
新增岛态慢速协调
新增通信和诊断
保留F21/F24/F25/S15
```

完整功能验证成功后，再做独立清理补丁，删除：

```text
已彻底失去连接的C1/C2/Mode7/Layer2诊断块
不再使用的旧显示和示波器
被新中央状态机替代的阶段常数
已证明无下游消费者的旧估计支路
```

F20/F22/F23 等 ESS1 历史模块不能仅凭“当前参数关闭”就删除，必须先做目的端口依赖审计。

# 12. 最终运行应达到什么效果

下面是首轮验收建议，不等同于甲方正式指标。

## J1 打开前

```text
ESS1已完成跟网→构网准备
PCC有功接近0
五台已进入最终孤岛参数
控制切换不明显扰动强网
```

## J1后0～0.2秒

目标：

```text
电压保持约0.90～1.10 pu
频率保持约49～51 Hz
无10～17 Hz正增长共同振荡
五台电流参考和实测电流有界
电流PI不出现同步单向漂移
```

## J1后0.2～1秒

目标：

```text
一次有功频率响应方向正确
EV欠频时减少充电
ESS2欠频时增加净出力
PV按可用余量行动
电压支撑不与有功响应争夺失控
```

## J1后1～5秒

目标：

```text
慢速协调使频率接近50 Hz
ESS1长期有功负担逐步回到偏置附近
五台功率按能力分担
总电流和调制度有余量
无慢电压塌陷和过压反复
```

## 重同步

保留当前基础门槛：

```text
电压差 ≤ 0.10 pu
频率差 ≤ 0.20 Hz
相角差 ≤ 10°
持续0.50秒
```

更优目标可以设为：

```text
电压差 ≤ 0.05 pu
频率差 ≤ 0.10 Hz
相角差 ≤ 5°
```

J1合闸后保持 ESS1 构网一段时间，再无扰恢复并网控制和 PCC AGC。

# 13. 如果完整功能运行仍失败，怎样继续

不会重新回到“从头一个块一个块乱试”。

最终控制器必须预留运行时诊断开关，默认全部功能开启；失败后只在同一 Build 中做有限、明确的验证。

## 失败发生在离岛准备阶段

优先检查：

```text
中央阶段路由
P0/Vanchor捕获
ESS1 F24/F25准备
参数平滑过程
```

## J1后0～0.1秒出现快速振荡

优先检查：

```text
快速电压前馈实际贡献
电流环
Vconv
端口输出导纳
数字延迟
```

## 0.1～1秒慢漂，但慢速协调尚未明显动作

优先检查：

```text
Kslow和分界频率
本地电压支撑
一次有功频率响应
ESS1输出阻抗
```

## 慢速协调进入后才失稳

直接检查：

```text
岛态协调总增益
五台分配方向
积分器
饱和和余量计算
```

## 总电流限制动作后才失稳

检查：

```text
电流优先级
上层抗积分饱和
电压支撑和有功响应争用
```

## 只在重同步/合闸时失稳

检查：

```text
S15同步量
ESS1频率修正
相角差
J1合闸后保持
并网控制重新接管
```

因此完整运行失败仍然可以形成清晰分支，不会回到原始根因树。

必要的单项验证仍可能存在，但它是：

```text
在完整最终架构内
根据失败阶段做的定向A/B
```

不是重新搭建旧的诊断森林。
