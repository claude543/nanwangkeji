# ESS2 A0结果：根因能否锁定、问题本质与可解决性

# 0. 结论先行

当前已经可以**高置信度锁定问题所在的控制层**：

> **ESS2真实物理并回 + Current Adapter（电流参考执行适配器）+ Current Regulator（电流控制器）本身，不会复现此前那种不断增长的慢振荡。**
>
> **此前失稳所必须新增的因素，是 P/Q Power Loop（有功/无功功率外环）这一层。**

但现在还不能严谨地说：

> “100%就是P有功外环”
>
> 或
>
> “100%就是Kp=0.06、Ki=2中的某一个参数”。

原因非常简单：

- 原失稳试验：P外环 = ON，Q外环 = ON；
- A0：P外环 = OFF，Q外环 = OFF；
- 两者之间同时改变了 P 和 Q 两条外环。

所以当前已经锁定到：

```text
P/Q功率外环层
```

下一轮 `P0` 只打开 P 有功外环、保持 Q 外环关闭，就可以完成最后一次分离。

# 3. A0仍然有0.75Hz左右的摆动，这是不是说明电流环还是有问题？

不是这个结论。

A0 state6后：

```text
Vpu / Pmeas / Qmeas / PLL
主导描述性频率约 0.749 Hz
```

说明这个ESS1-GFM + ESS2-GFL孤岛本身存在一个自然的低频摆动节奏。

但关键区别在于：

```text
A0：
这个摆动在衰减

原P/Q外环开启：
这个摆动在增长
```

所以真正的问题不是：

> “0.8Hz摆动本身存在。”

而是：

> **P/Q功率外环加入以后，把原本有正阻尼、会自己衰减的低频摆动，变成了负阻尼、会越来越大的摆动。**

“正阻尼”可以理解为：

```text
每摆一轮
→ 能量少一点
→ 振幅越来越小
```

“负阻尼”可以理解为：

```text
每摆一轮
→ 控制器又补进去一点能量
→ 振幅越来越大
```

A0和原试验已经构成非常强的对照。

# 5. 当前真正的问题是什么

现在最合理的物理解释已经非常明确。

孤岛本身：

```text
ESS1 GFM（构网型）
+
ESS2 GFL（跟网型）
+
真实网络
```

存在一个大约：

```text
0.7~0.9 Hz
```

的低频自然摆动。

当ESS2功率外环不参与时：

```text
母线发生一点扰动
↓
ESS2真实电流跟着产生暂态
↓
ESS1继续构网
↓
振荡能量逐渐耗散
↓
振幅越来越小
```

A0的数据就是这个状态。

而原正式试验打开功率外环以后：

```text
P/Q测量发生摆动
↓
功率外环根据误差生成新的Id/Iq参考
↓
ESS2主动改变电流
↓
电流又改变弱孤岛母线
↓
母线变化再进入PLL和P/Q测量
↓
功率外环再次动作
```

在当前参数和弱孤岛对象下，这一整圈的动作时序/相位不合适。

结果是：

```text
原本应该压振荡
↓
实际上每周期又给振荡补了一点能量
↓
低频摆动越来越大
```

所以当前根因层可以表述为：

> **ESS2的P/Q功率外环与ESS1构网弱孤岛之间存在低频负阻尼交互。**

这比“ESS2不能并网”精确得多。

也比“电流环坏了”更符合A0证据。

# 6. 能不能直接说就是P有功外环？

目前：

> **P有功外环是第一嫌疑，但还差P0最后一刀。**

为什么第一嫌疑是P？

原正式试验中：

```text
PIntegral不再为0
并且与Vpu/Pmeas一起慢速来回摆
```

而：

```text
QIntegral = 0
```

这说明P链参与程度明显更高。

但是：

> `QIntegral=0` 并不代表整个Q外环完全没有作用。

如果Q外环中：

```text
比例项 Kp × Qerror
```

仍然存在，它仍可能实时产生Iq参考。

另外弱网里P/Q并非绝对解耦。

所以：

```text
原试验：P ON + Q ON → 增长
A0：     P OFF + Q OFF → 衰减
```

只能严格证明：

```text
问题在P/Q功率外环层
```

还不能严格证明：

```text
只在P外环
```

# 7. 下一轮P0为什么现在非常关键

P0保持：

```text
P有功外环 = ON
Q无功外环 = OFF
Pref实际 = 0
```

其它和A0完全一样。

那么只有一个关键新增因素：

```text
P有功外环
```

如果出现：

```text
A0：
0.8Hz摆动逐渐衰减

P0：
同一个0.8Hz摆动重新逐渐放大
```

那么我们就可以正式冻结：

> **决定性不稳定来源就是ESS2 P有功功率外环。**

这是目前距离“唯一根因”最近的一轮。

---

# 8. 如果P0确认，是否就一定是Kp/Ki？

不是。

确认“P有功外环是决定性因素”之后，还需要区分P外环内部的机制。

可能包括：

1. **Kp（比例增益）/ Ki（积分增益）与弱孤岛不匹配**  
   这是当前最高概率候选之一。

2. **功率测量到控制作用的相位关系不合适**  
   即控制器看到误差后动作太快/太慢，在0.8Hz附近形成负阻尼。

3. **PLL（锁相环）与P有功外环耦合**  
   ESS2注入电流改变母线相角，PLL重新估算相角，再改变P计算和控制动作。

4. **P→Id转换/限幅/动态结构**  
   需要继续看P外环输出如何转成d轴电流参考。

当前并没有证据支持简单说：

```text
“Ki=2就是错”
```

所以不能直接盲调。

# 9. 如果P0确认P外环，下一步怎么继续拆

建议顺序：

```text
P0确认P外环导致增长
↓
C1：Ki=0，只保留P比例项
```

如果：

```text
Ki=0后稳定
```

说明积分作用是关键负阻尼来源。

然后：

```text
固定合理Kp
↓
Ki从0逐级恢复
↓
寻找稳定范围
```

如果：

```text
Ki=0仍不稳定
```

再查：

```text
Kp
↓
P测量动态
↓
PLL / 弱网耦合
```

而不是一次同时改很多参数。

# 10. 这个问题能不能解决

**从目前A0结果看，是可解决的，而且现在比之前更乐观。**

原因是：

> **去掉功率外环以后，底层物理系统不是持续发散，而是表现出衰减。**

这意味着我们面对的不像：

- 物理网络拓扑根本错误；
- ESS1 GFM完全撑不住；
- ESS2电流环方向错误；
- 并回本身必然不稳定；
- 调制器一接管就崩溃。

而更像：

> **一个上层闭环参数/动态匹配问题。**

这种问题通常可以通过：

- 降低功率外环带宽；
- 重配Kp/Ki；
- 改善P外环与PLL时间尺度关系；
- 必要时增加弱网模式下的增益调度/阻尼设计；
- 最后再恢复额外support；

解决。

但正确顺序仍然应该是：

```text
先P0确认唯一分支
↓
再拆比例/积分
↓
再调参数
```

不要现在直接改PI。

# 11. 当前冻结结论

A0以后可以正式冻结：

> **ESS2可以真实物理并回；在P/Q功率外环关闭、直接dq电流参考为0时，Current Adapter、电流内环、PLL和真实弱孤岛仍存在约0.75Hz低频摆动，但其电压、功率、频率和电流振幅总体随时间衰减。与此前P/Q功率外环开启时同一频段振荡快速增长形成鲜明对照。因此当前根因已经高置信度锁定在ESS2 P/Q功率外环与ESS1构网弱孤岛的低频负阻尼交互，而不是物理并回或电流执行链自身。P有功外环是首要嫌疑，但还需P0（P开、Q关、Pref=0）完成最后的P/Q分离。若P0复现增长，即可进一步冻结P有功外环，再通过Ki=0的比例-only试验等逐层确定具体参数/机制。该问题从A0证据看具备明确的可修复性。**
