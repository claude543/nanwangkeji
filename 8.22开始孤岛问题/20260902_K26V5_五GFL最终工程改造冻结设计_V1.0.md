# 2. 一个重要修正：当前模型的同步坐标不是“默认d轴对电压”

直接审查当前厂家 `Voltage Regulators` 得到：

```text
输入：
Vq
Vq_ref = Vout
Vd
Vd_ref = 0

误差：
e1 = Vq_ref - Vq
e2 = Vd - Vd_ref

输出Mux：
Id_ref = PI1(e1)
Iq_ref = PI2(e2)
```

因此在当前模型实际坐标约定中：

```text
正常同步时：
Vq 是主要电压幅值轴
Vd 应接近0
```

这与很多教科书常用的：

```text
Vd≈1
Vq≈0
```

不同。

所以最终工程控制禁止硬编码“d轴是电压轴”。

# 5. 最终 VFF 处理

原始问题：

```text
Current Regulator:
Vconv ≈ CurrentPI + Vterminal + Rff/Lff

Plant:
L di/dt ≈ Vconv - Vterminal - Ri
```

原始 `+Vterminal` 使端口电压作用被大幅抵消。

Mode7只做：

```text
fast变化削弱
slow/DC最终仍回到gain≈1
```

已经证明不够。

最终改为**锚定的增量前馈**：

\[
V_{ff}=V_{anchor}+K_{vff}\left(V_{raw}-V_{anchor}\right)
\]

物理意义：

```text
K_vff = 1：
原厂家完全电压前馈

K_vff = 0：
端口电压动态完全不再直接送入Vconv；
Current PI承担所需静态偏置

0 < K_vff < 1：
只保留一部分端口电压解耦
恢复一部分端口自然导纳/阻尼
```

## 5.1 无扰切换

GRID_NORMAL：

```text
Vanchor每采样跟随Vraw
Vff = Vraw exact bypass
```

进入PREPARE：

```text
上一采样的Vanchor自动成为冻结工作点
K_vff从1平滑降到island target
```

因为切换瞬间：

```text
Vraw ≈ Vanchor
```

所以理论切换冲击接近0。

## 5.2 本版故意不做post-island anchor recenter

原因：

```text
如果anchor不断跟随新V，
低频/DC前馈又逐渐恢复到gain=1，
有可能重新打开Layer-2根因。
```

因此第一版保持固定anchor。

Current PI允许产生有限稳态偏置，但必须在工程验证中证明：

```text
PI finite
不持续漂移
不长期碰限
```

# 6. 电压支撑不照搬论文AVC，而采用当前模型原生坐标方向

使用当前模型厂家 `Voltage Regulators` 的方向作为符号模板，但不用其强PI和积分器。

定义：

\[
V_{ref,pu}=\frac{V_{ref}}{V_{nom,prim}}
\]

当前坐标：

```text
主要幅值误差：
e_mag = Vref_pu - Vq

交叉轴误差：
e_cross = Vd
```

经过deadband和低通：

\[
\bar e[k]=\bar e[k-1]+\alpha(e_{db}[k]-\bar e[k-1])
\]

其中：

\[
\alpha=1-\exp(-2\pi f_{vs}T_s)
\]

支撑电流：

\[
I_{sup,d}=K_{mag}\bar e_{mag}
\]

\[
I_{sup,q}=K_{cross}\bar e_{cross}
\]

第一正式参数：

```text
Kmag   = 0.25
Kcross = 0.00
f_vs   = 2 Hz
deadband = 0.01 pu
```

`Kcross`路径保留为运行时参数，但首轮关闭。

原因：

```text
当前根因不是PLL；
不在第一次最终修复中再增加强相角/交叉轴控制。
```

# 7. P/Q外环不再从输出端硬缩放

不再使用Layer2：

```text
Ianchor + Kpq(Iraw-Ianchor)
```

而在Power Control的**参考输入端**做完全等价的误差门控。

原P误差：

\[
e_P=P_{ref}-P_{meas}
\]

设置：

\[
P_{ref,eff}=P_{meas}+g_{PQ}(P_{ref}-P_{meas})
\]

则：

\[
P_{ref,eff}-P_{meas}=g_{PQ}(P_{ref}-P_{meas})
\]

原Q误差：

\[
e_Q=Q_{meas}-Q_{ref}
\]

设置：

\[
Q_{ref,eff}=Q_{meas}+g_{PQ}(Q_{ref}-Q_{meas})
\]

则：

\[
Q_{meas}-Q_{ref,eff}
=g_{PQ}(Q_{meas}-Q_{ref})
\]

优点：

```text
不改Power Control内部结构
不改原PI
不改原PI anti-windup
只改变它看到的动态误差
```

# 8. gPQ状态逻辑

GRID_NORMAL：

```text
gPQ = 1 exact bypass
```

ISLAND_PREPARE：

```text
gPQ平滑下降到0
```

ISLAND_ACTIVE 初始：

```text
STABILIZE
gPQ = 0

→ 原P/Q PI不继续追离岛瞬间的大功率误差
→ 其积分输出基本停留在离岛前工作点
```

恢复条件：

```text
Vpu >= V_RECOVER
AND
previous-sample current_limit_active = 0
连续 dwell 时间
```

再进入RECOVERY：

```text
gPQ以慢速度 0 -> 1
```

若恢复途中：

```text
Vpu < V_BAD
OR
current_limit_active = 1
```

立即回STABILIZE。

首版：

```text
V_BAD     = 0.94 pu
V_RECOVER = 0.98 pu
dwell     = 0.20 s

gPQ down slew = 0.01/sample
gPQ up slew   = 0.0005/sample
```

100 µs下：

```text
1 -> 0约10 ms
0 -> 1约200 ms
```

# 9. 最终电流能力管理

原模型只有：

```text
P PI individual limit
Q PI individual limit
Vconv component limit
```

没有最终矢量：

\[
\sqrt{I_d^{*2}+I_q^{*2}}\le I_{max}
\]

因此正式新增。

首先：

\[
I_{pre}=I_{PQ}+I_{sup}
\]

但不能简单同比例缩放，因为孤岛电压支撑应优先。

先限制：

\[
|I_{sup}|\le I_{sup,max}
\]

若：

\[
|I_{sup}+I_{PQ}|\le I_{max}
\]

则：

```text
lambdaPQ = 1
Iout = Isup + Ipq
```

否则求最大的：

\[
0\le\lambda\le1
\]

满足：

\[
|I_{sup}+\lambda I_{PQ}|=I_{max}
\]

令：

\[
a=I_{PQ}\cdot I_{PQ}
\]

\[
b=2I_{sup}\cdot I_{PQ}
\]

\[
c=I_{sup}\cdot I_{sup}-I_{max}^{2}
\]

取：

\[
\lambda=
\frac{-b+\sqrt{\max(b^2-4ac,0)}}{2a}
\]

并截断到 `[0,1]`。

这样：

```text
电压支撑优先
P/Q方向尽量保持
总电流严格不超过Imax
```

第一版：

```text
Imax = 1.20 pu
```

运行时可调到1.25，无需Rebuild。

