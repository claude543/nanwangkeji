# 实际积分器与执行接口适配：本轮实现与执行说明

日期：2026年9月6日。

## 1. 本轮已经进入代码实现

本轮交付的是实际积分器和内外环执行接口的适配构建程序，不是新一轮数据提取或全模型审计。

已实现：六台带完整执行残差反馈的电流控制候选子系统、五台有功比例积分适配子系统、储能1两路电压比例积分组合适配子系统，共12个。它们对应实际模型中13处比例积分边界；储能1两路电压积分被组合成一个两维候选子系统，但原误差方向分别保留。

本轮程序会在本机创建和运行临时算法模型，验证真实离散积分语义及候选内部接线。无需再次运行上一轮24项测试。

## 3. 本轮具体落实的四件事

### 3.1 梯形积分的状态与输出不能混淆

实际旧模块使用梯形积分，并把初值作用在积分输出上。内部为下一拍保存的状态包含半步积分贡献，不等于本拍积分输出。

新适配器显式保存对应状态，并处理：首次输出、正常积分、无复位、上升沿复位、电平复位和接管匹配。

接管匹配的目标是比例积分器总输出，不是直接把目标数值写成积分状态。优先级为原复位高于接管匹配；目标超出状态或输出范围时记录不能完全匹配，不能同时声称已裁剪且严格无冲击。

原生积分器测试在本机用相同采样、积分方法、初值设置及复位类型逐样本核对。它检查正常未受限响应与原复位语义，不要求复现旧抗饱和门控在受限时的错误行为。

### 3.2 电流环反算使用完整、同拍配对的执行残差

每个候选电流子系统计算：

```text
比例积分器未限幅输出
→ 原局部比例积分输出限幅
→ 加入实际选中的前馈、交叉补偿及附加电压
→ 原d、q分量限幅
→ 最终幅值限制对应的等效电压
```

完整残差等于等效施加电压减去本拍附加电压，再减去本拍未限幅比例积分输出。它在同一计算中形成，保存到下一拍再进入积分更新，避免上一拍最终电压减去当前拍前馈。

候选保留原局部及分量限制，正常积分由一个明确的更新链处理；不再叠加一套未解释的旧积分门控。电压等效量不是开关端的瞬时实测电压。

当前子系统的前两个输出仍为分量限幅后的电压命令和局部比例积分输出，方便后续保留原调制链。直流电压由接口传入，不在控制核心里固定为1000伏。

### 3.3 储能1单独处理，不照搬五台跟网设备

储能1保留附加电压输入和有效模式。当前有效模式达到1.5时使用0.0015、0.125的局部电阻、电感前馈参数，否则使用0.004、0.21；既有附加电压仍进入汇总。

模式变化只丢弃不再适用的旧模式残差，不擅自清空比例积分状态。真正原复位和输出匹配通过独立接口处理。

储能1电压候选仍分别采用：q轴参考减q轴实测，以及d轴实测减d轴参考；增益0.02、0.14；原使能关系产生电平复位。没有直接改成另一种教科书电压环。

### 3.4 外环只反算自己的可执行份额

有功外环与储能1电压外环分别接受：自身可执行参考、明确参考裁剪标志、已确认的物理受限积分抑制以及接管目标。

没有裁剪证据时，不因普通参考差值就故障式回退。参考反馈和误差计算在结构上分开，残差经显式延迟返回；程序还会把候选输出通过一个受限参考模型闭合回来，用严格代数环检查验证真实反馈结构。

**自身可执行份额在整机中的具体来源仍待接合。** 它必须扣除不属于该外环的支撑、前馈和交接补偿，不能将当前候选输入直接接到全部最终电流。

## 5. 本轮实际验证与未验证内容

本环境已经执行27项离线数值交叉核对，包含独立梯形状态表示、初值与复位序列、20000组接管匹配、实际前馈分支、完整电压限制和隔离反算收敛。另对全部六个MATLAB（数值计算软件）文件进行了轻量词法、控制块配对和函数参数数量检查。

**本环境没有执行MATLAB或Simulink（图形仿真环境）。轻量静态检查不是MATLAB编译。** 配套状态文件明确记录这一区别。

你本机将执行：

1. 本轮适配规则检查。
2. 四种实际积分/复位配置、两种初态，共八次与本机原生积分器的逐样本对照。
3. 12个有显式状态的候选子系统构建与固定宽度编译。
4. 12个已生成子系统的动态输入回放，检查生成器接线、模式变化、限幅与匹配时序。
5. 有功和储能1电压两种实际参考反算闭环的代数环检查。
6. 新建候选模型保存后重载、再次编译。

生成子系统与逐拍函数对照，验证的是接线和计算时序，不是两个独立电气模型的稳定性证明。实际断路器序列、完整黑启动与重同步，也不由这些输入回放替代。

## 6. 现在怎样运行

完整解压配套压缩包，在MATLAB中切换到其中的 `K26_REAL_ADAPTERS_R1（实际适配器第1版）`文件夹，执行：

```matlab
result = BUILD_K26_REAL_ADAPTERS_R1;
```

不要只复制主脚本。六个MATLAB文件应在同一目录。

不需要重新构建、加载、执行或复位实时模型。程序不会加载、关闭、编译、保存正式工程，也不调用其初始化回调；已有正式模型可以保持原状态。

它保存的是新建的候选子系统模型，不是微网对象。**不要将候选模型加载到实时仿真平台。**

结束后上传：

```text
ADAPTER_RESULT_时间戳.zip
```

成功状态为 `ADAPTER_BUILD_AND_LOCAL_TEST_PASS（适配构建与本地测试通过）`。失败则输出已完成结果和完整异常，不修改正式模型，也不把失败改为通过。

## 7. 下一步与整机补丁的关系

本轮通过后，已建立的适配子系统和内部状态测试可以进入整机生成器，不再重复本次测试作为独立任务。

剩余具体工作是：五台方向/支撑/二次能力的联合接线，实际断路器与模式事件生成，外环自身份额的真实来源和受限确认，中央完整阶段逻辑与滤波，统一通道定义，以及完整电气动态验证。这些会决定最终成套补丁，而不是把当前候选模型直接替换正式工程。

**本轮推进的是具体代码和实际状态适配；不是宣称已经完成全部修复。** 最终补丁应复用这些自动测试，在保存正式模型前完成整体接口和模式检查，再由完整正式孤岛试验验证实际电气闭环。
