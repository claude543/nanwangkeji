# 12. S14-80的物理含义

S14-80不是简单：

```text
把允许范围从0.001改成0.02
```

而是：

```text
固定调试范围
↓
实时正常能力范围
```

实时范围由：

```text
ESS1当前负担
ESS1向上/向下P reserve
ESS1 Q/current/modulation健康
ESS2自身P能力
ESS2 current/modulation
q-bias实际占用
V/f健康
```

共同限制。

ESS1在合理工作区：

```text
ESS2不追着小纹波改变baseline
```

ESS1持续负担过高：

```text
ESS2慢慢多承担
```

ESS1持续负担过低：

```text
ESS2慢慢反方向调整
```

必须带：

```text
低通
死区
迟滞
变化率限制
```
