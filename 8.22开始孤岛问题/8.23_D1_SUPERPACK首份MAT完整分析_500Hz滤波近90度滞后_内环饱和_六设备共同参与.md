# 7. 为什么Id_ref会长期撞限幅？

J1前：

```text
Vd_filt ≈ 0
Vq_filt ≈ 1 pu
Vout    ≈ 0.994 pu
```

这是一种正常同步dq状态。

J1打开以后，真实abc电压进入530 Hz附近快速旋转模态。

在50 Hz dq坐标里，它变成约480 Hz快速旋转量。

因此后期：

```text
Vd/Vq不再是稳定DC
```

而是在dq平面里高速旋转。

其平均值接近0。

于是Voltage Regulator看到的不是：

```text
稳定Vq≈Vout
```

而是：

```text
快速变化的Vd/Vq
+
很大的平均电压误差
```

于是电流参考被长期顶到：

```text
±1.25附近
```

这是为什么Voltage Loop成为当前最值得优先修复的快速控制层之一。

> **D1首份SUPERPACK数据完整有效，并且已经实现此次“一次Build深入根因”的目标。实测直接证明：abc约530～535 Hz和dq约480～485 Hz是同一模态；500 Hz正式V/I二阶低通在该模态上实际提供约0.516增益和约−88°相位滞后，与理论设计完全吻合，因此它已从猜测升级为确定存在的重大相位损失环节；J1打开后约10～18 ms，Voltage/Current控制和ModIndex即开始碰限幅，后期Id_ref约94%时间处于上限附近；PWM之前的Vpwm_ab已经包含强约533 Hz分量，说明快速模态进入了控制输出，PWM/Converter“凭空造振荡”进一步降级；Fout/Vout几乎没有对应快速分量，Droop不是主源；六台变流器支路电流在约530 Hz上相干度约0.997～0.999，证明整个孤岛共同参与，其中PV1/PV2/ESS2和ESS1/EV1/EV2形成近180°的两组模态电流交换，ESS2相对于自身正常50 Hz电流的模态参与尤其高。当前最合理根因是：约527 Hz电气自然模态在失去强网后被激发，500 Hz测量滤波的大相位滞后、GFM快速内环及其饱和、多变流器动态交互共同造成总阻尼不足。现在不需要再加测点Build，应进入F1一次性可调修复设计。**
