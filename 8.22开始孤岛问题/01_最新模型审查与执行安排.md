## 三、第一处：低频无功标量没有沿真正的无功方向形成

五台管理器的当前实际连线均为：

```text
AA15_LFQ_OUTPUT_CORE（低频标量输出）
→ AA15_DAMP_Q_SUM_V46（固定q分量相加器）的第2输入
→ AA15_FINAL_GFL_LIMIT_CORE（最终电流限制核心）的第4输入
```

中频d分量则独立进入限制核心第3输入。由幅值误差产生的低频标量没有形成对应的d分量。

当电压方向与执行d轴重合，固定q轴可以近似代表无功方向；电压偏转几十度以后，就不再成立。修补应把低频标量单独沿当前电压的正交方向变成二维电流，然后与真正的二维中频阻尼合成。

**不得把整个中频向量旋转；不得把高优先级低频阻尼并入低优先级慢无功状态。**

这是对既定纯无功幅值支撑目标的具体实现遗漏。它可能参与有功扰动和无功支撑减弱，但其对全部电压摆动的贡献还需修补后的完整闭环验证。

## 四、第二处：角色限制仍残留固定d轴裁剪

这次直接在最新模型发现，五台状态核心仍保留以下逻辑，其中光伏和电动汽车实际生效：

```matlab
% dd：中频阻尼的原d分量；dq：原q分量。
if rr==1
    dd=min(dd,0.0); % 光伏按原d轴裁掉正方向
elseif rr==3
    dd=max(dd,0.0); % 电动汽车按原d轴裁掉负方向
end
```

而后级限制核心已经依据当前电压方向，把二维阻尼投影成真正的有功、无功分量，再执行设备角色约束。

所以实际是：**先按旧d轴裁一次，再按真正有功方向裁一次。**前级一旦剪掉一部分向量，后级不能把被剪掉的有效无功分量恢复回来。

这不意味着最终光伏一定反向吸收有功，也不意味着最终电动汽车一定反送电——后级仍有正确的最终方向限制。问题在于前级额外裁剪并不等价于“只限制有功”，会改变允许保留的无功阻尼。

本轮用未标记小缺口估计的10毫秒样本计算了前级剪切的独立几何影响，示例：

| 示例 | 被剪前d分量 | 被剪后d分量 | 对真实无功电流投影的改变 |
|---|---:|---:|---:|
| B光伏1，2.57秒，偏角约45.19度 | +0.02335标幺 | 0 | +0.01656标幺 |
| B电动汽车1，17.24秒，偏角约34.78度 | -0.04490标幺 | 0 | -0.02561标幺 |

这些是**限制核心之前的参考向量变化**，不是该支路独立测得的实际功率，也不是修改后电压改善量。

相对于“设备角色只约束真实有功作用”的当前设计意图，这是一处尚未完成的坐标迁移。建议让已经存在的后级真实有功投影承担这项角色限制，前级保留完整二维中频请求。是否改变特殊紧急保护必须另外核验，不能把其他限制一并删除。

## 五、第三处：光伏能力接口与实际基线不一致

最新中央协调代码仍然使用：

```matlab
pvmax1=max(pb1,max(pvmax1_kw,0.0)/punit);
```

其中：`pb1`（开断前捕获的光伏1功率基线），`pvmax1_kw`（输入的光伏可用功率，千瓦），`punit`（功率基准，千瓦）。

A/B中：可用功率每台65千瓦，基准100千瓦，捕获基线约0.85554标幺，即85.55千瓦。代码把两者取大，实际允许的上限至少维持85.55千瓦，而不是65千瓦。

**如果65千瓦被定义为物理可用上限，这就违反了该接口含义；如果它只是测试调度信号，就需要明确并修正名称/使用约定。**本轮还确认六个直流源都是理想1000伏源，所以模型不会因为这张65千瓦曲线而自动出现真实光伏能量不足。

因此，这不是当前电压摆动已证实的源头，但它会影响工况真实性、后续功率分配和板端能力一致性，不能说模型除此之外都正确。

不能在离网瞬间直接把上限从85.55降到65，再把产生的大功率差当成方向修补的结果。处理这项时，应在并网准备阶段先使基线进入可用能力范围，重新完成有功平衡，并把它作为另一个明确工况。

## 六、第四处：中央实际施加量回传没有直接进入偏置更新

最新中央无功核心接收五台参考施加量，计算：

```matlab
qapplied=ap1+ap2+ap3+ap4+ap5;
```

但下一拍状态 `qstaten`（下一拍中央偏置）主要根据当前偏置、可分配能力、电压误差及限速更新，没有使用这五项施加回传形成直接跟踪残差。

这意味着：在能力数值、电压误差与旧状态完全相同的条件下，单独改变五台施加回传，中央下一拍偏置仍然相同；只有输出的合计诊断变化。

需要准确区分：

- 代码有能力区间约束和退让，也有本地限制，**不能说完全没有抗饱和**。
- 能力回传本身可能间接受设备执行状态影响，不能说中央对设备毫无感知。
- 但不能再把现行中央状态律介绍成“直接用实际参考施加量跟踪中央积分状态”。历史版本4.8设计曾提出这种跟踪，当前版本4.9的保存实现已不是那个直接反馈形式。
- B的相关状态与施加量都为零，仍然摆动，所以此项不可能单独解释B的摆动。

这项应作为完整功能和限幅退出设计的核对对象。若决定恢复施加跟踪，应区分本地正常限速造成的短暂差异和真实执行能力不足，不能把正常渐入也强行拉回零。它不与首轮方向修补同时改变。

## 七、第五条具体作用链：减充电、充电恢复与有功协调

当前电动汽车欠压处理不是“只有严重故障才触发一次”，而是持续参与闭环：

- 本地电压达到0.95标幺及以上，允许完整充电请求；
- 低于0.85标幺，充电请求减为零；
- 中间区间线性改变请求比例。

按每台约100千瓦充电请求估算，在斜坡区内电压每增加0.01标幺，单台允许充电目标就增加约10千瓦，两台约20千瓦。这是当前代码的静态斜率，不是实际充电功率必然瞬时变化同样幅度。

该局部逻辑使用上一拍电压，但自身没有单独的恢复滞环或恢复斜率状态；后级功率环仍会限制实际响应速度，不能说真实电流无延迟阶跃。

A约25～26秒逐步接近完整充电目标，B约14秒已接近；两者随后都出现较大电压变化。这个先后关系值得分析，但不是仅凭时间顺序就能定罪。详见“复核数据/A_关键时刻.csv”和B对应文件。

同时，中央有功能力边界基于捕获基线和名义范围，未直接把局部欠压减充电比例纳入可执行下调范围；实测功率输入主要用于并网/准备阶段捕获，不直接在岛态状态更新中构成执行跟踪。

**这里有一条明确可分析的闭环，而不是泛泛说一台与五台交互：**

> 母线电压变化 → 充电目标改变 → 负荷和储能1功率分担改变 → 频率与中央有功修正改变 → 五台输出变化 → 母线电压再次变化。

可以通过现有数据复现各环节，必要时在同一工作点保持已施加的减充电比例做定向比较；不能从零关闭欠压保护，也不能临时改变充电基线后把结果称为同工况。

本轮没有证明应该立刻增加滞环或把恢复放慢。那些是有针对性的候选修法，要看真实响应方向、能力限制与稳定性，而不是默认“慢一点就好”。

## 十二、下一步怎样安排，避免继续无目标返工

### 当前应进行：方向一致性补丁的设计与离线核验

范围包含两处相互关联的旧轴假设：

1. 低频标量沿当前无功方向形成，保持原低频滤波、增益、状态和优先级。
2. 中频请求在前级不再按固定d轴冒充有功裁剪，设备角色方向由已有的真实有功投影限制统一负责。

不改储能1电压环0.02/0.14，不改电流执行适配器，不改中央增益，不删欠压减充电，不恢复旧控制器切换，不重做F24/F25（既有参考与输出电流交接）结构，不扩大外部通信或五组记录器。

本轮已经对该方向形成与现有下游限制规则的数值重写做了12000组检查：低频单独有功投影、无功幅值、坐标旋转一致性、总电流/支撑预算和设备方向约束，最大误差在浮点舍入量级。**这只是数学实现核验，不是MATLAB编译或实际闭环运行通过。**

实际补丁还须检查当前连线/源码身份、阶段0/1/5旁路、无效电压回退、显式一拍状态和下游优先级，并执行严格编译与保存后重载。EV2实际块名是 `Control System`（电动汽车2控制子系统），不能擅自拼成不存在的EV2_Control路径。

### 修补后：一次全功能15秒同工况对照

使用原A为基线，保留原有准备及开断流程。检查的不是“是否恰好跑到15秒”，而是：方向投影是否如预期修正；过冲/往复/恢复有何变化；末段是否可用；既有接口、交接和限制有没有回退。

若方向修复成立且动态明显改善，再在开发回归中覆盖一次旧版25秒附近的复发区间；常规演示仍可用15秒。

### 其他发现如何处理

- 能力接口先确定物理/调度语义，再在准备阶段平衡后单独纠正；不把功率工作点改变混入方向对照。
- 无功施加跟踪先核对约定，并用受控能力/限速输入做离线状态律检查；B已经排除其单独解释全部摆动。
- 若仍有类似动态，把电动汽车恢复和中央有功分担纳入完整对象；按分析结果选择定向对照，不能机械轮流关积分器。
- 未出现新的高频证据前，不重新执行已完成的527赫兹、直流接口和旧交接排错。

**今天能够落实的是这些具体位置与验证预期；尚未完成的是候选补丁在完整对象上的动态验证。保留这个边界，并不意味着没有思路，也不意味着其余部分已证明正确。**
