# 2. V1.0 设计在实施前发现并修正的两个重要缺口

## 2.1 缺口 A：所有五台都做完全对称 d 轴 damping，会碰撞资源有功方向约束

原 V1.0：

\[
i_{damp,d}=-G_d v_{bp,d}
\]

对所有 PV / ESS2 / EV 都双向。

这在“端口耗散”数学上成立，但对资源物理约束不够严谨：

- PV：额外正 d 电流可能要求超过可用光伏功率；
- EV：当前充电功率接近 `-1 pu` 时，额外负 d 电流可能要求超过最大充电，且绝不能变成 V2G 逻辑；
- ESS2：物理上可双向，适合承担完整 d 轴阻尼。

因此 V1.1 冻结成 **role-aware d-axis damping**。

### ESS2

\[
i_{damp,d}^{req}=-G_dv_{bp,d}
\]

双向。

### PV

只允许“主动削减注入”的方向：

\[
i_{damp,d}^{req}
=
\min(-G_dv_{bp,d},0)
\]

不依赖未知的瞬时 PV upward headroom。

### EV

只允许“减少充电”的方向：

\[
i_{damp,d}^{req}
=
\max(-G_dv_{bp,d},0)
\]

因此不会因为主动阻尼要求 EV：

```text
充得比 -1 pu 更深
或
变成 V2G
```

### q 轴

五台统一：

\[
i_{damp,q}^{req}=-G_dv_{bp,q}
\]

因为 q 轴由统一电流能力约束控制，不改变 EV 的有功充电方向合同。

### 关键性质

无论 role gating 是否动作：

\[
v_{bp,d}i_{damp,d}^{req}
+
v_{bp,q}i_{damp,q}^{req}
\le 0
\]

所以 gating 只会“少提供阻尼”，不会反向变成负阻尼。

# 5. P/Q release 的定位不变，但只作为 anti-cancellation，不冒充主稳定器

实际总支撑电流上一拍：

\[
\mathbf i_{sup,z}
\]

活动度：

\[
a_{raw}
=
\min\left(1,\frac{\|\mathbf i_{sup,z}\|}{0.05}\right)
\]

2 Hz 平滑：

\[
a_n=a_z+\alpha_R(a_{raw}-a_z)
\]

冻结：

```text
gammaP_min = 0.70
gammaQ_min = 0.20
```

\[
\gamma_P=1-0.30a_z
\]

\[
\gamma_Q=1-0.80a_z
\]

再和 downstream base-current limiter 的 delayed scale 合并：

\[
g_{P,eff}=\min(g_{P,limit,z},\gamma_P)
\]

\[
g_{Q,eff}=\min(g_{Q,limit,z},\gamma_Q)
\]

作用只有：

> 当显式支撑电流正在工作时，降低原 P/Q PI 对这条支撑电流的反向抵消。

# 7. support priority 与精确 current-circle 约束

## 7.1 damping 先做 role gating

得到：

\[
\mathbf d_{req}
\]

## 7.2 damping 本身径向限制到 IsupMax

\[
\|\mathbf d\|\le I_{sup,max}
\]

径向缩放保持耗散方向不变。

## 7.3 普通 PV / EV / 默认

顺序：

```text
damping
>
slow q support
>
base P/Q
```

slow q 只占 damping 剩余的 support-vector budget。

然后：

\[
\mathbf i_f=\mathbf s+\lambda\mathbf b
\]

用严格二次根求最大：

\[
0\le\lambda\le1
\]

且：

\[
\|\mathbf i_f\|\le I_{max}
\]

## 7.4 ESS2 under-frequency

顺序：

```text
damping
>
base P/Q / P-f active task
>
slow q support
```

如果：

\[
\|\mathbf b+\mathbf d\|\le I_{max}
\]

则强制：

```text
lambda = 1
```

slow q 只在以下两个区间交集内增加：

### support-vector circle

\[
d_d^2+(d_q+x)^2\le I_{sup,max}^2
\]

### final-current circle

\[
(b_d+d_d)^2+(b_q+d_q+x)^2\le I_{max}^2
\]

其中 `x = slow-q actual`。

如果 `base + damping` 本身已经超过 Imax：

```text
slow q = 0
```

再对：

```text
damping + lambda * base
```

求严格二次根。
