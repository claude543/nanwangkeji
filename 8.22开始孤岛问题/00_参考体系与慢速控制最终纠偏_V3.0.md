# K26_V5｜ESS1参考体系、慢速控制与三实时任务传播最终纠偏 V3.0

> 日期：2026-09-03  
> 依据：最新 V2 模型、V1/V2 正式运行证据、N1/N2/N3 编译态只读审计  
> 本文替代此前“把 `v_eff` 直接作为五台公共电压目标”的表述。  
> 当前角色保持：ESS1 为唯一构网主机；PV1、PV2、ESS2、EV1、EV2 为五台跟网从机。

---

# 0. 结论

## 0.1 ESS1的四个参考量必须分清

当前 ESS1 下垂控制的准确关系为：

\[
F_{\mathrm{out}}
=
f_{\mathrm{eff}}
-
0.5P_{\mathrm{ESS1}}
+
0.25
\]

\[
V_{\mathrm{out}}
=
\frac{v_{\mathrm{eff}}}{10000}
-
0.04Q_{\mathrm{ESS1}}
\]

其中：

- `f_eff`：有功—频率下垂曲线的基础频率截距，单位 Hz；
- `Fout`：考虑 ESS1 实际有功后的最终构网频率，单位 Hz；
- `v_eff`：无功—电压下垂曲线的基础电压截距，单位 V；
- `Vout`：考虑 ESS1 实际无功后的最终构网电压指令，单位 pu。

`v_eff` 不是实际母线电压，也不是应直接发给五台的本地电压目标；`Vout` 是 ESS1 自己电压调节环应使用的最终构网电压指令，但也不宜未经滤波和结构设计直接成为五台快速电压支撑的共同目标。

## 0.2 最终应增加两个物理上容易理解的系统目标

中央控制不直接以 `f_eff`、`v_eff` 为最终目标，而是定义：

- \(f_{\mathrm{bus}}^\star\)：希望母线实际达到的频率；
- \(V_{\mathrm{bus}}^\star\)：希望母线实际达到的电压；
- \(P_{\mathrm{ESS1}}^\star\)：希望 ESS1 长期承担的有功；
- \(Q_{\mathrm{ESS1}}^\star\)：希望 ESS1 长期承担的无功。

再由当前下垂方程反算 ESS1 内部参考：

\[
f_{\mathrm{eff}}^\star
=
f_{\mathrm{bus}}^\star
+
0.5P_{\mathrm{ESS1}}^\star
-
0.25
\]

\[
v_{\mathrm{eff}}^\star
=
10000
\left(
V_{\mathrm{bus}}^\star
+
0.04Q_{\mathrm{ESS1}}^\star
\right)
\]

当 ESS1 实际功率等于期望功率时：

\[
F_{\mathrm{out}}=f_{\mathrm{bus}}^\star
\]

\[
V_{\mathrm{out}}=V_{\mathrm{bus}}^\star
\]

这样可以同时明确：

```text
母线希望达到什么状态
ESS1长期希望承担多少功率
ESS1内部下垂参考该设成多少
```

## 0.3 有功慢速控制只保留一个积分目标

最终不同时使用：

```text
频率误差积分器
+
ESS1有功误差积分器
```

两者会通过 ESS1 的有功—频率下垂控制争夺同一个功率平衡过程。

最终使用：

```text
一个岛态频率恢复积分器
```

它通过五台设备的慢速功率分配把 `Fout` 拉回 \(f_{\mathrm{bus}}^\star\)。

ESS1希望长期承担的有功 \(P_{\mathrm{ESS1}}^\star\)，通过上面的代数关系设置 `f_eff`，不再使用第二个有功积分器。

## 0.4 电压侧采用同样原则

保留：

```text
ESS1原有无功—电压下垂
+
五台本地比例/滤波电压支撑
+
一个中央慢速电压恢复量
```

不同时再增加一个独立的 ESS1 无功积分器。

五台快速电压支撑使用本机电压测量和本机切岛前电压基准；中央慢速电压恢复量只缓慢平移 ESS1 和五台的共同目标。

# 1. `v_eff`和`Vout`的实际含义

## 1.1 为什么切岛前`v_eff`可能高于10 kV

V2 的 J1 开断附近：

```text
ESS1无功约 0.0592 pu
v_eff约 10067.8 V
```

代入：

\[
V_{\mathrm{out}}
=
10067.8/10000
-
0.04\times0.0592
\approx 1.0044\ \mathrm{pu}
\]

因此，`v_eff=10067.8 V` 并不是命令母线达到 10067.8 V。它先经过无功下垂修正，最终 ESS1 电压目标约为 1.0044 pu。

F24 的作用正是根据切岛前的实测电压和无功，反算出一个 `v_eff`，使 ESS1 切为构网后 `Vout` 与切换前电压一致，从而减少电压参考跳变。

## 1.2 `Vout`是否适合给五台

### 对ESS1自身

适合，而且必须使用：

```text
v_eff
+
ESS1无功下垂
→ Vout
→ ESS1电压调节环
```

### 对五台跟网设备

不能直接把每一个采样点的 `Vout` 都作为五台快速支撑目标。

原因是：

```text
ESS1无功变化
→ Vout变化
→ 五台同时改变无功电流
→ 又改变ESS1无功
→ 再次改变Vout
```

这会改变原 ESS1 无功—电压下垂的等效斜率和阻尼。它不一定必然错误，但属于一个新的强耦合闭环，必须通过稳定性模型证明，不能默认正确。

## 1.3 第一版基准方案

计划离岛准备阶段捕获：

- 每台本地电压 \(V_{i,0}\)；
- 初始母线目标 \(V_{\mathrm{bus},0}^\star\)。

五台本地目标为：

\[
V_{i,\mathrm{ref}}
=
V_{i,0}
+
\Delta V_{\mathrm{sec}}
\]

其中 \(\Delta V_{\mathrm{sec}}\) 是中央慢速电压恢复量。

ESS1基础目标同时变为：

\[
V_{\mathrm{bus}}^\star
=
V_{\mathrm{bus},0}^\star
+
\Delta V_{\mathrm{sec}}
\]

然后中央按 \(Q_{\mathrm{ESS1}}^\star\) 计算 `v_eff`。

这样：

```text
快速尺度：
ESS1下垂和五台本地电压支撑共同稳定电压

慢速尺度：
一个共同的电压恢复量平移所有目标
```

不会让五台快速追逐 ESS1 每一次无功下垂变化。

## 1.4 必须比较的第二候选

为了避免凭经验排除其他可能，稳定性模型同时比较：

\[
V_{i,\mathrm{ref}}
=
V_{i,0}
+
\Delta V_{\mathrm{sec}}
+
\alpha_v\,
\operatorname{LPF}
\left(
V_{\mathrm{out}}-V_{\mathrm{out},0}
\right)
\]

- \(\alpha_v=0\)：五台不直接跟随 ESS1 下垂后的电压变化；
- \(0<\alpha_v<1\)：五台只跟随一部分慢变化；
- \(\alpha_v=1\)：五台完整跟随慢变化。

最终值由稳定性和电压分担结果决定。第一版基准为 \(\alpha_v=0\)，但在计算完成前不把它冒充最终数值结论。

# 2. 两个有功慢速积分器分别会做什么

## 2.1 频率恢复积分器

输入：

\[
e_f
=
f_{\mathrm{bus}}^\star-F_{\mathrm{out}}
\]

作用：

```text
频率偏低
→ 慢慢提高五台的净有功注入

频率偏高
→ 慢慢降低五台的净有功注入
```

它用于消除 ESS1 有功下垂留下的稳态频率偏差。

## 2.2 ESS1有功卸载积分器

如果另设：

\[
e_P
=
P_{\mathrm{ESS1}}^\star-P_{\mathrm{ESS1}}
\]

它会试图让 ESS1 回到某个长期有功。

但当前 ESS1 下垂方程已经把 \(Fout\) 和 \(P_{\mathrm{ESS1}}\) 直接耦合。两个独立积分器可能出现：

```text
频率积分器要求五台增发
有功积分器又按另一目标继续分配
两者通过ESS1下垂相互抵消或反复修正
```

## 2.3 最终正确设计

只保留频率恢复积分器。

ESS1长期有功目标通过：

\[
f_{\mathrm{eff}}^\star
=
f_{\mathrm{bus}}^\star
+
0.5P_{\mathrm{ESS1}}^\star
-
0.25
\]

直接设置。

当频率积分器把 `Fout` 恢复到 \(f_{\mathrm{bus}}^\star\) 时，ESS1自然回到 \(P_{\mathrm{ESS1}}^\star\) 附近。

这不是少了一个功能，而是用一个积分器和一个代数约束完成两个一致目标，避免重复积分。

## 2.4 重同步时的处理

重同步时 \(f_{\mathrm{bus}}^\star\) 会被有意略微提高或降低，以移动孤岛相角。

此时：

- 五台频率响应使用 \(f_{\mathrm{bus}}^\star-Fout\)，不会把有意的同步频率偏移误认为系统事故；
- 岛态频率积分器进入“跟踪当前输出”状态，不继续与同步修正相互抵消；
- J1 合闸并进入构网保持后，再平滑恢复并网控制。

# 3. 三个实时任务之间怎样传播

三个从任务：

```text
SS_Slave：
EV1、EV2

SS_Slave2：
ESS1、ESS2

SS_Slave3：
PV1、PV2
```

中央任务：

```text
SM_Master：
统一状态机、参考权威、能力管理、
岛态慢速协调、重同步和J1命令
```

## 3.1 不建立SS之间的直接互连

统一采用：

```text
SS_Slave2中的ESS1
↓
现有ESS返回向量
↓
SM_Master
↓
三个组命令向量
↓
SS_Slave / SS_Slave2 / SS_Slave3
```

这样全系统只有一个参考权威和一个状态真值。

## 3.2 ESS1送到中央的量

现有 30 维 ESS 返回向量保持宽度不变，重新规划诊断尾部，至少包括：

```text
Fout
Vout
f_eff
v_eff
ESS1有功
ESS1无功
ESS1电流储备
ESS1调制度储备
主机参考有效标志
```

当前 `Fout`、`Vout` 已在现有26维诊断尾部中；`f_eff`、`v_eff`、ESS1无功等通过替换已经不再承担最终运行职责的旧试验诊断量实现，不盲目扩宽返回向量。

## 3.3 中央送给三组的量

每台原有12维输入继续保留：

```text
Fref：
ESS1使用f_eff；
五台使用期望母线频率f_bus*

Vref：
ESS1使用v_eff；
五台使用共同慢速母线电压目标，单位V

Pref：
并网时原命令；
孤岛时基础功率+慢速分配

Qref：
并网时原命令；
孤岛时本机无功基准

GridOn：
继续表示本机跟网/构网模式
```

每个设备组增加共享量：

```text
实际Fout
统一系统阶段
主机参考有效标志
两台设备各自的Pmin、Pmax和能力有效标志
```

五台本地频率响应计算：

\[
e_f
=
Fref-Fout
\]

其中：

- `Fref` 是当前希望母线达到的频率；
- `Fout` 是 ESS1 实际形成的频率。

## 3.4 为什么ESS2也使用中央广播副本

ESS2与ESS1虽然同在 `SS_Slave2`，但第一版不让ESS2使用一条零延迟本地副本，而让五台都使用同一份中央校验后的 `Fout`。

否则：

```text
ESS2先动作
PV/EV晚若干计算步动作
```

会人为形成资源之间的相位差。

最终模型将把通信传播作为一个显式、可记录的确定性延迟；稳定性分析覆盖1～3个100 μs计算步的范围。正式改模后再通过发送/接收回显量测真实延迟。

# 4. 五台一次有功响应走哪条控制路径

这一点不能遗漏。

原有功控制器参数较慢，仅把频率响应加到 `Pref` 后等待原功率环动作，可能不足以在J1后最初几百毫秒及时支撑。

稳定性模型同时比较两种路径：

## 路径A：只修改有功参考

```text
频率误差
→ 有功功率增量
→ Pref
→ 原功率控制器
→ 电流参考
```

优点：结构简单。  
风险：响应可能过慢。

## 路径B：互补的快速电流通道

```text
频率误差
→ 期望有功变化
→ 快速形成暂态d轴电流增量
+
同一有功变化送入原功率控制器
```

随着原功率控制器逐步接管，快速电流增量自动衰减，避免两条通道重复叠加。

最终是否采用路径B，由模型回答：

```text
路径A是否能在0.1～0.3秒内形成足够功率响应
路径B是否会与电流环、慢电压前馈形成新模态
```

这两个候选只在线下稳定性模型中比较，不先都塞入正式RT-LAB模型。

# 5. 下一步稳定性设计必须回答的问题

1. 路径A还是路径B适合五台一次有功响应；
2. 慢电压前馈比例和分界频率；
3. 五台本地电压支撑增益和带宽；
4. 电压参考的 \(\alpha_v\)；
5. ESS2、EV和PV各自的频率响应增益；
6. 一个频率恢复积分器允许的速度；
7. 一个慢速电压恢复控制器允许的速度；
8. 1～3个计算步传播延迟下是否仍稳定；
9. 欠压功率退让如何影响稳定性；
10. 电流限制及其反馈进入后是否产生新慢模态；
11. 参数变化和设备能力边界下是否有稳定余量；
12. 是否能复现历史17.165 Hz快速不稳定及其在快速前馈关闭后消失。

只有通过历史现象校准的模型，才允许给出最终参数。

# 6. 当前不再修改正式模型

正确顺序：

```text
建立并校准稳定性模型
↓
冻结结构候选和参数稳定区域
↓
生成一次性事务式正式改模脚本
↓
编译、重载和持久化审计
↓
计划离岛与稳定孤岛
↓
同一模型重同步和重新并网
```

本轮提供的 MATLAB 脚本完成：

- 精确下垂参考核对；
- V2工作点自动提取；
- 一个有功慢速积分器模型；
- 两种一次有功响应速度模型；
- 两种电压参考结构比较；
- 三任务传播延迟敏感性；
- 快速电压前馈在10.619 Hz和17.165 Hz的衰减筛选；
- 设备上下调能力检查；
- 不满足历史校准或能力条件时禁止输出最终参数。

它不修改 `K26_V5.slx`。
