# 1. 先回答你的第1个猜想：是不是因为没有做谐波消除、没有提取基波？

## 结论

# **不是“完全没有做”这个问题，而且现在不能把它作为主根因。**

原因有三层。

---

# 2. 第一层：物理功率级本来就有 LC Filter

当前单台逆变器的实际功率链是：

```text
Two-Level Converter
↓
L1
↓
输出节点
├── C1
└── Transformer / Stubline / Network
```

也就是说当前本来就有：

```text
LC低通滤波器
```

作用就是：

```text
4 kHz PWM开关波
↓
抑制高频电流/电压纹波
↓
让真正送到变压器和10 kV侧的波形更接近50 Hz正弦
```

所以不能说：

> “我们根本没有做谐波减少。”

如果这个LC完全没有作用，那么并网阶段也应该非常差。

但本轮数据实际是：

```text
J1 CLOSED：
PCC Vab ≈10.02 kV
50 Hz成分≈10.01 kV
非50 Hz分量很小
```

也就是说：

> **同一套PWM、逆变器、LC，在强网并网状态下能够形成很干净的基波结果。**

这非常重要。

如果问题只是：

```text
“滤波器设计根本不存在”
```

那么它不应该只在：

```text
J1 OPEN
```

以后突然恶化。

---

# 3. 第二层：控制测量里本来就做了基波/正序/二阶滤波

当前 `Measurements` 并不是直接拿原始PWM波形做所有控制。

它已经包含：

```text
PLL
Positive Sequence
正序提取

Power (PLL-Driven, Positive-Sequence)
基于PLL的正序功率测量

Second-Order Filter
二阶滤波

abc → dq
同步坐标变换
```

所以也不能说：

> “我们完全没有提取基波。”

实际上当前模型已经有一套相当明确的：

```text
原始Vabc/Iabc
↓
PLL / dq / 正序
↓
二阶滤波
↓
P/Q、VdVq、IdIq
```

测量链。

---

# 4. 第三层：就算我们现在增加“更强的基波提取”，也只能改善测量，不能消灭真实物理振荡

这是最关键的区别。

假设PCC真实波形已经是：

```text
50 Hz基波
+
一个非常大的快速振荡
```

如果我们加一个非常强的50 Hz带通滤波器：

```text
原始PCC Vabc
↓
50 Hz Bandpass
↓
得到一个漂亮50 Hz波形
```

那么只是：

> **我们把“看到的波形”变漂亮了。**

但真实电气网络里：

```text
几百Hz/更高频的大电压分量
```

仍然存在。

设备真实承受的：

```text
电压
电流
开关应力
滤波器电流
```

并不会因为显示端提取了50 Hz就消失。

---

# 5. 所以当前“基波提取”的正确定位是什么？

它有价值，但属于：

```text
测量鲁棒性
保护鲁棒性
同步判据鲁棒性
```

而不是当前第一物理修复手段。

未来可以做：

```text
PCC raw Vabc
↓
可信基波估计
↓
S15 ΔV/Δf/Δθ
```

以避免PLL在畸变时直接撞55 Hz。

但是：

# **必须先让真实孤岛电压本身恢复稳定。**

否则只是：

```text
让控制器看不到故障
```

而不是：

```text
把故障修掉
```

---

# 6. 甚至“再加很多滤波”有可能让控制更差

控制系统里滤波不是越强越好。

因为滤波意味着：

```text
延时
相位滞后
```

而GFM电压环本身已经是快速闭环。

如果：

```text
Vabc
↓
非常重的滤波
↓
Voltage Regulator
```

反馈变慢，

就可能进一步降低：

```text
Phase Margin
相位裕度
```

甚至更容易振荡。

所以不能采用：

```text
“有振荡
→ 加滤波
→ 再加滤波”
```

这种经验式处理。

# 7. 还有一个重要的新证据：当前异常快速分量是“三相有组织的”

我对本轮2 kHz的原始PCC `Va/Vb/Vc` 又检查了一层。

在70～80 s附近，当前日志中最强的快速分量约为：

```text
≈531 Hz
```

三个相电压在这个分量上的相位仍然大致保持：

```text
A-B ≈120°
B-C ≈120°
C-A ≈120°
```

同时约49.16 Hz的低频分量也保持大致120°关系。

这意味着：

> **当前快速分量不像“某一个测量通道随机坏掉”或者普通随机噪声，而是一个具有完整三相结构的电气振荡。**

但是必须继续保留一个限制：

```text
当前日志采样率 = 2 kHz
Nyquist = 1 kHz
```

所以：

```text
“≈531 Hz”
```

可能是：

```text
真实531 Hz
```

也可能是：

```text
>1 kHz真实分量混叠后的表观频率
```

因此现在最准确的术语应该是：

# **持续的平衡三相非基波振荡**

而不是直接叫：

```text
“第10次谐波”
```

# 8. 为什么不能直接叫“谐波”？

标准意义上的谐波通常指：

\[
f_h = h f_1
\]

比如50 Hz系统：

```text
5次 = 250 Hz
7次 = 350 Hz
11次 = 550 Hz
```

但我们当前低频基波约49 Hz，

而表观快速分量约531 Hz：

```text
531 / 49
≈ 10.8
```

并不是一个非常干净的整数倍。

再考虑2 kHz采样混叠，

现在更像：

```text
控制振荡
网络谐振
采样动态
或
PWM/控制相互作用
```

而不是简单“某次固定谐波太大”。

所以：

> **“没有做谐波消除”目前不是最好的故障描述。**

# 9. 第二个问题：是不是ESS1数量不对？只有一台GFM不够？

## 结论

# **一台ESS1作为唯一主要GFM源，在原理上完全可以成立。**

并没有电力系统规则规定：

```text
2PV+2ESS+2EV
↓
必须2台ESS同时GFM
```

一个孤岛完全可以是：

```text
ESS1 = GFM
PV1/PV2/ESS2/EV1/EV2 = GFL
```

前提是ESS1满足：

```text
容量足够
瞬时电流能力足够
GFM控制稳定
网络阻抗适配
其余GFL能稳定跟随
```

# 10. 为什么“一台GFM”在物理上可以撑起整个孤岛？

GFM的角色不是：

```text
“它必须独自提供所有六台设备的额定功率”
```

而是：

```text
建立电压
建立频率
建立相角
平衡瞬时功率失配
```

其余GFL仍然可以：

```text
发电
吸收
充电
放电
```

ESS1主要负责：

```text
把岛内功率平衡的残差
+
损耗
+
动态瞬时失配
```

兜住。

---

# 11. 当前更不能再拿“900 kW”证明一台ESS1一定不够

旧模型确实曾经存在：

```text
Load1 = 600 kW + 100 kvar
Load2 = 300 kW
```

被错误留在J1微网侧。

那时候一台约100 kW级ESS当然不可能支撑。

但现在已经修成：

```text
DER
→ PCC
→ J1
→ Load1/Load2 + Grid
```

J1打开以后：

```text
900 kW Load1/Load2
不在孤岛里
```

所以这个旧根因已经消失。

---

# 12. 而且我们离网前已经把PCC目标推到接近0 kW

当前试验有：

```text
35~50 s：
PCC target = 0 kW
```

目的就是在断开J1以前尽量做到：

```text
岛内总发电
≈
岛内总用电/充电
```

所以J1打开的一瞬间，不应该再出现：

```text
突然少了900 kW供电
```

那种大尺度持续功率缺口。

---

# 13. 但是“一台ESS1”仍然可能成为系统脆弱点

这里要区分：

```text
“理论上可以”
```

和：

```text
“当前这台ESS1的容量/控制参数一定足够”
```

后者还没有证明。

虽然平均PCC功率接近0，

瞬时仍然可能出现：

```text
滤波器充放电
变压器励磁
其他逆变器瞬态
线路损耗
GFL PLL重同步动态
电流阶跃
```

这些都需要GFM提供瞬时电流。

如果ESS1：

```text
Current Regulator打到限幅
ModIndex打到1
DC侧能力不足
```

就可能形成：

```text
电压调节失控
↓
其它GFL进一步响应
↓
系统振荡
```

所以：

> **“一台ESS1够不够”需要通过电流/调制裕度证明，而不是仅凭数量判断。**

增加ESS2 GFM后：

```text
两个GFM互相“打架”
```

所以不能采用：

```text
现在一台不稳
→ 再开一台看看能不能压住
```

作为正式根因修复。

它未来可以作为：

```text
对照实验
```

但不能在未定位前当成解决方案。

# 17. 高优先级疑点1：GFM电压环面对的Plant在并网和孤岛时完全不同

J1闭合：

```text
ESS1
↓
网络
↓
10 kV强网
```

电网非常硬。

ESS1的局部电压很难被自己随便推走。

J1打开：

```text
强网消失
```

这时ESS1必须自己面对：

```text
自己的LC
变压器
Line_ESS1
公共母线
其余5个变流器
```

于是：

```text
Voltage Regulator
+
Current Regulator
+
LC/network
```

的闭环极点完全改变。

这解释了一个非常重要的事实：

```text
55~60 s：
ESS1已经GFM
但强网仍在
→ 正常

60 s：
J1 OPEN
→ 持续振荡
```

这个现象天然指向：

# **网络依赖的闭环稳定性**

而不是简单“某个固定常数写错，所以任何状态下都应该坏”。

# 18. 高优先级疑点2：SM/SS分核以后，GFM的电压闭环绕了一大圈

这是目前非常值得重视、之前容易遗漏的一点。

当前ESS1真正的控制反馈不是SS内部本地低压测量。

而是：

```text
ESS1 Converter
↓
LC
↓
Stubline
↓
SM Transformer
↓
prim_ESS1高压侧真实Vabc/Iabc
↓
SM数字Mux/Memory
↓
SM→SS通信
↓
SS_Slave2
↓
ESS1 Measurements
↓
Voltage Regulator / Current Regulator
↓
PWM
↓
Converter
```

注意这里同时存在：

```text
物理跨任务边界
+
数字跨任务反馈
```

所以整个GFM电压闭环是：

```text
SS执行
→ 物理Stubline到SM
→ SM测量
→ 数字通信回SS
→ 再控制
```

而不是一个完全本地的单任务闭环。

# 19. 为什么这个分核延时可能在GFM里特别危险？

任何闭环都有：

```text
反馈延时
```

延时越大，

相位越滞后。

在某个频率：

```text
本来应该是负反馈
```

可能逐渐变成：

```text
接近正反馈
```

于是：

```text
某个自然振荡模态
被不断放大
```

并网GFL时：

```text
强网把电压钉住
```

所以这部分问题可能不明显。

孤岛GFM时：

```text
Voltage Regulator本身负责“钉住电压”
```

这时延时就进入最关键闭环。

因此：

# **“分核以后新增的GFM反馈时延是否让原来的控制参数失稳”是目前我认为必须正式审计的一条主线。**

这甚至可能比“有没有提取基波”更接近本源。

# 20. 高优先级疑点3：GFM Voltage Regulator一直在后台运行，却没有明显跟踪GFL当前状态

只读审计已经确认：

```text
Voltage Regulators
有两个带anti-windup的PI积分器
```

但没有找到明显：

```text
GFL IdIq_refF
→ 初始化/跟踪
→ GFM Voltage Regulator
```

的路径。

同时：

```text
Vreg_on = 1
```

使GFM电压PI即使在GFL阶段也一直后台计算。

这就引出一个很重要的问题：

```text
真正切GFM以前
GFM Voltage PI内部积分状态
究竟在哪里？
```

如果它已经：

```text
积到一个与当前GFL工作点无关的位置
甚至接近饱和
```

那么切过去时会直接产生：

```text
IdIq_ref跳变
```

# 21. 高优先级疑点4：Droop自生相角没有明显跟踪PLL相角

审计确认：

```text
Droop Control
↓
Discrete-Time Integrator1
InitialCondition = 0
ExternalReset = none
```

并且没有找到明显：

```text
theta_PLL / Freq_PLL
→ Droop
```

的跟踪初始化路径。

也就是说GFL阶段：

```text
PLL有一套theta_PLL
Droop自己还有一套theta_out
```

两套相角各走各的。

真正切换：

```text
wts
从theta_PLL
切到Droop theta_out
```

如果两者相角不一致，

就可能出现：

```text
PWM相位瞬间改变
```

这就是经典的：

```text
bumpless transfer
无扰切换
```

问题。

# 22. 但为什么“无扰切换问题”目前还不能独自解释全部持续振荡？

因为我们已经故意做了：

```text
55 s：
ESS1先GFM

55~60 s：
保持5 s
但J1仍 CLOSED

60 s：
才真正开J1
```

也就是说：

```text
模式切换
```

和：

```text
电气断网
```

已经分开了。

如果问题只是：

```text
切换瞬间theta错了一下
```

理论上5 s的强网阶段应该给它很多时间恢复。

但实际：

```text
真正持续振荡
仍然在J1 OPEN以后明显爆发
```

所以：

> **状态不对齐可能是诱因、初始扰动或放大因素，但“孤岛后闭环本身是否稳定”仍然更关键。**

# 23. 高优先级疑点5：LC滤波器不是“没有”，反而可能正是一个被激发的共振对象

有LC就必然有：

```text
自然谐振频率
```

大致由：

\[
f_r \sim \frac{1}{2\pi\sqrt{LC}}
\]

决定。

LC滤波器做得好：

```text
抑制PWM
```

但如果阻尼不足，

或者控制器带宽/延时与它发生耦合：

```text
LC自己的共振
```

会被控制器激发。

所以：

```text
“已经有滤波器”
```

不等于：

```text
“绝不会发生滤波器相关振荡”
```

反而应该查：

```text
L1实际值
C1实际值
等效R
变压器漏抗
Line_ESS1
控制带宽
```

然后计算实际谐振频率。

当前还没有完整C1数值，所以不能提前宣称：

```text
当前531 Hz就是LC谐振
```

但这是一个非常值得碰撞的方向。

# 36. 遗漏点6：SM→SS数字反馈延时和Stubline物理延时的叠加

当前GFM闭环同时跨：

```text

```

和：

```text

```

所以实际总延时可能包含：

```text

OpComm/任务同步
Measurements滤波
Unit Delay4/5
PWM一拍
```

其中任意一项单看都很小。

但对：

```text

```

来说100~500 μs已经会产生明显相位。

例如纯100 μs延时在500 Hz处产生的相位滞后约：

\[

=

=

=

\]

```text

```

这对稳定裕度已经非常敏感。

所以这一条值得高度重视。

# 37. 遗漏点7：Droop自身的工作点/符号/pu尺度

当前Droop频率结构不是简单：

```text
Fout = Fref
```

而是类似：

\[
f_{pu}
=
\frac{F_{ref}}{F_{nom}}
-
k_f P_{meas}
+
\frac{k_f}{2}
\]

其中：

\[
k_f = \frac{Frequency\_Droop}{100}
\]

也就是说模板把下垂中心放在：

```text
Pmeas ≈0.5 pu
```

而不是：

```text
P=0
```

所以必须确认：

```text
Frequency_Droop实际值
Pmeas实际范围
Pmeas符号
Pmeas单位
```

是否与当前ESS1运行点一致。

如果尺度或符号错，

Fout就可能偏离预期。

# 38. 但是Droop本身能不能解释“几百Hz”？

如果：

```text

```

是正常几个百分点，

而：

```text
Pmeas
```

也是正常±1 pu附近，

那么Droop只应该造成：

```text

```

而不应该正常地产生：

```text

```

因此如果以后真的测到：

```text

```

那将强烈指向：

```text
单位/尺度错误
Pmeas异常
计算链异常
```

而不是普通合理Droop行为。

# 39. 遗漏点8：其它GFL的PLL在弱岛中可能形成负阻尼

GFL本质上是：

```text

↓
```

在强网里：

```text

↓
```

于是形成一个额外闭环：

```text

→ Current
→ Voltage
→ PLL
```

这个闭环可能表现成：

```text

```

所以：

```text

+
五台GFL
```

也可能一起变不稳定。

# 61. 当前四个问题逐条回答

## 1）是不是因为没有谐波消除、没有提取基波？

**不是当前最可能的主根因。**

模型已经有：

```text
LC物理滤波
PLL
正序功率测量
Second-Order Filter
```

更重要的是：

```text
raw PCC Vabc本身已经出现持续三相振荡
```

所以增加基波提取只能改善“看法”，不能修复真实电压。

---

## 2）是不是ESS1只有一台不够？把它作为源头有问题？

**一台ESS1作为GFM源本身没有概念错误。**

但必须确认：

```text
瞬时电流裕度
调制裕度
GFM参数
网络强度
其它五台GFL交互
```

是否合理。

现在不能通过“再开ESS2 GFM”来跳过根因定位。

---

## 3）还有什么遗漏？

当前最重要的遗漏方向有：

```text
SM/SS分核反馈延时
prim高压侧远端电压反馈
Voltage/Current loop带宽匹配
LC自然谐振与阻尼
GFM-GFL多机交互
GFL→GFM内部状态不连续
Current/Voltage/ModIndex饱和
Vnom_dc固定值
100 μs与4 kHz PWM离散动态
Droop P-f工作点/单位/符号
```

其中：

# **分核反馈延时 + GFM闭环稳定性**

我认为尤其值得提升到最高优先级检查。

---

## 4）肯定是ESS1内部导致的吗？

# **不肯定，而且现在不能这样下结论。**

当前只能确认：

```text
ESS1是孤岛主要GFM
+
J1打开后孤岛PCC波形失稳
```

但根因可能属于：

```text
ESS1内部控制
```

也可能属于：

```text
ESS1 + 分核延时
```

也可能属于：

```text
ESS1 + LC/Transformer/Line
```

也可能属于：

```text
ESS1 + 另外五台GFL
```

即：

# **整个孤岛闭环。**

# 62. 当前最应该冻结的本源判断

> **现阶段不要把问题定义为“谐波太大”，因为谐波/快速分量更可能是闭环失稳的结果；也不要把问题定义为“ESS1数量少”，因为单GFM源架构本身成立；更不能提前断言“ESS1内部一定有bug”。最准确的故障定义是：强网退出后，当前分核实时模型中的GFM源、控制内环、LC/变压器/线路以及五台GFL形成的孤岛闭环缺乏足够动态稳定性，导致持续平衡三相非基波振荡。下一步首先应通过静态参数、延时和理论频率审计缩小机制范围，再安排最小动态取证。**
