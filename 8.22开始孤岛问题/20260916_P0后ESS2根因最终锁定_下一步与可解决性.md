# 0. 结论先行

现在可以把**决定性不稳定来源正式锁定到 ESS2 的 P有功功率外环**。

不是：

- ESS2物理并回；
- Current Adapter（电流参考执行适配器）；
- Current Regulator（电流控制器）；
- Q无功功率外环；
- 四路额外support；
- Coordinator；
- Secondary；
- CurrentLimit；
- 调制裁剪；

而是：

> **P有功功率外环一接入，在 Pref 实际仍为0的情况下，就把原本会衰减的弱孤岛低频摆动变成不断增长的负阻尼摆动。**

但还要区分两个层次：

```text
“哪个控制环是问题？”
→ 已经锁定：P有功功率外环

“P有功外环内部究竟是哪一个机制？”
→ 还差一刀：Ki=0 的比例-only试验
```

因此：

> **不再需要做 PQ0，也不需要继续排查Q外环。**

# 4. 当前最准确的物理根因

当前系统本身存在一个：

```text
约0.7~1 Hz
```

的弱孤岛低频摆动。

A0证明：

```text
不加P外环
→ 这个摆动本身有正阻尼
→ 越摆越小
```

P0证明：

```text
加入P外环
→ Pmeas变化
→ P误差变化
→ P PI生成d轴电流参考
→ ESS2真实电流变化
→ 弱孤岛母线V/θ/f变化
→ PLL和Pmeas再次变化
→ P PI再次动作
```

这一整圈在该频率附近产生：

> **negative damping（负阻尼，即每个周期控制器反而向振荡补充能量）**

因此问题本质已经可以写成：

> **ESS2 P有功功率外环与ESS1 GFM构网弱孤岛之间存在低频负阻尼动态交互。**

# 5. P外环内部又看到什么

当前P外环：

```text
Kp = 0.06
Ki = 2
```

P0的真实关系可以从记录量精确验证：

```text
Raw Id reference
=
0.06 × (Pref - Pmeas)
+
PIntegral
```

数值残差接近机器精度，说明我们确实看到了真实P PI输出组成。

P0 state6之后：

```text
比例项最大量级：
0.06 × |Perror|max
≈ 0.00192 pu

PIntegral最大绝对值：
≈ 0.01010 pu

Raw Id最大绝对值：
≈ 0.01046 pu
```

即：

```text
积分项最大幅值
≈ 比例项最大幅值的 5.3 倍
```

所以当前最强的**内部嫌疑**已经是：

> **P有功外环的积分作用。**

但这还不能直接写成：

> “Ki=2已经被证明一定错误。”

原因是：

> 积分量很大可以是形成负阻尼的关键原因，也可能是整个不稳定闭环中的主要参与者。

要完成最后区分，需要一次最小试验。
