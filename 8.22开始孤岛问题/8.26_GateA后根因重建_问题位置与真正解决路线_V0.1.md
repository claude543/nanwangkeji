# 2. 我独立复核后发现：旧窗口关于 F9（第九轮映射修正）的表述需要升级

## 2.1 当前 Voltage Regulators（电压调节器）的真实结构

当前 `ESS1_Control/Voltage Regulators（ESS1控制/电压调节器）`：

```text
u1 = PI(Vq_ref - Vq)

u2 = PI(Vd - Vd_ref)
```

当前输出 Mux（多路复用器）：

```text
legacy vector（原始向量）
=
[u1, u2]
```

后面的 Current Regulator（电流调节器）又把两个元素当成：

```text
[Id_ref, Iq_ref]
```

所以当前真实关系是：

```text
Id_ref = PI(Vq_ref - Vq)

Iq_ref = PI(Vd - Vd_ref)
```

这一点是模型静态结构事实。

---

## 2.2 但这并不等于“MathWorks原模型写错了”

这一点非常重要。

MathWorks Support Team（MathWorks技术支持团队）对其 `MicroGrid Islanded Operation（微电网孤岛运行）` 示例中的**完全相同问题**做过解释。

该示例本来就是：

```text
Vd_ref = 0
Vq_ref ≈ 1 pu

P = Vq*Iq + Vd*Id
Q = Vq*Id - Vd*Iq
```

当：

```text
Vd ≈ 0
Vq ≈ 1
```

时：

```text
P ≈ Vq*Iq

Q ≈ Vq*Id
```

因此示例用：

```text
Vq误差
→ Id_ref
→ 改变Q（无功功率）
→ 改变PCC电压
```

这属于：

# 基于无功—电压关系的交叉轴调压思想。

所以不能再写成：

```text
原始Voltage Regulator（电压调节器）就是明显接错线
```

这不是准确结论。

# 3. 真正发生问题的位置：F2（第二轮快速反馈修正）改变了被控对象

## 3.1 原控制器调的是什么

MathWorks（数学软件公司）原型中，Measurements（测量模块）计算的是：

```text

```

Voltage Regulators（电压调节器）通过：

```text

```

间接调节该电压。

因此：

```text
Vq误差 → Id
Vd误差 → Iq
```

至少有它原始的物理逻辑。

也就是说当前控制目标已经变成：

这和“通过无功改变PCC电压”是两个不同的控制对象。

# 4. 对本地滤波电容电压，正确动力学是什么

当前 B2（第二轮电容预接管试验）已经用实际数据验证：

```text
Bc ≈ 0.05 pu（标幺值）
```

在当前 dq（旋转坐标系）定义下，电容同步电流满足：

```text
iC_d ≈ -Bc * Vq

iC_q ≈ +Bc * Vd
```

更完整地写：

```text
iC_d
=
(Bc / wb) * dVd/dt
-
Bc * Vq

iC_q
=
(Bc / wb) * dVq/dt
+
Bc * Vd
```

因此如果要直接控制：

```text
Vd
Vq
```

电流参考应该分成三部分：

```text
第一部分：
同轴电压误差反馈

第二部分：
电容旋转坐标交叉耦合补偿

第三部分：
输出/负载电流前馈（可选）
```

即更标准的结构是：

```text
Id_ref
=
PI_d(Vd_ref - Vd)
+
iout_d
-
Bc*Vq

Iq_ref
=
PI_q(Vq_ref - Vq)
+
iout_q
+
Bc*Vd
```

当前第一轮并不需要立刻加 `iout（输出电流）` 前馈。

# 5. 为什么当前 legacy（原始）映射在 Vref=0 时尤其危险

Gate A（自治成岛验证关卡）0～0.5 s：

```text
Vd_ref = 0
Vq_ref ≈ 0
```

所以当前 Voltage PI（电压比例积分控制器）近似变成：

```text
u1 ≈ -K * Vq

u2 ≈ +K * Vd
```

而它直接形成：

```text
[Id_ref, Iq_ref]
≈
[-K*Vq, +K*Vd]
```

注意这个方向。

它不是：

```text
“电压大了就沿同一方向把电压压回去”
```

而是一个约90°旋转的电流作用。

# 8. 如果做 `[-u2,+u1]` 会发生什么

定义：

```text
u1 = PI(Vq_ref - Vq)

u2 = PI(Vd - Vd_ref)
```

则：

```text
Id_pi = -u2
Iq_pi = +u1
```

即：

```text
corrected（修正）PI vector（PI向量）
=
[-u2,+u1]
```

在 Gate A（自治成岛验证关卡）的 `Vref=0` 阶段：

```text
Id_pi ≈ -K*Vd

Iq_pi ≈ -K*Vq
```

这才变成：

# 电压出现偏差时，控制器产生与电压偏差方向相反的电流作用。

同一批 `20~80 ms` 数据如果只进行数学重排：

```text
corrected（修正）径向分量
≈ -2.83e-3
```

而正交分量：

```text
≈ -6.0e-5
```

即原来主要是“旋转作用”，修正后主要变成“径向负反馈”。

这就是为什么 `[-u2,+u1]` 是目前非常强的候选。

# 23. 40 Hz 和 527 Hz 到底怎么定位

它们现在都应该理解成：

# 被控制器激发的物理共振位置，而不是首要能量来源。

来自当前真实被动岛网中：

```text

+
六台Transformer magnetizing branch（变压器励磁支路）
```

的低频网络模态量级。

## 约527 Hz

来自：

```text
L1
Transformer leakage（变压器漏抗）
Stubline（分割线模型）
C1
```

的中高频LC模态。

这些模态存在本身不是错误。

真正的问题是：

```text

还是负阻尼。
```

# 30. 最终判断

现在已经不应该把当前问题概括成：

```text
“GFM参数没调好”
```

也不应该简单概括成：

```text
“Voltage Regulator两个轴接反”
```

更准确的是：

> **当前 K26_V5 的 ESS1 基本GFM问题，是在 F2 把快速反馈改成本地电容电压/电感电流以后，仍然保留了原 MathWorks 微电网示例面向PCC电压—无功关系设计的交叉轴 Voltage Regulator。Gate A的数据证明，在零电压参考下，这套混合结构产生的 Voltage PI 电流参考几乎完全是相对电压向量90°旋转的作用，而不是直接压制电压幅值的径向负反馈；F7=1 又使电流环变流器电压高度跟随本地电容电压，因此小扰动有机会通过离散电流环和被动LC网络获得负阻尼并自行增长。真正解决应当先用一次零Build的Voltage-PI整条切除实验确认这条路径是否为自激必要条件；确认以后，再把本地Voltage Loop重构成同轴电压误差PI `[-u2,+u1]`，随后加入B2已经验证正确的电容同步电流补偿 `[-Bc*Vq,+Bc*Vd]`。如果这样仍有窄频增长，再进入F7/Current Loop/output-impedance层。这样才能把基本GFM从结构上修正确，而不是继续靠F6/F8或参数扫描把振荡压住。**

## 外部核验依据

1. MathWorks Support Team（MathWorks技术支持团队）对 `MicroGrid Islanded Operation（微电网孤岛运行）` 示例说明：示例中的 `Vq误差→Id_ref` 交叉映射是基于 `Q-V（无功—电压）` 关系的设计，并非简单接线错误。
2. 常规 cascaded GFM voltage-current control（级联构网电压—电流控制）文献中，本地电容电压外环通常采用同轴 `Vd/Vq` 电压误差 PI（比例积分控制器），并加入 `[-ωC Vq,+ωC Vd]` 电容交叉耦合补偿以及可选负载电流前馈。
3. 当前模型 B2（第二轮电容预接管试验）已经独立验证本项目的电容同步电流符号正是 `[-Bc*Vq,+Bc*Vd]`。
