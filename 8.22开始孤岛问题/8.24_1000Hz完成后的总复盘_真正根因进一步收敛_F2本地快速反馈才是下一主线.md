# 4. 但1000 Hz为什么反而又出现很强的快速模态？


> **1000 Hz减少了相位滞后，但同时也让更多LC/快速模态能量进入控制反馈，原本被800 Hz压低的一部分快速动态又重新增强。**

```text

但相位滞后大

相位滞后变小
但快速模态进入控制器更多
```

800 Hz在这两者之间表现得“最不坏”，但仍然远远没有稳定。

# 10. 第一：反馈经过显式Memory和跨任务接口

基本步：

```text
Ts = 100 μs
```

当前异常在dq中约：

```text
~480 Hz
```

一个100 μs纯延时在480 Hz对应相位：

```text
360 × 480 × 0.0001
≈ 17.3°
```

仅仅：

```text
一个Memory
+
一个Vpwm Unit Delay
```

两个明确的一步离散环节，就已经是约：

```text
2 × 17.3
≈ 34.6°
```

还没有算：

```text
OpComm / task scheduling
Filter
PI
PWM/ZOH
Plant
```

所以：

> **即使把500 Hz Filter从-88°降到1000 Hz下约-45°，整个快速闭环的总相位代价依然可能很大。**

这和1000 Hz仍然失稳完全一致。

---

# 11. 第二：Current Regulator用的不是逆变器侧电感电流

当前正式V/I反馈来自：

```text
prim_ESS1
```

而电气路径是：

```text
Converter
↓
inv
↓
L1
↓
C1节点
↓
Stubline
↓
Transformer
↓
prim_ESS1
```

所以正式Current Regulator看到的电流已经位于：

```text
LC电容支路之后
```

而不是：

```text
L1中的逆变器侧电感电流 iL
```

---

# 12. 这为什么是一个非常本质的问题？

对于典型的：

```text
Converter
→ L
→ C
→ Network
```

级联Voltage/Current GFM，

最自然的快速状态是：

```text
Voltage loop：
测电容电压 vC

Current loop：
测电感电流 iL
```

原因：

```text
Current loop
直接控制L中的电流
↓
Voltage loop
通过iL给C充放电
↓
形成受控vC
```

这是一个清楚的：

```text
iL → vC
```

两层快速能量链。

# 22. 如果Current Loop改成iL，Rff/Lff也必须对应L1

当前物理：

```text
L1：
R = 0.003456 Ω
L = 0.000916732472209 H
```

低压100 kVA、480 V基准：

```text
Zbase
= 480² / 100000
= 2.304000 Ω
```

所以：

```text
R_L1_pu
= 0.003456 / 2.304000
= 0.001500 pu
```

50 Hz：

```text
X_L1_pu
= 2π50L / Zbase
= 0.125000 pu
```

也就是：

```text
Rff_local ≈ 0.0015
Lff_local ≈ 0.125
```

而当前：

```text
Rff = 0.004
Lff = 0.21
```

更像是把：

```text
L1
+
Transformer/Stubline等外部串联阻抗
```

一起纳入远端控制。

所以：

> **如果F2把Current Loop真正移到本地iL，就不能机械沿用0.004/0.21的前馈参数。**

F2不是把整个Measurements全部换成本地。

应保持：

```text
prim_ESS1高压侧
↓
P_meas / Q_meas
↓
Droop
```

原因：

```text
Droop是慢速系统层控制
需要看实际向外送出的高压侧功率
```

而：

```text
vC / iL
```

只服务：

```text
Voltage/Current fast loop
```

这正是“快慢解耦”。

# 36. 当前根因的最新版表述

到现在最准确的版本已经可以升级为：

> **系统约527 Hz的LC/网络自然模态本身并不是错误。真正问题是，当前RT-LAB实时化后的ESS1 GFM快速Voltage/Current Loop仍使用位于LC、Stubline和Transformer之后的 `prim_ESS1` 高压侧V/I，并通过SM侧Memory与跨任务接口返回SS控制器；因此毫秒级快环既没有直接使用LC的本地状态 `vC/iL`，又叠加了100 μs级离散时序。500 Hz正式测量滤波进一步造成显著相位滞后。500→800→1000 Hz实验证明改变Filter会显著移动不稳定模态，但任何截止频率都不能恢复50 Hz孤岛；裸比例电容电流AD的正负极性也都不能修复，说明问题不是一个单参数或简单符号问题。当前最高优先级根因已经从“500 Hz滤波参数”上升为“GFM快速反馈架构与LC状态/数字延时不匹配”。**
