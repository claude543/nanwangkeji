# 3. 为什么527 Hz解决了很多，系统反而还是12 kV？

因为新问题已经不在高频带宽，而在：

# **Voltage PI的内部状态没有在GFL→GFM frame切换时重置/无扰切换。**

这是本轮最重要的新结论。

---

# 4. 模型结构直接解释这个现象

最新SLX中的Voltage Regulators：

```text
PI regulator with anti-windup 1
→ Mux input1
→ Id_ref

PI regulator with anti-windup 2
→ Mux input2
→ Iq_ref
```

PI1误差：

```text
Vq_ref - Vq
```

PI2误差：

```text
Vd - Vd_ref
```

两路PI都有：

```text
ExternalReset = level
InitialCondition = 0
```

但顶层：

```text
Vreg_on
```

是一个始终为1的Constant。

Voltage Regulators内部的Reset逻辑是：

```text
On=1
→ Reset=0
→ PI正常积分、绝不复位

On=0
→ Reset=1
→ PI积分状态回Init=0
```

因此当前模型实际上：

# **Voltage PI从并网/GFL阶段开始就一直处于活动状态，并且从未在进入GFM时重置。**

---

# 5. 为什么以前Kp=2/Ki=14时这个问题不明显？

GFL阶段：

```text
fast feedback使用remote frame
Vd≈1
Vq≈0
```

但Voltage Regulator的目标仍是：

```text
Vd_ref≈0
Vq_ref≈约1
```

所以两个Voltage PI在GFL阶段会积累很大的内部状态。

20 s进入GFM以后，feedback frame突然改为local：

```text
理想local：
Vd≈0
Vq≈1
```

但是PI内部状态并不会一起改变。

原参数：

```text
Ki=14
```

很大，所以进入GFM以后旧状态能在1～2 s量级快速释放。

上一轮24.9 s已经回到：

```text
Vd≈-0.0001
Vq≈0.9792
Id_ref≈-0.5047
Iq_ref≈0.5286
```

因此25 s开J1时，至少进入了相对正确的GFM工作点。

```text

```


```text

```

# 10. 对此前根因结论应该怎么更新

```text

导致Voltage outer loop带宽过高
在dq≈470 Hz附近形成负阻尼
```

```text

↓

↓
不再出现向527 Hz不断爬升的快速模态
```

因此：

# **Voltage PI带宽过高仍是原527 Hz问题的主因。**

但把这个主因修掉以后，又暴露了一个此前被大Ki掩盖的模式切换问题：

```text
GFL期间Voltage PI一直积分
+
GFL和GFM使用不同feedback frame
+
进入GFM时PI state不reset / 不bumpless initialize
+
新的Ki=0.14不能快速冲掉旧state
```
