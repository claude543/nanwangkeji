# V4.8 q-bias 原理与电压/无功快慢层级说明

日期：2026-09-18

## 1. 为什么旧电压二次控制不够

旧路径：

```text
PCC电压误差
→ dVSecondary
→ VsupportRef
→ local slow-q
→ Iq
```

问题不是“没动作”，而是：

```text
dVSecondary 已经打到限制
但电压仍然偏高
```

说明旧方案通过修改一个“电压支撑参考”间接影响Q，链路长、权限受限，而且不容易建立一个稳定、可保持的无功工作点。

所以V4.8改为：

```text
PCC慢速电压偏差
→ 中央q-bias积分
→ 直接得到需要的q轴电流偏置
→ 各GFL本地执行
```

核心目的是：

> 建立一个可以长期保持的稳态无功工作点。

---

## 2. q轴电流为什么能调电压

在GFL的同步旋转dq坐标系里，如果d轴与电网电压主方向对齐：

```text
d轴电流
主要对应有功P

q轴电流
主要对应无功Q
```

符号正负取决于模型约定。

本项目已经冻结的方向是：

```text
母线电压偏高
→ 需要positive q-axis correction
```

q轴电流改变后：

```text
无功交换改变
↓
线路/变压器/滤波器上的无功压降改变
↓
母线电压幅值改变
```

所以 q-bias 不是“直接把电压改掉”，而是：

```text
V误差
→ 调Q
→ Q改变网络电压
```

---

## 3. 为什么要“bias（偏置）”

电压稳定在目标附近时，系统可能仍然需要一个非零Q。

例如：

```text
V已经≈1 pu
```

不代表：

```text
Q必须=0
```

因为网络、变压器、滤波器和负荷本身可能需要持续无功支撑。

如果只做瞬时比例式支撑：

```text
电压误差→0
↓
支撑量也→0
```

那么原来维持电压所需的Q会消失，电压又会偏回去。

q-bias的积分状态可以：

```text
误差存在时慢慢积累
↓
找到一个合适的非零Iq
↓
误差变小后仍保留这个Iq
```

所以它能建立“稳态工作点”。

---

## 4. 为什么要中央计算

不是为了让中央去做快速控制。

中央只做非常慢的系统级协调。

原因：

### 4.1 电压目标是公共母线目标

多个GFL面对的是同一个孤岛母线电压。

如果每台设备都各自独立积分同一个电压误差：

```text
PV自己积分
ESS自己积分
EV自己积分
```

容易出现：

```text
重复积分
相互抢调节
总Q过量
积分状态打架
```

### 4.2 中央只维护一个总需求

```text
QbiasTotal
```

回答：

> 整个孤岛一共还需要多少额外q轴电流偏置？

然后各设备本地根据自己能力执行。

### 4.3 本地能力仍由本地判断

每台GFL的Finalizer返回：

```text
正方向还能提供多少
负方向还能提供多少
实际已经执行多少
调制余量
是否被限幅
```

中央不自己猜设备还能出多少。

所以结构是：

```text
中央：
算“总共需要多少”

本地：
算“我最多能做多少、实际做了多少”
```

这样比五台各自闭门积分更稳定、更容易统一限制。

---

## 5. 为什么这个结构理论上更有效

它解决了旧方案的三个根本问题：

### 问题1：旧方案太间接

旧：

```text
V误差
→ 改VsupportRef
→ slow-q
→ Iq
```

新：

```text
V误差
→ q-bias
→ Iq
```

新的稳态通道更直接。

### 问题2：旧方案不容易保持非零稳态Q

新方案有一个明确积分状态：

```text
QbiasTotal
```

可以在误差消失后保持需要的Iq。

### 问题3：多GFL容易重复调节

新方案中央只有一个active voltage-restoration integrator，再结合每台设备的能力反馈统一分配。

## 6. 电压/无功并不是“只有慢速控制”

当前系统至少有三层：

### 第一层：最快速——ESS1 GFM电压环/电流环

```text
Voltage Reference
→ Voltage Loop
→ Current Reference
→ Current Loop
→ Converter
```

这是母线真正的快速建压和瞬时稳定层。

黑启动时电压首先靠它。

### 第二层：局部电压支撑——GFL bounded voltage support

原计划孤岛已经存在：

```text
local Vpu deviation
→ bounded q-axis voltage support
```

Stage2中曾设计为：

```text
bounded voltage support
+
vector current capability
```

参数层面约1 Hz量级。

它属于局部、受限、较快的辅助支撑。

### 第三层：最慢——V4.8 central q-bias

```text
PCC慢速电压误差
→ q-bias积分
→ 稳态Iq偏置
```

原设计的电压误差低通只有约0.10 Hz，目的就是只处理“慢慢偏掉的稳态电压”，不去抢快速动态。

---

## 7. 为什么P-f和V-Q看起来不是完全对称的“一次/二次”

它们功能上是对应的，但实现形式不同。

### 有功/频率

```text
ESS1 GFM快速承担
↓
Primary P-f
↓
Frequency Secondary
```

### 电压/无功

```text
ESS1 GFM快速电压环
↓
GFL局部bounded voltage support（可选/按阶段）
↓
中央q-bias慢速电压恢复
```

所以并不是：

```text
P-f有快慢
V-Q只有慢
```

而是：

```text
V-Q的快速层主要在ESS1 GFM本地
慢速稳态恢复才由q-bias负责
```

这正是分层控制。

---

## 8. 对当前黑启动的含义

下一版不应该让q-bias承担快速建压。

正确顺序：

```text
ESS1先把母线建起来
↓
ESS2恢复并接管P
↓
Primary / Frequency Secondary工作
↓
系统进入稳定孤岛
↓
q-bias再慢慢建立需要的稳态Q
```

因此q-bias更像：

> “把ESS1已经托住的电压，从‘能稳定运行’进一步恢复到更理想的长期工作点，并把一部分Q责任转移给已恢复GFL。”

这就是它在黑启动完成阶段最合理的角色。
