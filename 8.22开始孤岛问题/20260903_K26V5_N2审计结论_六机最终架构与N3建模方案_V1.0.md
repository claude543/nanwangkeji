# K26_V5｜N2 联合审计结论、六机最终控制架构与下一步稳定性建模方案 V1.0

> 日期：2026-09-03

> 当前角色：ESS1 为唯一构网主机；PV1、PV2、ESS2、EV1、EV2 保持电流控制型跟网设备  
> 依据：最新 V2 模型、V1/V2 正式运行证据、V4.0/V4.1 交接、N1/N2 编译态只读审计

# 0. 结论

## 0.1 现在已经可以进入架构级重构

当前问题已经不再是：

```text
不知道哪个模块坏了
```

而是已经锁定为：

```text
五台跟网设备原有的强网型端口与功率控制
不适合直接运行在
单台有限能力构网主机支撑的孤岛中
```

原有 10～17 Hz 快速失稳路径已经由历史因果试验锁定；V2 又证明，把快速/慢速电压前馈和功率误差动态全部强制关闭，也不能自动形成稳定孤岛。

因此下一版必须重构：

1. 六台设备在并网、离岛准备、孤岛和重新并网中的职责；
2. 五台跟网设备的岛态有功控制；
3. 五台本地电压支撑；
4. 慢、快电压前馈；
5. 总电流能力分配；
6. 下游限流反馈到上层控制；
7. 新的岛态慢速功率协调；
8. 统一状态机；
9. 重同步和合闸后的控制交接；
10. 数据记录。

## 0.2 现在还不能直接执行最终改模

结构已经可以冻结，但下列参数不能凭经验写死：

```text
慢电压前馈比例
慢、快电压分量的分界频率
本地电压支撑强度
ESS2 有功—频率响应强度
EV 减充电响应强度
PV 削减或增发响应强度
岛态慢速功率协调增益
ESS1 下垂和参考修正配合关系
```

下一步先用 MATLAB/Simulink 导出最新模型的精确数值合同，再建立离线平均模型和小信号模型。参数稳定范围确定后，才生成一次性事务式改模脚本。

## 0.3 现在不运行当前 V2

当前 V2 的第二阶段仍是诊断隔离状态；第三阶段只是恢复旧并网功率命令。无论强行打开第三阶段，还是再设置一个慢电压前馈比例，都不是完整孤岛控制器。

下一次 RT-LAB 运行应当发生在：

```text
完整控制结构
+
参数稳定范围
+
最终改模
+
编译与持久化审计
```

全部完成以后。

# 2. 审计确认的决定性结构事实

## 2.1 每台设备现有 12 维控制输入的准确含义

每台设备当前输入向量固定为：

| 索引 | 信号 | 中文含义 |
|---:|---|---|
| 1～3 | `Vabc` | 本机三相端口电压 |
| 4～6 | `Iabc` | 本机三相端口电流 |
| 7 | `Fref` | 频率参考 |
| 8 | `Vref` | 电压参考 |
| 9 | `Droop` | 构网下垂模式/使能 |
| 10 | `Pref` | 有功参考 |
| 11 | `Qref` | 无功参考 |
| 12 | `GridOn` | 跟网/构网模式选择 |

每组两台设备组成 24 维输入：

```text
PV1 + PV2 = 24
ESS1 + ESS2 = 24
EV1 + EV2 = 24
```

这意味着下一版可以复用原来的：

```text
Fref
Vref
Pref
Qref
```

传递新的岛态参考，不需要为这些信号另建一套重复通道。

## 2.2 ESS1 构网频率和电压已经到达中央任务

ESS1 构网模块：

```text
K26_V5
└─ SS_Slave2
   └─ ESS1_Control
      └─ Droop Control
         ├─ 输出1：Vout，构网电压目标
         ├─ 输出2：theta_out，构网相角
         └─ 输出3：Fout，构网频率
```

现有诊断向量中：

```text
ESS1 诊断第17路 = Fout
ESS1 诊断第18路 = Vout
```

其真实路径为：

```text
ESS1_Control/AA15_D1_FAST_DIAG_MUX18
↓
SS_Slave2/Mux
↓
SS_Slave2 → SM_Master 的现有 30 维返回向量
↓
SM_Master/Demux1
↓
SM_Master/AA15_D1_FAST_DEMUX18
```

因此：

```text
ESS1 Fout、Vout
已经可以在中央任务中使用
无需扩大 ESS1 → 中央任务的 30 维向量
```

## 2.3 五台设备当前仍使用本机锁相坐标

五台设备的实际执行频率和相角来自：

```text
各设备/Measurements/AA15_PLL_EXEC_FRAME_HOLD
```

中文作用：

> 本机锁相环正常时跟踪端口电压；低压时保持或自由运行，避免锁相角被失真电压带乱。

本机相角同时被以下位置使用：

1. 三相电压、电流转换到旋转坐标；
2. 有功、无功计算；
3. 对外诊断；
4. 最终 PWM 电压参考的执行相位链。

因此，若以后直接改用 ESS1 数字相角，不能只改一个坐标变换模块，必须同时替换所有测量、功率计算和 PWM 执行相位消费者。

---

## 2.4 第一版最终重构不直接广播 ESS1 相角

这一决定不是忽略 ESS1 相角。

孤岛时：

```text
ESS1 产生母线电压波形和物理相角
↓
五台设备本机锁相环测量该母线电压
↓
五台实际仍然跟随 ESS1 建立的相角
```

只是没有通过跨任务数字信号直接发送 `theta_out`。

第一版不直接广播相角的原因：

1. 五台正常坐标为 `Vd≈1 pu、Vq≈0`；
2. ESS1 构网电压环历史上使用 `Vd≈0、Vq≈1 pu`；
3. ESS1 内部存在 -120° 同步补偿和 -30° PWM 执行相位补偿；
4. `theta_out` 不是 ESS1 最终 PWM 相位链的全部；
5. 五台各自的固定偏置尚未被证明；
6. 跨任务直接发送角度还会引入环绕、延迟和所有消费者同步切换问题；
7. 历史 B1 已证明本机锁相动态不是原快速失稳的必要根因。

第一版采用：

```text
相角：
五台继续通过本机锁相环跟随 ESS1 建立的母线

频率：
显式接收 ESS1 Fout，用于有功—频率响应

电压目标：
显式接收 ESS1 Vout，用于构造本机电压支撑目标
```

如果最终一次控制稳定后，证据仍指向五个本机锁相环造成限制，再设计第二版公共相角。届时应传递：

```text
sin(theta_ESS1)
cos(theta_ESS1)
有效标志
```

而不是直接传递会在 0 与 2π 之间跳变的裸角度。

## 2.5 当前设备角色参数没有参与控制

五台管理模块都包含：

```text
AA15_P_ROLE
（设备角色参数）
```

当前取值：

```text
PV1/PV2 = 1
ESS2    = 2
EV1/EV2 = 3
```

但当前 V2 改模中，该参数直接连接到：

```text
AA15_ROLE_TERM
（终止模块）
```

所以角色参数只作为身份标记，没有进入控制律。

当前五台设备实际上使用几乎相同的孤岛控制，只是电压支撑电流上限不同：

```text
PV：0.20 pu
ESS2：0.30 pu
EV：0.15 pu
```

这是下一版必须纠正的结构缺陷。

## 2.6 当前第二阶段和第三阶段都不能作为最终岛态

当前本地状态核心的真实逻辑：

```text
阶段0：
原并网控制完全旁路

阶段1：
慢电压前馈目标 = 0
快速电压前馈目标 = 0
功率误差动态比例 = 0

阶段2：
慢电压前馈 = Kslow_stab
快速电压前馈 = Kfast_island
功率误差动态比例仍然 = 0

阶段3：
本机达到健康条件后
才逐步恢复旧 Pref/Qref 的误差跟踪

阶段4：
恢复原并网控制
```

问题有三项：

1. 阶段1把慢、快电压前馈都压到 0，不是最终孤岛准备状态；
2. 阶段2长期不具备设备差异化有功响应和岛态慢速协调；
3. 阶段3恢复的是旧并网功率目标，不是新的岛态功率目标。

下一版应废除“先长期极端隔离、健康后恢复旧功率”的控制哲学。

---

## 2.7 当前总电流限制采用固定无功支撑优先

现有总电流限制器在孤岛阶段执行：

```text
先完整保留 q 轴电压支撑电流
↓
再按同一比例缩小原有功/无功电流
↓
保证最终电流向量不超过 Imax
```

该结构能够保证总电流参考有界，但固定优先级不适用于所有资源和所有工况。

例如欠频时：

```text
ESS2：
需要保留有功放电能力

EV：
应先减少充电，而不是让下游限流被动削减

PV：
可以削减有功，给无功支撑释放电流能力
```

下一版要按资源角色和系统状态分配有功、无功电流能力，不能所有设备始终采用相同的“无功支撑绝对优先”。

---

## 2.8 当前下游限流没有反馈给上层功率积分器

当前链路：

```text
Power Control Loop
（原有功/无功控制器）
↓
原始电流参考
↓
AA15_ISLAND_GFL_SUPPORT_MANAGER
（V2 孤岛管理模块）
↓
总电流限制
↓
最终电流参考
↓
Current Regulator
（电流调节器）
```

原有功/无功控制器有自身内部防积分饱和，但看不到下游总电流限制的缩放结果。

下一版必须输出：

```text
有功电流实际执行比例 gP
无功电流实际执行比例 gQ
或
请求电流与最终电流的差值
```

再用一个计算步延迟反馈给上层控制，避免形成直接代数环。

---

## 2.9 当前重同步只完成了基础骨架

现有重同步包括：

```text
AA15_S15_SYNC_PHASE_ESTIMATOR
（两侧相位估计）

AA15_S15_Recovery_Manager
（重同步状态管理）

AA15_S15_Master_Fref_Router
（构网主机频率修正）
```

当前过程：

```text
孤岛 + 恢复请求
→ 保持 J1 打开
→ 调整 ESS1 频率参考
→ 电压差/频率差/相角差持续满足
→ 合上 J1
→ 保持约 0.2 s
→ 直接命令恢复正常并网模式
```

现有缺陷：

1. 两侧相位有效判据只检查原始电压幅值是否大于 1，量纲上过于宽松；
2. 相位来自原始三相电压的瞬时 Clarke/atan2 计算，缺少最终合闸所需的滤波和正序质量判据；
3. J1 合闸后约 0.2 s 就直接回正常模式；
4. ESS1 从构网回跟网的反向无扰交接从未验证；
5. 岛态一次控制、岛态慢速协调和 PCC 功率协调如何交接尚未纳入。

计划离岛成功不能使这些问题自然消失。

# 3. 六台设备最终职责

## 3.1 ESS1：唯一构网主机

ESS1 负责：

```text
形成母线电压波形
形成频率
形成相角
承担离岛瞬间的剩余有功和无功不平衡
为五台设备提供构网频率和电压目标
```

第一版保持已经验证的：

```text
F21：ESS1 电流调节状态交接
F24：构网频率/电压参考交接
F25：输出电流责任交接
ESS1 当前构网电压环、电流环和下垂主结构
```

但需要增加或明确：

1. `Fout` 和 `Vout` 的中央控制使用；
2. ESS1 实际有功、无功和能力余量；
3. 岛态长期希望承担的有功/无功偏置；
4. 合闸后继续保持构网的时间；
5. 构网回跟网的反向无扰交接。

ESS1 不作为岛态慢速协调中的普通被分配设备。

---

## 3.2 ESS2：主要双向有功支撑设备

ESS2 仍是电流控制型跟网设备。

孤岛有功行为：

```text
ESS1 频率低于额定值
→ ESS2 增加放电或减少充电

ESS1 频率高于额定值
→ ESS2 减少放电或增加充电
```

ESS2 是五台中最适合承担：

```text
快速双向有功支撑
+
岛态慢速功率转移
```

的资源。

最终限制必须来自：

```text
SOC
实际充放电功率上下限
总电流能力
允许功率变化速度
```

当前模型为理想直流源，真实电池动态没有完整建模，因此下一版至少要建立明确的“控制能力合同”，不能把理想直流源等同于无限储能能力。

---

## 3.3 PV1/PV2：可限发的跟网发电设备

孤岛时：

```text
频率偏高、发电过剩
→ 削减光伏有功

频率偏低、发电不足
→ 只有当前可用最大功率高于现有工作点时才能增加有功
```

当前没有完整证明光伏的实时可用最大功率和向上余量。

因此第一版安全规则：

```text
默认不承诺光伏向上增发
允许在过频、过压或电流能力不足时削减有功
```

后续若审计确认 `Ppvmax`（光伏当前可用最大功率）真实有效，再开放欠频增发。

光伏仍可在总电流允许时提供无功电压支撑。

---

## 3.4 EV1/EV2：可调充电负荷

当前项目有功符号：

```text
设备正有功：向交流系统送电
设备负有功：从交流系统吸收功率
```

EV 当前控制范围为：

```text
-1 pu：最大充电
0：停止充电
```

没有经过验证的正有功反向放电能力。

因此第一版：

```text
欠频或明显欠压
→ EV 充电功率向 0 方向移动，减轻岛内负荷

过频或功率过剩
→ 在允许范围内增加充电
```

EV 不按车辆向电网反送电设计。

# 4. 最终控制方程框架

以下只冻结结构，不提前写死增益。

## 4.1 切岛前工作点捕获

每台跟网设备捕获：

\[
P_{0,i},\quad Q_{0,i},\quad V_{0,i},\quad
V_{\mathrm{anchor},d,i},\quad V_{\mathrm{anchor},q,i}
\]

ESS1 同时捕获：

\[
V_{\mathrm{ESS1},0},\quad
P_{\mathrm{ESS1},0},\quad
Q_{\mathrm{ESS1},0}
\]

所有捕获必须由模型内部统一状态触发，并有确认信号，不能依靠 Host（上位机）异步轮询样本作为边沿真值。

---

## 4.2 五台本地电压参考

建议：

\[
V_{\mathrm{ref},i}^{\mathrm{local}}
=
V_{\mathrm{ESS1,out}}
+
\left(
V_{0,i}-V_{\mathrm{ESS1},0}
\right)
\]

含义：

```text
ESS1 的全局构网电压目标发生变化
→ 五台一起知道

每台原本由线路、滤波器和变压器造成的正常电压偏差
→ 继续保留
```

必须显式处理单位：

```text
ESS1 Vout 很可能为标幺值
设备输入 Vref 当前为伏特
```

所以中央路由应明确执行：

\[
V_{\mathrm{ref,send}}[\mathrm{V}]
=
V_{\mathrm{ESS1,out}}[\mathrm{pu}]
\cdot V_{\mathrm{nom,prim}}[\mathrm{V}]
\]

不能再次依赖隐式量纲猜测。

---

## 4.3 两频带电压前馈

保留：

\[
V_{\mathrm{ff}}
=
V_{\mathrm{anchor}}
+
K_{\mathrm{slow}}
\left(V_{\mathrm{slow}}-V_{\mathrm{anchor}}\right)
+
K_{\mathrm{fast}}
\left(V_{\mathrm{raw}}-V_{\mathrm{slow}}\right)
\]

其中：

```text
Kfast：
快速端口电压变化的前馈比例

Kslow：
慢速端口电压变化的前馈比例

fc：
快、慢电压分量的分界频率
```

已经可以冻结：

```text
第一版孤岛 Kfast = 0
```

因为原 10～17 Hz 快速失稳必要路径已经被因果试验锁定。

不能冻结：

```text
Kslow
fc
```

两者需要和电流环、电压支撑、有功—频率响应、ESS1 输出特性一起计算。

离岛准备阶段应直接把两者平滑移动到最终孤岛值，不再先把慢电压前馈压到 0、J1 打开后再恢复。

---

## 4.4 按设备角色形成岛态有功目标

统一结构：

\[
P_{i,\mathrm{cmd}}^{\mathrm{isl}}
=
\operatorname{sat}
\left[
P_{0,i}
+
\Delta P_{f,i}
+
\Delta P_{\mathrm{sec},i}
\right]
\]

其中：

- \(P_{0,i}\)：切岛前有功工作点；
- \(\Delta P_{f,i}\)：根据 ESS1 构网频率产生的快速响应；
- \(\Delta P_{\mathrm{sec},i}\)：岛态慢速协调修正；
- `sat`：根据该设备真实上下限约束。

### ESS2

\[
\Delta P_{f,\mathrm{ESS2}}
=
K_{f,\mathrm{ESS2}}
\cdot
\operatorname{DB}
\left(f_{\mathrm{nom}}-f_{\mathrm{ESS1}}\right)
\]

欠频时应得到正向增量。

### EV

EV 当前命令范围为 \([-1,0]\)。

欠频时命令向 0 移动，即减少充电。可写成同一频率误差形式，但最终必须限制在：

\[
-1 \le P_{\mathrm{EV,cmd}} \le 0
\]

### PV

过频时允许削减：

\[
\Delta P_{f,\mathrm{PV}}<0
\]

欠频时只有在：

\[
P_{\mathrm{available}}-P_{0}>0
\]

时才允许增加；否则向上增量为 0。

---

## 4.5 本地电压支撑

建议保留一条清晰、低带宽的本地电压支撑通道：

\[
\Delta I_{q,v,i}
=
-Y_{v,i}(s)
\cdot
\operatorname{DB}
\left(
V_{\mathrm{ref},i}^{\mathrm{local}}-V_i
\right)
\]

符号必须沿用当前 V2 已验证的坐标约定，不能套用通用教材方向。

不要同时加入多个相近带宽的无功调节器。原无功基准保持较慢，本地电压支撑负责较快的电压相关电流。

---

## 4.6 总电流分配不能固定一种优先级

形成三个需求：

```text
有功需求电流
无功基准电流
本地电压支撑电流
```

总电流必须满足：

\[
\sqrt{I_d^2+I_q^2}\le I_{\max}
\]

但优先级按设备和工况变化。

### ESS2

欠频时：

```text
保留必要有功电流
+
保留最低电压支撑电流
+
剩余能力再分配
```

### EV

先从命令层减少充电，避免把本可通过负荷削减解决的问题留给下游电流限幅。

### PV

可通过削减有功释放无功支撑能力。

最终限制器应输出：

```text
gP：有功请求实际执行比例
gQ：无功请求实际执行比例
limit_active：总电流限制是否动作
```

## 4.7 下游限流反馈

为避免直接代数环，使用一个计算步延迟后的执行比例：

\[
P_{\mathrm{ref,toPI}}
=
P_{\mathrm{meas}}
+
g_P[z^{-1}]
\left(
P_{\mathrm{cmd}}-P_{\mathrm{meas}}
\right)
\]

\[
Q_{\mathrm{ref,toPI}}
=
Q_{\mathrm{meas}}
+
g_Q[z^{-1}]
\left(
Q_{\mathrm{cmd}}-Q_{\mathrm{meas}}
\right)
\]

含义：

```text
下游只能执行 70%
→ 上层只追踪可实现的 70%
→ 不再继续把积分器推向无法执行的目标
```

是否还需要额外反算增益，应由最终限流试验和小信号/非线性模型共同决定。

# 5. ESS1 的频率、电压和相角安排

## 5.1 频率

ESS1 `Fout` 是岛态权威频率。

下一版路径：

```text
ESS1 Fout
↓
现有 30 维 ESS 返回向量
↓
SM_Master
↓
各设备现有 Fref 输入
↓
五台有功—频率响应
```

应增加有效标志和备用逻辑：

```text
ESS1 Fout 有效
→ 使用 Fout

Fout 无效或运输异常
→ 暂时使用本机执行锁相频率
→ 同时禁止岛态慢速积分继续累积
```

为避免不同任务中形成不一致的直接环，建议在中央或设备端加入统一的一拍延迟。100 μs 量级的确定性延迟远快于拟设计的有功—频率响应，但其确切影响仍应进入小信号模型。

第一版：

```text

五台本机锁相环跟踪母线
```

4. 相角运输使用正弦/余弦和有效标志；
5. 测量坐标与 PWM 执行坐标同时无扰切换。

# 7. 岛态慢速功率协调的设计边界

不能简单把：

```text
频率误差
+
ESS1 有功误差
```

作为两个互不相关的比例积分输入直接相加。

原因：

```text
ESS1 下垂控制已经把频率和有功耦合
```

如果中央控制器再次独立强力修正两者，可能形成重复积分和控制冲突。

正确流程：

1. 导出 ESS1 当前下垂控制的精确方程和符号；
2. 明确 ESS1 希望长期保持的有功/无功偏置和储备；
3. 根据下垂方程计算使 ESS1 位于目标偏置时对应的频率、电压参考截距；
4. 同时缓慢移动：
   - 五台的慢速有功分配；
   - ESS1 的频率/电压参考截距；
5. 保证最终频率回到 50 Hz，同时 ESS1 回到合理储备点。

这部分必须在下一步数值合同导出后才能写出准确公式。
