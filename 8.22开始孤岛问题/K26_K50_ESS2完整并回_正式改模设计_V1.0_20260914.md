# 2. 两篇新论文给本轮设计带来了什么

## 2.1 论文一

**Comparative Analysis of Grid-Forming Control of Energy Storage Systems for Black-Start（储能系统构网控制黑启动对比分析）**

DOI：

```text
10.1109/PEDG61800.2024.10667408
```

这篇论文真正支持本轮的内容有三点。

### 第一：Black-start（黑启动）本来就是分阶段过程

论文明确按：

```text
Transformer energization（变压器励磁）
→ Load pick-up（负荷投入）
→ Grid synchronization（电网同步）
```

组织黑启动。

这支持我们当前：

```text
ESS1（储能1）先建网
→ ESS2（储能2）再准备并入
→ 先形成电气连接
→ 再恢复功率
```

这种“电气恢复”和“功率责任恢复”分开的做法。

### 第二：Breaker close（断路器闭合）之前应该比较两侧真实电气状态

论文的 Grid Synchronization（电网同步）部分明确要求在断路器闭合前使：

```text
phase（相位）
frequency（频率）
voltage amplitude（电压幅值）
```

相互匹配。

论文算例引用的同步要求为：

```text
phase difference（相位差）≤ 20°
frequency difference（频率差）≤ 0.3 Hz
amplitude difference（幅值差）≤ 10%
```

这些不是我们的通用标准定值，但它非常明确地支持一个原则：

> **不能只看控制器内部认为自己同步了；真正要并接的两个断路器触点节点必须有可信的电气状态比较。**

这直接支持本轮新增真正的 `breaker-inner Vabc（断路器内侧三相电压）` 测量。

### 第三：电流内环在黑启动暂态中非常重要

论文采用 cascaded voltage-current control（级联电压-电流控制），并明确指出单纯电压单环不能很好限制变压器励磁等暂态过流。

我们的 ESS2（储能2）不是同一套 GFM（构网型）控制结构，但这一点仍提供了通用工程支持：

> **电气支路接通以后，不能继续人为禁止本来应该承担快速电流纠偏的底层电流闭环。**

因此它与我们R4已经发现的 `Current PI（电流比例积分调节器）被持续屏蔽` 方向一致。

## 2.2 论文二

**Self-Synchronization Scheme for Network of Grid-following and Grid-forming Photovoltaic Inverters（构网型与跟网型光伏逆变器网络自同步方案）**

DOI：

```text
10.1109/IECON48115.2021.9589752
```

这篇论文对我们的作用必须说准确。

它研究的是：

```text
并网时：
多台逆变器均为 GFL（跟网型）

电网断开后：
DER1（分布式能源1）切为 GFM（构网型）
DER2 / DER3 保持 GFL（跟网型）
```

也就是：

```text
1台 GFM（构网型）
+
多台 GFL（跟网型）
```

形成 single point of synchronization（单一同步参考点）。

这对我们的结构是正面支持：

```text
ESS1（储能1）作为唯一 GFM（构网型）
ESS2（储能2）继续作为 GFL（跟网型）
```

并不是原则上错误。

但必须注意：

> **这篇论文不是“物理断开的GFL（跟网型）怎样重新合闸并回已经建立的孤岛母线”的论文。**

它的 DER2 / DER3（分布式能源2/3）在切岛过程中本来就留在微电网内部，并没有像我们的ESS2那样：

```text
物理断开
→ 待并
→ 再合闸
```

所以它不能直接规定：

```text
ESS2的RestoreHold（恢复保持标志）
Power PI（功率比例积分调节器）
Current PI（电流比例积分调节器）
PLL（锁相环）
```

应该怎样切换。

它只能支持：

> **一台构网主机 + 其他跟网从机的组织方式本身是合理的；不用因为黑启动就把ESS2也改成GFM（构网型）。**

这是历史块命名造成的误导，不是我们现在在修改EV（电动汽车）。

```text

```

名字里虽然有 `EV1（电动汽车1）`，但它们在当前正式模型里实际都属于：

> **ESS2（储能2）物理支路。**

准确含义是：

```text

= 实际为 ESS2（储能2）断路器母线侧三相测量块
```

当前真正的 ESS2（储能2）电气顺序是：

```text

↓
EV1_inv（历史名称，实际为储能2变流器端测量）
↓
```

本轮也**不重命名这两个旧块**，因为改名会无谓影响历史脚本、路径、审计和追溯。

# 10. Executor（执行器）修改：READY（并入前就绪）频率条件

当前：

```text
abs(PLL_Hz - legacy MasterF)
<= DF_MAX
```

问题：

真实R4中：

```text
ESS2 PLL（储能2锁相频率）
≈ actual bus frequency（真实母线频率）
≈ 50.233 Hz

legacy MasterF（旧主频率诊断量）
≈ 49 Hz
```

所以这个判据会用错误参考否决真实同步状态。

修改：

```text
abs(PLL_Hz - fNom)
<= DF_MAX
```

其中：

```text
fNom = 50 Hz
```

注意：

> 这个条件只负责“ESS2（储能2）看到的已建立孤岛母线频率是否处于正常名义范围”。

它**不是**真正的两触点频率同步判据。

真正两侧同步由：

```text
phaseCorr（相位相关度）
+
continuous dwell（连续驻留）
```

来间接保证。

本轮不新增第二个 PLL（锁相环）。

# 13. Executor（执行器）修改：state4（状态4）重新定义

新的状态4中文名称：

> **断路器闭合 + 零电流主动调节**

状态输出必须是：

```text
breakerCmd（断路器命令）= 1
RestoreHold（恢复保持标志）= 0
RestoreAlpha（恢复系数）= 0
```

因此 Current Adapter（电流执行适配器）自动得到：

```text
IrefUsed（实际使用电流参考）
= alpha × FinalIref
= 0
```

```text
ImeasUsed（实际使用电流反馈）
= actual Imeas
= 真实电流
```

```text
MatchActive（输出匹配激活）
= 0
```

于是：

```text
Current error（电流误差）
= 0 - actual Imeas
```

原有 Current PI（电流比例积分调节器）立即恢复纠偏权。

# 14. 为什么 state4（状态4）不再做一次 oldPI match（旧PI输出匹配）

R6已经解析现有 Current Adapter（电流执行适配器）的状态。

待并阶段长期：

```text
error（误差）= 0
match（匹配）= 1
matchTarget（匹配目标）= 0
```

所以电流PI状态已经接近0，并已经完成初始化。

退出 hold（保持）第一拍：

```text
Kp = 0.3
Ki = 20
Ts = 100 us
```

未限幅近似：

```text
rawPI（原始PI输出）
≈ 0.301 × (-Imeas)
+ 0.00664449 × residualPrev（上拍执行残差）
```

因此本轮：

> **不再额外增加“一次 oldPI（旧比例积分输出）匹配”。**

理由：

1. 当前状态已经接近零；
2. 断路器闭合以后最重要的是尽快恢复真实纠偏；
3. 再做多拍匹配反而可能重新压制当前真正需要的电流控制。

# 19. Power Loop（功率控制环）本轮不改

位置：

```text

/SS_Slave2
/ESS2_Control
/Power Control Loop
```

中文职责：

> **ESS2（储能2）有功/无功功率比例积分控制环。**

V0.9旧草案计划增加：

```text
PowerLoopEnable（功率环二值使能）
```

并在 `alpha（恢复系数）>0` 时立刻让 Power PI（功率比例积分调节器）看到完整功率误差。

本V1.0取消这一项。

---

## 19.1 为什么取消

当前已经存在：

```text
P error（有功误差） × RestoreAlpha（恢复系数）
Q error（无功误差） × RestoreAlpha（恢复系数）
→ Power PI（功率比例积分调节器）
```

同时：

```text
FinalIref（最终电流参考）
× RestoreAlpha（恢复系数）
→ Current Adapter（电流执行适配器）
```

这是 double alpha（双重恢复系数）。

它的缺点：

> 早期恢复可能比线性斜坡更慢。

但它有一个非常重要的优点：

> Power PI（功率比例积分调节器）不会在下游实际执行能力仍被强烈限制时，提前对完整功率误差进行大幅积分。

如果改成：

```text
alpha > 0
→ Power PI立即看到完整误差
```

而下游仍：

```text
IrefUsed = alpha × FinalIref
```

那么外环可能不知道下游执行仍受限，形成新的积分积累风险。

本轮没有必要为了“数学上只有一层alpha”引入这个新风险。

所以：

> **本轮保留当前双alpha，先完成安全完整并回。**

后续如果真实数据证明功率恢复过慢，再单独优化恢复律。

两篇论文没有推翻这个方案。

相反：

- 第一篇黑启动论文支持“分阶段恢复 + 闭合前真实同步 + 接入暂态必须有电流调节能力”；

- 两篇都没有证据要求把ESS2（储能2）改成第二台GFM（构网型）；
- 两篇也没有证据要求重新设计我们已经验证过的ESS1（储能1）构网控制。
