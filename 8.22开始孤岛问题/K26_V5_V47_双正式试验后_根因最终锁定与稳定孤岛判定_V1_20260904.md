# 0. 最终结论

现在可以把问题锁到**控制架构层**，不再是“大范围不知道根因”。

真正的结论不是：

> “之前 Q PI 判断错了。”

而是：

> **原增长型慢失稳的主要首发机制已经被 V4.7 锁定并实质消除；当前剩余失败来自孤岛 Q/V 稳态调节架构不完整，随后又触发真实调制裕度不足。**

因此现在是两层连续因果：

```text
第一层：原动态失稳根因
五台 GFL live fixed-Q PI
继续改变 base-q
↓
V4.7 已修

第二层：V4.7 修完后暴露
孤岛缺少足够的稳态 q-bias / Q-V restoration authority
↓
Primary 稳在高电压偏置
↓
Secondary dV 已打满 -0.05 pu
仍拉不回额定电压
↓
高电压 + q支撑需求
使部分变流器进入 ModIndex=1
↓
后期电流跟踪恶化 / 频谱再次增长
```

这已经不是一个“根因根本没找到”的状态。

# 4. 为什么 V4.7 修 Q PI 后会留下高电压偏置？

这是当前最关键的架构问题。

V4.7 做了：

```text
J1前：
Q PI 实时控制 base-q

J1后：
base-q 固定在切岛前值
Qerror = 0
```

这样做正确地去除了 fixed-Q 积分竞争。

但同时也等于去除了：

> **任何能够在孤岛中缓慢重新建立“非零稳态 q 偏置”的积分机制。**

现在五台 q 侧主要变成：

```text
固定 base-q
+
slow-q 电压 droop
+
5~20 Hz damping
+
V4.6 LFQ
```

其中 slow-q 是 droop/比例型电压支撑，不是零稳态误差积分器。

---

# 5. 当前 slow-q 的真实静态关系

模型公式：

```text
e = VsupportRef - Vpu

deadband 后：

slow-q target = -Kmag * e
```

当前：

```text
Kmag = 0.25
deadband = 0.01 pu
```

高电压时：

```text
Vpu > VsupportRef
→ e<0
→ slow-q >0
```

这是正确方向：增加无功吸收代理，压低电压。

所以：

> **slow-q 方向不是错的。**

问题是静态增益和 bias 能力不足。

# 6. 为什么需要 1.19 pu 才形成 Primary 平衡？

Primary 后期五台实际 SupportQ 大约处于：

```text
~0.06 pu 量级
```

而当前 slow-q 增益只有：

```text
Kmag = 0.25
```

如果要靠纯 droop 产生：

```text
0.06 pu
```

的稳态 q 支撑，就需要约：

```text
0.06 / 0.25 = 0.24 pu
```

量级的有效电压误差。

再考虑：

```text

```

那么系统把电压工作点推到明显偏离参考的地方是完全可以解释的。

这正是：

> **droop 的稳态偏差。**

问题不在于 droop 本身存在，而在于：

> **我们把原 Q PI 积分退出后，没有补一个“岛内二次 q-bias 恢复”机制。**

# 9. 为什么“简单把 Secondary 限值从 ±0.05 调大”不是最好的最终设计？

因为当前 Secondary 做的是：

```text
移动 VsupportRef
```

它仍然通过：

```text
slow-q droop
```

间接产生 q bias。

当前五台晚期：

```text
VsupportRef ≈ 0.9516 pu
```

但 V 仍约：

```text
1.164 pu
```

所以 droop 误差仍约：

```text
0.21 pu
```

这才能维持当前所需的 q 支撑。

如果只想靠 VsupportRef 移动把同样的 q 支撑维持在 V≈1 pu：

当前 Kmag=0.25，需要把 VsupportRef 推到非常低的值。

这在控制语义上不漂亮，也会让：

- droop 工作点异常；
- Vref 物理意义越来越差；
- 大 Secondary reference shift 增加低频动态耦合。

更正确的是：

> **让 Secondary 直接建立一个 island q-bias / support-bias，Primary droop 只负责动态。**

# 10. 现在模型真正缺的是什么？

## 缺陷1：没有 island-specific steady q-bias restoration

现在：

```text
base-q = pre-island hold
```

永远冻结。

这解决了动态稳定问题，却没有提供：

```text
孤岛后根据电压慢慢调整 q 工作点
```

的机制。

所以新的完整结构应该是：

```text
Iq_cmd
=
Iq_base_preisland
+
Iq_secondary_bias
+
Iq_voltage_droop
+
Iq_damping
```

其中：

```text
Iq_secondary_bias
```

必须：

- 很慢；
- 基于母线电压误差；
- 有 headroom 约束；
- 有 anti-windup；
- 在五台之间合理分配；
- 不再恢复 fixed-Q tracking。

这才是当前真正缺的一层。

# 14. 为什么 Primary 和 Full 撞调制的是不同设备？

# 18. 当前根因最终应该怎样写？

建议正式冻结为：

## 原失稳根因

> 五台 GFL 在孤岛中继续使用 live fixed-Q PI 作为 base-q 动态来源，形成聚合 Q/V 低频竞争。V4.7 已通过 q-base hold + Qerror zeroing 消除这一机制，Primary 的 sub-Hz 和 5~30 Hz 残差由增长转为明显衰减。

## 当前剩余根因

> V4.7 去除了 fixed-Q 积分后，没有建立新的 island-specific steady q-bias secondary restoration；现有 voltage-support 仍以有限增益 droop 为主，中央 Secondary 只通过 ±0.05 pu 的 VsupportRef shift 间接改变 q 支撑，静态恢复权限不足。Full 中 VSEC 在降压方向长期饱和而电压仍高，随后部分 GFL 进入真实调制电压饱和，导致后期执行误差和频谱重新增长。

这是一条完整的因果链。

# 19. 下一版真正正确的方向

下一版不应该：

```text
恢复原 Q PI
单纯调小/调大 Q PI Ki
继续加另一个 0.25Hz damping
只把 VSEC limit 从0.05改成0.1/0.2
盲目调 Current PI
```

更合理的是：

```text
Primary:
pre-island base-q hold
+
fast/slow Q-V droop support
+
damping

Secondary:
NEW island q-bias integrator / coordinator
↓
依据 voltage error
↓
在五台设备之间按 q headroom 分配
↓
直接调整 q-bias
↓
电压回到1 pu时仍保留所需稳态 q bias
```

再加：

```text
modulation-headroom awareness
```

避免设备已经 ModIndex≈1 时继续增加不可实现的电流要求。

# 21. 当前是否还有必要怀疑 P-loop / Kslow？

优先级已经显著下降，但不能永久排除。

因为：

- Primary Q-root 修复后，原低频和中频残差已经强烈衰减；
- Full 的新增长与 Secondary饱和 / ModIndex饱和同时出现。

因此现在第一动作不应该改：

```text
P PI
Kslow
ESS1
```

只有在：

```text
q-bias restoration
+
modulation-aware allocation
```

完成后仍有增长，才回到 P-loop / Kslow。

# 22. 最终一句话

> **我们已经实现了“能离网、能活15秒、频率能维持”的功能性孤岛；还没有达到“电压合格、频谱不增长、执行器有裕度”的工程级稳定孤岛。原 fixed-Q PI 动态根因已经被 V4.7 修掉，当前真正缺的是岛内稳态 q-bias 恢复层，以及与真实调制裕度联动的资源分配。这就是为什么历次改模并非无效，却始终没有一次性把整个系统推到最终 PASS。**
