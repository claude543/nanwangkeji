## 3. 五台 V2 管理模块的静态合同

五台管理模块均为 **8 输入、18 输出**：

- `K26_V5/SS_Slave3/PV1_Control/AA15_ISLAND_GFL_SUPPORT_MANAGER`
- `K26_V5/SS_Slave3/PV2_Control/AA15_ISLAND_GFL_SUPPORT_MANAGER`
- `K26_V5/SS_Slave2/ESS2_Control/AA15_ISLAND_GFL_SUPPORT_MANAGER`
- `K26_V5/SS_Slave/EV1_Control/AA15_ISLAND_GFL_SUPPORT_MANAGER`
- `K26_V5/SS_Slave/Control System/AA15_ISLAND_GFL_SUPPORT_MANAGER`

所有父层端口连接已输出到：

- `06_five_gfl_manager_parent_connections.csv`
- `07_five_gfl_manager_internal_ports.csv`

当前最重要的结构事实：

1. `RawVdq`（原始 dq 端口电压）和 `RawIpq`（原功率环电流参考）进入管理模块；
2. 管理模块输出最终电压前馈和最终电流参考；
3. 管理模块生成的有效有功/无功参考再返回原 `Power Control Loop`（功率控制环）；
4. 当前 `AA15_ENG_STAGE` 是每台控制器内部的本地常数，由运行脚本逐台写入；它不是中央状态机产生的模型本地统一阶段真值；
5. 最终架构应替换这个阶段输入方式，而不是继续依赖五个独立 Host 写值。

## 4. 当前 V2 阶段语义的审计结论

V2 内部状态函数表明：

```text
阶段0：慢/快电压前馈均为1，原功率动态完整通过
阶段1：慢/快电压前馈均压到0，功率误差动态压到0
阶段2：慢电压前馈取 kslow_stab，快速前馈取 kfast_island，功率误差动态仍为0
阶段3：慢电压前馈取 kslow_rec，快速前馈取 kfast_island；满足内部健康条件后才恢复功率误差动态
```

因此，当前模型仅把 `Kslow` 改成 0.5 或 1，再运行阶段2，仍然不是“全部功能完整运行”，因为阶段2没有按资源类型设计的有功频率支撑，也没有新的岛态慢速功率协调。

最终重构应改成：

```text
J1打开第一拍已经存在：
- 经过设计的慢/快电压前馈
- PV、ESS2、EV各自不同的有功频率响应
- 本地电压支撑
- 最终电流能力限制
- 坐标保护/公共相角方案

稍慢进入但不以“系统已经稳定”为前提：
- 受限的岛态功率协调
- 频率恢复积分项
- ESS1长期功率卸载
```

## 8. 最终改模前的强制审计顺序

1. **物理拓扑**：J1、母线、六支路、变压器/滤波器、电压电流测量点；
2. **六台控制链**：并网与构网支路、所有 Switch 输入、最终 PWM 相位；
3. **坐标约定**：五台 d 轴电压定向与 ESS1 构网 q 轴电压定向的精确相位关系；
4. **任务运输**：ESS1 相角/频率是否可跨任务传递，延迟和宽度；
5. **资源能力**：PV可用功率、ESS2双向边界、EV仅可调充电、ESS1长期储备；
6. **最终控制方程**：电压前馈、有功频率支撑、电压支撑、慢速协调、总电流限制、抗饱和；
7. **记录量预算**：G26~G30 行语义一次冻结；
8. **事务式改模**：旧合同→备份→局部修改→编译态断言→全局断言→保存一次→重载审计。
