# 0. 给老师汇报用：全过程凝练版

如果只用几分钟向老师解释，可以按下面这条主线说。

## 0.1 一句话总括

> 这个问题最初是在把PCC真实断路器J1修通以后暴露的：以前逻辑上“离网”但真实电气断路器未必动作，真正让J1断开后，微电网侧电压无法正常维持。后续我们先从PCC原始电压中发现约0.53 kHz的快速振荡，再通过D1/F1/F2逐步把问题从“整个孤岛不知道哪里振”压缩到ESS1 GFM的快速反馈、外电压环带宽、状态和坐标问题；随后又把“并网切孤岛”和“ESS1自身能不能从死母线建立孤岛”拆开。Gate A自主成岛试验进一步暴露了Current Regulator电压前馈、PWM实时执行方式以及local-C1电压控制律的隐藏问题。最终采用本地vC/iL快反馈、Voltage PI 0.02/0.14、raw-vC内环前馈、Pulse Averaging PWM + Switching Function，以及 `F9同轴PI + F8输出电流前馈 + 电容同步补偿` 后，ESS1已经能够从0 V平滑建立到约10 kV，并在短Hold中稳定维持，当前基本证明了ESS1自主构网能力。

## 0.2 一步一步的老师汇报版

### 第1步：先把“假离网”改成“真离网”

早期策略逻辑控制的不是最终真实电气PCC断路器。修正路由后：

```text
策略/本地控制命令
→ S13 PCC Breaker Router
→ 100 μs Z^-1
→ J1_PCC_Breaker
```

J1第一次真正打开，Grid侧仍约10 kV，但微电网侧电压出现明显异常。

**汇报一句话：**

> “最初的问题不是GFM先坏，而是先发现离网动作对象不对；真实J1修通以后，真正的孤岛问题才第一次暴露。”

---

### 第2步：发现问题不是简单的“电压少一点”，而是50 Hz波形被快速振荡破坏

PCC原始三相电压频谱里出现约531 Hz强快速分量；根据ESS1支路 `L1 + C1 + Transformer leakage + Stubline` 参数理论计算，自然模态约527.4 Hz。

**汇报一句话：**

> “实际PCC电压里看到约531 Hz快速成分，而模型参数独立算出约527 Hz自然模态，两条独立证据高度吻合，所以问题从‘电压塌陷’进一步定位成了LC网络模态被控制器负阻尼放大。”

---

### 第3步：D1超级诊断证明是闭环问题，不是单纯PWM谐波

D1同一份数据里同时看到：

```text
abc快速模态 ≈ 530~535 Hz
dq同一模态 ≈ 480~485 Hz
二者相差约50 Hz
```

正式500 Hz二阶测量滤波器在该dq模态附近实测约：

```text
|H| ≈ 0.516
phase ≈ -88°
```

而且J1打开后10～18 ms，Current/Voltage loop和ModIndex就开始限幅；`Vpwm`在进入PWM以前已经带有快速模态。

**汇报一句话：**

> “D1把问题锁定为控制-电气闭环低阻尼：滤波器在危险频带引入接近90°相位损失，控制参考在PWM前已经振起来，因此不能把锅单独甩给PWM或单个测量块。”

---

### 第4步：F1证明“改滤波截止频率”和“裸电容电流主动阻尼”都不是根治

依次比较500/800/1000 Hz滤波，以及两种符号的裸 `±K·iC` 主动阻尼。

结果：

- 800 Hz相对最不坏；
- 1000 Hz虽然相位更小，但快速模态又增强；
- 两种简单主动阻尼符号都恶化；
- 没有任何一组恢复健康50 Hz孤岛。

**汇报一句话：**

> “滤波相位确实重要，但不是唯一根因；继续扫700/900/1200 Hz或裸主动阻尼增益信息量已经很低，所以我们停止参数碰运气，转向控制架构。”

---

### 第5步：F2把GFM快反馈从远端高压侧搬回ESS1本地LC状态

原来Voltage/Current快速环使用 `prim_ESS1` 高压侧远端测量，还跨 `SM→SS`。

F2改为：

```text
Voltage fast feedback → local vC
Current fast feedback → local iL
Rff = 0.0015 pu
Lff = 0.125 pu
local execution phase = 0
```

0.53 kHz快速模态大幅退出主导，50 Hz重新成为主要能量。

**汇报一句话：**

> “最大的结构性改善来自把毫秒级快环反馈搬回SS_Slave2本地，让Current Loop真正控制L1电流、Voltage Loop真正控制C1电压；慢速P/Q、Droop仍保留高压侧系统测量。”

---

### 第6步：数学上锁定Voltage PI 2/14过快

Current Loop带宽估算约118 Hz；原Voltage PI：

```text
Kp = 2
Ki = 14
```

对 `C1≈0.05 pu` 的本地电容Plant太快，实际闭环unity交越被推到约470 Hz dq附近，正好对应abc约520 Hz，并与理论527 Hz模态重合。

改成：

```text
Kp = 0.02
Ki = 0.14
```

后：

```text
515~535 Hz RMS下降≈97.1%
300~700 Hz RMS下降≈86.2%
```

**汇报一句话：**

> “原外电压环实际上比内电流环还快，违反级联控制基本带宽层级；把Voltage PI整体降100倍后，527 Hz主自激被强烈压制。”

---

### 第7步：再处理Voltage PI历史状态和dq同步

降低Ki以后，GFL阶段积累的Voltage PI积分状态不再能快速冲掉，因此F3加入GFL reset / GFM release；F4再处理GFL→GFM相角同步，最终明确GFM Voltage Regulator希望：

```text
Vd ≈ 0
Vq ≈ Vout
```

而不是只追求“abc波形相角连续”。

**汇报一句话：**

> “高频问题压下去以后，之前被遮住的状态和坐标切换问题才暴露出来，所以我们又解决了PI旧状态和dq目标轴不一致。”

---

### 第8步：8.26对验证方法做根本纠偏

过去很多测试是：

```text
强网存在
→ ESS1进入GFM
→ J1突然打开
```

它测试的是：

```text
Grid-to-Island Transfer（并网转孤岛切换）
```

却不能回答：

```text
ESS1 Autonomous Formation（ESS1能否自己从死母线构网）
```

于是建立Gate A：

```text
J1从第一步OPEN
其它5台active GFL隔离
保留5条Transformer/Stubline被动网络
ESS1用S14 Black Start
Vref 0~0.5 s = 0
0.5~5.5 s = 0→10 kV Ramp
```

**汇报一句话：**

> “我们把‘能不能自己成岛’和‘并网切岛能不能无扰’正交拆开，先证明ESS1本体的构网能力，再谈切换瞬态。”

---

### 第9步：Gate A暴露Vref=0仍自激，F10锁定Current Regulator的vC前馈

Gate A最初即使：

```text
Vref = 0
```

实际电压仍在几十毫秒内冲到10 kV以上。

F7因果矩阵表明Current Regulator中的local-vC voltage feedforward强烈参与。

进一步发现它使用的是经过800 Hz LPF的vC：

```text
理想：
vconv* = vC + PI + decoupling

原来：
vconv* = H(s)vC + PI + decoupling
```

于是残差：

```text
[H(s)-1]vC
```

在527 Hz附近已有约−66.7°相位差。

F10只把Current Regulator的vC feedforward改成raw-vC，电流反馈仍保持filtered。

结果Vref=0阶段不再持续自激。

**汇报一句话：**

> “Current Regulator的电压前馈本来应该即时抵消电容端电压，但我们把一个带明显相位滞后的滤波vC直接拿去前馈，等于用旧电压去抵消当前电压；切成raw-vC后零参考自激立即消失。”

---

### 第10步：F12证明4 kHz alias假设不成立

5 kHz日志里曾看到950/1050 Hz，怀疑它可能是4 kHz载波边带折叠。

于是设计4 kHz notch，并把Group29临时提升到10 kHz记录。

最终证明：

- F12 notch本身工作正确；
- 3950/4050 Hz被约21 dB抑制；
- 950/1050 Hz是真实控制域成分，不是4 kHz折叠；
- 4 kHz附近本来能量很小。

**汇报一句话：**

> “我们没有继续凭频谱猜，而是把日志升到10 kHz直接消除混叠歧义；结果证明4 kHz不是Formation根因，所以停止notch路线。”

---

### 第11步：F14把问题边界推进到ESS1_Control外部PWM/Converter执行层

此时出现一个决定性现象：

```text
ESS1_Control内部：
Current PI输出在增加
Vdq_conv在增加
Vpwm 50 Hz命令在增加

但是：
真实ESS1 primary Vab的50 Hz长期几乎不增加
```

说明故障边界已越过 `ESS1_Control` 输出。

旧执行方式：

```text
PWM Generator (2-Level)
+
Two-Level Converter / Switching devices
```

在：

```text
Ts=100 μs
Fsw=4 kHz
```

下一个PWM周期只有2.5个实时步。

F14改成：

```text
PWM Generator (Pulse Averaging)
+
Two-Level Converter / Switching function
```

以后，Vpwm增加时真实50 Hz电压立即连续响应，原来的“死区→阈值跳变→runaway”消失。

**汇报一句话：**

> “控制器命令本身是连续的，但详细开关模型在100 μs/4 kHz下执行分辨率太粗；改用Pulse Averaging + Switching Function后，物理50 Hz输出恢复连续跟随。”

---

### 第12步：F15/F16/F17把Voltage Loop的C1物理结构彻底理顺

健康执行层建立以后，才真正能判断Voltage Regulator到Current Reference的映射。

最终确认local C1控制不是简单“换个符号”：

```text
PI动态项：
[-u2, +u1]

CAP同步补偿：
[-Bc·Vq, +Bc·Vd]

输出电流前馈：
[Iout_d, Iout_q]
```

F16的 `[-u1,-u2]` 被明确否决，会产生增长的低频振荡。

F17只开PI动态项+CAP后系统稳定但建压明显滞后。

**汇报一句话：**

> “电容dq方程决定Voltage PI负责动态电压误差，而CAP项补旋转坐标同步电流；F17说明这套结构稳定，但还缺负载/网络输出电流前馈，所以PI被迫自己慢慢积分出全部输出电流。”

---

### 第13步：F18打开F8输出电流前馈后，Formation跟踪基本恢复

F18：

```text
F9 = [-u2,+u1]

F8:
IOUT_GAIN = -1
CAP_GAIN = 1
Bc = 0.05
```

实际形成：

Id_ref = -u2 + Iout_d - Bc·Vq  
Iq_ref = +u1 + Iout_q + Bc·Vd

F18短试验中实际电压基本贴合Ramp；F18L2完整0→10 kV中：

```text
t≈1 s   primary Vab≈1.04 kV
t≈2 s   ≈2.99 kV
t≈3 s   ≈5.09 kV
t≈4 s   ≈7.06 kV
t≈5 s   ≈9.17 kV
t≈5.5 s ≈10.11 kV
```

5.5～6.2 s短Hold：

```text
primary Vab RMS≈10.156 kV
Fout≈50.235 Hz
Vq≈1.0066 pu
Vd≈-0.0011 pu
ModIndex avg≈0.764，max≈0.792
Current PI远离±1.25限幅
```

**汇报一句话：**

> “最后把输出电流前馈补齐以后，Voltage PI终于只负责小的电压误差，母线从0平滑建立到10 kV，dq轴和调制度都进入健康状态；当前ESS1自主成岛的Formation已经基本通过。”

> “ESS1这一条支路自己的10 kV侧电压是什么样？”

`PCC`回答：

> “整个2PV+2ESS+2EV微电网在边界处最终形成的电压是什么样？”

两者中间还有：

```text

公共母线
其它5条支路
```

所以看到PCC振荡，并不能第一时间宣布“ESS1_Control内部一定是源头”。

# 3. 所有“频率”也必须分开

## 3.1 Fout：GFM自己命令/形成的频率

在ESS1 GFM内部：

```text
Droop
→ Fout
→ theta积分
→ GFM dq / abc生成
```

Group29中：

```text
row18 = Fout
```

它表示：

> ESS1 GFM控制器当前要形成多快的交流旋转角速度。

它不是直接由PCC波形测出来的PLL频率。

---

## 3.2 PCC PLL Frequency：从边界电压估出来

路径：

```text
SM_Master/Three-Phase V-I Measurement3
→ PCC Vabc
→ J2_PCC_Measurements
→ PLL
→ Freq_pcc
```

它回答：

> “PLL看当前PCC波形，估计其基波频率是多少？”

当PCC电压已经被几百Hz快速模态严重污染、50 Hz分量很弱时，PLL可能暂时显示55 Hz或其它异常值。

所以：

> **PLL显示55 Hz，不等于物理电压真的变成了纯55 Hz交流电网。**

---

## 3.3 50 Hz实际基波：要从真实电压波形判断

我们真正说：

```text
“50 Hz有没有建立？”
```

最可靠的方法不是只看一个`Freq`数字，而是看：

1. `primary Vab` / `PCC raw Vabc`的时域波形；
2. 45～55 Hz频带RMS或FFT主峰；
3. 同步dq中是否形成稳定DC分量；
4. Fout/PLL是否与其一致。

例如健康GFM本地采用q轴电压定向时：

```text
真实50 Hz正序电压
↓ Park变换
selected Vd ≈ 0
selected Vq ≈ 稳定正DC
```

所以：

```text
Vq≈1 pu
Vd≈0
```

是“50 Hz电压已经与GFM坐标对齐”的强证据。

## 3.4 527 Hz / 531 Hz到底是什么

它们都不是“电网运行频率”。

### 527.4 Hz

根据：

```text
L1
C1
Transformer leakage
Stubline leakage
```

理论计算出的ESS1支路自然模态。

近似：

```text
X_L,total ≈ 0.17976 pu
B_C ≈ 0.05 pu

f_r ≈ 50 / sqrt(0.17976×0.05)
≈ 527.4 Hz
```

### 约531 Hz

早期PCC原始Vabc实际频谱中看到的快速分量。

两者接近说明：

> 实际运行时，LC/网络自然模态被严重激发。

但不能说：

```text
“PCC频率=531 Hz”
```

正确说法是：

> PCC的正常50 Hz基波上出现了强约0.53 kHz快速成分，严重时该快速成分甚至超过50 Hz基波。

# 4. “10 kV / 50 Hz要求不满足”到底是怎么判断的

## 4.1 电压不是必须数学上等于10000.000 V

系统额定：

```text
Vnom = 10 kV
```

但GFM还有Voltage Droop（电压下垂），正常可能出现：

```text
9.8 kV
10.0 kV
10.2 kV
```

甚至具体允许区间要结合Q和最终项目指标。

真正明显FAIL是：

```text
2~3 kV
5~7 kV长期无法恢复
12~14 kV并长期饱和
或者电压主要被几百Hz快速振荡主导
```

这些不是正常Droop误差。

---

## 4.2 频率也不是必须固定50.000 Hz

当前Frequency Droop约1%，模型含偏置。

历史推导：

```text
Fout ≈ 50.25 - 0.5*Pmeas_pu
```

因此：

```text
P≈0 → Fout约50.25 Hz
P≈0.5 pu → Fout约50 Hz
P≈1 pu → Fout约49.75 Hz
```

所以健康GFM不是要求：

```text
50.000 Hz一丝不差
```

而是要求：

```text
有界
符合P-f Droop
实际三相电压仍以约50 Hz基波为主
没有持续高频/低频发散
```

F18L2短Hold中：

```text
Fout≈50.235 Hz
```

在当前轻载Gate A和Droop结构下是合理的。

# 18. Voltage PI 2/14：为什么最终被数学锁定为原527 Hz的主导根因

Current PI：

```text

Ki=20
```

结合L1、800 Hz反馈和100 μs延时，估算：

```text

```

有正相位裕度。

```text

```

对C1≈0.05 pu：

低频理想带宽意图约：

```text

≈ 2*50/0.05
≈2000 Hz
```

这已经远高于118 Hz内环。

考虑真实Current Loop、Filter和延时后，外环unity落到：

```text

```

此时相位已经非常差。

而：

```text

```

与实测520～527 Hz几乎重合。

```text
Voltage Kp过大
→ 外环快于内环
→ unity被推入LC危险频带
→ Filter+delay使相位严重恶化
→ 给527 Hz物理模态负阻尼
→ 快速振荡增长
```

# 26. 为什么filtered-vC用于前馈在原理上不对

L1物理关系：

```text
L di/dt = vconv - vC - R i
```

Current Regulator若要控制iL，理想：

```text
vconv*
=
vC
+
PI(i_ref-i)
+
R/L decoupling
```

其中：

```text
+vC
```

作用是即时抵消电容节点电压。

但原来用：

```text
H(s)vC
```

于是：

```text
vconv* - 真正vC
```

多出：

```text
[H(s)-1]vC
```

800 Hz、ζ=1 LPF在：

```text
527 Hz:
|H|≈0.697
phase≈-66.7°
```

所以你不是“把当前vC前馈回去”，而是：

> 用一个幅值变小、相位明显落后的旧vC去抵消当前真实vC。

对于快环来说非常危险。

# 31. F14：100 μs / 4 kHz为什么会有实时PWM分辨率问题

# 50. 这次排错最值得内化的工程方法

## 50.1 先看物理边界，再看算法

```text
Breaker到底动没动？
测量点到底在哪？
Load到底属于哪一侧？
```

如果这些没锁定，控制器分析可能全建立在错误对象上。

---

## 50.2 “测量值正常”不等于“物理波形正常”

```text
RMS正常
PLL Frequency正常
```

仍可能有强谐波/模态。

必须保留：

```text
raw Vabc
频谱
dq
饱和状态
```

交叉验证。

---

## 50.3 快环必须看真正被控制的本地状态

Current Loop最自然：

```text
iL
```

Voltage Loop最自然：

```text
vC
```

系统层P/Q/Droop才适合看高压远端测量。

---

## 50.4 级联控制必须保持带宽层级

```text
Voltage outer loop << Current inner loop
```

不是所有PI越大越“跟得快”。

外环跑到内环能力以外，最终会在电气自然模态附近变成负阻尼。

---

## 50.5 Feedforward不是随便“加快响应”

Current Regulator中的：

```text
+vC
```

是根据Plant方程做模型抵消。

这种直接抵消量如果加入大相位滤波：

> 可能比不用更危险。

---

## 50.6 频谱设计前先确认采样率和alias

永远先写：

```text
fs_control
fs_log
Decimation
Nyquist
```

再讨论某个频率是不是“真实4 kHz边带”。

F12就是一次很典型的正确止损。

---

## 50.7 一个A/B只能回答一个问题

F14只有执行表示变化，所以它能强因果说明PWM/Converter执行层问题。

如果当时同时改：

```text
PI
F8
F9
PWM
```

即使PASS也不知道为什么。

---

## 50.8 失败试验也必须有“关闭一个分支”的价值

例如：

```text
F11 → SNR不足，不能定罪Current PI
F12 → 关闭4 kHz alias
F16 → 关闭错误交叉动态mapping
```

失败并不等于没有信息。

# 52. 最终结论

截至当前，最合理的整体认识不是：

```text
“一个孤岛问题查了很多天还没找到原因”
```

而是：

> **真实J1接通以后暴露了一个被强网长期遮蔽的多层GFM问题。早期原0.53 kHz问题主要来自远端快反馈、错误frame以及过快Voltage outer loop对LC自然模态提供负阻尼；把快环本地化并降低Voltage PI后，该模态被基本解决。随后在真正的Autonomous Gate A中，又逐层暴露出Current Regulator filtered-vC前馈、100 μs/4 kHz详细开关执行分辨率、以及local-C1电压控制缺少完整CAP/输出电流前馈等问题。F10、F14和F18分别解决这些层后，ESS1现已能够独立从死母线平滑建立约10 kV、50 Hz级岛网并完成短Hold。当前不应继续修改ESS1内部基本GFM，而应进入长Hold、五台GFL恢复、完整六设备孤岛和最终grid-to-island transfer验证。**

---

## 最后给自己记住的五句话

1. **PCC电压不是prim_ESS1电压，527 Hz也不是系统频率。**
2. **真正判断50 Hz建立，要看真实Vabc/primary Vab的基波和dq，不是只看PLL数字。**
3. **Current Loop控制local iL，Voltage Loop控制local vC，P/Q Droop看系统级高压测量。**
4. **F18最终成功不是某个PI“调对了”，而是反馈位置、带宽、状态、前馈、PWM执行和C1物理控制律全部一致以后才成立。**
5. **现在ESS1已经基本会“自己成岛”；下一阶段才是“带着另外5台一起稳定成岛”和“从并网状态无扰切过去”。**

# 附录C｜`ESS1_Control`内部每层到底是什么

## C.1 Measurements

职责不是“只测量”，还包含：

```text
abc→dq
raw/filtered V/I
remote/local fast feedback selector
```

F1、F2、F10都与这一层不同分支有关。

### 需要特别区分

```text
Voltage Regulator feedback
```

和：

```text
Current Regulator中的vC直接feedforward
```

不是同一用途。

F10只是把后者切raw，不等于把整个系统所有电压滤波都去掉。

---

## C.2 Droop（下垂控制）

慢速系统层：

```text
P变化 → Fout变化
Q变化 → Vout变化
```

它负责形成：

```text
频率参考/角度
电压幅值参考
```

而不是直接开关IGBT。

---

## C.3 Voltage Regulators（电压外环）

当前目标轴：

```text
Vd_ref = 0
Vq_ref = Vout
```

raw PI定义：

```text
u1 = PI(Vq_ref - Vq)
u2 = PI(Vd - Vd_ref)
```

最终PI参数：

```text
0.02 / 0.14
```

外环只应慢速决定“需要多少额外电流来修正电容电压”。

## C.4 F9

Voltage PI输出之后的映射。

最终mode1：

```text
[-u2,+u1]
```

含义：

```text
Vd误差动态 → Id
Vq误差动态 → Iq
```

符合C1动态方程的同轴控制。

---

## C.5 F8

位置：

```text
F9
↓
AA15_F8_VOLTAGE_LOOP_FEEDFORWARD
↓
Id/Iq_ref最终限幅
↓
Current Regulator
```

最终同时加入：

```text

```

这是F18成功的关键。

## C.6 Current Regulator（电流内环）

目标：

```text

```

主要结构：

```text

→ Current PI

+

+
R/L dq decoupling
→ Vd/Vq_conv
```

最终：

```text

```


的增益。


这一组合是当前冻结值。

# 附录D｜为什么F18完整公式是合理的：用KCL一步一步理解

在C1节点：

```text
iL = iC + iout
```

所以要让电容电压变化，你需要的iL不是只有“调电压那一点电流”。

必须同时提供：

```text
① 外部网络已经要走掉的iout
② C1在旋转dq中维持电压所需同步电流
③ 真正改变Vd/Vq所需动态电流
```

因此：

```text
iL_ref
=
iout
+
iC_sync
+
iC_dynamic
```

对应：

```text
iC_dynamic
= Voltage PI through F9

iC_sync
= [-Bc*Vq, +Bc*Vd]

iout
= F8 output-current feedforward
```

于是：

```text
Id_ref
=
-u2
+Iout_d
-Bc*Vq

Iq_ref
=
+u1
+Iout_q
+Bc*Vd
```

### 通俗理解

如果一条水管一边要给外面的用户供水，一边要给水箱升水位：

- `Iout` = 用户正在用掉的水；
- `CAP` = 水箱在旋转坐标下维持当前状态本来就需要的“基础流量”；
- `Voltage PI` = 真正为了把水位从当前值调到目标值额外加的那一点流量。

F17没有Iout前馈，相当于PI先自己慢慢学会“用户到底用了多少水”，所以水位上升很慢。

F18直接把用户用水量前馈进去，PI只管水位误差，所以Formation立即跟上。

# 附录E｜以后看到某个异常，优先看哪几个量

## E.1 “电压突然塌了”

先看：

```text
row23 J1
row21 primary Vab
row22 PCC Vab
Grid-side V
```

回答：

1. J1到底开没开；
2. 是ESS1 local先掉，还是PCC才掉；
3. Grid侧还正常吗。

---

## E.2 “频率不对”

不要先看一个Freq数字。

联合：

```text
row18 Fout
PCC PLL Frequency
row21/22 raw voltage spectrum
local Vd/Vq
```

---

## E.3 “Current Loop是不是坏了”

看：

```text
row8/9 Id/Iq_ref
row38/39 selected actual Id/Iq
row12/13 Current PI
row14/15 Vd/Vq_conv
```

如果：

```text
ref≈actual
```

就不能因为系统总电压错而直接怪Current PI。

---

## E.4 “PWM是不是没执行”

看：

```text
row14/15 Vdq_conv
row17 Vpwm
row21 physical primary Vab
```

如果：

```text
Vpwm连续变化
但physical fundamental长期不响应
```

问题边界就在控制器输出之后。

F14就是这么锁到PWM/Converter的。

---

## E.5 “是不是高频模态”

必须先写：

```text
fs_control
fs_log
Decimation
Nyquist
```

再做FFT。

不能看到950 Hz就直接说“1 kHz振荡”，更不能不检查alias就设计notch。

# 附录F｜当前真正的“下一阶段”，和当前GFM内部排错的边界

当前不要再：

```text
扫Voltage PI
扫Current PI
扫F8 gain
扫CAP gain
扫F7
加notch
改F9
改F14 PWM
```

除非未来新数据出现直接反证。

```text

↓
2. 恢复一台GFL，小功率接入
↓
3. 逐步恢复另外4台
↓

↓
5. P/Q/I预平衡
↓
6. Grid-connected → Islanded transfer
↓
7. Resynchronization → Grid-connected
```

这时如果并网切岛仍失败，首先查的是：

```text
边界电流连续
P/Q预平衡
F3/F4状态与角度
Supervisor HOLD
J1 timing
```

而不是再次怀疑ESS1有没有自主构网能力。
