# 8.26｜ESS1固定GFM锚点 vs 现有GFL→GFM模式切换：到底改变什么、哪些旧结论仍有效、为什么更容易实现

# 0. 最关键结论

把ESS1改成：

```text
长期/固定GFM锚点
```

并不是：

```text
换一个名字
```

也不是：

```text
J1一开就一定稳定
```

真正改变的是：

# ESS1不再经历“控制结构切换”，而只经历“网络拓扑切换”。

当前模式切换架构：

```text
并网阶段：
ESS1 = GFL
↓
离网准备：
ESS1 GFL → GFM
↓
再打开J1
↓
ESS1继续GFM
```

固定GFM架构：

```text
并网阶段：
ESS1已经是GFM

↓
离网准备：
ESS1仍然是GFM

↓
打开J1

↓
ESS1仍然是GFM
```

所以在真正J1打开的瞬间：

```text
ESS1控制器本身不换模式
不换PI
不换theta来源
不换Id/Iq_ref来源
不reset/释放一组新的状态
```

只剩：

```text
网络边界从Grid-connected变成Islanded
```

这就是它明显更干净的根本原因。

---

# 1. 先纠正一个容易产生的误解

固定GFM不等于：

```text
ESS1在并网时“取代大电网”
```

强网存在时：

```text
Grid
```

仍然是远比ESS1强的电压/频率源。

ESS1作为GFM并联强网时，更准确地像：

```text
一个带Droop和输出阻抗的受控交流电压源
```

与强网并联。

强网会把公共频率/相角强力钳住，

而ESS1根据：

```text
Vref
Fref
P-f Droop
Q-V Droop
```

形成自己的P/Q工作点。

所以：

```text
ESS1 = GFM
```

不意味着：

```text
ESS1独占系统频率。
```

在强网下，它只是一个grid-forming/grid-supporting source与强网并联。

---

# 2. 当前“模式切换架构”真正做了什么

过去我们的结构本质是：

## GFL阶段

ESS1：

```text
PLL theta
+
P/Q current reference
+
Current Regulator
```

Voltage PI/Droop即使存在，也不一定是最终实际控制路径。

---

## GFL→GFM切换

需要同时发生很多事情：

```text
1. GRIDON切换
2. IdIq_ref来源切换
3. Voltage PI开始真正接管
4. Voltage PI状态需要正确初始化/reset
5. Droop theta开始真正接管
6. PLL theta → Droop theta需要坐标连续
7. Fref/Vref需要切到GFM逻辑
8. Current Loop接收到新的参考结构
```

这就是为什么我们曾经遇到：

```text
F3：
Voltage PI stale state

F4：
Droop theta / dq轴不同步
```

这些问题。

它们不是LC电气Plant本身的问题。

它们属于：

# hybrid mode transition problem

即混合控制模式切换问题。

---

# 3. 固定GFM以后哪些东西直接消失

如果ESS1从整个运行周期就保持：

```text
GRIDON = 0
Droop = active
Voltage Loop = active
Current Loop = active
```

那么以下切换不再发生：

---

## 3.1 不再有Voltage PI从“后台状态”突然接管

原问题：

```text
GFL阶段Voltage PI后台积分
↓
切GFM
↓
旧积分状态突然进入实际电流参考
```

固定GFM：

```text
Voltage PI从一开始就是实际控制的一部分
```

所以不存在：

```text
inactive controller
→ active controller
```

的状态接力。

---

## 3.2 不再有PLL theta → Droop theta硬切换

原模式：

```text
GFL：
theta = PLL

GFM：
theta = Droop
```

所以必须F4做：

```text
同步
held reset
release
```

固定GFM：

```text
正常运行一直使用Droop theta
```

因此在J1 OPEN那一刻不发生theta source切换。

---

## 3.3 不再有GFL IdIq_ref → Voltage-loop IdIq_ref切换

当前GFL：

```text
IdIq_ref = P/Q current reference
```

GFM：

```text
IdIq_ref = Voltage Loop output
```

固定GFM以后：

```text
一直是Voltage Loop形成GFM current reference
```

所以J1断开时不会重新更换电流参考生成器。

---

## 3.4 不再需要“提前5秒切GFM预热”

过去：

```text
20 s：
ESS1切GFM

20~25 s：
与强网并联5 s

25 s：
J1 OPEN
```

本质上就是为了：

```text
先让GFM状态稳定
再开J1
```

固定GFM以后：

```text
不需要专门这个prepare period
```

ESS1天然已经GFM-ready。

---

# 4. 这就是为什么固定GFM明显更容易实现

不是因为它更“强”。

而是因为它减少了大量离散状态变化。

当前模式切换：

```text
控制器模式变化
+
网络拓扑变化
```

固定GFM：

```text
只有网络拓扑变化
```

从控制理论上看，

固定GFM减少了：

```text
state reset
state mapping
reference handoff
angle handoff
controller bumpless transfer
hybrid switching logic
```

这些非常难排错的环节。

---

# 5. 但固定GFM不会自动解决什么

这是最重要的边界。

即使ESS1一直GFM，

J1打开前如果：

```text
P_tie ≠ 0
Q_tie ≠ 0
I_tie ≠ 0
```

J1一开：

```text
Grid承担的功率/电流
仍然必须瞬间转移到岛内资源。
```

所以仍然可能：

```text
电压跌落
频率摆动
Current limit
ModIndex saturation
LC mode被激发
```

因此：

# 固定GFM ≠ 无扰切岛。

它只是把问题从：

```text
“控制模式切换 + 功率边界切换”
```

简化为：

```text
“只剩功率边界切换”
```

---

# 6. 这和我们A0/B1/B2有什么关系

这是当前最关键的事实。

A0/B1/B2中，

我们并不是：

```text
J1打开的同时
ESS1才刚刚切GFM
```

而是：

```text
4 s：
ESS1已经进入GFM

4~7 s：
ESS1作为GFM与Grid并联

7 s：
才打开J1
```

也就是说：

# A0/B1/B2在J1 OPEN那一刻，本质上已经非常接近“固定GFM切岛”。

因为ESS1在J1开前已经连续GFM运行了3秒。

旧31 s/66 s工况更是：

```text
GFM预运行5 s
```

---

# 7. 所以固定GFM会不会改变A0/B1/B2失败结论

## 不会从根本上推翻。

这是必须明确的。

A0/B1/B2已经证明：

```text
ESS1已经GFM-ready
frame正确
Vd≈0
Vq≈1
状态运行数秒
```

以后，

J1突然OPEN仍然失败。

所以：

> **当前J1 OPEN失败不能再简单归因于“GFL→GFM切换发生得太突然”。**

固定GFM虽然可以取消整个前置模式切换复杂性，

但：

```text
当前J1 boundary removal问题
```

依然需要解决。

---

# 8. 那固定GFM还有什么价值

价值非常大，但价值在系统架构简化，不是“自动治愈J1”。

---

## 8.1 删除F3这一类模式接管问题

F3曾经解决：

```text
Voltage PI stale state
```

固定GFM后：

```text
这个问题根本不会产生。
```

---

## 8.2 大幅简化F4

F4当前负责：

```text
强网并联期间
让Droop angle对齐PLL/grid frame

J1开后
释放Droop自由积分
```

如果ESS1长期GFM，

仍然需要：

```text
第一次与Grid并联时同步
```

或：

```text
重新并网时同步
```

但不再需要：

```text
GFL→GFM模式切换时
PLL theta → Droop theta
```

这一套复杂handoff。

所以：

```text
F4的“坐标校准结论”
仍有效

F4的“模式切换用途”
大幅减少
```

---

## 8.3 S15状态机会简单很多

现在S15：

```text
NORMAL
↓
准备离网
↓
把ESS1切GFM
↓
held sync
↓
开J1
```

固定GFM后：

```text
NORMAL：
ESS1本来就GFM

↓
PREPARE_ISLAND：
只做P/Q/I_tie balance
Supervisor HOLD

↓
OPEN J1
```

明显更简单。

---

## 8.4 非计划孤岛更有优势

如果发生意外Grid loss：

当前GFL架构必须：

```text
检测Grid loss
↓
切ESS1 GFM
↓
初始化状态
```

存在检测和切换延时。

固定GFM：

```text
ESS1本来就在形成电压
```

Grid突然消失后只需要继续运行。

所以对：

```text
unintentional islanding
```

固定GFM更天然。

---

# 9. 之前的哪些结论完全不受影响

以下结论是Plant/坐标/参数事实，

与ESS1以后固定还是切换GFM基本无关。

---

## 9.1 527 Hz是物理LC自然模态

仍成立。

因为：

```text
L
C
Transformer
Stubline
```

没变。

---

## 9.2 Voltage PI 2/14太快

仍成立。

固定GFM甚至意味着Voltage PI长期工作，

所以：

```text
2/14跨到LC频段
```

更不能接受。

---

## 9.3 0.02/0.14显著压制原527 Hz

仍成立。

这是实际MAT结果。

---

## 9.4 local vC / iL、sign、R/L、phase0

全部仍成立。

这些属于ESS1 local fast loop本身。

---

## 9.5 Current PI 0.3/20当前基线

不会因为是否模式切换自动改变。

---

## 9.6 五台GFL真实隔离后的结果

仍成立。

它验证的是：

```text
其它五台active control
不是A0首发的必要原因
```

和ESS1固定GFM无冲突。

---

# 10. 哪些历史结论会“变成不再需要”，但不是被推翻

这是非常重要的区别。

---

## 10.1 F3

历史事实：

```text
当前模式切换架构下
Voltage PI stale state确实存在。
```

这个事实不会变。

但如果最终架构改成：

```text
ESS1一直GFM
```

那么：

```text
F3这种GFL阶段reset政策
可能不再需要。
```

所以是：

```text
历史诊断正确
最终架构中问题消失
```

不是：

```text
以前F3判断错了。
```

---

## 10.2 F4 held angle sync

同样：

```text
-2π/3
```

对当前q轴frame校准的结论仍有效。

但固定GFM不再需要：

```text
“切GFM前持续reset Droop theta”
```

这种模式handoff逻辑。

同步功能会主要用于：

```text
初次并网
或
重新并网
```

---

# 11. 哪些结果必须重新验证

如果最终正式采用“ESS1固定GFM”，以下必须重新建立baseline。

---

## 11.1 正常并网工作点

ESS1长期GFM以后：

```text
P_ESS1
Q_ESS1
ModIndex
Fout
Vout
```

长期稳态可能和原GFL状态不同。

所以NORMAL grid-connected baseline要重新测。

---

## 11.2 ESS1 SOC / P长期偏置

如果Droop reference不合理，

ESS1可能长期：

```text
放电
或
充电
```

导致SOC漂移。

所以需要secondary control / AGC慢慢把ESS1功率拉回合理值。

---

## 11.3 Tie-line P/Q

固定GFM可能改变：

```text
Q sharing
P sharing
```

所以Gate B仍然必须以：

```text
P_tie
Q_tie
I_tie
```

实测为准。

---

## 11.4 Reconnection

ESS1长期GFM以后，

孤岛→并网时不能简单：

```text
切回GFL再合闸
```

更合理的流程是：

```text
保持GFM
↓
RESYNCHRONIZATION
ΔV/Δf/Δtheta → small
↓
J1 CLOSE
↓
再决定是否继续GFM或切GFL
```

这个流程需要重新设计。

---

# 12. 为什么固定GFM不等于“完全不需要模式”

即使ESS1一直GFM，

系统仍然有状态：

```text
GRID_CONNECTED
ISLANDED
RESYNCHRONIZATION
RECOVERY
```

只是：

# ESS1的底层控制模式不再变化。

变化的是：

```text
上层控制目标
P/Q分工
Supervisor状态
Breaker状态
secondary control
```

所以它不是“没有状态机”。

而是：

```text
减少底层控制器mode switching
```

---

# 13. 两种架构的直接对比

| 项目 | ESS1 GFL→GFM切换 | ESS1固定GFM |
|---|---|---|
| 并网阶段ESS1 | GFL | GFM |
| 离网阶段ESS1 | GFM | GFM |
| J1开断前需切控制模式 | 是 | 否 |
| Voltage PI状态接管 | 需要 | 不需要 |
| PLL→Droop theta handoff | 需要 | J1开断时不需要 |
| Current reference来源切换 | 有 | 无 |
| F3类问题 | 可能出现 | 原理上消失 |
| F4模式handoff | 复杂 | 大幅简化 |
| Tie-line P/Q预平衡 | 仍需要 | 仍需要 |
| J1 OPEN瞬态 | 仍存在 | 仍存在 |
| Black Start | GFM切换后实现 | 天然更直接 |
| 非计划孤岛 | 需检测+切GFM | 更容易继续支撑 |
| 并网P/Q管理 | 相对简单 | 需要合理Droop/secondary control |
| 控制实现复杂度 | 高 | 较低 |

# 14. 为什么固定GFM对我们当前项目特别有吸引力

因为当前已经证明：

```text
ESS1在J1 CLOSED时
作为GFM并联Grid
可以稳定工作。
```

A0/B1健康开断前：

```text
Vd≈0
Vq≈1
ModIndex有裕度
```

所以：

```text
“GFM不能并强网”
```

不是当前问题。

既然GFM本来就可以并网，

那继续让ESS1：

```text
先GFL
再切GFM
```

就需要问：

> 这个复杂模式切换到底给项目带来什么必要收益？

如果没有硬性研究要求，

固定GFM会更简洁。

---

# 15. 但为什么Gate A仍然必须做

因为固定GFM架构成立的前提是：

# ESS1真的能在没有Grid时自主形成并维持岛网。

现在我们只证明：

```text
ESS1 GFM + Grid并联
可以健康
```

还没证明：

```text
ESS1 GFM独立
可以健康。
```

所以Gate A依然是关键。

---

# 16. Gate A PASS以后，固定GFM方案会变得很有吸引力

如果Gate A证明：

```text
J1初始OPEN
ESS1可以自主软启动
并维持真实被动岛网
```

那么最简最终架构可以直接考虑：

```text
ESS1长期GFM

其它5台GFL
```

Gate B只研究：

```text
并网时：
如何管理ESS1 P/Q

准备离网：
如何把P/Q/I_tie压小

如何HOLD secondary control

J1 OPEN
```

而不再研究：

```text
ESS1 GFL→GFM
```

---

# 17. Gate A FAIL以后，固定GFM也救不了我们

如果：

```text
J1从一开始OPEN
Supervisor旁路
Vref慢Ramp
五台active GFL断开
```

ESS1仍不能建立稳定岛网，

那么：

```text
“让ESS1长期GFM”
```

不会 magically解决问题。

因为它的基本GFM autonomous能力就不合格。

那时必须先修：

```text
autonomous output impedance
LC damping
Current Loop
F6
```

或者考虑换GFM master。

---

# 18. 所以固定GFM和当前模式切换的核心差异可以压成一句话

当前方案：

> **离网时既改变ESS1控制器本身，又改变电气网络。**

固定GFM：

> **离网时ESS1控制器保持原样，只改变电气网络和上层功率管理。**

这就是它更好实现、更容易验证、更不容易产生状态跳变的根本原因。

---

# 19. 之前所有验证是否因此“作废”

# 完全不会。

应该分三类。

---

## A类：永久有效

```text
527 Hz物理LC模态
Voltage PI 2/14错误
0.02/0.14改善
local V/I
phase0
R/L
sign
Current PI baseline
五台GFL隔离结论
```

这些继续作为固定GFM设计基础。

---

## B类：证明了旧模式切换架构为什么复杂

```text
F3 stale state
F4 GFL/GFM angle handoff
```

如果固定GFM，

这些具体故障不再是最终运行问题，

但它们不是白做：

> 它们恰恰证明了“模式切换为什么容易出问题”。

---

## C类：仍必须继续处理

```text
Gate A autonomous capability
J1 open boundary current/P/Q
Supervisor hold/release
full six-inverter island
```

固定GFM并不会自动关闭这些。

---

# 20. 对当前项目最合理的决策顺序

现在不要立即宣布：

```text
最终就改固定GFM。
```

正确顺序：

```text
Gate A
↓
ESS1 autonomous GFM PASS？
│
├─ NO
│   → 先修GFM本体
│
└─ YES
    ↓
    正式比较两种系统架构：

    A. GFL→GFM mode switching

    B. ESS1 permanent GFM anchor
```

此时从：

```text
复杂度
鲁棒性
CHIL实现
BOARD15状态机
论文价值
```

再做最终选择。

---

# 21. 当前一句话最终判断

> **固定GFM不会推翻我们过去的MAT结论，也不会自动消除当前J1开断失败；它真正消除的是“ESS1底层控制器从GFL切到GFM”这一整类hybrid mode transition问题。我们过去的F3/F4正好证明了这一类切换确实复杂，而A0/B1/B2又证明即使ESS1已经提前GFM数秒，J1边界切换本身仍有独立问题。因此固定GFM的价值不是“让所有旧问题消失”，而是把最终系统从“控制模式切换+网络切换”简化成“GFM始终存在，只管理P/Q/I预平衡和网络切换”。原527 Hz、VPI、local frame等结论继续有效；F3/F4的模式handoff用途会减少；Gate A和Gate B仍必须做。Gate A PASS以后，固定GFM才会成为一个真正值得采用的更简洁最终架构。**
