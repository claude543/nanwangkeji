# K26_K50 五台 GFL 物理恢复架构｜R1 后剩余审计与冻结条件

日期：2026-09-12  
当前模型：`K26_K50_CLEAN_P1`  
状态：**R1 大架构已明确；最终 Patch 设计尚不宣布冻结，先完成 R2 最后一轮定向只读审计。**

## 1. R1 已经确认的事实

- 五台 GFL 分布在三个实时任务：
  - `SS_Slave3`：PV1、PV2
  - `SS_Slave2`：ESS2
  - `SS_Slave`：EV1、EV2
- 五台均已有各自的 `AA15_GFL_ISLAND_SUPPORT`。
- 五台 `AA15_V49_CURRENT_EXECUTION_ADAPTER` 核心代码一致。
- 五台最终状态核心、最终限幅核心一致。
- 五台 `Power Control Loop` 结构一致，均含两个离散积分器。
- 当前 OpWrite 已经正好 5 个：G26～G30；**禁止设计 G31**。
- ESS2 Stage1 后段已经证明：P/Q/支撑参考为 0，但最终电流参考仍持续偏大、调制度长期饱和，因此不能把原因归结为“Q 没归零”。

## 2. 为什么 R1 还不能直接下 Patch

仍必须把下面四项在**当前用户磁盘模型**里自动化闭合：

1. 五台 P/Q 功率环的误差符号、PI 参数、输出限幅和积分状态语义；
2. 五台 Current Adapter 的真实积分使能、复位、初始化匹配语义；
3. LOCAL15 S14 的黑启动阶段 `AA15_BS_STAGE_ECHO` 当前是否已进入三个 SS 任务，以及现有 24 维组向量是否有 spare；
4. ESS2 断路器内外真实节点、现有两只 V-I 测量块的位置，以及 C2 节点是否存在直接电压测量。
