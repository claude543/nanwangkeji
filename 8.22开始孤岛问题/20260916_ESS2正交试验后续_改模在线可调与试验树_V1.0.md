# ESS2正交试验之后还要怎么查：改模、在线可调与后续试验树 V1.0

# 0. 先纠正一个关键点

你说得对：

> **“电流执行器 + 功率外环都开启”的试验其实我们已经做过了。**

当前这轮正式小功率试验本质上已经证明：

```text
Current Adapter（电流参考执行适配器） = 开
Power Loop（功率外环） = 开
↓
Pref先保持0约5秒
↓
已经出现慢振荡增长
↓
之后才进入 -0.005 pu 小功率斜坡
```

所以我们现在不需要再做一次“两个都开”的重复实验。

下一步真正缺的是：

```text
A：
Current Adapter = 开
Power Loop = 关
```

也就是只拿掉功率外环，保留后面的真实电流执行链。

---

# 1. 如果去掉PQ功率外环以后稳定，是不是就直接修PQ外环？

**方向上是。**

但还不能立刻开始盲调 `Kp/Ki`。

因为“去掉PQ外环以后稳定”只能证明：

> **决定性不稳定因素在功率外环这一层或它与PLL/弱网的反馈关系中。**

它还不能自动告诉我们：

```text
究竟是：
P外环？
Q外环？
P比例项？
P积分项？
功率测量滤波？
PLL参与？
P/Q耦合？
```

所以后面还需要第二层正交试验。

---

# 2. 现在最合理的完整试验树

整个后续不要再“大范围改模型”，而应该像剥洋葱一样每次只拆一层。

---

## Test A0：纯电流执行，零电流参考

```text
Current Adapter = ON
P Power Loop = OFF
Q Power Loop = OFF

Id_ref = 0
Iq_ref = 0

额外support = OFF
Coordinator = OFF
Secondary = OFF
```

目的：

> 看“只有真实电流执行链存在”时，ESS2并回以后会不会自己激发当前约0.8~0.9 Hz慢振荡。

### 如果 A0 都不稳定

那么：

```text
Power Loop不是根因
```

问题继续下沉到：

- Current Adapter；
- Current Regulator（电流控制器）；
- PLL（锁相环）；
- dq坐标；
- VFF（电压前馈）；
- 弱网电气耦合。

这时不能去调 Power PI。

### 如果 A0 稳定

说明：

> **电流执行层本身至少在零参考附近可以稳定工作。**

继续 A1。

---

# 3. Test A1：关闭功率外环，直接给一个极小固定d轴电流

这是我认为非常重要、而且比“马上调Power PI”更有价值的一步。

配置：

```text
Current Adapter = ON
P Power Loop = OFF
Q Power Loop = OFF

Direct Id injection（直接d轴电流注入）：
0 → 一个非常小的固定值

Iq_ref = 0
```

注意：

> 这不是让ESS2“通过功率外环控制 -0.005 pu”。

而是：

> **完全绕过功率外环，直接告诉电流内环：给我一个很小的d轴电流。**

---

## 为什么A1非常重要？

因为它可以回答：

> **ESS2的物理功率通道和电流内环到底有没有能力稳定地送/吸一点有功？**

如果：

```text
Power Loop关闭
↓
给一个很小的固定Id
↓
ESS2确实产生一小段稳定P
↓
整个孤岛仍然稳定
```

那就非常有力地说明：

```text
功率器件
+
滤波器
+
Current Adapter
+
Current Regulator
+
ESS1 GFM
+
弱孤岛物理网络
```

本身是可以承担小功率交换的。

于是问题就不再是：

> “ESS2只要一有功率就不稳定。”

而是：

> **“ESS2只要让Power Loop根据P误差不断自动调整Id，就不稳定。”**

这个因果区分非常关键。

---

# 4. 如果A0、A1都稳定，下一步才是真正锁Power Loop

---

## Test B-P0：只打开P外环，目标仍为0

配置：

```text
Current Adapter = ON

P Power Loop = ON
Q Power Loop = OFF

Pref = 0
Qref = 0
```

这次只增加一个东西：

```text
P Power Loop（有功功率外环）
```

如果：

```text
A0稳定
A1稳定
B-P0重新出现同样0.8~0.9 Hz慢振荡
```

那么因果证据就非常强：

> **P外环就是决定性新增因素。**

这时才应该开始研究P外环怎么修。

---

# 5. Q外环怎么办？

不能把P和Q重新绑在一起。

虽然本轮 `QIntegral=0`，当前主要嫌疑明显偏向P外环，但如果我们要做严格诊断，模型最好还是把：

```text
P Power Loop Enable
Q Power Loop Enable
```

拆开。

后续可以单独做：

```text
Test B-Q0：
P Loop = OFF
Q Loop = ON
Qref = 0
```

以及更晚：

```text
Test Q-small：
P Loop = OFF
Q Loop = ON
给极小Qref
```

但当前优先级明显低于P链。

---

# 6. 如果确认是P外环，下一步从哪里修？不是直接盲调Kp/Ki

确认P外环是决定性因素后，还应该继续拆：

```text
P Power Loop
=
比例部分
+
积分部分
+
P测量
+
PLL/坐标动态
+
弱网对象
```

推荐顺序如下。

---

## Test C1：P外环只保留比例项

也就是：

```text
Kp = 当前值
Ki = 0
Pref = 0
```

### 如果C1稳定

说明：

> **积分作用是决定性新增因素之一。**

这时候才值得研究：

- Ki太大；
- 功率外环积分带宽太快；
- 积分器和PLL/ESS1 GFM形成慢振荡；
- 是否需要抗积分饱和/跟踪型积分；
- 是否需要弱网模式下的Ki调度。

### 如果C1仍然不稳定

说明：

> 问题并不依赖积分项。

继续检查：

- Kp本身；
- 功率测量动态；
- PLL；
- P计算坐标；
- 弱网对象相位滞后。

---

# 7. 如果比例项自己也不稳定，再怎么查？

这时再做：

## Test C2：降低P外环比例增益

例如按倍率做，不要乱选绝对值：

```text
Kp scale = 1.0
0.5
0.25
0.1
```

每一轮：

```text
Ki = 0
Pref = 0
```

目的不是找“最好参数”，而是看：

> **降低P外环带宽以后，0.8~0.9 Hz负阻尼是否逐渐消失。**

如果随着Kp降低：

```text
振荡增长率持续下降
```

那就说明：

> **外环太激进 / 带宽与弱网对象不匹配。**

---

# 8. 如果比例-only稳定，再怎么处理积分？

再做：

```text
Kp固定在已验证稳定值
Ki从0开始逐级恢复
```

例如：

```text
Ki scale：
0
0.1
0.25
0.5
1.0
```

每轮单独 Reset → Load → Execute。

观察：

- 是否出现0.8~0.9 Hz；
- 振荡增长率；
- PIntegral幅值；
- Pmeas；
- Vpu；
- PLL；
- current error；
- modulation headroom。

这样可以得到一个很清楚的：

> **Ki稳定边界趋势。**

而不是“凭感觉调小一点”。

---

# 9. 还需不需要测一个真实小功率目标？

需要。

但在P外环零目标已经稳定以后才做。

顺序：

```text
Pref = 0
确认稳定

↓
-0.001 pu

↓
-0.0025 pu

↓
-0.005 pu
```

最好用同样固定斜率。

这一步回答：

> **外环在零误差附近稳定，不代表它面对真实功率任务也一定稳定。**

所以最后还要验证闭环承担实际功率的能力。

---

# 10. 我们现在改模应该改成“在线可调”吗？

**是，但只暴露最少的一组诊断参数。**

不要再把一大堆模型内部东西都做成在线可调。

建议新增/暴露：

```text
BASETEST_ENABLE

P_LOOP_ENABLE
Q_LOOP_ENABLE

ADAPTER_ALPHA_OVERRIDE_ENABLE
ADAPTER_ALPHA_CMD

DIRECT_ID_INJECTION_ENABLE
DIRECT_ID_REF_PU

DIRECT_IQ_INJECTION_ENABLE
DIRECT_IQ_REF_PU

P_KP_SCALE
P_KI_SCALE

Q_KP_SCALE
Q_KI_SCALE
```

其中第一阶段真正要用的只有：

```text
P_LOOP_ENABLE
Q_LOOP_ENABLE
ADAPTER_ALPHA_CMD
DIRECT_ID_INJECTION_ENABLE
DIRECT_ID_REF_PU
```

Kp/Ki倍率先暴露出来，但在A0/A1/B-P0因果隔离完成以前不要乱调。

---

# 11. 为什么用“倍率”而不是直接把Kp/Ki重写掉？

因为当前正式参数：

```text
P Kp = 0.06
P Ki = 2
```

最好继续保留为基准。

诊断层做：

```text
Kp_eff = Kp_base × P_KP_SCALE
Ki_eff = Ki_base × P_KI_SCALE
```

例如：

```text
P_KP_SCALE = 1
P_KI_SCALE = 0
```

就得到比例-only。

优点：

- baseline清楚；
- 恢复容易；
- Python只改倍率；
- 不容易把正式参数写乱；
- 每次实验可复现。

---

# 12. Python应该怎么参与？

是的：

> **模型暴露最少的在线可调参数，Python负责每一轮试验配置。**

但正式比较不要让Python在一轮里面随意“边看边调”。

正确方式：

```text
每一轮：
Reset
↓
Load once
↓
MODEL_PAUSED @ t≈0
↓
Python写入固定配置
↓
立即readback
↓
Execute
↓
模型内部按固定时序运行
↓
Pause
↓
保存G27/G29/G30
↓
DirectMAT分析
```

也就是说：

> **Python负责“实验配置”，模型负责“实验时序”，MATLAB负责“数值计算”。**

这继续沿用我们已经验证成熟的分工。

---

# 13. 不建议同一轮里在线扫很多参数

虽然参数可以在线写，但不建议：

```text
跑着跑着：
Kp=1
↓
0.5
↓
0.25
↓
Ki又变
```

因为：

- 积分器带有历史状态；
- 母线已经受前一阶段扰动；
- 不同参数之间不是相同初始条件；
- 后面很难做严格A/B比较。

所以：

> **在线可调 ≠ 同一轮随便调。**

真正用途是：

> **不用每改一个诊断参数就重新Build模型。**

每一轮仍然应该从相同初始状态启动。

---

# 14. 当前最推荐的改模结构

不要大改Power Loop内部。

只加一个 BASETEST Diagnostic Router（基础诊断路由器）。

概念上：

```text
                 ┌──────────── P_LOOP_ENABLE
P error ────────>│
                 │
                 └──────────── Power PI
                                  │
                                  │ normal P current ref
                                  ▼
                           ┌──────────────┐
Direct Id Ref ────────────>│ BASETEST MUX │
                           └──────────────┘
                                  │
                                  ▼
                         Current Adapter
                                  │
                                  ▼
                         Current Regulator
```

并保留：

```text
Imeas
↓
Current Regulator
```

永远不关闭。

Q轴同理，但当前可以先保持Q Loop关闭、Iq direct=0。

暂时不要：

- 改VFF；

- 开Secondary；
- 恢复PV/EV；

```text
A0：
outer loop OFF / direct current 0

A1：
outer loop OFF / direct small Id

B-P0：
P outer loop ON / Pref 0
```

这三步。

# 16. 当前一句话决策

> **对，我们已经做过“Current Adapter + Power Loop都开”的试验，所以不需要重复。下一版模型应该暴露少量BASETEST在线诊断参数，由Python在每一轮开始前配置：先做A0纯电流执行零参考，再做A1绕过功率外环直接给极小d轴电流，确认ESS2物理和电流内环能稳定承担一点真实有功；如果这两步稳定，再做B-P0只加入P功率外环而Pref仍为0。只有B-P0重新出现0.8~0.9 Hz慢振荡以后，才正式进入P外环内部的比例/积分分解和Kp/Ki稳定边界试验。**
