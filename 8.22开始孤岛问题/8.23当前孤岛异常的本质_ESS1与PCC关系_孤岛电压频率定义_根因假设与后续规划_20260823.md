# 0. 先给最重要的结论

当前真正的问题已经不能再简单概括成：

```text
PCC频率显示55 Hz
```

也不能简单概括成：

```text
离网时电压有一个瞬态
```

本轮高分辨率数据说明，真正的问题是：

# **J1真正打开、强电网支撑消失以后，微电网孤岛侧没有形成一个健康、稳定的约50 Hz三相正弦电压，而进入了持续的强振荡/严重波形畸变状态。**

于是出现两个“表面症状”：

```text
症状1：
PCC的总RMS电压仍能达到约10~11 kV
看起来好像“电压恢复了”

但实际上：
50 Hz附近的基波已经大幅衰减
大量RMS来自非50 Hz振荡/高频成分
```

以及：

```text
症状2：
PCC PLL测频逐渐升高
最后撞到55 Hz限幅

但55 Hz并不是一个健康的、
稳定的“真实55 Hz孤岛基波”
```

所以当前根问题应该重新命名为：

# **“孤岛建立后的电压波形稳定性问题”**

或者更通俗：

# **“ESS1接过‘电网电压源’这个任务以后，整个孤岛没有稳定成正常的10 kV、50 Hz三相电网。”**

---

# 1. 现在问题究竟从哪里开始出现？

这是当前最重要的时间因果。

本轮高分辨率SM记录锁定：

```text
55~60 s：
ESS1已经进入GFM
但J1仍然闭合
上级强电网仍然连接
PCC电压和频率基本正常

60.0005 s：
真实J1打开

之后：
PCC三相电压波形开始明显恶化
PCC PLL频率开始漂移

约60.43 s：
PCC测频撞到55 Hz上限

此后：
异常波形持续存在
不是一个短暂尖峰
```

所以：

> **真正把问题暴露出来的事件，是“J1真正断开，强电网支撑消失”。**

---

# 2. 这是不是说明J1本身有问题？

目前不支持这个结论。

J1已经完成：

```text
真实物理断路器修复
+
100 μs Z^-1处理
+
真实开断时刻记录
```

而且最新回归证明：

```text
并网状态正常
J1打开前PCC波形健康
J1打开后才出现孤岛异常
```

所以目前更合理的理解不是：

```text
“J1开错了”
```

而是：

> **J1一打开，原来由强网承担的“建立电压、频率、相角”的责任转移到了孤岛内部，而当前孤岛自身没有稳定承担住这个任务。**

# 3. 为什么55~60 s ESS1已经GFM了，却不能证明ESS1构网正常？

这是一个很容易误解的地方。

55 s以后：

```text
ESS1 GridOn = 0
→ GFM控制路径已经选中
```

但此时：

```text
J1仍然闭合
→ 10 kV强网仍直接连接着微电网
```

因此整个系统仍然有一个非常强的外部电压源：

```text
上级电网
→ 10 kV
→ 50 Hz
→ 强电压刚度
```

即使ESS1的GFM：

- 电压环不够稳定；
- 相角状态有偏差；
- 电流环和电压环组合有问题；
- 与其他逆变器存在交互问题；

强电网都可能把母线电压牢牢“压”在接近正常状态。

所以：

```text
ESS1切GFM
+
J1仍闭合
+
PCC看起来正常
```

只能证明：

> GFM控制路径能够在强网存在时接入运行。

它不能证明：

> ESS1能够在失去强网以后独立支撑整个孤岛。

真正的考试是：

```text
60.0005 s
J1 OPEN
```

这一刻以后。

# 4. 当前已经知道哪些“不是根因”？

先把已经排除或明显降级的方向列出来，这样后面不重新绕回去。

---

## 4.1 不是以前的900 kW负荷边界错误

旧拓扑：

```text
DER
→ PCC Measurement
→ 900 kW Load1/Load2
→ J1
→ Grid
```

J1打开以后900 kW还留在岛内，因此必然严重功率不足。

现在已经改成：

```text
DER
→ PCC Measurement
→ J1
→ Load1/Load2 + Grid
```

因此J1打开后：

```text
Load1/Load2
留在Grid侧
```

900 kW长期过载主根因已经排除。

---

## 4.2 不是主网频率本身异常

本轮：

```text
Grid measured frequency
≈ 50 Hz
```

全程稳定。

所以不是：

```text
上级电网自己从50跑到了55
```

---

## 4.3 不是S15把ESS1 Fref命令成55 Hz

本轮Group28中：

```text
AA15_S15_FREF_TRIM_HZ = 0
```

而：

```text
ESS1 Final Fref
J1打开前 ≈ 49.996 Hz
之后下降
最终 ≈49 Hz
```

所以：

```text
55 Hz
```

并不是上层直接向ESS1下发：

```text
“请输出55 Hz”
```

造成的。

---

## 4.4 不能再把PLL当成唯一根因

如果只是：

```text
真实Vabc一直很正常
但PLL自己算错
```

那么修PLL就够了。

但本轮已经看到：

```text
PCC真实Vabc本身
在J1打开以后就发生严重非50 Hz振荡/畸变
```

所以：

> PLL的55 Hz失真是一个**症状**，但不是全部根因。

PLL面对的输入本身已经不好。

---

## 4.5 “离网后普通PCC AGC还继续更新”不是当前高频振荡的首要嫌疑

当前LOCAL15确实存在：

```text
进入孤岛以后
普通PCC有功协调没有被真正门控
```

这是一个模式语义问题。

但基础AGC更新周期约：

```text
1 s
```

而当前波形里出现的是：

```text
远高于1 Hz的快速振荡
```

因此普通PCC AGC可能影响：

```text
孤岛慢速功率平衡
Pref运行点
长期频率/功率状态
```

但它很难直接解释：

```text
几百Hz甚至更高的持续电压振荡
```

所以它不是当前高速振荡的第一根因。

而且BOARD15 C09已经正式实现了离网模式对P协调更新的门控，因此这一项后续作为Board集成验收项处理，不作为当前LOCAL15模型大改项。

# 5. 那么现在最可能的根因在哪一层？

现在只能给出**根因区域和优先级**，还不能假装已经知道唯一根因。

目前最值得怀疑的是：

# **“ESS1 GFM + 逆变器控制内环 + 孤岛电气网络之间的动态稳定性。”**

可以分成四类。

# 6. 候选根因A：ESS1的GFL→GFM状态切换没有真正做到状态对齐

此前只读审计已经看到：

```text
Droop相角积分状态
没有明显的PLL相角跟踪初始化

Voltage Regulator
没有明显用GFL当前电流参考
去初始化GFM电压调节器状态
```

通俗解释：

并网时，ESS1走的是：

```text
GFL
跟网控制链
```

准备离网时切成：

```text
GFM
构网控制链
```

这两套控制器内部都有自己的“记忆”：

```text
相角
积分器
电流参考
电压调节状态
```

如果GFM接管前，这些内部状态并没有对齐到当前实际运行点，

就可能发生：

```text
切换时：
GFL的当前状态
≠
GFM内部当前状态

↓
控制器突然接管
↓
电压/电流命令跳变
↓
激发振荡
```

但要注意：

> 这一点目前只是“高优先级候选”，还不是最终判决。

因为55~60 s有强网存在，强网可能把这种问题暂时压住；J1打开后才真正暴露。

---

# 7. 候选根因B：ESS1 GFM电压环/电流环本身在孤岛网络下不稳定

当前ESS1 GFM并不是一个简单理想电压源。

内部大致是：

```text
Droop
↓
电压参考
↓
Voltage Regulator
↓
Id/Iq_ref
↓
Current Regulator
↓
变流器电压命令
↓
PWM
↓
逆变器
↓
滤波器/变压器
```

并网时：

```text
强网阻抗很低
母线很硬
```

离网以后：

```text
强网消失
```

ESS1的：

```text
电压外环
电流内环
滤波器
变压器
线路
```

共同决定闭环极点。

如果某一组：

```text
PI增益
采样
延迟
滤波器参数
阻尼
```

只适合强网条件，

孤岛以后就可能出现：

```text
欠阻尼
甚至持续振荡
```

这与当前现象非常吻合：

```text
强网在 → 正常
强网断 → 持续振荡
```

# 8. 候选根因C：ESS1 GFM与其他五台GFL逆变器之间发生控制交互/网络谐振

孤岛里不是只有ESS1一台设备。

当前岛内还有：

```text
PV1
PV2
ESS2
EV1
EV2
```

它们大部分仍按GFL路径工作。

于是孤岛结构变成：

```text
ESS1
= 唯一主要电压/频率形成源

其余设备
= 跟着孤岛电压运行的电流型/GFL设备
```

每一台设备都有：

```text
PLL
电流环
滤波器
变压器
线路
```

这些控制和网络阻抗耦合以后可能出现：

```text
GFM-GFL interaction
构网/跟网交互振荡

或

converter-network resonance
变流器-网络谐振
```

因此即使：

```text
ESS1单独看控制器没明显错
```

六设备并在同一个弱孤岛以后仍然可能不稳定。

这也是为什么下一步不能只盯Droop一个块。

# 9. 候选根因D：当前看到的具体“约500 Hz”并不一定是真实振荡频率

本轮SM日志：

```text
采样率 = 2 kHz
Nyquist = 1 kHz
```

模型真实：

```text
100 μs
= 10 kHz
```

因此更高频的：

```text
PWM相关成分
电流环振荡
滤波器谐振
```

可能在2 kHz记录中混叠到：

```text
约500 Hz
```

所以现在可以确定：

```text
存在很强的非50 Hz持续波动
```

但还不能确定：

```text
真实主振荡频率究竟是不是530 Hz
```

这正是全速SM记录以后要解决的一个问题。

# 10. 为什么这个问题一定要解决？

这里“必须解决”不是为了让曲线好看。

它直接关系到五件核心事情。

---

## 10.1 如果孤岛电压本身不健康，就根本不能说“孤岛运行成功”

一个正常50 Hz微电网不能只满足：

```text
RMS≈10 kV
```

还必须至少满足：

```text
三相基本平衡
以50 Hz基波为主
波形近似正弦
频率稳定
电压稳定
```

如果：

```text
总RMS = 10 kV
```

但10 kV主要来自几百Hz甚至更高的振荡，

这不是：

```text
正常10 kV交流电网
```

---

## 10.2 S14黑启动会失去意义

黑启动的核心就是：

```text
没有主网
↓
ESS自己建立一个正常的交流电网
```

如果ESS1只能建立：

```text
严重畸变的10 kV量级波形
```

那么即使：

```text
状态机进入BLACK_START
```

也不能称为真实黑启动成功。

---

## 10.3 S15重同步根本无法可信工作

S15依赖：

```text
ΔV
Δf
Δθ
```

但这些量都建立在：

```text
PCC电压是一个正常近正弦基波
PLL能够正确锁定
```

这个前提上。

现在PCC波形严重异常时：

```text
PCC Freq = 55
PCC Phase = ?
PCC RMS = ?
```

这些数字已经不能按正常同步量理解。

此时如果还执行：

```text
同步判断
→ J1重合
```

是错误的。

---

## 10.4 BOARD15以后会收到错误的Plant状态

Board最终不是只看PCC有功。

它还需要系统状态，例如：

```text
PCC V
PCC f
模式
设备执行状态
```

如果Plant在孤岛后自己振荡，

那么Board看到：

```text
异常V/f
```

以后做出的策略动作就会混入Plant本身故障。

最后我们会分不清：

```text
是Board算法错
还是实时对象本身就不稳定
```

因此最终CHIL前必须把Plant稳定性问题隔离掉。

---

## 10.5 第一篇论文的实验会被污染

论文要研究：

```text
执行状态失配
+
状态重建
+
恢复协调
```

如果孤岛Plant本身已经存在严重控制振荡，

那么实验中：

```text
PCC误差
设备执行偏差
恢复超调
```

都可能同时含有：

```text
Plant不稳定
```

这会让论文无法干净证明：

```text
性能变化是因为所研究的方法
```

还是：

```text
因为基础模型本身异常
```

# 11. 第二个问题：ESS1的Vabc和PCC频率到底有什么关系？

这是一个非常关键的问题。

你的疑问是：

> “ESS1交流端实际形成的三相电压被prim_ESS1测出来，这是ESS1；我们现在发现异常的是PCC频率，这是PCC。两者不是两个地方吗？”

答案是：

# **对，它们是两个不同的测量位置；但它们属于同一个孤岛电气网络，而且ESS1正是这个孤岛里的主要构网源。**

所以两者不是“同一个量”，但存在明确的物理因果关系。

# 12. 先把当前位置画出来

根据最新模型本体，ESS1这一支路可以简化成：

```text
                    微电网公共网络
                          │
                          │
                     Line_ESS1
                          │
                ESS1支路10 kV节点
                          │
                    prim_ESS1
               【Vabc/Iabc测量】
                          │
              10 kV / 480 V变压器
                          │
                       滤波器
                          │
                    ESS1逆变器
```

而系统边界是：

```text
2PV + 2ESS + 2EV
        │
        ▼
微电网公共网络
        │
        ▼
PCC V/I Measurement
        │
        ▼
J1_PCC_Breaker
        │
        ├── Load1
        ├── Load2
        │
        ▼
上级电网
```

所以：

```text
prim_ESS1
```

测的是：

> **ESS1支路自身的10 kV侧局部电压。**

而：

```text
PCC Measurement
```

测的是：

> **整个微电网在与上级电网连接边界处的10 kV母线电压。**

它们不是同一个位置。

---

# 13. 为什么两个位置的电压会相互关联？

因为中间不是断开的。

它们之间通过：

```text
Line_ESS1
+
微电网公共母线
```

电气连接。

所以ESS1作为一个电压源向网络作用时：

```text
ESS1逆变器
↓
滤波器/变压器
↓
ESS1本地10 kV节点
↓
Line_ESS1
↓
微电网公共母线
↓
PCC
```

它建立出来的电压波形会沿电气网络传播到PCC。

---

# 14. 并网时为什么两者关系不那么显眼？

因为此时：

```text
PCC
↓
J1 CLOSED
↓
强网
```

强网本身就是一个很强的10 kV、50 Hz电压源。

所以网络实际是：

```text
强网
←→ PCC
←→ 微电网母线
←→ ESS1
```

此时ESS1更多是在：

```text
往已经存在的电压上注入电流/功率
```

而不是：

```text
整个网络都由ESS1定电压
```

因此即使ESS1自己的构网控制有一些问题：

```text
PCC仍可能被强网固定得很好
```

---

# 15. J1打开以后为什么ESS1和PCC的关系突然变得关键？

J1一打开：

```text
PCC
×
Grid
```

强网不再参与岛内电压形成。

于是：

```text
ESS1 GFM
```

必须承担：

```text
建立岛内电压
+
建立岛内频率
+
建立相角基准
```

这时因果链变成：

```text
ESS1 GFM
↓
ESS1本地Vabc
↓
微电网线路/其他设备
↓
PCC Vabc
↓
PCC PLL
↓
PCC Frequency
```

所以：

> **PCC频率并不是凭空产生的。它首先来自PCC处真实Vabc的相位变化，而PCC Vabc在孤岛里又受到ESS1这个GFM源以及整个网络共同决定。**

# 17. 所以“ESS1 Vabc”和“PCC Frequency”之间不是一跳关系

不是：

```text
ESS1 Vabc
= PCC Frequency
```

```text

↓
```

```text

→ PLL对PCC Vabc的频率估计
```

# 18. 第三个问题：所谓“孤岛的电压”究竟是哪里的？



# 22. 那“孤岛频率”又究竟是哪里的？

频率和电压不完全一样。

在一个正常、同步运行的AC孤岛中：

```text

```

应该共享同一个基本：

```text

```

例如：

```text

PV节点   ≈ 50.0 Hz
```

它们的：

```text
相角
```

可以不同，

电压幅值也可以不同，

但是在稳定同步状态下：

> **基波频率应该基本相同。**

---

# 23. 为什么频率看起来像“全局量”？

因为不同母线之间如果长期：

```text
ESS1 = 49 Hz
PCC = 55 Hz
```

它们的相角差会不断积累：

\[
\Delta\theta(t)
=
2\pi(f_1-f_2)t
\]

两者不可能在一个连通AC网络里长期保持同步。

所以正常稳态下：

```text
一个连通孤岛
→ 一个共同系统频率
```

# 24. 但是为什么不同PLL又可能报出不同“频率”？

因为实际记录的：

```text
Freq_PLL
```

不是“自然界直接给你的频率”。

它是：

```text
PLL根据当地Vabc
估计出来的频率
```

当Vabc严重畸变时：

```text
不同地点
不同PLL
不同限幅
不同滤波
```

可能得到不同的“瞬时频率”。

此时：

> **“系统频率是多少”本身已经不能只靠一个PLL数字定义。**

这就是我们现在的情况。

# 25. 当前真正的“孤岛频率”应该怎么理解？

本轮数据中：

```text
PCC PLL = 55 Hz
```

但PCC Vabc的低频主成分大约：

```text
49.1~49.2 Hz
```

同时：

```text
ESS1 Final Fref ≈49 Hz
```

所以更准确说：

> **当前孤岛仍存在约49 Hz的低频基波成分，但这个基波已经被非常强的非50 Hz振荡/高频畸变覆盖，因此系统已经不处于一个可以用单一“健康频率”描述的正常孤岛状态。**

所以现在不能说：

```text
孤岛频率 = 55 Hz
```

也不能简单说：

```text
孤岛频率 = 49 Hz
```

更准确是：

```text
基波附近 ≈49 Hz
+
强烈持续振荡
+
PLL已失去可信度
```

# 31. 当前为什么“不正确”？

当前PCC在J1打开以后：

```text

```

这一点表面上看很像正常。

但分解以后：

```text
50 Hz附近基波
只剩约1~1.5 kV量级

大量RMS来自
持续非50 Hz振荡/高频分量
```

所以当前的错误不是简单：

```text
“电压太高”
或
“电压太低”
```

而是：

# **电压波形的频谱结构已经错了。**

正常应该：

```text
绝大部分能量集中在50 Hz基波
```

现在却：

```text
大量能量集中在非50 Hz快速振荡
```

---

# 32. 这也解释了为什么PCC PLL会报55 Hz

PLL的工作对象应该是：

```text
近似正弦的三相基波
```

现在它面对：

```text
基波很弱
+
巨大快速振荡
```

相当于你让一个“专门追踪正常50 Hz正弦”的算法去追一条已经严重变形的波。

于是：

```text
PLL估计开始漂
```

最终：

```text
外部Saturation
把它夹在55 Hz
```

所以55 Hz是一个非常合理的“失锁后限幅症状”。

## 3. 孤岛电压/频率到底是ESS1的还是PCC的？

### 电压

不是一个唯一全局值。

```text
ESS1有ESS1本地电压
PCC有PCC电压
其他母线也有各自电压
```

ESS1作为GFM负责建立电压基准，

### 频率

在健康稳定的连通孤岛中：

```text
所有节点的基波频率
应该基本一致
≈50 Hz
```

ESS1 GFM负责形成这个系统频率基准，

PCC只是其中一个系统级测量位置。

正确孤岛应该是：

```text
ESS1端：
近似10 kV、50 Hz、三相正弦

PCC微网侧：
同样以10 kV、50 Hz基波为主
允许有小的压降/功角差

Grid侧：
10 kV、50 Hz
但与岛内通过OPEN的J1断开
```

```text
PCC总RMS看起来约10~11 kV
但正常50 Hz基波很弱
持续快速振荡占主导
PLL因此失真并报55 Hz
```

所以当前不是“PCC一个数字不漂亮”，

而是：

# **孤岛电网本身还没有真正形成一个健康的50 Hz交流系统。**
