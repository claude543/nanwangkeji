# 8.23｜80 MB诊断文件与530 Hz、480 Hz、500 Hz关系澄清

## 1. 80 MB MAT 会不会“吃掉”80 MB聊天上下文？

不会。

后续MAT主要是在分析环境里直接读取数组、做FFT、互谱、相位、时间窗和模态参与度计算。不会把80 MB里的每一个double数值全部转换成聊天文字。因此：

```text
MAT文件磁盘大小
≠
聊天上下文消耗
```

80～90 MB这种量级可以继续处理。真正需要注意的是这个项目对话本身已经很长，我无法查看网页版对你显示的精确剩余上下文或保证当前窗口永远不会触发上限。

所以后续固定采用：

```text
MAT → 工具直接分析
→ 聊天只保留关键结果
→ 每个关键断点生成8.23_xxx.md
```

即使之后需要换窗口，也可以依靠最新断点文件继续，不需要重新排错。

## 2. 这些频率必须彻底分开

| 数字 | 性质 | 正常吗？ |
|---|---|---|
| 50 Hz | 微网正常三相基波 | 应该存在 |
| 55 Hz | 当前异常波形下PLL测频撞上限的表现 | 不正常，只是症状 |
| 约527.4 Hz | ESS1相关LC/网络理论自然模态 | 这个“模态存在”本身可以正常 |
| 约530～532 Hz | abc实测到的持续快速振荡 | 不正常 |
| 约480～482 Hz | 同一个530 Hz正序异常进入50 Hz dq坐标后的表现 | 不正常，不是第二个故障 |
| 500 Hz | ESS1正式测量二阶低通滤波器的参数 `fn_Filter` | 参数本身正常，但位置非常可疑 |
| 4 kHz | PWM开关频率 | 正常设计参数 |

---

## 3. “530 Hz正序振荡”不是说530 Hz应该存在

“正序”只描述三相关系。

正常三相50 Hz电压：

```text
A → B → C
相差约120°
```

属于正常50 Hz正序基波。

我们实测的530 Hz异常分量也表现出近似A-B-C、120°的组织结构，所以称它为“正序型/正序三相快速振荡”。

但是：

```text
50 Hz正序基波
→ 正常，应该存在

530 Hz正序快速分量
→ 异常，不应该以现在这种大幅值持续存在
```

“正序”绝不等于“正常”。

---

## 4. 527 Hz是什么？

此前根据：

```text
L1
C1
Transformer leakage
Stubline leakage
Line_ESS1
```

得到约527.4 Hz的理想化自然模态。

任何L/C网络都可能存在自然模态，所以：

```text
“存在527 Hz模态”
```

本身不是故障。

正常系统应该：

```text
受到扰动
↓
527 Hz附近短暂振几下
↓
因为有足够阻尼
↓
迅速衰减
↓
重新由50 Hz基波主导
```

当前错误是：

```text
J1打开
↓
该模态被激发
↓
没有衰减
↓
越来越强
↓
实际稳定在约530～532 Hz附近的持续快速振荡
```

所以真正故障是：

# **该模态阻尼不足，甚至可能存在等效负阻尼。**

---

## 5. 为什么理论527 Hz，实际530～532 Hz？

527.4 Hz来自简化LC/网络参数估算。

真实模型还包括：

```text
Voltage Loop
Current Loop
测量滤波
PWM
数字延时
其它5台GFL
饱和
运行工作点
```

所以真实频率与理论值相差几Hz完全合理。

重要的是：

```text
理论约527 Hz
实测约530 Hz
```

落在同一个模态区域。

---

## 6. 480 Hz又是什么？

它不是第二个物理共振。

ESS1 GFM使用约50 Hz同步旋转dq坐标。

如果abc中存在一个约530 Hz、与正方向同向旋转的三相分量，那么控制器站在50 Hz旋转坐标中看到的相对频率大约是：

```text
530 - 50
≈ 480 Hz
```

所以：

```text
abc：约530 Hz
dq：约480 Hz
```

是同一个异常。

正常50 Hz正序基波进入50 Hz同步dq后：

```text
50 - 50 = 0 Hz
```

因此健康状态下Vd/Vq、Id/Iq主要应该接近DC及较慢动态，而不应该持续存在很强480 Hz振荡。

---

## 7. 所以dq里的480 Hz“应该有”吗？

不应该以当前这种大幅值持续存在。

真正“可以正常存在”的只是：

```text
系统数学上具有约527 Hz自然模态
```

当这个模态没有被明显激发，或者具有足够阻尼时：

```text
abc没有强530 Hz持续振荡
dq自然也没有强480 Hz持续振荡
```

当前480 Hz只是530 Hz异常真正发生以后，在dq坐标里看到的同一件事。

---

## 8. 500 Hz低通滤波器又是什么？

最新只读审计已经确认正式GFM反馈：

```text
VdVq_meas
IdIq_meas
P_meas
Q_meas
```

都经过二阶低通：

```text
Fo = fn_Filter
fn_Filter = 500 Hz
ζ = 1
Ts = 100 μs
```

所以500 Hz是：

# **控制器测量滤波器的设计参数。**

它不是另一个500 Hz振荡源。

---

## 9. “500 Hz刚好碰到了527 Hz共振”这个理解接近，但需要修正

更准确的说法是：

```text
LC/网络本身有约527 Hz自然模态
↓
实际abc失稳后约530 Hz
↓
进入50 Hz同步dq
↓
表现成约480 Hz
↓
而正式反馈低通滤波器Fo恰好是500 Hz
```

因此真正发生的“碰撞”是在控制域里：

```text
异常dq模态 ≈ 480 Hz
滤波器特征频率 = 500 Hz
```

两者非常接近。

---

## 10. 为什么这可能危险？

低通滤波器不仅衰减高频，还产生相位滞后。

当前ζ=1的标准二阶低通在480～500 Hz附近，连续域直觉上已经是：

```text
幅值约降到一半量级
相位滞后接近90°
```

实际K26_V5是离散100 μs实现，所以最终真实数值必须由D1直接测：

```text
raw Vdq / Idq
vs
filtered Vdq / Idq
```

不能把理论近似直接当最终结论。

危险机制不是：

```text
500 Hz滤波器主动制造500 Hz信号
```

而可能是：

```text
约527 Hz LC模态被激发
↓
abc约530 Hz
↓
dq约480 Hz
↓
经过500 Hz测量滤波
↓
产生明显相位滞后
↓
Voltage/Current Loop收到“晚了”的反馈
↓
再叠加100 μs级数字/任务延时
↓
本来应该给模态刹车
却可能阻尼不足甚至反向助振
```

因此500 Hz滤波器目前是高优先级的“负阻尼贡献者候选”，但还没有被证明是唯一根因。

---

## 11. 下一轮D1为什么一定要测滤波前后？

因为只有同时测：

```text
Vdq_raw_before_filter
Idq_raw_before_filter

Vd/Vq_after_filter
Id/Iq_after_filter
```

才能直接知道480 Hz附近：

```text
滤波器衰减了多少
滞后了多少
```

再继续对齐：

```text
IdIq_ref
PIdq
VdVq_conv
ModIndex
Vpwm
```

就能判断控制链在哪一级开始对模态产生放大/负阻尼作用。

## 12. 最终最容易记住的版本

> **系统正常应该由50 Hz正序基波主导。ESS1相关L/C网络从数学上本来可以具有约527 Hz的自然模态，这本身不算错误；只要阻尼足够，它平时不会形成大幅振荡，扰动后也应该迅速衰减。当前J1打开以后这个模态失稳，在abc真实电压里表现成约530 Hz的强三相正序型振荡。因为GFM控制器使用50 Hz同步dq坐标，同一个异常在dq里表现成约480 Hz。480 Hz也不是正常应该持续存在的量。ESS1正式反馈又恰好采用500 Hz二阶低通，因此这个约480 Hz控制域模态正落在滤波器动态敏感区；滤波器可能通过很大的相位滞后削弱控制器对该模态的阻尼，但不是“500 Hz自己产生了530 Hz共振”。D1要做的就是直接测滤波前后和后续控制链，把这条机制证明或排除。**
