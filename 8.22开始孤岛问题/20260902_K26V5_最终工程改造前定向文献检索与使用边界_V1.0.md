# K26_V5｜最终工程改造前定向文献检索与使用边界 V1.0

> 日期：2026-09-02  
> 目的：不是重新做大综述，而是为“1 GFM + 5 GFL 计划离岛工程修复”提供高质量外部参照，防止凭经验盲改。

## 1. 文献在本项目中的地位

本项目的根因判断优先级：

```text
K26_V5 实际因果试验
>
当前 Simulink / RT-LAB 真实结构
>
与本拓扑高度相近的高质量论文
>
一般教科书/经验
```

因此文献只回答：

1. 1台 GFM + 多台 GFL 的孤岛架构本身是否成立；
2. GFL 在不变成 GFM 的情况下能否提供电压/频率/阻尼支撑；
3. 如何从输出导纳/阻抗角度设计，而不是继续盲扫 PI / Kslow / Kpq；
4. 电流限制、anti-windup、弱电压 PLL、并离网切换有哪些已知陷阱；
5. 哪些控制结构值得映射到 K26_V5，哪些不应照搬。

# 2. 第一优先级：直接对应“孤岛中的 GFM–GFL 交互”

## P1
**Transient Synchronization Stability of an Islanded AC Microgrid Considering Interactions Between Grid-Forming and Grid-Following Converters**

- IEEE Journal of Emerging and Selected Topics in Power Electronics
- 2023
- DOI: 10.1109/JESTPE.2023.3271418

本项目用途：

```text
最直接的系统级理论邻居。
重点看：
GFM–GFL动态交互
damping / passivity
不同控制参数如何改变孤岛稳定域
```

不要照搬其具体控制器；重点吸收其“交互系统而非单设备故障”的分析框架。

## P2
**Transient Synchronization Stability Analysis and Enhancement of an Islanded Microgrid Considering Interactions Between Andronov-Hopf Oscillator Based Inverter and Grid-Following Inverter**

- IEEE Transactions on Energy Conversion
- Vol. 41, No. 1, 2026
- DOI: 10.1109/TEC.2025.3597925

本项目用途：

```text
较新的岛状 GFM–GFL 交互文献。
重点看：
GFL参数也能改变整体稳定性；
严重扰动 + current limit 后如何分阶段处理；
仿真 + HIL 验证结构。
```

# 3. 第二优先级：证明“1 GFM master + GFL slaves”不是错误架构

## P3
**A Master-Slave Model Predictive Control Approach for Microgrids**

- IEEE Transactions on Power Electronics
- Vol. 40, No. 1, 2025
- pp. 540–550
- DOI: 10.1109/TPEL.2024.3464105

论文直接研究：

```text
并网：
系统连接大电网

孤岛：
master = GFM
slaves = GFL
```

并使用 HIL 验证并网、孤岛切换与负荷变化。

对 K26_V5 的关键意义：

> 不需要因为当前失稳就把 ESS2/PV/EV 全部改成 GFM。  
> “ESS1 GFM + 其余 GFL”这个总体架构是可以成立的，问题在于我们的 GFL 孤岛行为和协调方式。

# 4. 第三优先级：GFL 可以保持电流控制，同时成为 grid-supporting

## P4
**Consensus Control for Coordinating Grid-Forming and Grid-Following Inverters in Microgrids**

- IEEE Transactions on Smart Grid
- Vol. 13, No. 5, 2022
- pp. 4123–4133
- DOI: 10.1109/TSG.2022.3158254

用途：

```text
看 GFM/GFL 协调；
GFL 不必变成 GFM，也可以参与：
电压恢复
频率恢复
功率分担
无功环流抑制
```

注意：这是 secondary coordination，不能直接替代我们当前 first-layer / inner-loop admittance 问题的修复。

## P5
**Enhanced Grid-Following (E-GFL) Inverter: A Unified Control Framework for Stiff and Weak Grids**

- IEEE Transactions on Power Electronics
- Vol. 39, No. 5, 2024
- pp. 5089–5107
- DOI: 10.1109/TPEL.2024.3350528

用途：

```text
重点看：
GFL在强网/弱网条件下的统一稳定控制
dq耦合
active damping
不把“GFL稳定”简单等价成“调PLL”
```

这篇对我们下一步“仍保持 current-controlled GFL，但重塑端口动态”很有参考价值。

# 5. 第四优先级：直接对应我们已经找到的 VFF / 输出导纳问题

## P6
**Quantitative stability analysis of Grid-Following inverter with Grid-Supporting control and stability enhancement method based on Multi-Voltage feedforward**

- International Journal of Electrical Power & Energy Systems
- Vol. 179, 2026
- Article 112023
- DOI: 10.1016/j.ijepes.2026.112023

这篇非常值得精读。

其核心提醒不是“加 grid-supporting control 一定稳定”，反而是：

```text
grid-supporting control
可能引入新的 dq admittance coupling
↓
必须看 Ydd/Ydq/Yqd/Yqq
↓
通过 voltage feedforward reshaping 改稳定性
```

这和 K26_V5 的证据高度呼应：

```text
terminal Vdq feedforward
→ GFL aggregate dynamic admittance
→ 与ESS1有限输出阻抗交互
```

因此下一版不能“随便加虚拟导纳/Volt-Var”。

必须把：

```text
原VFF
+
新增voltage-support current
+
PQ outer loop
+
Current PI
```

作为一个整体输出导纳问题设计。

# 7. 文献检索后的当前工程判断

## 7.1 可以确定的

```text
1 GFM + 多 GFL 的孤岛架构本身完全可以成立。
```

所以不需要因为失稳就把五台全部改 GFM。

```text
GFL 仍然可以保持 current-controlled / PLL-following 基本形态，
同时增加 grid-supporting 特性。
```

所以“电流源”和“提供支撑”不是互斥概念。

## 7.2 不能直接从文献推出的

不能直接说：

```text
给五台全部加同一个虚拟导纳
→ 一定稳定
```

也不能直接说：

```text
把所有GFL切到ESS1公共相角
→ 一定稳定
```

也不能直接照抄某篇论文的：

```text
Kp
Ki
virtual R
virtual X
droop coefficient
```

原因：

```text
K26_V5的：
滤波器
变压器
网络
标幺
dq定义
Power Control
Current Regulator
数字采样
PWM
SSN/Stubline
设备功率方向
都不同
```

# 8. 文献 + K26_V5 证据共同支持的下一步

下一步不是 Patch，而是 E1 严格只读工程审计。

必须先拿齐：

```text
A. 五台 Current Regulator 的完整方程、参数、限幅、anti-windup
B. 五台 Power Control 的完整方程、参数、Vdq真实用途
C. 当前Layer2 VFF/Iref wrapper的准确插入边
D. 当前已有电流限幅与ModIndex路径
E. 每个控制器可直接拿到的J1 / mode / GridOn / island信号
F. ESS1 GFM angle/frequency是否已有可复用跨任务通道
G. 不扩第6个OpWrite情况下还能记录什么
```

审计后才冻结以下最终设计：

```text
1. frequency-shaped VFF / output-admittance shaping
2. voltage-support / virtual-admittance current path
3. island-compatible P/Q release / derating
4. unified current vector limiter
5. outer-loop anti-windup
6. frame robustness strategy
7. prepare / stabilize / recovery / normal state machine
8. PV / ESS2 / EV 资源差异化规则
```

# 9. 当前最重要的设计原则

> 不把论文当答案；把论文当“防止我们漏掉已知控制原理和已知失败模式”的外部约束。

最终控制器必须同时满足：

```text
K26_V5 实际因果证据
+
当前模型真实结构
+
输出导纳/阻抗稳定性逻辑
+
高质量文献已有经验
+
RT-LAB 100 us实时资源约束
```

这四层全部对齐之后才改模型。
