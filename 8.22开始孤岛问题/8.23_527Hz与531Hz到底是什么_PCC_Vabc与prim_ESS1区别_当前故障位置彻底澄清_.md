## ——PCC原始Vabc与prim_ESS1的区别，以及“现在到底是谁的问题”的彻底澄清

> 日期：2026-08-23  
> 当前对象：最新 `K26_V5`  
> 本文目的：把当前最容易混淆的三个概念彻底分开：
>
> 1. **50 Hz系统频率**
> 2. **527.4 Hz理论自然振荡频率**
> 3. **约531 Hz在PCC原始Vabc中看到的快速频谱分量**

# 0. 先把最重要的误解纠正

当前存在三个完全不同意义的“频率”。

```text
50 Hz
= 正常交流微电网的基波频率
= 我们真正希望系统运行的频率

527.4 Hz
= 根据ESS1支路L/C/漏抗等参数计算出来的
  理论自然振荡频率
= 一个“系统容易振起来的模态频率”
= 不是控制器命令，不是PCC正常运行频率

约531 Hz
= 从上一轮PCC原始三相电压Vabc的频谱里
  看到的一个非常强的快速振荡成分
= 实际观测量
= 也不是“PCC系统频率”
```

最需要记住：

# **527.4 Hz 与约531 Hz都不是“微电网应该运行的频率”。**

微电网正常运行频率仍然应该是：

```text
≈ 50 Hz
```

---

# 1. 什么叫“系统频率50 Hz”？

正常三相电压，例如A相：

\[
v_a(t)=V_m\sin(2\pi 50t)
\]

B、C相则相差120°。

这说明：

```text
每秒完成50个完整正弦周期
```

这个50 Hz才是：

```text
微电网的基波频率
```

正常孤岛情况下应该看到：

```text
PCC Vabc：
主要是一组50 Hz三相正弦

ESS1 local Vabc：
也主要是一组50 Hz三相正弦
```

不同节点允许：

```text
幅值略有差异
相角略有差异
```

但正常同步状态下：

```text
基波频率应基本一致≈50 Hz
```

# 2. 那527.4 Hz到底是什么？

## 2.1 它不是“测出来的”

527.4 Hz不是从MAT直接读出来的。

它是我们拿当前模型里的电气参数：

```text
L1
+
C1
+
Transformer leakage
+
Stubline leakage
+
Line_ESS1
```

通过LC网络的理论关系计算出来的。

所以它的身份是：

# **理论自然振荡频率 / resonance-mode candidate**

---

# 3. 什么叫“自然振荡频率”？

先用最简单的LC解释。

一个电感：

```text
L
```

可以储存：

```text
磁场能量
```

一个电容：

```text
C
```

可以储存：

```text
电场能量
```

如果某一瞬间受到扰动：

```text
电容电压高了一点
```

它会通过电感放电。

然后：

```text
电感电流又把能量送回电容
```

于是能量会在：

```text
电容电场
↔
电感磁场
```

之间来回交换。

如果没有阻尼，这个系统天然会以：

\[
f_r=\frac{1}{2\pi\sqrt{LC}}
\]

附近的某个频率振荡。

---

# 4. 一个机械类比

可以把：

```text
L + C
```

想象成：

```text
质量块 + 弹簧
```

弹簧系统有：

```text
自己的固有频率
```

比如：

```text
你推一下
↓
它最喜欢以10 Hz左右来回晃
```

这不表示：

```text
这个机器正常工作频率就是10 Hz
```

而只表示：

> 这个机械系统受到扰动以后，最容易在10 Hz附近形成振动。

我们的527.4 Hz也是完全同样的意义。

---

# 5. 所以ESS1系统实际上同时存在两种完全不同的频率概念

```text
正常工作：
50 Hz

电气网络天然容易振动：
约527 Hz
```

这二者完全不矛盾。

一个正常的逆变器可以：

```text
输出50 Hz基波
```

同时其滤波器内部天然有：

```text
几百Hz甚至几kHz的自然模态
```

关键是：

> 正常情况下这些非基波模态应该被足够阻尼，不能成长成大幅持续振荡。

---

# 6. 那为什么我们计算出来是527.4 Hz？

当前静态审计得到的ESS1相关实际参数大致构成：

```text
Converter
↓
L1
↓
C1并联
↓
Transformer leakage
↓
Differential Stubline leakage
↓
Line_ESS1
↓
公共微电网
```

当前统一折算以后，大致得到：

```text
总串联电抗 X_L_total ≈ 0.17976 pu
C1电纳              ≈ 0.05 pu
系统基准             = 50 Hz
```

理想化关系：

\[
f_r
\approx
\frac{f_0}
{\sqrt{X_{L,pu}B_{C,pu}}}
\]

代入：

\[
f_r
\approx
\frac{50}
{\sqrt{0.17976\times0.05}}
\]

得到：

\[
f_r\approx527.4\text{ Hz}
\]

所以：

# **527.4 Hz的意思是：按照当前ESS1支路的L/C/漏抗参数，这条电气支路存在一个大约0.53 kHz附近的天然振荡模态。**

---

# 7. 它是不是意味着系统一定会在527.4 Hz振？

不是。

这点非常重要。

就像：

```text
一座桥有某个固有频率
```

不代表：

```text
它每时每刻都在剧烈振动
```

如果：

```text
扰动小
+
阻尼足够
```

那么这个模态即使被轻微激发：

```text
振几下
↓
迅速衰减
↓
看不出来
```

只有：

```text
阻尼不足
```

甚至：

```text
控制器/网络在这个频率提供负阻尼
```

时，才可能：

```text
振动越来越明显
或者长期持续
```

所以目前真正的问题不是：

```text
“为什么模型存在527 Hz自然频率？”
```

所有LC系统都有自然模态。

真正的问题是：

# **“为什么J1打开以后，这个约0.53 kHz模态没有被压住？”**

# 10. 531 Hz不等于“PCC频率531 Hz”

这是第二个非常容易误解的地方。

假设一个波形是：

\[
v(t)
=
10000\sin(2\pi50t)
+
500\sin(2\pi531t)
\]

它里面同时有：

```text
50 Hz主基波
+
531 Hz振荡/谐波成分
```

我们不能说：

```text
“这个电网的频率是531 Hz”
```

系统基波仍然是50 Hz。

531 Hz只是：

```text
叠加在波形上的快速成分
```

---

# 11. 当前情况比这个例子更严重

正常应该：

```text
50 Hz：
非常大

531 Hz：
很小
```

但当前孤岛以后：

```text
50 Hz附近基波变得很弱

约531 Hz快速成分变得非常大
```

所以不是简单：

```text
“有一点高次谐波”
```

而是：

```text
异常快速振荡已经严重破坏了正常50 Hz电压
```

---

# 12. 还有一个必须继续保留的技术限制

当前531 Hz来自：

```text
2 kHz采样
```

所以：

```text
Nyquist频率 = 1 kHz
```

虽然531 Hz本身低于1 kHz，可以被记录，

但是：

```text
如果真实Plant存在高于1 kHz的成分
```

降采样以后仍有可能：

```text
alias
混叠
```

到531 Hz附近。

所以现在最严谨的说法仍然是：

# **“上一轮2 kHz数据中的表观主快速分量约531 Hz。”**

而不是：

```text
“已经100%证明实际物理模态就是531.000 Hz”
```

的弱网交互。

# 34. 为什么“PCC原始Vabc”这个词非常重要？

因为它不是：

```text
PCC PLL算出来的频率
```

也不是：

```text
Fundamental模块算出来的50 Hz基波
```

它是：

```text
PCC测量块直接输出的
Va(t), Vb(t), Vc(t)
```

所以它告诉我们：

> 电气网络本身的波形已经异常。

这就是为什么我们已经能够排除：

```text
“只有PLL显示错”
```

---

# 35. 但它仍然不能告诉我们“异常是谁最先产生的”

因为它在：

```text
整个网络最外侧边界
```

是一个系统结果。

相当于：

```text
你站在河流下游
看到水很浑
```

你已经知道：

```text
水确实浑了
```

但还不知道：

```text
污染是在上游第一个工厂产生
还是中间某条支流产生
```

---

# 36. `prim_ESS1`的意义就像去“ESS1支流出口”取水样

如果：

```text
prim_ESS1已经浑
```

说明污染很早就在ESS1支路出现。

如果：

```text
prim_ESS1很清
PCC才变浑
```

说明主要问题在后面的公共网络/其它设备。

# 37. 所以当前最准确的一句话是什么？

# **我们已经知道“整个孤岛在PCC处存在约0.53 kHz持续快速电压振荡”，同时ESS1支路的理论自然模态恰好约527 Hz，因此ESS1支路是最高优先级嫌疑对象；但因为上一轮记录的是PCC Vabc而不是prim_ESS1 Vabc，目前还没有证据证明振荡首先起源于ESS1的SS内部。**

# 47. 当前最终结论

> **527.4 Hz是根据ESS1相关电气支路参数算出来的“理论自然谐振频率”，不是正常系统频率，也不是直接测量结果。约531 Hz是从PCC处独立三相V-I测量块 `Three-Phase V-I Measurement3` 的原始Vabc波形中做频谱分析看到的“实际快速振荡分量”，它同样不是PCC正常系统频率。PCC原始Vabc不是 `prim_ESS1` 测出来的；`prim_ESS1` 是ESS1支路本地10 kV侧的另一个独立V-I测量点。因为目前531 Hz只在PCC端被记录，所以我们只能确认整个孤岛存在快速振荡，并发现ESS1支路理论模态与它高度接近；还不能证明故障一定起源于 `SS_Slave2/ESS1_Control`。下一步最决定性的证据是同一次孤岛试验中比较 `prim_ESS1 Vabc` 与 `PCC Vabc`，以区分“ESS1源端/局部闭环问题”与“公共网络/多GFL交互问题”。**
