# K26 V4.9 A/B 30秒碰撞后的根因锁定与下一版方案

## 0. 先给最终判断

**这两轮30秒试验带来了决定性信息。**

现在可以把问题从过去很大的根因树压缩到一层：

> **当前计划孤岛失败的主问题已经不在启动、J1开断、F21/F24/F25交接、直流电压接口、中央q-bias本身或“电流一饱和就崩”这些层面；而在孤岛建立后的低频闭环：ESS1唯一GFM与五台GFL本地电压/功率支撑、Stage3慢速功率恢复之间的动态配合没有形成足够阻尼的稳定层级。**

中央 q-bias **不是该振荡存在的必要条件**。把它完全置零后，振荡仍然存在，而且后期更早重新出现。

但是，当前 B 试验只隔离了中央**电压/q-bias**积分；Stage3 的有功—频率 Secondary（慢速二次有功恢复）仍在，因此目前还不能诚实地把“ESS1电压PI”“五台低频支撑”“有功Secondary”三者中的某一个单独写成唯一元凶。

所以现在能锁定的是**设计层级**，不是某一个小数参数。

# 1. A/B两轮到底证明了什么

## 1.1 A和B是非常干净的中央q-bias对照

B相对A的运行参数差异只有：

```text
AA15_P_KI_QBIAS:
A = 0.30
B = 0
```

开断前工作点差异只有约数值舍入量级：

```text
Ppcc差 ≈ 4e-15 kW
Qpcc差 ≈ 1.4e-13 kvar
V差    ≈ 1.8e-12 V
频率差 ≈ 1.4e-14 Hz
F24/F25捕获值也几乎完全一致
```

0～0.7秒两轮电压时序的RMS差只有约：

```text
1.45e-13 pu
```

也就是说，本轮不是“两个工况碰巧不一样”。

它真正实现了：

```text
同一模型
同一工作点
同一开断
同一0.02/0.14
同一F24/F25
同一五台Primary
同一有功/频率协调
唯一预定改变：中央q-bias Ki
```

## 1.2 中央q-bias不是振荡根因

A：
- 前3秒大波动；
- 约12～25秒出现较安静的低压平台；
- 25秒后再次增长；
- 约28.1秒峰值约1.282 pu；
- 到30秒并没有稳定结束，记录冲洗阶段仍在继续变化。

B（q-bias=0）：
- 前3秒仍然出现几乎相同的大波动；
- 3～10秒仍有0.88～1.26 pu量级变化；
- 10～15秒暂时变安静；
- 约15.8秒就重新出现约1.275 pu峰值；
- 之后一直有明显往复变化。

因此：

> **q-bias可以改变慢工作点和振荡何时重新出现，但它不是振荡能够存在的必要条件。**

更准确地说：

```text
A有q-bias：
把一段安静区推迟/延长到约25秒

B无q-bias：
安静区大约15秒附近就结束

但两者最终都重新出现同类低频波动
```

所以不能：
- 删除q-bias当最终修复；
- 继续只调q-bias滤波/积分，期待全部解决。

## 1.3 15秒“后期已收敛”的结论被30秒数据正式推翻

A在12～15秒：

```text
Vmean ≈ 0.9350 pu
Vstd  ≈ 0.000659 pu
```

15～20秒、20～25秒仍很安静。

但25～30秒：

```text
Vmean ≈ 1.0601 pu
Vmin  ≈ 0.8824 pu
Vmax  ≈ 1.2830 pu
Vstd  ≈ 0.1333 pu
```

因此：

> **12～25秒只是暂时落入一个安静平台，不是最终收敛。**

这解释了为什么15秒试验曾让我们误以为“现在变成前期振荡、后期稳定”。

真正的30秒事实是：

> **前期振荡 → 中间安静 → 后期重新振荡。**

所以当前系统更像一个**低阻尼、随慢状态/工作点变化会重新被激发的闭环模态**，而不是一个普通的一次性切换暂态。

# 2. 为什么这次和V4.8“前稳后坏”看起来反过来了

这不是随机反转，而是非常有信息量。

## V4.8

历史V4.8表现大致是：

```text
最初几秒较平
→ 后面进入高压平台/执行压力
→ 12~15秒严重恶化
```

V4.8后来确认存在：
- 固定dq轴与真实电压方向不一致；
- 下游最终执行限幅没有完整反馈到电流PI；
- q-bias状态律反向微调会出现过强向零释放；
- 后期PV和ESS1出现明显执行受限。

这些会让一个本来就不够好的低频闭环，在后面进入限幅/状态积累以后越来越坏。

## V4.9

V4.9修了：
- 实际电压方向u/n；
- 六台完整执行残差anti-windup；
- q-bias普通反向不再快速清零；
- 后来又修正六台Vdc接口和强网bypass。

于是：

```text
原来“执行层越陷越深、很难恢复”的机制
明显减弱
```

A中也确实看到：
- 1～3秒第一次大电压变化时，ESS1电流仍跟得很好；
- 3～6秒执行压力变大；
- 6～25秒执行又恢复得很好；
- 25秒后电压模态重新增长，执行压力才再次跟着变大。

这说明改模不是白做。

**改模把旧的“后期执行器锁死/状态积累型失败”消掉了一大部分，于是更底层的低频闭环阻尼问题暴露出来。**

换句话说：

```text
V4.8：
低频闭环问题
+ 错误方向
+ 执行windup
+ qbias错误回调
→ 后期越走越坏

V4.9：
方向、执行、状态律明显修正
→ 不再永久卡死
→ 但原来的低频闭环层仍没有真正完成稳定性整定
→ 于是表现为“振荡—安静—重新振荡”
```

这就是前后现象碰撞后最重要的启示。

# 4. 现在真正剩下的闭环

当前长期孤岛实际上存在下面这些时间尺度：

```text
ESS1 Current Regulator
        ↑ 快

5~20 Hz 五台中频阻尼
        ↑

ESS1 Voltage PI（0.02 / 0.14）
        +
五台 local slow-q（fc≈1Hz，Kmag≈0.25）
        +
五台继承的 LFQ 阻尼
    HP≈0.18Hz / LP≈0.35Hz / GLFQ≈0.25
        +
Stage3 P/f Secondary
        +
中央 q-bias Secondary（A有，B没有）
        ↓ 慢
```

历史V4.6是按照当时约0.25Hz问题设计的：
- 0.15～0.5Hz LFQ负责动态耗散；
- 1Hz slow-q负责局部电压支撑；
- 接近DC由Secondary负责恢复。

但V4.9已经改变了：
- 五台基础P/Q电流的物理方向；
- 实际电流执行关系；
- 限幅后的动态状态；
- 中央q-bias状态律。

**对象已经变了，原来冻结的各层增益却没有作为一个整体重新验算。**

A现在最明显的前10秒成分约0.6Hz；25秒后重新出现的波动又落回约0.3～0.6Hz附近。

这恰好位于：

```text
原0.15~0.5Hz LFQ
和
1Hz local slow-q
和
ESS1 Voltage PI低频积分作用
之间的交界区域
```

因此当前最强的设计级结论是：

> **我们现在的缺陷不是“某根线又接错”，而是低频电压/功率支撑存在多个历史叠加环节，缺少在V4.9新对象下重新进行的整体稳定性设计。**

这是为什么继续盲调某一个增益很危险。

# 5. A数据还暴露了一个很重要的现象：ESS1电压PI在安静平台仍持续积累

A的安静低压阶段：

```text
15s：V ≈ 0.935，VPI_mapped_Iq ≈ 0.003
20s：V ≈ 0.938，VPI_mapped_Iq ≈ 0.054
22.74s：V ≈ 0.942，VPI_mapped_Iq ≈ 0.084
25s：V ≈ 0.947，VPI_mapped_Iq ≈ 0.107
27s：V ≈ 0.969，VPI_mapped_Iq ≈ 0.125
```

与此同时：
- 电流跟踪很好；
- 电压命令并未长期硬顶限；
- 电压目标仍约1.00pu。

所以0.935的“平”不是控制器已经停下来。

它更像：

```text
母线暂时很平
但电压积分器仍在慢慢积累纠偏
+ 五台局部支撑/有功Secondary也在慢变
→ 工作点逐渐移动
→ 最后再次越过低阻尼区域
→ 振荡重新出现
```

这也解释了：

> **“看起来平了10秒”为什么仍不能等同于真正稳定。**

# 6. q-bias在A里到底起了什么作用

A中q-bias从正值慢慢下降：

```text
约15s：+0.126
约20s：+0.044
约22.74s：穿过0
约25s：-0.034
```

在这个期间电压维持在0.935～0.947附近。

B完全没有它，却在约15～16秒重新开始大幅波动。

因此在当前完整闭环中：

> **q-bias并不是制造振荡的根源；它事实上改变了慢工作点，使振荡重新被激发的时间明显推迟。**

但是A最终仍重新振荡，所以：

> **它只能移动/补偿工作点，不能替代Primary本身的稳定性。**

# 9. 下一版模型的最终架构现在可以先锁定，不必等参数

无论上面的Stage2结果是哪一种，最终控制层次应该是：

```text
并网 NORMAL
    ↓
PREPARE
    ↓
ESS1 GFL→GFM + J1 still closed
    ↓
J1 OPEN
    ↓
ISLAND_PRIMARY
    │
    │ ESS1唯一负责形成母线V/f
    │ 五GFL只做有边界的一次支撑
    │
    ├─ 等待Primary稳定条件持续满足
    ↓
ISLAND_SECONDARY
    │
    │ 很慢地消除剩余f/V静差
    │ 不参与第一轮切岛暂态争夺
    ↓
ISLANDED steady
```

## 必须改变当前“J1+0.2秒固定进入全部Secondary”的思想

对于一个只是15项策略之一的计划孤岛，完全没必要在J1后200毫秒就急着同时启动所有慢恢复。

更合理的是：

```text
J1 OPEN
→ Primary先把系统接住
→ V/f/执行裕度进入健康区并持续一小段时间
→ Secondary再平滑投入
```

这是控制职责的简化，不是再增加复杂模块。

# 10. 如果最终证明Primary有问题，怎么改

## 10.1 不先改0.02/0.14

0.02/0.14已经有历史527Hz的强证据。

所以首先保留。

## 10.2 重点处理五GFL低频支撑重叠

当前同时有：

```text
0.18~0.35Hz LFQ
+
1Hz slow-q
```

前者是针对历史约0.25Hz模式加出来的。

当前对象最明显问题已经迁移到约0.4～0.6Hz。

如果Stage2-only仍不稳定，下一版不应该再堆第三个低频阻尼器，而应：

> **把五台低频电压支撑整理成一个职责清楚、单调、限幅明确的一次支撑通道。**

建议设计方向：

```text
local V deviation
→ 一个经过验证的低频q-V支撑环
→ support budget
→ current circle
→ Current Adapter
```

保留：
- 5～20Hz专用阻尼；
- current-circle；
- role safety；
- 当前u/n方向；
- Current Adapter anti-windup。

不再让：
- 历史0.25Hz专用LFQ；
- 1Hz slow-q；
- 新的其它低频补偿

长期以互相重叠的方式共同“猜”电压。

具体是删除LFQ还是调整slow-q，必须由Stage2-only和线性模型决定，不在这里凭直觉硬选。

## 10.3 最后才重新整定ESS1 Voltage PI

如果五台Primary层简化后仍然低阻尼，再重新评价ESS1 0.02/0.14。

任何新值都必须同时满足：

```text
低频阻尼改善
+
不能让527Hz问题回来
+
Current Adapter保持裕度
```

禁止直接恢复2/14。

# 11. 如果Stage2-only稳定，Stage3怎么改

这种情况下模型改动更小。

## 11.1 Secondary不再固定0.2秒强制投入

改为：

```text
Primary healthy dwell
→ Secondary enable
```

健康条件使用已经存在的量即可：
- 电压进入项目宽范围；
- ESS1频率正常；
- 没有持续调制/电流限制；
- 状态持续一定时间。

不要求电压等于1.000000pu。

## 11.2 P/f Secondary和q-bias分开投入

不要一个Stage同时让两个积分器立即自由运行。

推荐：

```text
Primary stable
↓
先允许必要的慢频率恢复
↓
再允许慢电压工作点恢复
```

或者根据线性/时域结果反过来。

重点是：

> 一次只有一个慢积分职责明确地改变系统工作点。

## 11.3 q-bias保留，但只承担DC/极慢恢复

B已经证明删掉它不是答案。

所以保留：
- 非零稳态bias；
- capability限制；
- request/reference/measured分层；
- anti-windup。

但其投入和时间尺度必须以稳定Primary为前提。

# 12. 我们到底需要做到怎样的“孤岛PASS”

用户的目标不是做一套学术论文级无穷工况稳定性证明，而是实现15项策略中的一项正常计划孤岛。

因此建议把验收分成两层。

## Level 1：策略功能PASS —— 当前必须完成

在一个规定的典型工作点：

1. 并网初始状态正常；
2. 计划离岛准备完成；
3. ESS1无冲击切为GFM；
4. J1真实打开；
5. 五台GFL保持在线；
6. 母线电压/频率经历有限、衰减的转换暂态；
7. 在一个事先定义的过渡时间以后，进入宽松正常区；
8. 之后连续运行30秒，**不能再次长大或重新振荡**；
9. 无持续CurrentLimit / ModIndex顶限；
10. 没有NaN、设备掉线、异常重合闸或状态机错误。

建议继续沿用项目已有的宽松后期观察范围：

```text
V：0.90 ~ 1.10 pu
f：49.5 ~ 50.5 Hz
```

作为项目内部功能筛查。

**切换最初的单次过冲不应该用“一个采样点超过1.2就失败”的方式评价。**

过渡期应该看：
- 峰值；
- 持续时间；
- 是否衰减；
- 是否触发真实设备保护边界。

真实硬件允许的最大过渡电压最终应由设备/项目要求决定，不由本报告编造。

### 对当前项目，一个合理的简单PASS口径可以冻结为：

> **J1开断后允许3～5秒转换过程；之后电压保持0.90～1.10pu、频率保持49.5～50.5Hz并连续维持至少30秒，波动包络不重新增长，设备无持续饱和。**

这里“3～5秒”是建议的项目内部验收窗口，不是行业标准；正式采用前由项目组确认即可。

## Level 2：工程鲁棒性 —— 计划孤岛通过以后再做

再补：
- 一个小负荷/功率扰动；
- 紧急切岛；
- 黑启动；
- 重同步；
- 板端CHIL。

不能要求计划孤岛这一轮提前证明所有这些工况。

# 14. 对“模型怎么设计到没有缺陷”的回答

不能证明一个复杂控制模型“没有任何缺陷”。

但可以做到：

> **每个控制量只有一个明确的主人；每个时间尺度只有明确职责；每个状态切换有初始化/退出规则；每个执行器限制能反馈到真正拥有积分状态的控制器；每个新增环节先证明不与已有环节争夺同一动态。**

当前项目过去返工多，最主要的教训就是：

```text
局部问题修完
→ 又叠一个新控制器
→ 局部再PASS
→ 但没有把整个新对象重新做稳定性设计
```

现在应该停止这种方式。

下一版真正的目标不是“再加一个F26/F27”，而是：

> **把现有孤岛控制削减成结构清晰的Primary + Secondary两层，并用当前A/B真实波形校准低频稳定性。**
