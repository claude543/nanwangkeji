# K26_V5 当前根因判断、历次改模效果与彻底解决路线 V1

> 日期：2026-09-04  
> 基础：最新版 V4.6 模型、V4.5→V4.6 改模脚本、V4.6 仅一次控制 10 s 试验、V4.6 一次+二次控制 15 s 试验、最新两份交接文档及旧窗口补充问答。  
> 本文目的：不重复历史流水账，而是回答现在最关键的几个问题——前面的改模到底有没有用、为什么还没彻底锁定根因、当前模型真正还缺什么、是否已经接近最后一层排错、下一步怎样最有把握地解决计划性离网问题。

---

# 0. 先给最终结论

## 0.1 前面的改模绝大多数不是白做，而且确实逐层解决了真实问题

现在不能把过去半个月概括成：

> “改了很多次，但都没用。”

更准确的是：

```text
ESS1 构网本体问题
→ 已经基本解决

并网→孤岛的状态/参考/电流责任交接问题
→ 已经基本解决

五台跟网设备 10~17 Hz 左右的中频端口失稳
→ V4.5 已明显压制

二次电压恢复的历史状态反向滞留问题
→ V4.6 已验证改善

剩余：
五台跟网设备在孤岛低频仍保持“强网式 Q 跟踪”
+
大摆动后真实调制电压裕度不足
```

所以我们不是一直在原地打转，而是在**一层一层把被上层问题遮住的更深问题暴露出来**。

---

## 0.2 现在最高置信度的首发根因已经非常集中，但还差最后一个直接证据闭环

我目前的判断是：

> **最可能的首发根因，是五台跟网设备在孤岛后仍然让无功外环比例积分器以“固定 Q 必须被消除误差”的方式持续工作。**

其结果是：

```text
母线电压变化
→ 五台 Qmeas 同时变化
→ 五个 Q 外环同时产生 Q 误差
→ 五个积分器在低频共同改变 q 轴基础电流
→ ESS1 作为唯一构网设备只能通过有限 Q-V 阻抗承受这个聚合无功变化
→ 母线电压再次变化
→ 形成五台共模低频闭环
```

这与强网情况完全不同。

强网下，母线电压由外部大电网固定，Q 外环可以放心把 Q 当作独立控制目标。

孤岛后，母线电压本身就是系统内部状态，五台设备再同时“强制 Q 回到固定目标”，就会与唯一构网设备的电压形成竞争闭环。

---

## 0.3 但我现在仍不会写“Q 外环已经 100% 被证明为唯一根因”

原因不是因为证据弱，而是因为我们此前那张 0.25 Hz 诊断表使用的是：

```text
FinalIref_q
```

也就是最终 q 轴电流参考，而不是无功外环比例积分器的原始输出。

所以当前证据等级应该写成：

```text
已证明：
孤岛低频电压/Q端口仍失稳

最高置信度嫌疑：
Q 外环 / 基础 q 电流通道

仍需直接锁死：
raw/base q current 的 0.25 Hz 幅值和相位
+
Q PI 内部积分状态
+
真实调制饱和链
```

这三个东西一旦锁死，根因就不再停留在“高置信度”，而可以升级成“直接控制链证据”。

# 1. 历次改模到底有没有起作用？

答案：**有，而且作用要分成“根因修复”“必要强化”“保护层”“被证伪的假设”四类。**

| 修改 | 现在的评价 | 是否继续保留 |
|---|---|---|
| ESS1 本地电容电压/电感电流快速反馈 | 修掉早期约 530 Hz 物理/控制共振问题的重要步骤 | 保留 |
| ESS1 电压环重新降带宽 | 明显降低 500 Hz 附近危险模式 | 保留 |
| F21 电流比例积分器切换状态处理 | 解决构网切换时约 -450 kW 冲击 | 保留 |
| F24 构网频率/电压参考交接 | 已证明切岛边沿参考连续 | 保留 |
| F25 输出电流责任交接 | 解决构网电流责任切换问题的重要模块 | 保留 |
| 永久执行坐标保持 | 显著改善孤岛动态，且已经证明有益 | 保留 |
| V4.5 的 5~20 Hz 主动阻尼 | 真正压低旧 10~17 Hz 中频模式 | 保留 |
| P/Q 支撑反抵消机制 | 防止功率外环快速抵消支撑 | 原则保留，但未来无功侧语义要重审 |

| V4.6 0.18~0.35 Hz q 轴低频阻尼 | 结构和符号并非错误，但不足以解决首发慢模态 | 不再当主稳定器，V4.7 优先关闭/降级 |

最关键的数据是：

```text
V4.5 仅一次控制：
5~30 Hz late/early ≈ 0.238
```

说明旧中频问题已经明显衰减。

但：

```text
0.05~2 Hz late/early ≈ 1.85
主峰约 0.25 Hz
```

说明更慢的模式成为新的主矛盾。

V4.6 又增加低频 q 轴支路以后：

```text
0.05~2 Hz late/early ≈ 1.93
```

低频主模式没有被解决。

因此 V4.6 的低频 q 轴支路所证明的不是“又失败了一次”，而是：

> **“仅仅在原 Q 外环外面再叠加一个低频阻尼支路”这一修法不充分。**

这使根因位置进一步向内部 Q 外环收缩。

# 2. 为什么根本原因到现在才接近锁定？

这里有五个原因。

## 2.1 这是典型的多时间尺度嵌套控制问题

早期模型同时存在：

```text
约 530 Hz 的快速共振
10~17 Hz 的中频端口模式
约 0.25 Hz 的低频电压/Q模式
数秒级二次恢复
```

当 530 Hz 问题存在时，0.25 Hz 根本没有机会完整发展。

当 10~17 Hz 模式很强时，0.25 Hz 又被中频模式遮住。

所以表现出来的确是：

```text
修掉第一层
→ 第二层变得可见

修掉第二层
→ 第三层成为主导
```

这在多环控制系统中并不反常。

---

## 2.2 我们以前记录的是“最终电流参考”，不是“无功外环原始输出”

此前有：

```text
FinalIref_q
Support_q
Qmeas
QrefEff
gQ
```

但没有直接记录：

```text
Q PI 原始输出
Q PI 积分状态
Q PI 内部抗积分饱和状态
```

所以之前看到的是：

```text
最终 q 轴电流摆动很大
```

但不能直接说：

```text
这全部就是 Q PI 产生的
```

现在已经知道可以利用现有数据反解：

\[
I_{base,q}
=
\frac{I_{final,q}-I_{support,q}}{g_Q}
\]

前提是 `gQ`（q轴基础电流缩放系数）不能太接近零。

这一步以前没有先做，是当前证据链最后一个明显缺口。

---

## 2.3 以前的设计更多是在“外围补偿”，而不是改变岛内主控制权

V4.5/V4.6 以后，q 轴上实际上同时存在：

```text
原 Q 外环产生的基础 q 电流
+
慢速电压支撑
+
5~20 Hz 主动阻尼
+
V4.6 低频 q 轴阻尼
+
二次电压参考移动
```

问题在于：

> 最里面的原 Q 外环仍然是一个带积分作用的强 Q 跟踪器。

于是形成了一个结构性矛盾：

```text
外围控制：
想根据电压改变 q 电流

原 Q PI：
又想把 Q 拉回固定目标
```

这就是为什么外围支撑越来越多，但仍无法彻底稳定。

---

## 2.4 分析脚本曾把“试验有效性”和“物理失败”混到一起

V4.6 仅一次控制试验：

```text
J1 正确
Stage2 正确
Stage3 未进入
二次控制=0
主构网信号有效
故障码=0
```

这些都通过。

但旧分析器因为 EV2 后期支撑/电流约束压力，把总 `HardContractPass` 拉成 0，于是分类成了“无效合同”。

正确解释应该是：

```text
运行有效性：PASS
控制执行合同：PASS
物理稳定性：FAIL
执行器/限幅压力：FAIL
```

如果把这些层次混在一个布尔量里，会干扰根因判断。

---

## 2.5 三种“饱和”此前容易被混在一起

必须永远区分：

1. **功率控制无功 PI 自身输出饱和**
2. **Manager（孤岛支撑管理模块）的电流圆限幅**
3. **真正的变流器电压/调制饱和**

它们不是同一个边界。

这也是接下来必须处理清楚的一部分。

# 3. 我自己的独立判断：为什么 Q 外环现在已经非常可疑？

这部分不是简单重复旧窗口，而是我根据目前模型结构和数据重新做的判断。

---

## 3.1 当前 Q 外环参数在 0.25 Hz 几乎就是纯积分器

五台设备的无功外环比例积分器：

```text
Kp = 0.06
Ki = 2
```

比例积分器：

\[
G_{PI}(j\omega)
=
K_p+\frac{K_i}{j\omega}
\]

在：

```text
f = 0.25 Hz
ω = 2πf ≈ 1.571 rad/s
```

积分项幅值：

\[
\frac{K_i}{\omega}
\approx
\frac{2}{1.571}
\approx 1.273
\]

远大于：

```text
Kp = 0.06
```

因此理论上：

```text
幅值 ≈ 1.275
相位 ≈ -87.3°
```

也就是说，在 0.25 Hz 处它本质上就是一个很强的积分控制器。

它的 PI 零点大约在：

```text
5.3 Hz
```

所以在 0.25 Hz 这种远低于 5.3 Hz 的频率上，积分作用当然占主导。

---

## 3.2 实际数据与这个理论特征高度一致

现有 0.25 Hz 数据中：

```text
FinalIref_q / Qerror 幅值比
≈ 1.40 ~ 1.67
平均约 1.51
```

而相位：

```text
FinalIref_q 相对 Qerror
≈ -70° ~ -92°
```

理论 PI 是：

```text
约 1.275
约 -87°
```

虽然 `FinalIref_q` 不是原始 Q PI 输出，但二者已经非常接近“积分器主导”的特征。

这不能单独构成最终证明，却已经远远超过普通的“猜测”。

---

## 3.3 外围支撑明显压不过基础 q 电流动态

在 0.25 Hz：

```text
FinalIref_q / Support_q
PV / EV 约 14 倍
ESS2 约 4 倍
```

这意味着：

> 我们一直在用一个很小的外围电压支撑量，去对抗内部更大的基础 q 电流变化。

只要内部 Q PI 继续强力积分，外围再增加一点低频阻尼，很容易变成：

```text
支撑在推
Q PI 在反向拉
```

所以 V4.6 没有解决慢模态，在结构上是可以解释的。

---

## 3.4 五台共模是“聚合外环”而不是单设备故障的典型特征

五台电压高度共模，说明：

```text
不是 PV1 单机控制错误
不是 EV2 单机控制错误
不是某一台参数坏了
```

而是：

```text
所有设备共享母线电压变化
→ 所有 Q 外环共同响应
→ 五个积分器通过同一母线形成聚合低频反馈
```

强网下这五个控制器面对的是“刚性外部电压”。

孤岛下它们面对的是：

```text
ESS1 有限电压源
+
网络
+
彼此的电流响应
```

系统性质已经完全改变。

# 4. 当前模型的真正设计缺陷在哪里？

我认为现在至少有“一主一辅”两个明确的结构缺陷。

---

# 4.1 主缺陷：并网和孤岛仍共用同一套强 Q 跟踪哲学

当前最根本的问题不是某个增益不好，而是：

> **控制目标没有真正切换。**

现在实际更接近：

```text
并网：
Q PI 强跟踪 Qref

孤岛：
还是 Q PI 强跟踪 Qref
+
额外叠加电压支撑
```

更合理的结构应该是：

```text
并网：
Q PI 是主控制器

孤岛：
预切岛基础 q 电流是工作点
电压支撑是主要动态控制
Q 目标只保留为慢速监督/偏置
```

也就是说：

> 五台设备仍然可以保持跟网型、电流控制型，不需要变成构网型；
>
> 但是在孤岛低频段，它们不能再表现成“五个固定 Q 的强积分器”。

这是 V4.7 应该真正修改的地方。

---

# 4.2 辅助缺陷：电流调节器看不到真正的下游调制饱和

我直接检查最新版模型的电流调节器结构后，确认：

电流比例积分器本身有自己的输出限幅和条件积分抗饱和。

但随后还有：

```text
电流 PI 输出
+
电压前馈
+
R/L 解耦前馈
→ 最终变流器 dq 电压命令
→ 再次 Saturation（饱和）
```

而这个**最终电压命令饱和**没有反馈回内部电流比例积分器的抗积分饱和逻辑。

这意味着：

```text
PI 自己可能认为“我还没饱和”
但 PI + VFF + 解耦项已经超过变流器可实现电压
→ 最终命令被截断
→ 实际电流跟不上
→ PI 仍可能继续要求更大校正
```

这正好解释为什么：

- 0~2 s 慢模态已经开始发展；
- 2~4 s 后调制度逐渐碰到上限；
- 后面 5~30 Hz 残差和电流跟踪误差明显恶化。

因此：

> **调制饱和不是 0.25 Hz 首发根因，但它是导致系统进入强非线性、失去恢复能力的重要放大器。**

---

# 5. 为什么 current-circle（二维电流圆）做对了，系统仍然会崩？

因为：

```text
电流可实现
≠
电压可实现
```

当前二维电流圆只保证：

\[
\|I_{ref}\| \le I_{max}
\]

但逆变器真正能不能实现这个电流，还取决于它需要输出多大的交流侧电压。

当母线已经升到：

```text
1.15 pu
1.20 pu
甚至更高
```

再叠加：

```text
滤波器压降
电流动态补偿
电压前馈
```

可能出现：

```text
Iref 仍在电流限制范围内
但 Vconv 已经超过调制器能输出的最大电压
```

于是：

```text
ModIndex → 1
```

所以当前设计还有一个重要认识：

> **最终保护体系不能只有“电流能力约束”，还要知道“电压/调制裕度”。**

但这项目前应该作为第二层鲁棒性修复，不应该抢在 Q 外环根因前面改 Current PI 参数。

# 6. 计划性离网真的这么难吗？

## 6.1 计划性离网本身不是一个“理论上特别难、难以实现”的功能

工程上：

```text
1 台构网设备
+
若干跟网资源
```

完全可以稳定孤岛。

当前也没有任何数据证明这个拓扑物理上不可稳定。

相反：

- ESS1 已经证明能单独形成电压和频率；
- 频率通道整体明显比电压健康；
- J1 已经是真实物理断开；
- 执行坐标和参考交接可以连续；
- 10~17 Hz 中频问题可以被压制。

所以：

> **不是六逆变器拓扑本身做不到。**

---

## 6.2 这个项目之所以显得特别难，是因为我们是在“强网控制模型上改造成可孤岛模型”

如果一开始从零设计一个完整孤岛控制器，一般会明确划分：

```text
并网 Q/P 跟踪模式
孤岛 P/f、Q/V 支撑模式
状态交接
二次恢复
执行器饱和保护
```

而我们当前模型最初并不是按照这套哲学构建。

我们做的是：

> 在大量既有控制器、封装块、六设备任务、100 μs 实时模型、RT-LAB 接口不允许随意破坏的前提下，把它逐步改造成真正可以计划离网的控制系统。

因此我们必须一个一个暴露：

```text
隐藏状态
强网假设
坐标问题
输出导纳问题
积分器问题
饱和问题
```

难度主要来自**遗留控制架构的重构**，而不是“计划离网理论本身做不到”。

---

# 7. 我们是否已经到了最后一层排错？

我的回答不是简单“是”。

更准确：

> **我们已经到了“最后一个已知主控制架构层”，但不能保证只剩最后一个小 Bug。**

现在剩余问题可以分成：

## 第一层：首发低频根因

```text
五台 GFL 岛内 Q 外环 / 基础 q 电流
```

这是当前最优先、最高置信度的根因。

## 第二层：大扰动执行恢复

```text
真实调制电压裕度
+
下游饱和是否反馈给电流控制器
```

它更像失稳后的放大器/恢复障碍。

## 可能的残余第三因素

```text
P 外环的 constant-P 增量阻抗
Kslow=0.5 对低频输出阻抗的影响
```

目前证据都没有要求先改它们。

因此我更愿意描述为：

> **我们已经进入倒数一到两层，而不是还在大范围找根因。**

如果下一轮把 Q 外环基础电流直接证明并重构，同时把调制裕度链锁死，那么后面大概率就进入“最终验收调试”，而不是继续大规模找方向。

# 8. 下一步最正确的方向是什么？

## 核心原则

**现在不要再做新的物理孤岛试验，也不要再改参数。**

先完成三份证据。

---

# 8.1 证据 A：用现有 V4.6 原始 MAT 反解基础 d/q 电流

必须同时算：

\[
I_{base,d}
=
\frac{I_{final,d}-I_{support,d}}{g_P}
\]

\[
I_{base,q}
=
\frac{I_{final,q}-I_{support,q}}{g_Q}
\]

其中：

```text
gP/gQ 太小时不允许强行除
```

必须自动输出：

- 有效样本比例；
- 被排除样本比例；

- `BaseIq / Qerror`；
- `BaseIq` 相对电压误差的相位；

分析时间窗优先使用：

```

五台高度相干
```

那么 Q 外环首发根因就可以正式锁死。

# 9. 三份证据完成后，V4.7 应该怎样设计？

我目前认为最干净、最符合已有模型结构的方案，不是“修改 Q PI 参数”，也不是“把 Q PI Ki 调小”。

而是：

> **并网保留原 Q PI；孤岛把它从主动态控制权中退出。**

---

# 9.1 Stage0：并网

完全保持当前结构。

```text
Qref
→ Q PI
→ raw Iq
```

原来的 Q 跟踪能力不动。

---

# 9.2 Stage1：计划离网准备

在最终强网稳定工作点捕获：

```text
Iq_base0 = 当时 raw q 轴基础电流
```

最好是一个很短的准稳态均值，而不是单采样点。

同时记录：

```text
Q PI 当前输出
Qmeas
Qref
```

目标只有一个：

> J1 打开时基础 q 电流不能跳。

---

# 9.3 Stage2：孤岛一次控制

这里是 V4.7 最关键的结构变化。

不再使用：

```text
live Q PI output
```

作为基础 q 电流。

改成：

```text
Iq_base = captured Iq_base0
```

然后：

\[
I_{q,cmd}
=
I_{q,base}
+
I_{q,voltage-support}
+
I_{q,damping}
\]

其中：

- `Iq_base`：预切岛工作点；
- 电压支撑：优先复用已经存在的 slow-q（慢速无功电压支撑）；
- 中频阻尼：继续保留 V4.5 已证明有效的 5~20 Hz 主动阻尼；
- V4.6 0.18~0.35 Hz LFQ（低频 q 轴附加阻尼）先关闭或降为零，避免控制重叠。

最重要的是：

> **岛内 Q 目标不再通过一个 Ki=2 的积分器不断改变基础 q 电流。**

---

# 9.4 同时让后台 Q PI 自己停止积累

这里有一个非常适合当前模型、而且不用修改封装 PI 内部的办法。

因为当前真实 Q error 是：

\[
Q_{error}=Q_{meas}-Q_{refEff}
\]

所以在 Stage2/3 可以令：

```text
QrefEff = Qmeas
```

于是：

```text
Qerror = 0
```

这样：

- 比例项变成零；
- 积分器输入为零；
- 内部状态停止继续积累；
- 不需要修改封装 PI 内部；
- 不需要给 PI 增加 reset 端口。

但必须注意：

> **不能简单把现有 gQ 直接设成 0。**

因为当前 `gQ` 同时参与基础 q 电流缩放和 Q 跟踪软化，语义耦合。

V4.7 应该把两件事拆开：

```text
Q tracking authority
```

和：

```text
base q current physical scaling
```

不能继续用一个系数同时代表两种事情。

这是 V4.7 一个很重要的结构整理点。

---

# 9.5 Stage3：孤岛二次恢复

二次电压控制只做：

```text
移动 VsupportRef（电压支撑参考）
```

然后五台的电压支撑电流响应这个参考。

不要再出现：

```text
二次控制要求电压变化
+
Q PI 又把 Q 强行拉回固定目标
```

V4.6 已证明有效的二次电压历史状态释放继续保留。

---

# 9.6 Stage4/5：恢复并网

不能简单 Switch 回 Q PI。

要满足：

```text
当前实际基础 Iq
≈
Q PI 当前输出
```

再恢复控制权。

第一版 V4.7 如果在整个孤岛期间都保持：

```text
Iq_base = Iq_base0
```

而后台 Q PI 又通过 `QrefEff=Qmeas` 保持积分状态不漂移，那么恢复并网时两者天然比较接近。

这会比“岛内继续让 Q PI 乱积分，最后再硬切回来”容易很多。

然后在强网重新建立后：

```text
QrefEff：
Qmeas
→ 原 Qref
```

做有界斜坡恢复。

# 10. V4.7 要不要同时改电流 PI？

**第一版不建议改 Kp/Ki。**

原因：

```text
0~2 s 时慢模态已经在发展
但 ModIndex 仍未成为首发主因
```

所以先改 Current PI 会把主因和放大器混在一起。

正确方式：

1. V4.7 主体先解决 Q 外环控制权；
2. 同时增加/记录调制裕度状态；
3. 保证最终命令饱和时不会继续扩大上层 q 请求；
4. 如果 Q 外环修复后仍出现真实调制饱和，再针对电流环的下游 anti-windup 做第二步。

这比现在直接扫 Current PI 更可靠。

# 11. P 外环要不要一起停掉？

现在不建议。

原因：

- 频率比电压明显健康；
- 现有 0.25 Hz d 轴电流摆动明显小于 q 轴；
- P-f 中央通道已不是首发；
- 同时改 P/Q 会破坏因果辨识。

但这次离线重构必须把：

```text
BaseId
```

一起算出来。

如果最终发现：

```text
BaseId 0.25Hz 也很强
```

或者表现出明显 constant-P（恒功率）负增量阻抗效应，那么再进入 V4.8/后续小修。

不能提前假设它完全无关。

---

# 12. Kslow 要不要再扫？

不建议。

当前 `Kslow=0.5` 确实会改变低频输出阻抗，但现在没有证据说明它是 0.25 Hz 主因。

更合理的顺序是：

```text
先去掉 Q PI 的强积分竞争
→ 看 0.25 Hz 是否消失
→ 如果仍存在
→ 再评估 Kslow
```

否则现在扫 Kslow 只能让问题重新变成参数试错。

# 18. 一句话回答你的几个问题

### “我们的几次改模有没有作用？”

**有。多数修改都解决了真实分层问题；V4.6 低频 q 轴阻尼不是根因修复，但它成功证伪了“只缺外围低频阻尼”这一假设。**

### “为什么根因还是没有完全锁定？”

因为此前没有直接看到 Q PI 原始基础 q 电流和积分状态，而且最终电流参考中混入了支撑和限流。现在只差把现有数据反解并与真实模型状态链对上。

### “设计到底哪里有缺陷？”

最大的缺陷是：**并网和孤岛仍共享同一个强 Q 积分跟踪目标；其次是实际调制电压饱和没有完整进入电流控制器的抗饱和闭环。**

### “计划性离网是不是太难？”

不是。难点来自我们在一个原本偏强网跟随逻辑的六逆变器实时模型上做无冲击岛网重构，而不是这个拓扑物理上不可实现。

### “是不是最后一层排错？”

**已经到倒数一到两层。** 主控制层是岛内 Q 端口，执行鲁棒性层是真实调制裕度。后面不应该再大范围找方向。

### “接下来究竟怎样才能彻底解决？”

**先完成三份只读/离线证据，随后把五台跟网设备的岛内无功控制从“强 Q 积分跟踪”切换为“捕获基础 q 电流 + 电压支撑 + 已验证中频阻尼”，后台 Q PI 在孤岛通过零误差保持状态；然后再用调制裕度审计决定是否补下游抗饱和。Primary-only 通过后再进完整 Secondary。**

这条路线是目前证据最完整、改动层级最正确、也最有可能真正结束这次计划离网排错的路线。
