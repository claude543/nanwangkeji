# 8.25｜F4之后总复盘：不是“验收太严”，当前主因是dq同步目标不完整，并需复核孤岛功率平衡

## 0. 最重要结论

目前绝不是：

```text
所有原因都排除了
+
所有解决办法都试完了
+
这个模型就是做不到
```

真实情况是：

```text
我们已经排除了/修复了很多前层问题
↓
每修掉一层，后面被前层错误掩盖的问题才暴露
↓
最新F4又给出了一个非常具体的新证据：
“Droop相角虽然被同步了，但同步到了错误的dq轴”
```

因此当前方向没有被证明错误，模型也没有被证明无法实现健康孤岛。

反而，最新MAT已经把当前最主要的问题进一步锁死。

# 2. 我们没有“试遍所有办法”

此前很多试验的目的不是“碰运气寻找一个能跑的参数”，而是定位因果：

```text
800 / 1000 Hz
→ 判断filter是不是唯一根因

AD正负号
→ 判断裸iC damping能不能直接修复

MODE1 / MODE2
→ 判断remote feedback和local feedback的影响

phase -30 / 0
→ 判断transformer frame compensation

2/14 -> 0.02/0.14
→ 判断Voltage outer loop bandwidth

F3 reset
→ 判断历史PI state
```

所以不能把整个过程理解成：

> “所有方法都试了一遍仍然失败”。

更准确：

> 每轮都是在缩小问题空间；最新F4仍然失败，是因为F4的同步目标本身还少算了一层坐标定义，而不是因为“相角同步这个方向无效”。

# 3. 最新F4 MAT给出的决定性新证据

最新F4在J1打开前24.9–25.0 s：

```text
PCC ≈ 10.0005 kV
Fout ≈ 49.9243 Hz
```

表面看起来很正常。

但是ESS1 GFM local dq：

```text
selected Vd ≈ 0.9672 pu
selected Vq ≈ 0.0684 pu

电压矢量角 ≈ 4.0°
```

而Voltage Regulator的模型结构明确要求：

```text
Vq_ref - Vq -> PI1
Vd - Vd_ref -> PI2

其中：
Vd_ref ≈ 0
Vq_ref ≈ Vout ≈ 0.984 pu
```

所以它真正希望：

```text
selected Vd ≈ 0
selected Vq ≈ 0.98
```

也就是电压应该在q轴。

当前F4却把电压几乎完全锁在d轴：

```text
Vd≈0.97
Vq≈0.07
```

这不是“小误差”。

这是接近90°的dq轴定义错误。

# 4. F4为什么会导致Id/Iq_ref持续增加

20–25 s强网GFM阶段，最新MAT平均：

```text
q轴电压误差：
Vout - Vq ≈ 0.920 pu

d轴电压误差：
Vd - 0 ≈ 0.986 pu
```

Voltage PI：

```text
Ki = 0.14
```

5 s积分量理论约：

```text
PI1：
0.14 × ∫(Vout-Vq)dt
≈ 0.644 pu

PI2：
0.14 × ∫Vd dt
≈ 0.690 pu
```

实际MAT：

```text
20.0–20.05 s：
Id_ref ≈ 0.0216
Iq_ref ≈ 0.0234

24.9–25.0 s：
Id_ref ≈ 0.6559
Iq_ref ≈ 0.7026
```

几乎和理论积分量一一对应。

这是当前最强的因果证据：

> **F4同步器确实把Droop angle“锁住”了，但锁在了Voltage Regulator不希望的d轴；因此Voltage PI在强网下连续5 s面对近1 pu的恒定dq误差，积分参考自然涨到0.65–0.70 pu。**

所以25 s开J1以前，ESS1已经不是一个正常待接管的GFM工作点。

# 5. 我需要修正前面的F4相角推导

前面F4使用：

```text
thetaDroop_sync = thetaF - pi/6
```

这个推导只比较了Vref Generation里的：

```text
wts
+
transformer phase correction
```

但它遗漏了两个关键事实：

1. `Vref Generation`在相角计算中还显式加入：
   ```text
   angle(VdVq_conv)
   ```
   不是只有`wts + phase offset`。

2. GFM Voltage Regulator自身采用：
   ```text
   Vd_ref = 0
   Vq_ref = Vout
   ```
   也就是**q轴电压定向**。

因此：

> `thetaF - pi/6`只保证了部分角度表达式看起来连续，并没有保证GFM控制器的完整dq坐标定义连续。

最新MAT已经实证这一点。

# 6. 当前正确同步角强烈指向再增加约-90°

F4当前：

```text
thetaDroop = thetaF - 30°
```

得到：

```text
local V angle ≈ +4°
```

目标：

```text
local V angle ≈ +90°
```

若其它量不变，要让测得dq电压从：

```text
[d≈1, q≈0]
```

```text
[d≈0, q≈+1]
```

Droop坐标需要再向负方向移动约90°。

所以当前最有物理依据的候选不是：

```text

```

而是：

```text
-30° - 90°
= -120°
= -2*pi/3
```

即：

```text
F4_SYNC_OFFSET_RAD candidate
= -2*pi/3
```

但现在不应该马上Build。

F4已经把这个offset做成runtime tunable，所以可以**零Build、不开J1地先验证**。

# 8. 10 kV / 50 Hz是不是必须“一丝不差”

不是。

这一点需要正式修正我们此前过于简单的验收口径。

## Frequency Droop

当前模型：

```text
Frequency_Droop = 1%
Fnom = 50 Hz
```

Droop公式：

```text
f_pu
=
Fref/Fnom
- 0.01*Pmeas
+ 0.005
```

如果：

```text
Fref=50 Hz
```

则：

```text
Fout
=
50.25 - 0.5*Pmeas_pu
```

所以：

```text
P=0 pu
→ Fout≈50.25 Hz

P=0.5 pu
→ Fout≈50.00 Hz

P=1 pu
→ Fout≈49.75 Hz
```

因此当前Droop本身就不是设计成：

> 不管输出多少功率都必须50.000 Hz。

---

# 9. Voltage Droop同样不是固定10.000 kV

模型：

```text
Voltage_Droop = 4%
```

电压参考近似：

```text
Vout_pu
=
Vref/Vnom
- 0.04*Qmeas_pu
```

若：

```text
Vref/Vnom=1
Q在±1 pu范围
```

正常Droop参考本来就可能约：

```text
0.96～1.04 pu
```

对应10 kV基准约：

```text
9.6～10.4 kV
```

所以：

> **最终验收不应该要求“必须严格10.000 kV / 50.000 Hz”。**

真正应该要求：

```text
稳定
有界
符合Droop P-f / Q-V关系
不长期饱和
不持续振荡
不超出设备/项目允许带宽
```

# 11. 当前条件能不能实现健康孤岛

目前没有任何证据说明“物理条件根本做不到”。

相反：

- 强网阶段可以稳定在10 kV附近；
- phase0旧测试曾经达到正确local `Vd≈0,Vq≈0.98`；
- 527 Hz主模态在0.02/0.14下曾下降约97%；

这些都说明：

> 控制器和电气对象不是从根本上不可控。

当前失败更像是**状态/坐标切换设计还没完全统一**。

# 12. 但还有一个必须认真验证的潜在遗漏：孤岛功率平衡/ESS1容量

这个问题此前还没有完全关闭。

Droop公式可以由Fout反推控制器感知的Pmeas。

如果：

```text
Fref=50
Frequency_Droop=1%
```

29–30 s：

```text
Fout≈49.22 Hz
```

对应的Pmeas量级约：

```text
Pmeas≈2.1 pu
```

如果这个值在正确波形下仍然成立，就意味着：

> ESS1可能正在被要求承担超过自身100 kVA基准的净有功不平衡。

这种情况下，再怎么调PI也不能让单台ESS1在额定范围内完美维持孤岛。

不过当前波形本身已经错误并存在谐波/饱和，所以这个2.1 pu目前还不能直接解释成真实稳态负荷。

因此顺序必须是：

```text
先修正dq同步目标
↓
得到无饱和、正确frame的孤岛
↓
再检查Droop反推P/Q
↓
判断ESS1容量和岛内功率平衡是否合理
```

如果正确frame以后仍要求：

```text
|P_ESS1| > 1 pu
或
|Q_ESS1| > 1 pu
```

那才说明下一层不是控制参数，而是：

```text
孤岛功率平衡 / 资源分工 / ESS1容量
```

需要调整。

# 16. 当前最准确的一句话

> **项目方向没有被证明错误，也不是“所有办法都试完仍然无解”；最新F4反而把当前失败精确暴露为一个坐标定义错误：F4把Droop theta同步到 `thetaF-pi/6` 后，强网GFM电压被锁在 `Vd≈0.97,Vq≈0.07`，而Voltage Regulator明确要求 `Vd≈0,Vq≈Vout`。20–25 s近1 pu的恒定dq误差经Ki=0.14积分5 s，理论产生0.64/0.69 pu电流参考，与MAT实测0.656/0.703几乎完全一致。因此当前主因不是验收太严，而是F4同步目标还差约90°；下一步应零Build把候选offset改到约 `-2π/3`，先只做强网GFM坐标校准、不打开J1。与此同时，最终验收也应修正：Droop控制下10 kV/50 Hz是名义值，不要求数学上完全相等；但当前7–13 kV、电流/调制长期饱和显然远超正常Droop偏差。frame修正后还必须检查ESS1孤岛P/Q容量和平衡，这才是目前尚未完全关闭的第二个潜在问题。**
