# 0. 冻结结论

本文件冻结的是**当前整理模型上的第一阶段功能改进设计与后续执行顺序**。

当前不再保留以下开放设计选择：

- 不再讨论是否先等待板端；
- 不再讨论是否先进行全模型重新审计；
- 不再讨论首轮是否调 ESS1 电压 PI、中央 q-bias、P/f 二次恢复、EV 欠压阈值或 PV 功率基线；
- 不再讨论是否新增一个独立阻尼控制器；
- 不再讨论是否立即切换成持续构网或第二台构网；
- 不再讨论是否先大规模删除、重新收纳或重新布局。

第一轮功能修改固定为同一主题的两项坐标一致性修复：

1. **LFQ 低频无功标量按真实无功方向形成二维电流后再进入原最终限制器。**
2. **删除 5–20 Hz 中频阻尼在 State Core 中的旧固定 d 轴角色预裁剪，只保留下游真实有功方向角色约束。**

除此之外，第一轮不改变其它控制功能或运行工况。

# 3. 缺陷一：LFQ 固定 q 轴注入

## 3.1 当前真实错误链

当前链路：

```text
State Core out12 = damp_d_req
    └──────────────→ Final Limit in3

State Core out13 = damp_q_req
    ↓
AA15_DAMP_Q_SUM_V46 in1

LFQ Output qreq
    ↓
AA15_DAMP_Q_SUM_V46 in2

AA15_DAMP_Q_SUM_V46 out1
    ↓
Final Limit in4
```

所以 LFQ 标量 `qreq` 被直接解释为执行坐标中的固定 q 分量。

当电压真实有功方向不是 `[1,0]` 时，这不再等价于纯无功。

---

# 4. 缺陷一的最终冻结修法

## 4.1 不新增独立方向控制器

不采用“额外建立一个新的动态方向状态”。

不采用“始终使用上一拍 UDIR 直接旋转 LFQ”。

最终方案是：

> **把 LFQ 标量作为独立输入送入现有 `AA15_FINAL_GFL_LIMIT_CORE`，直接复用该核心当前已经存在的真实 `u/n` 方向计算。**

这样：

- 不重复写一套方向计算；
- 不增加新的动态状态；
- 正常电压时使用当前拍 `vd/vq`；
- 低电压或无效电压时自动复用当前 Limit Core 已存在的 UDIR_D/Q 回退；
- 与后续角色约束、电流圆、支撑预算使用完全相同的方向定义。

## 4.2 Limit Core 接口

当前：

```text
16 inputs
```

修复后：

```text
17 inputs
```

只新增最后一个标量输入：

```text
lfq_req
```

原 1–16 号输入顺序全部保持。

## 4.3 Limit Core 内部计算

现有方向：

```matlab
vm = hypot(vd,vq);

if voltage valid
    udn = vd/vm;
    uqn = vq/vm;
else
    use delayed UDIR_D/Q fallback;
end

n1 = -uqn;
n2 =  udn;
```

新增 LFQ 映射：

```matlab
dampd_total = dampd_req + n1*lfq_req;
dampq_total = dampq_req + n2*lfq_req;
```

然后原来的：

```matlab
dp = udn*dampd_req + uqn*dampq_req;
dr = n1*dampd_req + n2*dampq_req;
```

改为：

```matlab
dp = udn*dampd_total + uqn*dampq_total;
dr = n1*dampd_total + n2*dampq_total;
```

其余角色约束、IsupMax、Imax、slow-q、最终角色投影均保持原样。

数学上：

```text
u · n = 0
```

所以 LFQ 的新增有功投影理论上为零：

```text
u · (n * lfq_req) = 0
```

它只进入真实无功方向。

# 5. 缺陷一的连线修改

每台仅修改当前缺陷附近的局部链：

原：

```text
StateCore.out13 ─→ DAMP_Q_SUM.in1
LFQ.out1        ─→ DAMP_Q_SUM.in2
DAMP_Q_SUM.out1 ─→ Limit.in4
StateCore.out12 ─→ Limit.in3
```

新：

```text
StateCore.out12 ─→ Limit.in3      （保持）
StateCore.out13 ─→ Limit.in4      （改为直接进入）
LFQ.out1        ─→ Limit.in17     （新增独立 LFQ 输入）
```

删除已经失去功能的：

```text
AA15_DAMP_Q_SUM_V46
```

以及**只服务该 Sum 输出到 Limit.in4 的那一组局部 P6 Goto/From 路由**。

不按名字批量删除其它 P6 标签。

删除前必须证明：

- Sum 两个输入来源分别就是 StateCore.out13 与 LFQ.out1；
- Sum 输出唯一正式消费者就是 Limit.in4；
- 被删除的 Sum-output 标签没有其它消费者。

# 6. 缺陷二：旧固定 d 轴预裁剪

## 6.1 当前错误代码

当前 State Core 的 5–20 Hz 中频阻尼：

```matlab
dd = -gdamp*vbpd;
dq = -gdamp*vbpq;

rr = round(role);

if rr==1
    dd=min(dd,0.0);
elseif rr==3
    dd=max(dd,0.0);
end

damp_d_req=dd;
damp_q_req=dq;
```

这相当于在真实方向限制以前，先按旧执行 d 轴做一次角色限制。

# 7. 缺陷二的最终冻结修法

只删除旧 d 轴角色预裁剪：

```matlab
dd = -gdamp*vbpd;

damp_d_req = dd;
damp_q_req = dq;
```

不删除 `role` 输入，因为它仍用于 EV 欠压减充电等其它正式逻辑。

不改变：

```text

damp_lp

滤波状态
Stage 2–4 使能
Stage 0/1/5 清状态
```

# 8. 为什么删除前级裁剪后仍有设备角色保护

现有 Final Limit 已经执行真实方向约束：

```text
u = [udn, uqn]
n = [-uqn, udn]
```

中频阻尼真实有功投影：

```text
dp = u · damping
```

现有角色规则：

```text
PV:
dp ∈ [-ip, 0]

EV:
dp ∈ [0, -ip]

ESS2:
不施加 PV/EV 单向角色约束
```

最终输出还再次计算：

```text
pout = u · [fd,fq]
```

并执行最终 PV/EV 方向保护。

所以删除 State Core 的固定 d 轴预裁剪：

> 不等于删除设备有功角色保护。

真正角色保护仍由 Final Limit 在真实物理有功方向执行。

# 10. 补丁前数学单元测试——硬门槛

正式编辑模型以前必须在独立数学函数上通过：


## T2 无 LFQ 等价

当：

```text

```

新的 Limit Core 与原 Limit Core 对同一输入必须一致。

## T3 Stage 0/1/5 旁路

不论 LFQ 输入是多少：

```text

```

正式输出仍按原 bypass 返回 rawd/rawq。

## T4 低电压回退

验证：

```text
|V| >= 0.2 pu -> 当前 vd/vq 方向
|V| < 0.2 pu / 非有限 -> 原 UDIR_D/Q fallback
```

不能建立第二套低压规则。

## T5 PV 角色

最终：

```text
pout >= 0
```

不能因取消旧 d 裁剪而允许 PV 最终吸收有功。

## T6 EV 角色

最终：

```text
pout <= 0
```

不能产生 V2G。

## T7 ESS2

不能错误套用 PV/EV 单向角色限制。

## T8 电流圆

随机和边界输入均验证：

```text
hypot(fd,fq) <= Imax + tolerance
```

## T9 支撑预算

验证原 IsupMax 预算仍由 Final Limit 承担。

## T10 非有限数

LFQ 正常输出本身已有 finite 保护；
新补丁不得降低现有有限数保护等级。
