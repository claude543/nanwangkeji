| 问题 | 本次依据 | 要解决的关系 |

| d、q轴与实际电压方向偏离后，有功通道产生大量无功交叉分量 | 实际电压、电流、功率重算及模型运行坐标 | 功率请求怎样成为正确方向的电流 |

## 五、预计的局部修改方法：哪些可先定，哪些必须等审计

### 1. 功率分量与实际电压方向统一

候选方向仍是保留公共执行坐标，用有效电压方向定义有功电流和吸收无功电流，再转换到实际d、q执行轴。

审计还要确认储能1的电压定向、测量变换和相移补偿；如果偏离首先来自这些环节的具体错误，应先修正该错误，不能用旋转五台电流参考来掩盖构网侧问题。下列公式是已经核对的候选接口关系，不是预先判定所有坐标环节有错。

对于本模型已核对的功率符号，令电压单位方向为：

\[
\boldsymbol u=\frac{[v_d,v_q]^T}{\sqrt{v_d^2+v_q^2}},\qquad
\boldsymbol n=[-u_q,u_d]^T.
\]

则参考电流可以表示为：

\[
\boldsymbol i^*=i_P^*\boldsymbol u+i_R^*\boldsymbol n.
\]

其代数关系为：

\[
P^*=|V|i_P^*,\qquad Q^*=-|V|i_R^*.
\]

**不能只在最终参考后旋转一次就认为完成。** 同步设计事项包括：原积分状态怎样接管，基础工作点保持的量到底是什么，光伏/充电方向怎样判断，动态阻尼哪些量保持原矢量作用，二次能力区间怎样沿正确无功方向计算。

低压、无效电压、启动时没有可靠方向时，不能直接做除法。有效性阈值、暂时保持与恢复方法，需要根据实际测量滤波和状态接口确定，不在本轮缺少本机求值时写死。

**并网旁路和交接起点要保留；孤岛内部既然要修复，就不能再要求它和旧版有缺陷的一次层逐样本完全相同。** 这与不再额外跑透明回归并不冲突。

### 2. 六台电流环补齐最终执行残差

设实际已知的所有叠加项之和为：

\[
\boldsymbol u_{pre}=\boldsymbol u_{PI}+\boldsymbol u_{FF}+\boldsymbol u_{other}.
\]

经过模型真实的分量和幅值限制后，得到同坐标、同单位的等效可施加电压命令 \(\boldsymbol u_{lim}\)。候选残差为：

\[
\boldsymbol r=\boldsymbol u_{lim}-\boldsymbol u_{pre}.
\]

等价的比例积分跟踪目标是：

\[
\boldsymbol u_{PI,track}=\boldsymbol u_{lim}-\boldsymbol u_{FF}-\boldsymbol u_{other}.
\]

这里的等效可施加电压命令，不是开关桥臂瞬时电压，也不是只取一个0～1调制度当反馈。要按实际归一化和相角处理解释。

采用反算还是条件积分、怎样与既有局部限幅配合、是否需要一个明确的离散反馈状态，都在本机积分器结构和采样核对后决定。**不把“加一拍就没有代数环”当作动态稳定证明，也不为了省事将原离散积分方法换掉。**

该方法依据是已有执行器约束下的抗积分饱和原理；含前馈时，跟踪量必须扣除前馈贡献。[参考1]

### 3. 储能1电压外环按下游真实受限处理

先确定内电流环在能力内能够跟踪，受限时不会继续不合理积累，再处理外电压环的限幅与抗饱和。

不能把全部电流跟踪误差无条件反馈给外电压积分器，否则会把正常内环延迟当成持续能力不足。需要配合最终限幅状态及适当时间条件。

这项先核对接口，再决定实际改动多少，不预先把电压环增益放大或缩小若干倍。

### 4. 中央偏置恢复为正常的连续积分规则

普通运行允许同一个积分状态围绕非零稳态工作点增减。取消“仅因偏置与期望变化率异号，就固定大速度向零释放”的通用处理。

较快的有效电压误差只用于制止明显不利的新增长，不因为误差反号就清空全部已有偏置。能力耗尽、退出模式与故障释放单独定义。

当五台电流方向定义调整时，中央分配量的单位、符号及本地反馈含义也要同步明确。不能一处已经变成电压定向无功电流，另一处还按物理q轴解释。

### 5. 本轮不增加有功重调度层

保留现有有功频率协调和原试验初值，暂不扩大板端点表，不提高电流、电压或调制度极限，不为追求合格波形而降低测试负荷。

如果基础执行关系修正后仍证明原工作点超出真实能力，再把降载作为运行约束处理。那是有证据的后续决定，不是本轮提前选定的根因。

## 六、审计后如何停止检查并进入改模

审计必须回答下表中的问题；信息已齐就停止重复检查，不再为了增加通过项重复跑同样的审计。

| 冻结项 | 所需信息 |
|---|---|
| 修改对象 | 实际模块路径、当前函数正文、所连接的唯一输入输出 |
| 数值含义 | 单位、符号、功率/电流基准、采样周期、有效性条件 |
| 状态接管 | 原状态、初值计算、切换连续性、退出和重新进入行为 |
| 约束处理 | 电流圆、角色限制、实际电压能力、正常延迟与受限的区别 |
| 原功能保持 | 阻尼职责、参考交接、唯一频率恢复任务、板端模式语义 |
| 验证方式 | 模块数值测试、严格编译、正式孤岛需要记录的实际量 |
| 实施保护 | 源文件备份、允许修改的范围、失败时整文件恢复 |

**审计状态只会表示是否可进入设计审阅，不会出现“全部设计绝对正确”或者“允许直接验收稳定”。**

本机返回结果以后，下一份应当是具体的局部修改合同和实现代码，不再泛泛重复“需要更多审计”。只有发现会实质影响修改的新依赖，才补该依赖。

顺序为：

**本机边界审计 → 局部设计冻结 → 候选模块级测试 → 备份并事务改模 → 独立核验 → 完整正式孤岛试验。**

模块级测试不是又安排一场透明回归，也不是把实际微网中的必要功能逐个关掉。它用于在独立的小模型或数值函数中测试公式、状态接管、限幅与异常分支，再把合格模块组合进正式模型。

原有功初值、负荷和正式离网时序先保持，便于比较。修复涉及相互依赖的同一坐标链时，应把该链一起改完整，不能为了形式上的单变量而故意留下前后单位不一致的版本。

正式试验至少覆盖已知异常出现的整个15秒过程。如果末段仍有明显状态迁移，不把试验提前截断后宣称稳定；进一步观察时长依据最慢有效控制动态和试验目标决定。

## 十、这次用什么判断是否真的改善

不只看电压平均值或某一个频谱比值。需要同时观察：

| 方面 | 实际判据对象 |
|---|---|
| 切换成立 | 实际断路器、唯一构网主机、母线和负荷供电情况 |
| 控制含义一致 | 有功/无功分量是否按所定义方向生成电流，是否出现隐藏大交叉任务 |
| 实际执行改善 | 限幅前后电压、积分状态、最终电流参考与实测电流 |
| 稳态质量 | 暂态后电压与有效频率进入约定范围，而不是只在早期几秒合格 |
| 动态行为 | 振荡或均值迁移不继续增长；不把一次暂态的频谱峰直接命名为固有模态 |
| 能力边界 | 不能长期依靠饱和维持；参考侧标志为零不能替代实际电流检查 |
| 其他策略 | 黑启动、失网处置、重同步、回并网使用各自入口和验收，不以计划离网替代 |

暂态允许波动；真实电压与电流持续恶化不能用降低判据要求来掩盖。硬件保护值与研究筛选阈值仍应明确区分。

## 十一、对“能否绝对正确、是否一次解决”的回答

现在可以确定的是：**下一步应从增加上层功能，转为修已有控制关系；可以针对实际模块和公式推进，不必再重复提取同一批数据。**

有依据的把握在于：具体不一致已经能用源码、连线与记录互相核对，修复目标可验证。不能承诺的部分是：修复后全部耦合动态会天然落在最佳增益和工作点，或一次正式试验即可覆盖所有策略。

本轮不再使用“最后一层排错”“已经没有任何设计缺陷”“改完必定稳定”等说法。实际通过什么就认可什么；如果仍有异常，用它与本次明确修改的关系继续缩小范围，而不是再次无依据改换主线。
