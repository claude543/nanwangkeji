# 8.26｜为什么选择ESS1作为孤岛源，以及真实孤岛/并离网状态究竟如何建立

# 0. 先给最终答案

## 0.1 “ESS1作为孤岛源”到底是什么意思

这里的“源”不是：

```text
ESS1必须承担整个微电网全部有功/无功
```

而是：

# ESS1被指定为Grid-Forming（GFM，构网型）电压/频率参考源。

它负责建立：

```text
母线电压幅值 V
频率 f
相角 theta
```

也就是说，当上级电网不存在以后：

```text
谁来定义“10 kV、50 Hz、当前相角是多少”？
```

当前项目把这个职责交给ESS1。

其它：

```text
PV1
PV2
ESS2
EV1
EV2
```

当前主要按Grid-Following（GFL，跟网型）运行。

它们不是没有能源。

它们只是不能在没有外部电压波形时自己定义：

```text
V/f/theta
```

而是：

```text
检测已有母线电压
PLL同步
按照Pref/Qref向母线注入电流
```

所以最终孤岛正常状态可以是：

```text
ESS1 = GFM
负责形成电网

PV1/PV2/ESS2/EV1/EV2 = GFL
负责在ESS1形成的电网上按P/Q出力
```

---

# 1. 为什么一开始选择ESS1

这里需要区分：

## 1.1 项目文件可以直接确认的事实

当前模型的控制架构已经明确形成：

```text
ESS1：
GFM master

其它5台：
GFL
```

ESS1内部已经具有完整：

```text
Droop Control
Voltage Regulator
Current Regulator
GFL/GFM mode switch
F3 state management
F4 angle sync
```

所以过去GFM排错自然围绕ESS1展开。

这是模型架构事实。

---

## 1.2 为什么工程上储能最适合作为单主GFM

这是工程控制逻辑。

ESS通常比PV和EV更适合承担GFM主机。

### 原因1：有功双向调节

ESS可以：

```text
放电：
向岛网补P

充电：
吸收多余P
```

所以可以快速承担：

```text
generation-load mismatch
```

---

### 原因2：无功调节独立

在变流器容量范围内可以快速调Q，

用于：

```text
电压形成
电压恢复
```

---

### 原因3：能源可控

PV：

```text
受光照限制
```

无法保证任何时刻都有足够P。

EV：

```text
是否接车
SOC
用户充电需求
```

不确定。

ESS：

```text
SOC和功率边界可管理
```

更适合承担微网主参考。

---

### 原因4：天然适合黑启动

若DC侧储能已经带电，

ESS变流器可以在：

```text
外部交流电压=0
```

时自己合成交流电压。

这就是black-start/grid-forming的重要能力。

---

# 2. 为什么是ESS1，不是ESS2

如果ESS1和ESS2硬件参数、SOC、容量完全相同，

那么：

# ESS1并不是物理上唯一可以当GFM的设备。

它只是当前模型中被指定为master。

完全可以设计成：

```text
ESS2 = GFM master
ESS1 = GFL
```

甚至：

```text
ESS1 + ESS2
双GFM
```

但双GFM会额外产生：

```text
P-f droop sharing
Q-V droop sharing
virtual impedance
circulating current
角度/频率协调
```

所以在定位阶段使用：

```text
1台GFM + 5台GFL
```

是最简单、可解释性最强的架构。

---

# 3. 一个孤岛是不是必须选一台逆变器作为“源”

如果岛内没有：

```text
同步发电机
柴油机
其它电压源
```

而全部都是电力电子GFL设备，

那么答案是：

# 至少需要一个Grid-Forming source。

不一定“恰好一台”。

可以：

```text
1台GFM + N台GFL
```

也可以：

```text
2台或多台GFM并联
```

甚至全部设备GFM。

但：

```text
至少一个设备必须负责定义V/f。
```

---

# 4. 为什么全部GFL不能自己形成孤岛

典型GFL控制逻辑：

```text
测量母线Vabc
↓
PLL得到theta
↓
根据Pref/Qref计算Id/Iq
↓
控制电流注入已经存在的电网
```

问题在于：

```text
J1打开
+
岛内没有任何GFM
```

以后：

```text
谁先建立Vabc？
```

GFL自己需要一个已有Vabc才能PLL同步。

所以形成逻辑会陷入：

```text
“我要先看到电网
才能向电网送电”
```

而岛内根本没人先创建电网。

因此：

# 至少一个GFM必须先建立交流母线。

---

# 5. GFM真正做什么

GFM不是简单：

```text
给一个Pref
```

它更像一个受控交流电压源。

例如ESS1：

```text
P-f Droop
决定频率/角速度

Q-V Droop
决定电压幅值

Voltage Loop
决定需要多少电感电流

Current Loop
让实际电流跟踪

PWM + inverter
实际合成Vabc
```

因此：

```text
DC储能
↓
ESS1 inverter
↓
GFM control
↓
形成10 kV/50 Hz岛网
```

---

# 6. 最终六机孤岛正常状态应该是什么

不是：

```text
ESS1单独供所有负载
其它5台全部断开
```

正常目标应该是：

```text
             ESS1
             GFM
          形成V/f/theta
               │
               ▼
        微电网交流母线
       ┌───────┼─────────┐
       │       │         │
      PV      ESS2      EV
     GFL      GFL       GFL
       │       │         │
       └──按P/Q共同承担───┘
```

ESS1主要承担：

```text
瞬时功率不平衡
电压/频率基准
快速扰动
```

而不是长期独自承担全部P/Q。

上层AGC/BOARD15再逐渐调节：

```text
PV
ESS2
EV
```

把ESS1的长期偏差卸掉。

# 7. “孤岛已经建立”到底需要满足什么

仅仅：

```text
J1 OPEN
```

不能称为健康孤岛。

真正建立必须同时满足：

## 电气条件

```text
J1 = OPEN
```

岛网与上级电网电气断开。

---

## 电压条件

本地母线：

```text
V ≈ nominal
```

有界、稳定、无持续振荡。

---

## 频率条件

```text
f ≈ nominal/droop允许范围
```

有界。

---

## 功率平衡

岛内：

```text
ΣP_source
≈
ΣP_load + losses
```

以及：

```text
ΣQ_source
≈
ΣQ_load + reactive network demand
```

---

## 控制条件

至少一台：

```text
GFM active
```

其它GFL：

```text
PLL lock到本地岛网
```

而不是继续依赖Grid-side reference。

---

## 设备约束

```text
current不过限
ModIndex不过长期饱和
DC source不超功率
SOC允许
```

# 8. 我们现在真正应该区分两种“建立孤岛”的方式

这是整个项目接下来最重要的概念。

---

# 9. 方式A：Black Start / Island Start

中文：

# 从一开始就没有上级电网，由ESS1自己把孤岛“从0建立起来”。

典型过程：

```text
J1 = OPEN
↓
其它GFL暂时不参与
↓
ESS1进入GFM
↓
Vref从较低值/0缓慢Ramp
↓
形成本地Vabc
↓
稳定到10 kV / 50 Hz
↓
其它GFL PLL锁到ESS1形成的母线
↓
逐台投入
↓
逐步恢复P/Q
```

---

# 10. 这个过程回答什么问题

它回答：

> **ESS1本体到底有没有形成电网的能力？**

没有：

```text
Grid突然被拿走
PCC电流突然消失
J1开断瞬态
```

所以是最纯粹的：

```text
autonomous grid-forming capability
```

测试。

---

# 11. 为什么应该先做这个

如果Island Start都失败：

```text
J1本来就是OPEN
没有任何Grid切换瞬态
```

ESS1仍然不能建立10 kV，

那么才可以真正说：

```text
ESS1本体GFM控制
/
LC output impedance
```

有问题。

---

# 12. 如果Island Start稳定意味着什么

意味着：

```text
ESS1
+
真实Transformer/Stubline网络
```

本身可以形成稳定岛网。

那A0~B2失败就不是：

```text
“ESS1根本构不了网”
```

而是：

# “并网状态切换到孤岛状态的过程没有设计正确”。

# 13. 方式B：Grid-connected → Island transition

不掉电

# 14. 真正正确的切岛流程不能只是“同步角度→开J1”

完整流程应该是：

## Step 1：选择GFM master

```text
ESS1
```

---

## Step 2：ESS1在J1仍闭合时进入GFM-ready

但必须：

```text
V
f
theta
```

与强网匹配。

我们F4主要解决的是：

```text
theta / dq frame
```

---

## Step 3：做Tie-line P/Q预平衡

这是目前以前做得不够完整的地方。

打开J1前，应该让：

```text
P_tie → 0
Q_tie → 0
|I_tie| → 小
```

方法不是只调ESS1。

而应该利用：

```text
PV1/PV2
ESS1/ESS2
EV1/EV2
```

共同调P/Q。

例如：

```text
微网内部发电
≈
内部负载+损耗
```

从而使Grid几乎不再提供净功率。

---

# 15. 为什么P和Q都必须平衡

如果只做到：

```text
P_tie≈0
```

但：

```text
Q_tie很大
```

J1打开以后：

```text
无功/电流责任仍会突然转移
```

一样可能造成：

```text
Voltage jump
Current transient
```

所以切岛不能只盯PCC active power。

必须看：

```text
P
Q
I
```

---

# 16. Step 4：HOLD上层慢控制

在J1即将打开时，

例如：

```text
AGC
secondary V/f PI
Microgrid Supervisor
```

不应该继续积分追踪grid-connected目标。

应该进入：

# HOLD

冻结关键慢状态。

避免：

```text
开断瞬间
上层控制器也同时大动作
```

---

# 17. Step 5：打开J1

如果此时：

```text
V/f/theta匹配
P/Q/I_tie≈0
ESS1 GFM already active
```

那么J1开断理论上只是一项很小的网络拓扑变化。

而不是：

```text
同时把0.2~1 pu负荷突然扔给ESS1
```

---

# 18. Step 6：Island RELEASE

J1确认OPEN后：

```text
ESS1继续GFM
```

并释放：

```text
island secondary V/f restoration
```

其它GFL：

```text
继续同步到ESS1形成的本地母线
```

然后AGC/BOARD15：

```text
重新分配P/Q
```

让ESS1回到合理功率/SOC区间。

# 19. 最终并→离网状态机应该是什么

一个合理状态机：

```text
GRID_CONNECTED
    │
    │ island request
    ▼
PREPARE_ISLAND
    │
    ├─ ESS1 GFM-ready
    ├─ V/f/theta synced
    ├─ P_tie≈0
    ├─ Q_tie≈0
    └─ I_tie small
    ▼
HOLD
    │
    ├─ freeze slow integrators
    └─ freeze transition target
    ▼
OPEN_J1
    │
    ▼
ISLANDED
    │
    ├─ ESS1 = GFM master
    ├─ other resources = GFL
    ├─ island V/f restoration
    └─ P/Q redistribution
```

这才是完整离网建立。

# 20. 并网恢复则反过来

```text

↓
RESYNCHRONIZATION
```

控制：

```text

Δtheta
```

然后：

```text
PCC breaker close
```

确认合闸。

再：

```text
ESS1根据需要恢复GFL

```

```text
NORMAL
```

# 21. 为什么ESS1不能在最终系统里永远独自扛着

即使ESS1额定能扛瞬态，

长期也不合理。

因为：

```text
SOC会漂
Current margin会耗尽
效率下降
容量可能不足
```

所以GFM master的作用是：

# “定电网 + 吃瞬态”

而AGC/其它资源作用是：

# “慢慢分担稳态功率”。

例如：

```text
岛网突然缺30 kW
↓
ESS1瞬时先增加30 kW
↓
频率只轻微下跌
↓
BOARD15/AGC发现
↓
逐渐让：
PV +10
ESS2 +10
EV减少充电10
↓
ESS1恢复到原工作点附近
```

这是完整的primary-secondary功率分工。

# 24. 最终答案

## 为什么选ESS1

项目现有架构已经把ESS1设计为GFM master；

工程上ESS又是最合适的构网候选：

```text
双向P
快速Q
SOC可控
黑启动能力
```

选择ESS1而不是ESS2主要是master assignment，不是物理唯一性。

---

## 是否必须选一个源

在当前六逆变器、没有同步机的岛网里：

# 至少需要一个GFM电压/频率源。

不要求恰好一个。

当前采用：

```text
1 GFM + 5 GFL
```

是最简单合理的架构。

---

## 真正孤岛如何建立

有两种：

```text
Island Start：
J1一开始OPEN
ESS1自己建立V/f

Grid-to-Island：
先同步+P/Q/I预平衡
再开J1
```

不能把两者混成一个问题。

---

## 离网状态究竟是什么

不是：

```text
J1=OPEN
```

这么简单。

而是：

```text
J1 OPEN
+
ESS1形成稳定V/f
+
岛内P/Q平衡
+
其它资源同步到本地母线
+
控制器不依赖上级Grid
+
无长期饱和/振荡
```

这才叫真正ISLANDED。
