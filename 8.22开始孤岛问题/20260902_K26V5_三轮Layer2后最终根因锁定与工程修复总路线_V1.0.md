# K26_V5｜三轮 Layer-2 后最终根因锁定与工程修复总路线 V1.0

> 日期：2026-09-02  
> 对象：2PV + 2ESS + 2EV 六逆变器微电网，计划性离岛，ESS1=GFM，其余五台=GFL  
> 本文定位：结束“继续找根因”的发散阶段，冻结机制级根因，并把下一阶段转为工程控制重构与闭环验证。

---

# 1. 最终结论先行

## 1.1 六设备原始计划性离岛为什么失稳

根本原因不是 J1 本身、F24/F25、ESS1 电流限幅、某一个 PLL 参数或某一个 PI 参数。

真正的系统级根因是：

> **五台 GFL 仍沿用面向强电网设计的“高刚度电流源/近恒功率”控制结构，而离岛后唯一电压源变成有限输出阻抗、有限控制带宽和有限调制能力的 ESS1 GFM。强网消失以后，五台 GFL 的聚合动态导纳与 ESS1 GFM 输出阻抗形成不稳定闭环。**

这个架构失配表现为两个时间层：

### Layer 1：快速失稳
五台 GFL Current Regulator 中：

```text
本地端口 Vdq
→ 近单位增益直接电压前馈
→ Vconv
```

强网时这是普通电压扰动解耦。

离岛时本地端口电压已经是系统内部状态，这条路径等价于把电感对象中的端口电压作用大幅抵消，使 GFL 更接近“理想电流源”、减少自然输出导纳/阻尼。

结果：

```text
GFL aggregate dynamic admittance
×
ESS1 GFM finite output impedance
→ 10~17 Hz 正增长系统模态
```

这一层已经由 C1、C1-Q、Mode6、Mode7 因果链强锁定。

### Layer 2：慢失稳
Mode7 抑制快速前馈后，五台 GFL 仍保留强电网控制哲学：

```text
慢端口电压前馈仍接近单位增益
+
P/Q 外环仍持续追踪功率目标并推动 Id/Iq reference
```

因此 GFL 在低频仍缺少足够的“母线电压变化 → 有利电流变化”的被动/支撑通道。

Mode1、Mode2、Mode3证明：

```text
Kslow变化 → 慢电压轨迹显著改变
Kpq变化   → 慢电压轨迹显著改变
Kslow+Kpq同时变化 → 轨迹再次显著改变
```

但三种 0.5 干预均没有形成稳定平衡。

所以最终不能把根因写成：

```text
Kslow参数太大
或
Kpq参数太大
```

而应写成：

> **五台 GFL 在孤岛低频尺度仍是缺乏电压支撑/虚拟导纳的功率跟踪电流源。单纯削弱前馈或削弱 P/Q 动态只能改变轨迹，无法建立稳定的孤岛电压平衡。**

# 3. 已经可以关闭或显著降级的根因分支

## 3.1 PLL 不是原始快速根因
B1 在完整 coherent execution frame 下仍存在原快速失稳。

所以：

```text
native PLL动态修正
≠ 原10~17Hz快速失稳的必要原因
```

低电压后 PLL/frame 可继续成为放大器，因此最终工程控制仍应做低电压 frame 硬化，但不应回到“先调PLL参数”的路线。

## 3.2 F25 不是首发根因
Layer-2 三轮中没有先发生：

```text
F25 slew limit
F25 magnitude limit
F25 timeout
```

Mode3 同样没有。

F25保留，不重做。

## 3.3 ESS1 电流参考饱和不是首发根因
Mode3：

```text
ESS1 Iref saturation residual：无
ESS1 Iref component near limit：无
```

ESS1 ModIndex >0.98 直到 J1+约2.446s 才发生，而电压早在约0.224s开始<0.95pu、0.767s已<0.5pu。

所以调制能力是后期放大/限制，不是初始失稳原因。

## 3.4 ESS1 F/V目标不是先主动崩坏
电压下降期间 ESS1 Vout/Fout 仍保持相对有界。

因此不是：

```text
ESS1先命令电压掉下去
```

而是：

```text
ESS1想维持电压
但五GFL+网络形成的闭环使母线实现不了该目标
```

# 5. 最终控制结构建议

## 5.1 并网模式：完全保留原控制器

```text
J1 closed / GRID-CONNECTED
→ 原Power Control
→ 原Current Regulator
→ 原Vdq直接前馈
```

保持既有行为，不因为修孤岛破坏并网性能。

## 5.2 计划离岛 PREPARE

在真实计划离岛请求到 J1 open 前：

```text
捕获五台各自当前：
Vanchor_d/q
Ianchor_d/q

平滑进入孤岛GFL支持模式
```

用途仅为无扰切换，不是永久冻结工作点。

禁止最终工程版再依赖固定：

```text
8.1894 s
```

必须改为事件/状态驱动。

## 5.3 孤岛模式：VFF重新定义

不再使用：

```text
Vff = 100% terminal Vdq
```

建议形式：

```text
Vslow = LPF(Vraw)

Vff_island
=
Vanchor
+ Kdc * (Vslow - Vanchor)
+ Khf * (Vraw - Vslow)
```

设计原则：

```text
Khf << 1
Kdc < 1
```

但 Kdc/Khf 不再靠盲扫选，而应从输出导纳/阻尼目标反推。

Mode7/Mode1已经证明：

```text
Khf≈0 有必要
Kdc=1 仍有慢问题
Kdc=0.5 只能延缓，不构成完整解
```

## 5.4 必须新增“虚拟导纳 / 电压支撑电流”——这是现有诊断方案缺失的关键

仅降低 VFF 会把误差转给 Current PI。

因此必须补一个明确的母线电压恢复通道：

```text
ΔI_v = Yv(s) · (Vref_dq - Vdq)
```

然后：

```text
Iref_final
=
Ianchor
+ Gpq(s)·(Iref_PQ_raw - Ianchor)
+ ΔI_v
```

意义：

```text
母线电压下降
→ 五台GFL不再继续表现成纯恒功率电流源
→ 主动产生有利的电压相关电流
→ 聚合输出导纳获得正阻尼/电压刚度
```

这才是从结构上解决问题，而不是把责任全部推给Current PI。

## 5.5 P/Q外环必须改成孤岛兼容，而不是永久0.5

建议：

```text
P/Q raw PI
↓
孤岛动态低通 / rate limit
↓
电压依赖功率降额
↓
电流矢量限制
↓
anti-windup回灌
```

在欠压时不能继续“尽量维持原功率”。

资源行为应区分：

### PV
```text
欠压 → 允许主动功率快速削减
留出电流能力做电压/无功支撑
```

### EV
```text
EV充电是可削负荷
欠压 → 降低充电功率/电流需求
不能维持恒功率吸收
```

### ESS2
```text
欠压 → 优先承担额外有功/无功支撑
```

所以最终工程版不应让 PV/ESS2/EV 五台全部使用完全相同的“功率继续追踪”策略。

# 6. 电流限制必须放到最终孤岛参考之后

最终：

```text
Iref_PQ
+
Iref_voltage_support
↓
dq vector magnitude limiter
↓
Current Regulator
```

并且 limiter 必须有：

```text
active/reactive priority
outer-loop anti-windup
```

否则电流限制后 P/Q PI 继续积分，会制造新的慢恢复/过压问题。

---

# 7. PLL / frame 最终工程处理

PLL不是原快速根因，但低电压后独立PLL会变成放大器。

最终推荐优先：

```text
GRID CONNECTED
→ 各GFL本地PLL

ISLAND PREPARE / ISLANDED
→ 五GFL使用ESS1 GFM公共 angle/frequency
```

如果当前跨任务没有低成本公共角度通道，则第二选择：

```text
低压时 coherent hold/free-run
+
恢复后bumpless reacquire
```

但这属于鲁棒性层，不应替代上面的虚拟导纳/PQ孤岛化。

# 8. ESS1现在怎么处理

第一版最终工程Patch：

```text
不改ESS1主控制参数
不改F24/F25
```

原因：

```text
没有证据表明ESS1先失稳
```

先把五台GFL负担改正确。

若新GFL孤岛控制完成后仍出现：

```text
ESS1持续ModIndex≈1
Iref饱和
电压仍无法维持
```

再进入：

```text
ESS1 GFM output impedance / voltage-loop stiffness设计
```

否则现在调ESS1会混淆根因。

# 10. 最终一句话

> **当前六设备失稳的根本原因已经不是一个待寻找的“坏参数”，而是强网型五GFL电流源控制结构与单ESS1 GFM孤岛电压源之间的动态阻抗/功率控制架构不匹配。快速直接Vdq前馈造成第一层10~17Hz失稳；快速层被处理后，慢VFF与持续P/Q功率追踪继续使五GFL在低频过度电流源化。真正工程修复必须把五GFL变成孤岛兼容的 grid-supporting current-controlled units：降低/整形VFF只是第一步，必须新增虚拟导纳/电压支撑、电压依赖的P/Q降额、电流优先与anti-windup，并在低压孤岛下使用可靠的公共/保持frame。**
