# 5. 但是为什么还不能说“SS内部已经被证明有问题”？

关键就在：

# **`prim_ESS1`到底在哪里。**

`prim_ESS1`不是SS里面的测点。

它在：

```text
SM_Master
```

而且位于：

```text
SS功率级
↓
Differential Stubline
↓
SM中的变压器
↓

```

以后。

所以：

```text
prim_ESS1已经振荡
```

能够证明：

> **振荡在到达PCC之前已经存在。**

但不能直接证明：

> **振荡最早就是SS内产生的。**

# 14. 情况A：`inv`就已经有很强0.53 kHz

如果：

```text
inv Vabc
已经出现很强0.53 kHz

LC输出也有
prim也有
PCC也有
```

说明：

> **振荡已经深入到逆变桥交流端。**

但依然有两种机制：

### A1 控制/PWM主动生成或放大

例如：

```text
Voltage Regulator
Current Regulator
500 Hz measurement feedback
PWM
```

在这个频段形成了负阻尼。

### A2 网络模态反向传到Converter端

即：

```text
LC/网络已经振荡
↓
电流反向作用
↓
Current Regulator不断追赶
↓
Converter端也出现同频响应
```

因此：

```text
inv强振荡
```

会把我们带到下一层：

```text
IdIq_ref
IdIq_meas
VdVq_conv
ModIndex
```

判断谁先开始振。

# **振荡主要在LC滤波器/外部网络模态上被放大。**

这会强烈支持：

```text
LC resonance
+

```

而不是先怪Droop。
