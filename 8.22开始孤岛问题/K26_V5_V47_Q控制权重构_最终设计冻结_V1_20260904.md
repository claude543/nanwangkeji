# 0. 最终结论先写在最前面

现在已经不是“Q 外环可能有问题”这种宽泛判断。

经过这次两份新证据碰撞以后，可以把剩余问题收缩为：

> **五台仍为 GFL（Grid-Following，跟网型）的设备，在 ESS1 已经作为唯一 GFM（Grid-Forming，构网型）建立孤岛后，仍继续使用原强网式 Q 恒定跟踪比例积分器作为基础 q 轴电流的主动态来源。**

这条路径在孤岛里形成了：

```text
公共母线电压变化
        ↓
五台 Qmeas 同时变化
        ↓
五台 Qerror = Qmeas - QrefEff
        ↓
五个 Q PI 同时积分
        ↓
五台 raw/base q 电流同时变化
        ↓
五台无功输出改变公共母线电压
        ↓
ESS1 有限 Q-V 输出阻抗同时响应
        ↓
再次回到公共母线电压
```

因此，当前首发慢模态的主要问题不是：

```text
ESS1 不会构网
Current PI 参数错误
5~20 Hz 阻尼没工作
电流圆首先撞限
ModIndex 首先饱和
V4.6 LFQ 符号写反
```

而是：

> **孤岛以后，五台 GFL 的“无功控制权”没有真正从并网 Q 跟踪切换成孤岛电压支撑。**

# 4. 0.25 Hz 数据现在已经把 raw/base q 电流直接剥出来了

这次不再使用：

```text
FinalIref_q
```

代替 Q PI 输出。

使用真实关系：

\[
I_{final,q}
=
I_{support,q}
+
g_Q I_{base,q}
\]

所以：

\[
I_{base,q}
=
\frac{I_{final,q}-I_{support,q}}{g_Q}
\]

而在本次分析窗口：

```text
五台 gQ = 1
CurrentLimit = 0
```

因此这里实际上退化成：

\[
I_{base,q}
=
I_{final,q}-I_{support,q}
\]

也就是说：

> **本轮 BaseIq（基础 q 轴电流）的反解没有被电流圆限幅污染。**

# 7. 为什么分析器最后却给 StrongQPIBaseQEvidenceScreen=0？

这个 0 **不是物理否定，而是分析器判据设计错误。**

原判据要求：

```text
五台 raw BaseIq 两两相关系数必须为正
```

这是不合理的。

因为：

- PV1/PV2 是发电资源；
- EV1/EV2 是充电负荷；
- 各自局部 dq 坐标/功率方向存在符号差异。

实际：

```text
PV1 ↔ PV2   correlation ≈ +1.000
EV1 ↔ EV2   correlation ≈ +1.000
PV ↔ EV     correlation ≈ -0.996
ESS2 ↔ EV   correlation ≈ -0.981
```

而对应的 0.25 Hz 相位差接近：

```text
0°
或
180°
```

这不是“不相干”。

恰恰代表：

> **同一个公共慢模态在不同资源符号约定下表现为同相/反相。**

如果看：

```text
abs(correlation)
```

则：

```text
最小 ≈ 0.9810
中位数 ≈ 0.9964
```

非常高。

把相位差折叠到：

```text
0° / 180°
```

之后，中位偏差只有约：

```text
7.45°
```

因此：

> **`StrongQPIBaseQEvidenceScreen=0` 是分析器 signed-correlation（带符号相关性）假阴性，不是当前根因假设失败。**

这一点已经由本轮人工碰撞纠正。

不需要重新跑物理试验。

# 8. P 外环是不是也有 0.25 Hz？

有。

BaseId（基础 d 轴电流）0.25 Hz 幅值大约是 BaseIq 的：

```text
PV   ≈ 26%
ESS2 ≈ 36%
EV   ≈ 28%
```

所以不能说：

> P 外环完全没有参与。

但现在不应该同时修改 P 外环。

原因：

1. Q 通道幅值明显更大；
2. 频率目前明显比电压健康；
3. P/f 一次控制和二次有功协调仍需要 P 外环执行；
4. 同时冻结 P/Q 会破坏因果辨识；
5. 当前没有证据证明 P 外环是首发不稳定源。

因此：

> **V4.7 只改 Q 控制权，不改 P 控制权。**

如果 Q 重构后仍有残余慢模态，再判断 P 恒功率增量阻抗是否是下一层。

# 19. Stage2~4 为什么设置 QrefEff = Qmeas？

因为真实误差：

\[
Qerror=Qmeas-QrefEff
\]

所以：

```text
Stage2~4：
QrefEff = Qmeas
```

就有：

```text
Qerror = 0
```

作用：

1. Q PI 比例项归零；
2. Q PI 积分输入归零；
3. 内部积分器不再继续积累；
4. 不修改封装 PI；
5. 不需要 reset；
6. 不需要 state projection（状态投影）；
7. 回并网时保留原内部状态，不制造新的隐藏 windup（积分累积）。

# 20. 为什么不能只“旁路 Q PI”而不管 Qerror？

如果只把 Q PI 输出旁路：

```text
Final current 不再用 Q PI
```

但后台：

```text
Qerror 仍存在
```

那么 Q PI 内部积分状态仍会继续变化。

等重新并网：

```text
重新接回 Q PI
```

就可能产生大冲击。

所以：

> **“冻结应用的基础 q 电流”与“让后台 Q PI 零误差保持”必须同时做。**

这是 V4.7 真正完整的地方。

# 25. V4.6 LFQ 这次为什么先保留？

V4.6 已经证明：

```text

```

但没有证明：

```text

```

> **V4.7 第一版保留 V4.6 LFQ 完全不动。**

```text

→ FAIL

V4.7
held base q + zero-error Q PI + 同一个 LFQ
→ PASS
```

因果解释最干净。
