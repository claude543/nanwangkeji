# K26_V5｜Mode7 后根因重新收敛：为什么快速振荡消失但电压仍慢塌陷 V1.0

> 日期：2026-09-02  
> 核心结论：**之前锁定的 dq 端口电压直接前馈，是原 10～17 Hz 快速失稳的根因路径，这一点没有被 Mode7 推翻；Mode7 反而进一步证明了这一点。真正被 Mode7 推翻的是“只要把快速前馈分离掉，整个计划性离岛就一定稳定”这一过度推论。当前暴露出了第二层、更慢的电压稳定问题。**

---

# 1. 先把 Mode7 到底做成没有说清楚

五台设备都满足：

```text
Mode = 7
旧C1 = 正常
C2 = 正常
D轴旧门 = 正常
Q轴旧门 = 正常
```

新分离器：

```text
干预前：
最终输入 = 原始端口dq电压

干预后：
快速变化保留比例 = 0
```

而且逐点公式残差：

```text
约 1.1e-16
```

说明新分离器确实按设计执行，不是“模型没有改对”。

自动报告里的 `contractPass=0`，唯一来源是：

```text
raw/applied Iref 最大差 ≈ 0.001122 pu
```

其余模式、门、分离公式、干预前旁路全部为0误差。

所以这不是一个“Mode7没执行”的失败。

这个 0.001122 pu 需要下一版分析器按时间定位，而不应该把整个试验一票否决。

---

# 2. Mode7 做掉了什么

原系统 / C2：

```text
约17 Hz
正增长率约 +25/s
```

只保留 Q 动态时：

```text
约10.6 Hz
正增长率约 +69/s
```

Mode7 后：

```text
没有发现五台共同的高可信正增长快速模态
```

五台 `Vconv_d/Vconv_q` 的最佳拟合总体表现为：

```text
衰减
或
低可信边界解
```

因此：

> **原来那一层“dq端口电压快速直接前馈 → GFL聚合负阻尼 → 快速振荡”的机制，确实被新控制切断了。**

这说明之前对第一层根因的定位是对的。

---

# 3. 但是系统出现了完全不同的慢电压塌陷

一次侧电压 20 ms 因果 RMS：

```text
J1 + 0.020 s : 10.030 kV
J1 + 0.100 s :  9.956 kV
J1 + 0.150 s :  9.809 kV
J1 + 0.200 s :  9.397 kV
J1 + 0.300 s :  8.292 kV
J1 + 0.500 s :  5.268 kV
J1 + 0.750 s :  1.260 kV
```

这个形状和历史快速失稳完全不同：

```text
不是10~17Hz快速振荡放大
而是约0.15s以后开始持续丢失电压支撑
```

因此现在必须把：

```text
“原快速失稳”
```

和：

```text
“当前慢电压塌陷”
```

分成两层问题。

---

# 4. 为什么 slow/fast split 没有最终解决

Mode7 的设计是：

```text
Vff
=
Vslow
+
Kfast*(Vraw-Vslow)
```

第一轮：

```text
Kfast = 0
```

所以：

```text
Vff = Vslow
```

但是 SlowTracker 的关键性质是：

```text
非常慢的变化：
Vslow最终仍然跟上Vraw
```

换句话说：

```text
10~17Hz快速变化
→ 被压掉

接近直流 / 很慢的变化
→ 前馈增益仍然接近1
```

所以 Mode7 只修改了 GFL 的**中低频快速动态导纳**，没有真正改变其**接近直流的输出导纳**。

这正是当前最重要的新认识。

---

# 5. 用最简单公式说明

GFL 电流对象近似：

```text
(Ls + R) Δi
=
ΔVconv - ΔVterminal
```

控制器：

```text
ΔVconv
=
CurrentPI
+
Fvff(s) ΔVterminal
+ ...
```

因此：

```text
Δi
```

对：

```text
ΔVterminal
```

的响应近似受到：

```text
Fvff(s) - 1
```

控制。

如果：

```text
Fvff ≈ 1
```

则：

```text
端口电压变化
很难自然引起电流变化
```

GFL 就很像理想电流源。

Mode7：

```text
10~17Hz：
Fvff明显小于1

很低频：
Fvff重新趋近1
```

因此：

```text
快速负阻尼解决了
低频电压支撑不足仍可能存在
```

---

# 6. 当前第二层根因候选不应该只剩一个

现在不能再把全部慢塌陷机械地归到“还是Vff”。

当前至少有三个需要正交区分的机制。

---

## 候选 A：低频仍然过度电流源化

Mode7 低频仍：

```text
Fvff → 1
```

所以五台 GFL 对慢母线电压下降仍然非常不敏感。

整个孤岛的慢电压支撑几乎仍由 ESS1 一台 GFM 承担。

这可能使系统慢慢失去电压刚度。

---

## 候选 B：五台 GFL 的 P/Q 外环在低电压下表现成恒功率行为

当一个恒功率设备要求：

```text
P ≈ V * I
```

如果：

```text
V下降
```

为了继续维持同样 P：

```text
I必须上升
```

这会形成典型的：

```text
电压越低
→ 电流要求越高
→ 电压进一步下降
```

的负增量阻抗效应。

Mode7 数据中六支路电流在慢塌陷过程中确实出现了明显变化。

过去 C2 已经证明：

```text
P/Q动态不是原快速振荡存在的必要条件
```

但那不等于：

```text
在快速根因被修好以后
P/Q动态仍然不可能成为第二层慢塌陷的根因
```

这是必须重新主动验证的。

---

## 候选 C：ESS1 电压支撑能力/限制器成为第二层瓶颈

数据中：

```text
ESS1 Fout 0.2~1s只变化约0.09Hz
执行角导出频率也约50Hz
```

说明：

```text
ESS1频率主线没有先失控
```

但是：

```text
ESS1电压实际大幅下降
```

所以需要进一步看：

```text
ESS1电压参考是否仍在1pu附近
ESS1电压PI是否要求继续升高支撑
F25是否进入幅值/斜率限制
ESS1实际电流是否触碰支撑上限
```

历史已经证明 F25 不是原快速失稳的首发根因。

但在当前新的“0.2~1s慢塌陷”里：

```text
F25/电流能力
可以成为后续真正限制GFM电压支撑的第二层因素
```

不能沿用旧结论直接排除。

---

# 7. 当前报告里两个数字不要误判

## `contractPass = 0`

不是 Mode7 算法错。

五台：

```text
模式/旧门误差 = 0
分离器公式误差 ≈ 1e-16
干预前旁路误差 = 0
Kfast 1→0正常
```

只有：

```text
IrefResidual ≈0.001122 pu
```

导致旧分析器的“一票否决”。

下一版应当按：

```text
最终稳态窗口
干预窗口
J1后窗口
```

分别看 Iref 差值，而不是用全程最大值。

---

## `PCC physical frequency mean≈99.7 Hz`

这个也不能作为真实频率结论。

因为电压已经塌到：

```text
1~5kV
```

严重畸变时简单零交越会：

```text
多算交点
漏算交点
```

于是得到：

```text
100Hz
150Hz
```

假频率。

真正更可信的是：

```text
ESS1 Fout约50Hz
ESS1执行角导出约50.04Hz
```

所以当前不是“频率先变成100Hz导致电压塌陷”。

---

# 8. 根因树现在应该重新冻结为“两层”

```text
计划性离岛失败
│
├─ 第一层：快速动态失稳
│   │
│   └─ 五GFL dq端口电压动态直接前馈
│       → 聚合输出导纳/阻尼异常
│       → 10~17Hz正增长
│
│       【已主动锁定】
│       【Mode7已显著消除】
│
└─ 第二层：慢电压塌陷
    │
    ├─ A. 低频Vff仍≈1，五GFL慢动态仍过度电流源化
    │
    ├─ B. P/Q恒功率外环形成低频负增量阻抗
    │
    └─ C. ESS1 GFM电压/电流支撑最终受限
```

所以：

> **不是根因完全找错；而是项目中实际存在至少两层失稳机制。我们此前把第一层成功锁定后，过早把它等同于“整个计划性离岛的唯一根因”。Mode7 正好把第二层暴露出来。**

---

# 9. 下一步不要继续调 fc

最容易走错的方向是：

```text
1Hz不行
→ 改0.5Hz
→ 0.1Hz
→ 0.01Hz
```

这样最终只会越来越接近：

```text
C1 hard HOLD
```

虽然可能把塌陷推迟，但不能证明工程机制正确，而且又会重新制造慢相角/PI补偿问题。

所以：

> **停止用 fc 扫描追稳定。**

Mode7 已经完成了它最重要的使命：

```text
证明快速VFF根因
+
暴露低频第二层
```

---

# 10. 下一次 Build 应做“一次性低频根因 Harness”

不要单独先修某个候选。

一次 Build 加三个正交能力，然后根据证据顺序运行。

---

## 基线 M7

保留当前：

```text
快速VFF已抑制
慢VFF仍保留
P/Q动态正常
```

结果：

```text
快速稳定
慢电压塌陷
```

作为第二层基线。

---

## M8：去掉低频“理想电流源化”

不是 hard HOLD。

而是：

```text
Vff = Kv * Vraw
```

孤岛后让：

```text
Kv < 1
```

并通过无扰偏置/平滑接管保证：

```text
Vconv不突然跳
```

这样：

```text
端口电压无论快慢变化
都能重新产生一定自然电流响应
```

它直接验证候选 A。

具体 Kv 不应该先随机扫。

第一轮首先设计一个明确的“强作用值”，并把 Kv 运行时可调。

---

## M9：M7 + 冻结 P/Q 最终电流参考

保持当前 slow/fast VFF 不变。

但在计划离岛前：

```text
把五台 applied Id/Iq_ref
冻结在最后稳定值
```

这样低电压以后 P/Q 外环即使继续计算：

```text
也不能为了维持恒功率而不断改变实际电流指令
```

它直接验证候选 B。

注意：

```text
旧 C2 只能排除P/Q是“快速原失稳”的必要条件
M9回答的是P/Q是不是“慢塌陷”的必要条件
```

两个问题不同。

---

## M10：M8 + M9 同时

如果：

```text
M8单独不稳定
M9单独也不稳定
M10稳定
```

则说明：

```text
低频输出导纳不足
+
恒功率外环
```

必须共同存在才产生慢塌陷。

这是典型交互机制。

# 12. 下一步真正的工程解决方向

当前已经不适合把：

```text
slow/fast split
```

当最终解决方案。

它应保留为：

```text
第一层快速阻尼修复
```

最终控制很可能需要：

```text
第一层：
削弱危险的快速端口电压直接前馈

+

第二层：
让五台GFL在孤岛下具有明确、受控的低频电压相关响应
```

第二层最终可能落到：

```text
降低孤岛下的端口电压前馈增益
或
显式虚拟导纳 / 虚拟阻抗
或
电压-无功支撑
```

并且需要处理：

```text
P/Q恒功率外环
与
GFM电流能力
```

之间的协调。

---

# 13. 当前最重要的一句话

> **我们现在不是“根因又找不到了”，而是从一个混合失稳问题中成功剥掉了第一层快速不稳定。Mode7 的失败本身是很有价值的：它证明快速dq前馈路径已经被正确处理，却留下一个时间尺度完全不同的慢电压塌陷。下一步不应该继续调1Hz参数，而应该用一次 Build 的正交 Harness 区分“低频输出导纳不足”“恒功率P/Q外环”“ESS1支撑受限”这三条第二层机制。只有这一层也锁定后，才能设计真正完整的计划性离岛解决方案。**
