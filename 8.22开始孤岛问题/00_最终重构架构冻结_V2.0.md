# K26_V5｜N3 审计后最终重构架构冻结 V2.0

> 日期：2026-09-03  
> 当前模型：ESS1 为唯一构网主机；PV1、PV2、ESS2、EV1、EV2 为五台跟网从机  
> 依据：最新 V2 模型、V1/V2 正式运行数据、V4.0/V4.1 交接、N1/N2/N3 编译态只读审计  
> 本文用途：冻结下一次正式改模前的系统架构、职责、接口、在线实验方式、数据记录和验证边界。

---

# 0. 最终判断

## 0.1 现在不是继续给旧模型调一个参数

当前已经锁定的根本问题是：

```text
五台跟网设备仍沿用强电网条件下的高刚度功率跟踪和端口前馈方式
+
离岛后只有 ESS1 提供有限带宽、有限输出阻抗和有限调制能力的构网电压
+
五台缺少按设备类型设计的有功—频率响应、欠压功率退让和完整限流反馈
+
原公共连接点功率协调在 J1 打开后失去正确控制对象
```

因此下一版需要改的是完整控制结构，不只是 `Kslow`（慢电压前馈比例）。

## 0.2 当前方案不能宣称“绝对无缺陷”

复杂闭环在正式实现和运行前，不能诚实保证不存在任何隐藏错误。

现在可以保证的是：

1. 已知结构缺陷都被逐项纳入修复合同；
2. 已纠正此前方案中三个可能产生新问题的地方：
   - 不把 ESS1 的 `Vout`（下垂后的电压指令）直接复制给五台；
   - 不使用两个独立积分器同时追踪频率和 ESS1 有功；
   - 不以牺牲在线改参能力为代价建立统一状态机；
3. 每个主要控制作用都有原始请求、实际施加和物理响应记录；
4. 下一次运行若失败，可以按发生阶段限定到具体闭环，不会重新从全部模型开始盲排。

这是一套面向当前已锁定根因的完整架构级修复方案，不是数学上未经验证就声称完美的方案。

# 1. 统一状态机不会削弱在线改参能力

当前五台各自通过一个 `AA15_ENG_STAGE`（本机工程阶段常数）由上位机分别写入。问题不是“能不能在线写”，而是五个值可能因上位机异步写入而短暂不一致。

下一版采用：

```text
模型内部唯一有效系统阶段
+
上位机高层请求
+
统一人工覆盖接口
+
各功能独立在线开关
+
所有增益和限制继续在线可调
```

## 1.1 三种阶段控制方式

新增：

- `CFG_STAGE_CONTROL_MODE`（阶段控制方式）
  - 0：自动状态机；
  - 1：保持当前阶段；
  - 2：统一人工阶段。
- `CFG_STAGE_MANUAL_VALUE`（统一人工阶段值）。
- `REQ_PLANNED_ISLAND`（计划离岛请求）。
- `REQ_RESYNC`（重同步请求）。
- `REQ_ABORT`（取消或安全退出请求）。

人工阶段不是分别写五台，而是一次写入一个全局值，再由模型同一计算步同时送到五台。

## 1.2 仍然保留的在线实验能力

所有关键功能保留统一在线开关：

```text
快速有功—频率响应
本地电压支撑
岛态慢速功率协调
慢电压前馈
限流反馈
坐标保持
```

所有关键增益、死区、滤波频率、功率上下限、电流限制和斜率继续使用可在线写入的常数，并由运行脚本统一写入和回读。

所以改造后：

```text
在线改参能力更强
阶段一致性更可靠
```

而不是更不方便。

# 2. ESS1 的频率、电压和相角不能混为一个“参考”

## 2.1 `Fout`：可以作为五台的公共频率反馈，但不能裸接

模型位置：

```text
K26_V5/SS_Slave2/ESS1_Control/Droop Control/Fout
```

中文含义：

> ESS1 构网振荡器实际采用的频率，是孤岛中的权威频率。

正确使用方式：

```text
ESS1 Fout
→ 现有 ESS 返回向量
→ SM_Master 中央参考路由
→ 有效性判断与一拍确定性延迟
→ 复用每台现有 Fref 通道
→ 在五台新管理模块中作为有功—频率响应输入
```

不能只把 `Fout` 写入现有 `Fref` 后就认为已经生效。当前五台的 `Fref` 只连接到各自 `Droop Control`（下垂模块）；五台在跟网状态时该支路不是有功控制主链。最终补丁必须把同一 `Fref` 信号明确分支到新的五台管理模块。

## 2.2 `Vout`：不直接作为五台本地电压目标

模型位置：

```text
K26_V5/SS_Slave2/ESS1_Control/Droop Control/Vout
```

`Vout` 不是单纯的额定电压设定值。当前 ESS1 中：

```text
基础电压参考
+
ESS1 无功下垂反馈
→ Vout
```

如果五台又共同追踪 `Vout`，会把 ESS1 无功反馈再次送入五台支撑通道，可能形成重复无功闭环。

最终采用两个量：

- `Vbase`（公共电压基础目标）：来自 ESS1 的有效电压参考截距，即 F24 输出的 `v_eff`，单位为伏特；
- `Vout`（ESS1 下垂后的内部电压指令）：只用于监测、合同核对和 ESS1 内部分析。

五台本地电压目标为：

```text
本机切岛前电压
+
公共电压基础目标相对切岛时基础目标的变化量
```

这样既能让 ESS1 改变全局电压目标，又保留各台因线路、变压器和滤波器形成的正常电压差。

当前五台的 `Vref` 也只进入各自旧下垂模块，最终补丁必须明确把 `Vref` 分支到新管理模块，并在模块中从伏特换算为标幺值。

## 2.3 `theta_out`：第一版不直接数字广播

模型位置：

```text
K26_V5/SS_Slave2/ESS1_Control/Droop Control/theta_out
```

五台第一版继续通过本机锁相环跟随 ESS1 建立的物理母线相角。

原因：

1. 五台正常坐标为 `Vd≈1 pu、Vq≈0`；
2. ESS1 构网电压环历史上采用 `Vd≈0、Vq≈1 pu`；
3. ESS1 内部还有 −120° 同步补偿和 −30° PWM 相位补偿；
4. ESS1 的 `theta_out` 不是最终 PWM 执行相位链的全部；
5. 五台测量坐标、功率计算和 PWM 执行相角必须同时切换；
6. 本机锁相动态已被历史因果试验排除为原快速失稳的必要根因。

公共数字相角不是永久排除，而是第二级增强方案。只有最终一次控制稳定性计算通过、运行仍明确指向本机锁相限制时，才增加 `sin(theta)`（相角正弦）、`cos(theta)`（相角余弦）和有效标志，并统一切换所有消费者。

# 3. 唯一参考权威

下一版在：

```text
K26_V5/SM_Master/AA15_LOCAL_CONTROL_STACK
```

增加一个统一参考路由模块。

其职责不是再增加一套控制器，而是保证同一时刻每个参考只有一个合法来源。

## 3.1 ESS1 频率基础参考来源

```text
正常并网：
原上层参考

ESS1构网准备：
F24无扰对齐输出

稳定孤岛：
岛态基础频率参考

重同步：
岛态基础参考 + S15同步修正

J1合闸保持：
冻结合闸前最后有效值

并网恢复：
从当前值平滑返回原并网参考
```

## 3.2 ESS1 电压基础参考来源

与频率参考采用相同的单一权威路由：

```text
正常并网参考
→ F24对齐
→ 孤岛基础电压
→ 必要的慢速电压恢复修正
→ 合闸保持
→ 并网恢复
```

禁止 F24、岛态协调和 S15 同时直接写同一个 ESS1 参考。

# 4. 六台设备的最终职责

## 4.1 ESS1：唯一构网主机

ESS1 负责：

```text
形成母线电压波形
形成频率和相角
承担 J1 打开瞬间的剩余有功和无功
提供 Fout 和公共电压基础目标
在重同步时接受小幅频率修正
```

第一版保持已经验证的：

```text
F21
F24
F25
当前构网电压环
当前构网电流环
当前下垂主结构
```

新增：

```text
构网参考单一权威路由
构网参考有效标志
瞬时/长期功率储备监测
构网回跟网的反向无扰交接
```

## 4.2 ESS2：主要双向有功支撑资源

欠频时：

```text
增加放电或减少充电
```

过频时：

```text
减少放电或增加充电
```

ESS2 优先承担快速双向有功响应和岛态慢速功率转移，但必须受：

```text
SOC
功率上下限
电流能力
功率变化速度
```

约束。

## 4.3 EV1、EV2：可调充电负荷

当前只按：

```text
-1 pu：最大充电
0：停止充电
```

设计，不假定支持车辆反向放电。

欠频或欠压时：

```text
充电功率向0移动
→ 直接减轻孤岛负荷
```

过频或功率过剩时：

```text
在允许范围内增加充电
```

EV 的负荷削减必须在有功命令层完成，不能等到最终电流限幅器被动削减。

## 4.4 PV1、PV2：可限发的跟网发电资源

过频或功率过剩时：

```text
削减光伏有功
```

欠频时：

```text
只有当前可用最大功率高于现有工作点时才允许增加
```

如果可用最大功率没有有效数据，默认向上调节余量为0。

欠压或总电流不足时：

```text
允许削减有功
→ 释放无功/电压支撑电流能力
```

# 5. 当前 V2 必须重写的五台本地管理模块

保留模块位置：

```text
各设备 Power Control Loop（功率控制环）
与
Current Regulator（电流调节环）
之间
```

重写：

```text
AA15_ISLAND_GFL_SUPPORT_MANAGER
（五台跟网设备孤岛管理模块）
```

## 5.1 新输入

每台新管理模块至少接收：

1. 本机端口 d/q 电压；
2. 原功率控制产生的 d/q 电流参考；
3. 本机实测有功；
4. 本机实测无功；
5. 中央有功基准/慢速调度；
6. 中央无功基准；
7. 本机实测 d/q 电流；
8. 统一系统阶段；
9. ESS1 构网频率；
10. 公共电压基础目标；
11. 主机参考有效标志；
12. 本机有功下限；
13. 本机有功上限；
14. 本机能力数据有效标志。

## 5.2 新控制顺序

```text
捕获切岛前本机工作点
↓
按设备角色计算快速有功—频率响应
↓
叠加岛态慢速有功修正
↓
按电压和能力限制形成可实现的有功命令
↓
原功率控制器产生基础电流参考
↓
叠加本地电压支撑电流
↓
按设备角色分配总电流能力
↓
形成最终电流参考
↓
把实际执行比例反馈给上层功率控制器
```

## 5.3 电压前馈

继续保留“两频带电压前馈”结构：

```text
切岛前电压工作点
+
慢速端口电压变化的一部分
+
快速端口电压变化的一部分
```

第一版可冻结：

```text
快速端口电压变化的直接前馈比例 = 0
```

慢速前馈比例和快慢分界频率必须结合完整控制器计算，不能再通过 RT-LAB 连续试 0.4、0.5、0.6。

## 5.4 欠压功率退让

下一版必须显式加入：

```text
母线电压下降
→ EV减少充电
→ PV必要时削减发电
→ ESS2有功命令按总电流能力约束
```

作用是打破“电压越低仍要求维持同样功率”的近恒功率行为，而不是只靠无功电流支撑。

# 6. 一次有功响应和慢速协调不能重复控制

## 6.1 一次有功响应

五台根据 ESS1 的 `Fout` 快速改变净有功：

```text
频率偏差
→ 比例型响应
→ 有死区、滤波、斜率和能力限制
```

它负责 J1 打开后的首轮功率平衡。

## 6.2 慢速协调

中央协调器只使用一个主要积分目标：

```text
把 ESS1 的 Fout 缓慢恢复到50 Hz
```

然后按五台上调/下调余量分配。

不能同时再设置一个独立的 ESS1 有功积分器，因为 ESS1 当前下垂已经把有功和频率耦合。两个积分器会重复争夺同一物理量。

## 6.3 ESS1 长期有功偏置

希望 ESS1 长期保持多少有功，不再由第二个积分器强追，而是通过下垂基础频率参考的代数关系设定。

当前下垂参数下：

```text
ESS1有功偏置确定
→ 对应一个基础频率参考
→ 慢速频率恢复到50 Hz时
→ ESS1自然回到该有功偏置附近
```

具体数值由下一步参数模型计算，不需要用户手工推导。

# 7. 总电流限制与上层防积分饱和

## 7.1 不是所有设备都固定“无功绝对优先”

最终采用按资源角色和当前工况变化的优先级：

- ESS2 欠频时保留必要有功支撑，同时保留最低电压支撑；
- EV 优先在命令层减少充电；
- PV 可以削减有功释放无功支撑能力；
- 最终矢量限流只作为最后安全边界。

## 7.2 下游执行比例回到上层

最终限流器输出：

```text
gP：有功请求实际执行比例
gQ：无功请求实际执行比例
```

经过一个计算步延迟后，原功率控制器追踪：

```text
当前实测功率
+
可实际执行比例 × 功率误差
```

这样下游只能执行70%时，上层不会继续按100%误差积分。

# 8. 计划离岛前必须增加可行性判定

计划离岛不是收到请求就直接打开 J1。

J1 打开前同时检查：

1. J1 当前闭合；
2. 上级电网电压、频率有效；
3. PCC 有功和无功在允许范围；
4. ESS1 已完成构网切换准备；
5. F24、F25 已准备；
6. 五台已捕获工作点并进入孤岛参数；
7. ESS1 电流和调制度有足够储备；
8. 五台能力上下限有效；
9. 五台合计上调、下调余量可以覆盖预计误差；
10. 构网频率和公共电压基础目标有效；
11. 统一系统阶段在三组实时任务中一致。

任一关键条件失败：

```text
不打开J1
保持并网
输出明确失败原因码
```

J1 已打开后若出现能力不足：

```text
优先减少EV充电
ESS2进入受限支撑
PV按功率过剩/欠压规则削减
仍无法维持时进入安全降载或受控停运状态
```

# 9. 统一状态机

最终建议状态：

| 状态 | 中文含义 |
|---:|---|
| 0 | 正常并网 |
| 1 | 计划离岛功率预平衡 |
| 2 | ESS1构网与五台孤岛参数准备 |
| 3 | J1开断边沿已武装 |
| 4 | 孤岛一次控制 |
| 5 | 孤岛一次控制与慢速协调共同运行 |
| 6 | 重同步跟踪 |
| 7 | J1合闸后ESS1继续构网保持 |
| 8 | 并网控制恢复 |
| 9 | 取消、能力不足或故障安全状态 |

状态机在模型内部运行；上位机只发送请求和在线参数。

# 10. 重同步现在纳入架构，但单独验收

计划离岛成功不是重同步自然成功。

现有 S15 重同步模块需要补：

1. 两侧电压采用同类滤波和正序相位；
2. 有意义的电压有效门限；
3. 电压、频率、相角差持续满足；
4. J1 合闸后 ESS1 继续构网；
5. 岛态一次控制和慢速协调平滑退出；
6. 原并网功率控制从当前工作点接入；
7. PCC 功率协调逐步恢复；
8. ESS1 构网回跟网的反向无扰交接。

第一轮验收只做：

```text
并网 → 计划离岛 → 稳定孤岛 → 岛态慢速协调
```

第二轮在同一最终模型中做：

```text
稳定孤岛 → 重同步 → J1合闸 → 恢复并网
```

最后再做完整端到端运行。

# 11. 通信接口冻结方向

## 11.1 ESS1 到中央任务

继续使用现有 30 维返回向量，不扩宽。

重新规划现有诊断尾部，至少送出：

```text
Fout
Vout
f_eff
v_eff
ESS1有功
ESS1无功
主机参考有效标志
```

## 11.2 中央任务到三组设备

每台原有 12 维输入继续保留。

状态相关复用：

```text
Fref：
并网时为原参考；
孤岛时为 ESS1 Fout。

Vref：
并网时为原参考；
孤岛时为公共电压基础目标，单位伏特。

Pref：
并网时为原功率命令；
孤岛时为本机切岛基准 + 慢速协调修正。

Qref：
并网时为原无功命令；
孤岛时为本机无功基准/慢速无功修正。
```

每组增加8个原子化合同量：


# 13. 参数计算不是“只靠调参数解决”

最终模型要新增和重写大量结构：

```text
统一状态机
参考权威路由
设备差异化有功响应
欠压功率退让
本地电压支撑
按角色分配的总电流限制
限流反馈
岛态慢速协调
计划离岛可行性判定
反向构网—跟网交接
重同步有效性
诊断与通信
```

建立小信号和输出特性模型的作用只是：

> 在结构已经正确的前提下，计算这些新增环节的增益和速度范围，避免再用 RT-LAB 盲扫。

计算要回答：

```text
扰动进入后会衰减还是放大
慢电压前馈保留多少
电压支撑应多快、多强
ESS2和EV的频率响应应多强
慢速协调应比一次控制慢多少
数字任务延迟是否影响稳定性
```

用户不需要手工理解推导；最终交付会把计算结果转换成可直接写入模型的参数和允许范围。
