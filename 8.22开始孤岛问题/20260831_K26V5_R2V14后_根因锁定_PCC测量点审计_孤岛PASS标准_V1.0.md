# 1. PCC测量点是否测错？

没有。

当前冻结物理拓扑是：

```text
2PV + 2ESS + 2EV
        │
        │ 微电网公共网络
        ▼
Three-Phase V-I Measurement3
【PCC微网侧原始V/I】

        │
        ├─ J1_Load1

```

也就是说：

> `Three-Phase V-I Measurement3` 位于 J1 的微电网侧。

模型中还有另一套独立的：

```text
J2_Grid_VI
→ J2_Grid_Measurements
```

专门测上级电网侧。

所以 PCC 与 Grid 两侧没有混淆。

# 3. 一个必须修正的名字：Vab_rms_true_V并不是真正“宽带True RMS”

模型内部实际链路是：

```text
PCC raw Vabc
→ Va - Vb
→ Fundamental (PLL-Driven)
→ 幅值
→ 1/sqrt(2)
→ Vab_rms_pcc
```

所以 Host 变量虽然叫：

```text
Vab_rms_true_V
```

物理上更准确的名字应该是：

```text
PCC fundamental Vab RMS
```

它表示：

> PCC线电压基波RMS。

它不是把全部谐波、畸变都平方积分以后得到的宽带 true RMS。

这不影响本轮“孤岛失败”结论，因为它已经出现：

```text
0.329 pu ~ 1.495 pu
```

级别的巨大基波幅值变化。

但正式动态诊断仍应该同时看 Group29 中的：

```text
PCC raw Va/Vb/Vc
```

防止只用PLL加工后的幅值判断高频/谐波问题。

# 4. Freq_Hz是什么

链路：

```text
PCC raw Vabc
→ 归一化
→ PLL (3ph)
→ 45~55 Hz Saturation
→ Freq_pcc
```

所以：

> 它也是 PCC 微网侧的PLL频率估计。

当 PCC 电压健康时，这个频率量是正确的系统边界频率指标。

当电压已经跌到3~6 kV并严重畸变时：

> PLL频率本身的可信度会下降。

因此深度失稳期间不能只依赖 `Freq_pcc` 判断物理频率，需要一起看：

- raw PCC Vabc；
- ESS1 Droop Fout；
- theta / dtheta；
- 必要时正序相角轨迹。

但是本轮仅靠电压就已经足够判 FAIL。

# 5. J1打开以后为什么Ppcc/Qpcc接近0不能说明孤岛正常


以后 PCC V-I Measurement 的串联电流接近0。


> 断路器确实切断了与上级电网的功率交换。

它不是：

> “孤岛内部功率已经平衡”的证明。

J1后真正要看：

```text

ESS1 P/Q
五台GFL P/Q
六台电流
Voltage PI
Current PI
Iref
ModIndex
Vpwm

```

# 8. F25 timeout是根因还是后果？

当前最严谨表述：

> **主要是系统不准稳的结果，但它在100ms以后可能继续放大/改变后续轨迹。**

为什么首先判断它是结果？

因为timeout之前已经出现：

```text
post mean持续移动
post drift显著
raw IOUT不准稳
```

系统已经没有向新的稳态收敛。

但是：

```text
100ms后F25冻结一个0.47pu的最后FAST值
```

之后如果系统仍不断变化，这个固定hold可能成为后续额外失配。

所以不能写成：

```text
F25完全无关
```

正确写法是：

```text
原“责任没有交接”问题：
已解决。

六机剩余动态：
在F25正常FAST期间已经出现。

F25 timeout/fallback：
可能成为第二阶段放大因素，
但不是目前最早、最基础的故障解释。
```

# 9. 为什么现在高度指向“五GFL聚合动态”

最强的正交对照：

```text
R1：
五台active GFL物理隔离
+
F25
→ 计划带电切岛稳定

R2：
五台active GFL全部物理在线
+
同一F25
→ 六机孤岛失稳
```

因此真正新增的系统层是：

```text
五台GFL及其LC/PLL/Current Loop/PQ控制
```

而历史上还做过：

```text
五台GFL仍物理在线
但P/Q scale≈0
```

J1后仍失稳。

因此又排除了：

```text
只是五台设备有功功率太大
ESS1容量不够
直接满功率失衡
```

这使剩余根因更像：

> **GFL即使基波P/Q接近0，物理连接以后仍表现为动态导纳；它们与唯一ESS1 GFM输出阻抗发生动态耦合。**

# 16. 能不能彻底解决

从现有证据看：

> **可以继续收敛，而且问题已经从“整个控制系统哪里都可能错”缩小成了一个明确的多变流器动态稳定层。**

理由：

```text
Gate A：
ESS1能自主成岛

R1：
ESS1能从强网带电切到孤岛并稳定

R2：
六机J1前全部协调链都正常
只有五GFL全部参与后的孤岛动态不稳定
```

因此不是：

```text
架构从根上不可用
```

而是：

```text
唯一GFM的输出阻抗
与五台GFL聚合导纳
在孤岛弱网条件下缺少足够稳定裕度
```

这个问题可以通过：

- 定位主要负阻尼环节；
- 降低/重塑GFL动态参与；
- 调整PLL/Current Loop带宽或虚拟阻抗；
- 提高GFM输出阻抗整形/电压环阻尼；
- 必要时增加多GFM协同；

中的一种或组合解决。

但现在还不应该直接调PLL或增加第二GFM，因为精确负阻尼来源还没有完成最后一层分解。
