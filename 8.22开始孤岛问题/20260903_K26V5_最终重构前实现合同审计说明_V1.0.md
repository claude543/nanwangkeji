# K26_V5 最终重构前最后一轮实现合同审计

这不是重新排查根因，而是正式大改前的“防返工合同审计”。

重点只做三件事：

1. 把相角/频率执行坐标链彻底确认；
2. 把资源能力和参考信号真实消费者确认；
3. 把正式补丁必须满足的编译后断言提前列死。

## 第一版推荐相角架构

推荐：

```text
健康电压：
五台使用本机PLL执行角

低压或本机PLL无效：
捕获本机最后有效执行角
+
使用经中央校验、统一延迟后的ESS1 Fout推进相角

电压恢复：
无扰重新捕获本机PLL
```

也就是：

```text
本机PLL + ESS1公共频率辅助的相干自由运行
```

而不是第一版直接广播 ESS1 绝对相角。

原因不是ESS1相角不能审计，而是五台各自的本地端口相位、滤波器/变压器/线路压降和现有控制坐标约定客观存在。直接统一绝对角会改变五台现有 `Vd≈1, Vq≈0` 的控制合同，并要求重新解释所有功率和电流方程。

如果以后实测证明本机PLL仍是明确限制，再启用第二级公共数字相角：
`ESS1 wts -> sin/cos -> SM_Master -> 五台 -> 所有坐标消费者统一切换`。
