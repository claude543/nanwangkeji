# 3. 当前五台 GFL 的确切关键方程

五台结构相同，角色参数不同。

## 3.1 Power Control

### P 轴

误差：

\[
e_P=P_{\rm ref,eff}-P_{\rm meas}
\]

PI：

```text
KpP = 0.06
KiP = 2
Ts  = 100 us
internal saturation = ±1 pu
anti-windup = existing block internal logic
```

### Q 轴

模型实际 Sum 为：

\[
e_Q=Q_{\rm meas}-Q_{\rm ref,eff}
\]

PI 参数同 P 轴：

```text
KpQ = 0.06
KiQ = 2
```

由实际结构与运行方向：

```text
P 增大 → Id 正向增大
Q 增大 → Iq 更负
```

因此在电压 d 轴基本对齐时：

\[
P \sim +I_d,\qquad Q \sim -I_q
\]

Power PI 的零点量级：

\[
\omega_z=\frac{K_i}{K_p}\approx 33.33\ {\rm rad/s}
\]

即约：

\[
f_z\approx 5.3\ {\rm Hz}
\]

所以原 P/Q 外环并不是相对 10 Hz 模态“完全不动”，它会参与端口动态。

# 5. G08 冻结：显式主动阻尼的 dq 方向

## 5.1 不采用另一个 Voltage PI

不新增：

```text
ΔIq = K(Vref - V)
```

作为“主动阻尼”。

因为当前已经有 1 Hz q 支撑，再叠一个相同类型环容易重复控制。

---

## 5.2 采用 band-limited virtual conductance

定义局部电压的中频分量：

\[
\mathbf v_{bp}
=
\begin{bmatrix}
v_{bp,d}\\
v_{bp,q}
\end{bmatrix}
\]

新增稳定电流：

\[
\boxed{
\mathbf i_{damp}
=
-G_d\mathbf v_{bp}
}
\]

第一版：

\[
\boxed{G_d=1.0}
\]

两轴同增益。

### 为什么负号是正确的

当前 GFL 采用“向 AC 母线注入为正”的电流语义。

电压扰动上升：

```text
ΔVd > 0
→ ΔId_damp < 0
→ 减少向母线注入
```

电压扰动下降：

```text
ΔVd < 0
→ ΔId_damp > 0
→ 增加向母线注入
```

扰动小信号功率：

\[
\Delta p_{damp}
\propto
\Delta\mathbf v^T\Delta\mathbf i_{damp}
=
-G_d\Delta\mathbf v^T\mathbf H_{bp}\Delta\mathbf v
\]

只要目标频带内：

\[
\Re\{H_{bp}\}>0
\]

就表现为**耗散性虚拟电导**，而不是负阻尼。

## 6.2 因果离散实现

每个 dq 轴各使用两个显式 Unit Delay 状态。

低频状态：

\[
v_{5,n}
=
v_{5,z}
+
\alpha_5(v-v_{5,z})
\]

其中：

\[
\alpha_5
=
1-e^{-2\pi 5T_s}
\approx 0.003136663
\]

高通中间量：

\[
u_{hp}=v-v_{5,z}
\]

20 Hz 低通 band-pass 状态：

\[
v_{bp,n}
=
v_{bp,z}
+
\alpha_{20}(u_{hp}-v_{bp,z})
\]

其中：

\[
\alpha_{20}
=
1-e^{-2\pi20T_s}
\approx0.012487743
\]

**当前周期的 damping output 使用 `vbp_z`，而不是 `vbp_n`：**

\[
i_{damp}=-G_d v_{bp,z}
\]

因此：

```text
Raw Vdq
→ filter state next
→ Unit Delay
→ damping current
```

没有新增：

```text
Raw Vdq → same-sample Iref
```

的直接通道。

这点非常重要：

> **不会把我们已经处理掉的“direct terminal-V fast feedforward”重新引回来，也不会形成新的同采样代数环。**

# 9. G10 冻结：P/Q 外环不能抵消 stabilizing current

## 9.1 不采用旧“固定 PQGate=0/0.5”方案

历史已经证明：

```text
固定冻结/固定比例降低 P/Q
```

本身不能解决根问题。

本次 P/Q release 的作用不是“稳定器本体”，而是：

> **当 explicit support current 正在工作时，防止原 P/Q PI 把这条支撑电流重新抵消。**

---

## 9.2 用实际 support current 的平滑 envelope 作为 release 指标

新增实际总支撑电流上一拍状态：

\[
\mathbf i_{sup,z}
=
\begin{bmatrix}
i_{sup,d,z}\\
i_{sup,q,z}
\end{bmatrix}
\]

定义：

\[
a_{raw}
=
\min\left(
1,
\frac{\|\mathbf i_{sup,z}\|}{I_{release,full}}
\right)
\]

冻结：

```text
I_RELEASE_FULL = 0.05 pu
release envelope fc = 2 Hz
```

\[
a_n=a_z+\alpha_R(a_{raw}-a_z)
\]

\[
\alpha_R
=
1-e^{-2\pi2T_s}
\approx0.001255848
\]

使用**延迟的 envelope `a_z`**：

\[
\gamma_P
=
1-(1-\gamma_{P,min})a_z
\]

\[
\gamma_Q
=
1-(1-\gamma_{Q,min})a_z
\]

冻结：

```text
gammaP_min = 0.70
gammaQ_min = 0.20
```

即：

\[
\gamma_P=1-0.30a_z
\]

\[
\gamma_Q=1-0.80a_z
\]

### 为什么 P 不完全释放

Primary P-f 和微网有功平衡仍然需要五台参与，所以 P 最低仍保留 70% error tracking。

### 为什么 Q 释放更强

当前 local voltage support 和 damping q current 最直接与：

```text
Qref ≈ 0
```

发生冲突。

如果 Q PI 仍 100% 追 Qref，它会主动抵消为了稳定母线而施加的 q current。

# 10. G11 冻结：单一 support-current 合成与严格矢量限流

## 10.1 现有 IsupMax 重新定义

不增加第二套资源上限。

原：

```text
PV  IsupMax = 0.20
ESS2         = 0.30
EV           = 0.15
```

正式解释为：

> **每台设备所有非 P/Q 稳定支撑电流的总预算。**

即共享：

```text
active damping
+
slow q voltage support
```

---

## 10.2 支撑优先级

全设备第一优先级：

```text
1. Active damping
```

因为它负责 Primary 稳定。

普通 PV / EV：

```text
1. active damping
2. slow q voltage support
3. base P/Q current
```

ESS2 under-frequency：

```text
1. active damping
2. base P/Q current / P-f任务
3. slow q voltage support
```

即：

> **保留原 ESS2 频率支撑意图，但绝不允许频率优先把 active damping 挤掉。**

---

## 10.3 damping vector 先限于 IsupMax

请求：

\[
\mathbf d_{req}
=
\begin{bmatrix}
i_{damp,d}\\i_{damp,q}
\end{bmatrix}
\]

若：

\[
\|\mathbf d_{req}\|>I_{sup,max}
\]

径向缩放到：

\[
\|\mathbf d\|=I_{sup,max}
\]

因为 damping 无积分器，不存在 wind-up。

---

## 10.4 slow q support 只使用 damping 后剩余的 support budget

已知 `d_d`：

\[
q_{sup,cap}
=
\sqrt{
\max(I_{sup,max}^2-d_d^2,0)
}
\]

\[
s_q
=
{\rm clamp}
(d_q+i_{slow,q},-q_{sup,cap},q_{sup,cap})
\]

得到：

\[
\mathbf s=
[d_d,s_q]
\]

因此：

\[
\|\mathbf s\|\le I_{sup,max}
\]

---

## 10.5 base P/Q current 使用严格二次方程，不再用近似“剩余模长”

设：

\[
\mathbf b=
[i_{PQ,d},i_{PQ,q}]
\]

最后：

\[
\mathbf i_{final}
=
\mathbf s+\lambda \mathbf b
\]

要求：

\[
\|\mathbf i_{final}\|\le I_{max}
\]

定义：

\[
a=\mathbf b^T\mathbf b
\]

\[
c=\mathbf s^T\mathbf s-I_{max}^2
\]

\[
m=\mathbf s^T\mathbf b
\]

若 `a` 足够小：

```text
lambda = 1
```

否则最大可行：

\[
\lambda_{cap}
=
\frac{
-m+\sqrt{
m^2+a(I_{max}^2-\|\mathbf s\|^2)
}
}{a}
\]

最后：

\[
\lambda
=
{\rm clamp}(\lambda_{cap},0,1)
\]

这比当前 V3.4：

```text
remaining = sqrt(Imax^2 - support_q^2)
raw vector × remaining/raw_mag
然后再 + support_q
```

严格，因为旧写法没有显式处理：

\[
2\mathbf s^T(\lambda\mathbf b)
\]

交叉项。

历史 V2 曾经对 scalar q support 使用过同类二次方程；本版只是把它严格推广到二维 support vector。

# 11. ESS2 under-frequency 的严格优先算法

当：

```text
role == ESS2
master_f < 49.98 Hz
PrefCmd > Pmeas + 0.002
```

执行：

### 第一步：damping 绝不让位

先计算并 clip：

\[
\mathbf d
\]

### 第二步：判断 `base + damping` 能否直接放入 Imax

如果：

\[
\|\mathbf b+\mathbf d\|\le I_{max}
\]

则：

```text
lambda = 1
```

保证 P/Q base 不被慢 q 支撑抢占。

### 第三步：slow q 只在两个约束交集内加入

同时满足：

```text
support-vector budget IsupMax
final-current circle Imax
```

求 slow q 的允许上下界，取距离请求最近的可实现值。

如果：

\[
\|\mathbf b+\mathbf d\|>I_{max}
\]

则：

```text
slow q support = 0
```

再对：

```text
damping + lambda * base
```

使用严格二次方程。

因此顺序明确：

```text
稳定阻尼
>
ESS2 under-frequency base P任务
>
slow voltage support
```

# 12. slow q support 的 downstream anti-windup

当前 q support state 自己只知道：

```text
自己的 IsupMax clip
```

不知道最终 limiter 是否因 damping/base current 又把它截掉。

新 limiter 增加内部输出：

```text
SlowQActual
SlowQClipActive
```

下一拍 state core：

```text
if SlowQClipActive_z:
    slowQ_state_base = SlowQActual_z
else:
    slowQ_state_base = old slowQ state
```

然后才继续朝：

```text
-kmag * filtered voltage error
```

slew。

作用：

# 13. Current Regulator / Power PI 的处理原则

第一版明确：

```text
不改 Power PI Kp/Ki
不改 Current PI Kp/Ki
不改 Rff/Lff
不改 final voltage saturation
```

原因：

1. 这两套原控制在强网运行健康；
2. 当前根因已经锁到孤岛端口整体，而不是单 PI 参数；
3. 显式 damping bypass Power Control，正是为了避免再靠 PI 扫描塑造端口；
4. 同时改 PI 会破坏因果可解释性。
