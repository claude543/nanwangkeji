# 0. 最终结论

## 根因已经可以封板

最终根因不是：

```text
PLL
P/Q外环
F25
单独d轴
单独q轴
某一个14～17Hz固定频率
```

而是：

> **五台 GFL（跟网型变流器）Current Regulator（电流调节器）中，对 terminal Vdq（端口dq电压）采用近 unity（单位增益）的动态直接前馈这一控制架构，在 J1 打开后仍继续工作。强网下它是合理的电流环解耦；孤岛后 terminal Vdq 已成为由 ESS1 GFM（构网型变流器）、五台 GFL 与网络共同决定的内部状态，无条件的动态直接前馈会显著削弱 GFL 对母线电压扰动的自然输出导纳/阻尼，使五台 GFL 过度“理想电流源化”，并与 ESS1 的有限输出阻抗及网络形成非无源/低阻尼闭环。**

D、Q 两轴都具有独立致失稳能力。

因此最终工程修复必须：

> **对完整 dq-vector terminal-voltage feedforward 做对称的弱网/孤岛动态整形，而不是只修 d、只修 q，或只对 14～17 Hz 做窄带 notch。**

# 9. 最终根因的控制方程解释

简化 GFL plant（对象）：

```text
(Ls + R) Δi
=
ΔVconv
-
ΔVterminal
```

Current Regulator 近似：

```text
ΔVconv
=
C_i(s)(ΔIref - Δi)
+
F_vff(s) ΔVterminal
+
其它解耦项
```

于是 terminal voltage 对输出电流的动态关系包含：

```text
[F_vff(s) - 1] ΔVterminal
```

如果：

```text
F_vff(s) ≈ 1
```

GFL 对 terminal-voltage perturbation（端口电压扰动）的自然响应被接近抵消：

```text
Yout_gfl ≈ 很小
```

GFL 越像理想电流源。

强网下这是正常的。

但是 J1 打开后：

```text
Vterminal
```

不再是独立外部量，而是系统内部状态。

此时：

```text
Vterminal
→ direct Vdq feedforward
→ Vconv
→ converter current
→ network voltage
→ Vterminal
```

构成系统级反馈。

五台并联后：

```text
5 × Ygfl
```

与：

```text
ESS1 GFM Zout
+
network
```

发生耦合。

测量滤波、数字采样、PWM、Current PI 和网络都会影响 F_vff(s) 的幅相，因此实际并不是理想数学上的“完全瞬时抵消”。

结果就是非无源/低阻尼聚合输出导纳。

# 11. 为什么不能永久 HOLD D/Q

C1 的 full DQ hard HOLD：

```text
快速失稳显著消失
```

但出现慢频率/相角滑移。

原因是永久 HOLD 同时破坏了：

```text
DC/慢速工作点适应
```

Current PI 被迫长期补偿 raw-applied mismatch。

因此最终方案必须满足两个要求：

```text
危险动态：
direct feedforward 不再接近 unity

DC / 慢变化：
feedforward 仍能跟随
```

# 12. 最优先的最终解决方向

## 方向A：dq向量对称的 slow/fast split feedforward

建议把两轴使用**完全相同的动态传递函数**：

```text
Vslow_dq = SlowTracker(Vraw_dq)

Vff_applied
=
Vslow_dq
+
Kfast · (Vraw_dq - Vslow_dq)
```

### strong-grid

```text
Kfast = 1
```

得到：

```text
Vff_applied = Vraw
```

保持当前并网性能。

### island / weak-grid

第一轮工程验证：

```text
Kfast = 0
```

得到：

```text
Vff_applied = Vslow
```

即：

- DC/慢变化仍会跟踪；
- 10～17Hz 等快速危险动态被强烈削弱；
- 不再是永久 HOLD；
- d/q 两轴保持旋转对称，不制造新的轴向不平衡。

这是当前证据下**最小、最直接、最可解释**的工程修改方向。

> **K26_V5 完整六机计划切岛失稳的根本原因已经通过 B1/C1/C2/C1-Q/Mode6 主动因果实验锁定到五台 GFL Current Regulator 的 terminal-Vdq dynamic direct-feedforward 架构。D/Q 2×2 因果真值表表明：D、Q 动态前馈同时存在时出现约17Hz正增长；仅保留D时转为d轴电压幅值塌陷；仅保留Q时出现约10.62Hz、σ≈+69s⁻¹的新q轴正增长；只有两轴危险动态都被切断时快速失稳被打断。因此问题不是某个单轴或固定频率，而是孤岛/弱网条件下近unity terminal-voltage feedforward使五台GFL聚合输出导纳过度电流源化，并与ESS1 GFM有限输出阻抗和网络形成低阻尼/非无源耦合。最终解决方向应停止轴向排查和窄带追频，改为对d/q两轴采用相同的、模式相关的动态前馈整形：强网保持原unity feedforward，孤岛/弱网保留DC/慢速跟踪但显著削弱快速terminal-voltage feedforward，并在需要时配合virtual impedance/active damping进行输出导纳塑形。**
