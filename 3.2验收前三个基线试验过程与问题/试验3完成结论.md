# 一、试验3的最终定量结果

## 1. PCC跟踪性能

稳定区间统计为：

| 指标     |        数值 |
| ------ | --------: |
| PCC目标  | −40.00 kW |
| PCC均值  | −39.66 kW |
| PCC中位数 | −39.55 kW |
| 最大值    | −26.08 kW |
| 最小值    | −56.74 kW |
| 峰峰值    |  30.66 kW |
| RMS    |  39.82 kW |

稳态平均误差为：

```
e_ss = −40 − (−39.66) = −0.34 kW
```

误差绝对值仅约：

```
0.34 kW
```

说明：

> **从平均功率角度看，PCC闭环跟踪精度较高。**

按照均值与RMS估算，PCC稳定区间的标准差约为：

```
σ_P = sqrt(39.82² − 39.66²) ≈ 3.57 kW
```

最大值和最小值属于原始PCC信号中的瞬时波动，不能直接理解成闭环长期偏离目标30.66 kW。

# 二、资源调节结果如何理解

虽然最终净变化只有约20 kW，但资源实际进行了：

* PV增加约49.08 kW；
* EV增加充电约29.52 kW；
* 两者相互抵消后剩约19.56 kW。

若用简单的"总命令变化量"衡量：

```
A = 49.08 + 29.52 = 78.60 kW
```

约为所需净调节量20 kW的：

```
78.60 / 20 ≈ 3.93
```

这不是标准评价指标，但可以直观说明：

> **`Ts=1 s`时仍有PV增发与EV增充相互对冲，只是已经远小于`Ts=0.1 s`时PV、EV、ESS全部接近边界的严重程度。**

# 四、AGC状态结果

状态统计为：

| 指标  |      数值 |
| --- | ------: |
| 最大值 |      +1 |
| 最小值 |      −1 |
| 均值  | −0.4001 |
| 中位数 |      −1 |
| RMS |  0.8944 |

状态只出现：

```text
+1、0、−1
```

没有出现：

```text
+2、−2
```

说明：

* `+1`：需要增加微网净出力；
* `−1`：需要降低微网净出力；
* `0`：偏差处于死区；
* 没有出现资源能力不足状态。

状态均值本身没有明确物理意义，因为状态是离散标志，并且会在两个AGC更新时刻之间保持。真正有意义的是：

> AGC仍在正向调节、停止调节和负向调节之间切换，但没有再进入能力不足状态。

# 五、资源优先级验证结果

从命令波形可以确认：

## 当dP为正

AGC优先增加PV：

```text
PV先增加
ESS保持0
EV初期不动作
```

## 当PCC越过目标、dP变负

AGC优先使EV增加充电：

```text
EV命令变得更负
ESS仍保持0
```

因为EV能力已经足够，未继续调用ESS，也未立即降低PV。

因此，资源优先级与完整代码一致：

```text
dP>0：
PV → ESS放电 → EV减少充电

dP<0：
EV增加充电 → ESS充电 → PV降低
```

9. 建立了后续V4板端移植可使用的完整AGC基线。

## 试验3正式结论

> 在完整AGC代码和理想通信条件下，基础AGC能够实现PCC有功功率闭环跟踪。将控制周期由0.1 s调整为1.0 s后，PCC稳定区间平均值为−39.66 kW，与−40 kW目标的平均误差约为0.34 kW；两台PV最终分别约为0.5454 pu，两台EV约为−0.7476 pu，两台ESS保持0，资源对冲较0.1 s工况显著减轻。结果证明控制更新周期与约1 s设备响应动态不匹配，是0.1 s工况下命令过度累积的重要因素。但原始PCC功率仍存在约3.57 kW标准差的波动，AGC状态仍在正、负方向之间切换，PV与EV仍存在一定对冲，说明控制周期不是唯一影响因素。

试验3至此可以正式结束。下一项可采用`Ts=1.0 s`不变，只将死区由2 kW调整为10 kW，判断剩余状态切换和PV—EV对冲是否主要由PCC纹波触发。
