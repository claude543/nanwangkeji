# 1. 当前最终技术主线

只保护一个核心技术关系：

> **根据EV剩余需充电电量、PCC当前允许的瞬时负荷释放余量以及现有防逆流资源的有效跟随速度，生成EV充电末段功率轨迹；EV负荷逐步减少的同时，产生等幅的防逆流同步补偿需求，使末段过程中PCC功率尽量不因EV逐步退出而发生同幅变化，最终只保留不超过当前有效瞬时余量的小功率退出。**

核心链：

```text
EV剩余需充电电量 Erem
            +
PCC有效瞬时负荷释放余量 M0
            +
防逆流有效同步补偿速度 R0
            ↓
EV末段目标功率 P*
            ↓
EV逐步降低充电负荷
            +
同步产生防逆流补偿需求
            ↓
最终EV只剩M0附近功率
            ↓
完成充电并退出
            ↓
已有S4防逆流反馈控制接管后续PCC状态
```

# 2. 正式写作前新增的三个技术修正

## 2.1 EV可控性条件

本发明主要实施方式适用于：

> **能够接受外部有功功率设定值并在允许范围内连续或分级调节充电功率的EV充电设备。**

EV或BMS本身仍具有最高优先级的电池安全和充电限制。

设车辆/充电设备当前允许的正常充电功率上限为：

\[
P_i^{normal}
\]

本算法生成：

\[
P_i^*
=
\sqrt{
M_0^2+7200R_0E_i^{rem}
}
\]

实际目标为：

\[
P_i^{cmd}
=
\min(P_i^{normal},P_i^*)
\]

但必须注意：

- 当 \(P_i^{normal}\ge P_i^*\) 时，本算法能够主动塑造EV末段轨迹；
- 当车辆/BMS自身把允许功率降低到 \(P_i^{normal}<P_i^*\) 时，本算法不能强迫EV提高功率。

因此正式技术效果必须表述为：

> **在充电设备能够跟踪本方法目标功率且车辆侧允许功率不低于所述目标功率的末段区间内，本方法能够按照所设计的轨迹主动降低EV充电功率。**

若车辆自身提前快速降功率，则：

- 以EV实际功率变化作为同步补偿量计算依据；
- 已有S4防逆流反馈控制继续承担后备保护；
- 不宣称此时仍严格满足 \(\mathrm dP/\mathrm dt=-R_0\)。

这属于实施边界，不是第二创新点。

---

## 2.2 同步补偿量是“累计需求”，不是每周期重复叠加

末段启动时EV功率为：

\[
P_s
\]

当前EV功率为：

\[
P_i^{EV}(k)
\]

定义：

\[
\boxed{
\Delta P_{AR}^{ff}(k)
=
P_s-P_i^{EV}(k)
}
\]

其含义是：

> **相对于末段启动时刻，现阶段总共需要形成多少防逆流补偿功率。**

如果已有防逆流资源接口采用增量形式，则第 \(k\) 个周期新增的补偿增量应为：

\[
\boxed{
\delta P_{AR}^{ff}(k)
=
P_i^{EV}(k-1)-P_i^{EV}(k)
}
\]

不能在每个周期把累计量 \(\Delta P_{AR}^{ff}\) 再重复相加。

正式正文必须区分：

- 累计补偿需求：\(\Delta P_{AR}^{ff}\)
- 相邻周期新增补偿量：\(\delta P_{AR}^{ff}\)

---

## 2.3 EV完成后，补偿状态不能预设“立即释放”

当EV完成：

\[
P_i^{EV}\rightarrow0
\]

同步补偿资源已经形成一定功率状态。

该状态不能与EV断开同时清零，否则可能造成新的PCC功率跃变。

正确表述冻结为：

> **EV完成充电后，当前补偿状态转交已有S4防逆流反馈控制，由S4根据后续PCC实际功率决定维持、增加或减小相应补偿。**

因此后续正文不要写成：

> “EV完成后逐渐释放补偿。”

因为是否可以释放取决于当时实际PCC状态。

- 优先权日：2024-08-26
- 公开日：2024-12-03
- 技术对象：光伏 + 储能 + 充电桩 + 防逆流
- 与本项目场景接近程度：**最高**

### 已公开的关键内容

该方案：

1. 实时采集充电桩和光伏侧交流母线电流；
2. 根据充电桩负载、光伏发电和储能状态执行防逆流；
3. 明确计算充电桩负载电流变化量；
4. 当充电桩负载电流骤降时，调整甚至停止光伏和储能运行，以避免电能倒送。

### 它已经占据的内容

不能把下面内容作为我们的创新：

- 光储充系统防逆流；
- 检测充电桩负荷骤降；
- 充电桩负荷骤降后调整PV/ESS；
- 利用充电桩负载变化触发防逆流。

### 与本方案的真正区别

它主要是：

```text
充电桩负荷已经骤降
        ↓
检测负荷变化
        ↓
再调整PV/ESS
```

本方案是：

```text
EV尚未完成充电
        ↓
利用剩余需充电电量提前形成末段功率轨迹
        ↓
EV下降过程中同步形成防逆流补偿需求
        ↓
最终只保留受控的小功率退出
```

因此第1部分正式写作时，CN119070379A应当作为**最接近的同场景现有技术候选之一**。

# 5. 现有技术核验后的最终创新边界

经过本轮核验，不能保护的内容已经很明确：

- 光储充防逆流；
- 充电桩负荷骤降检测；
- 负荷骤降后控制PV/ESS；
- 防逆流考虑设备响应时间；
- EV剩余充电电量；
- EV末段ramp-down（功率下降）；
- 两个资源等幅协调以维持净功率。

因此正式交底书必须始终把创新集中在下面这一完整组合：

\[
\boxed{
E_i^{rem}
+
M_0
+
R_0
\rightarrow
P_i^*
}
\]

其中：

\[
\boxed{
P_i^*
=
\sqrt{
M_0^2+7200R_0E_i^{rem}
}

\[
\boxed{
\Delta P_{AR}^{ff}
=
P_s-P_i^{EV}

以使EV逐步退出过程与已有防逆流资源的同步补偿相协调。

- 未发现单篇现有技术直接完整公开上述组合；

# 6. 完整数值实施例

以下数值只用于说明算法，不代表现有项目实测结果。

## 6.1 参数设置

设：

\[
P_{\mathrm{exp,lim}}=0\ \mathrm{kW}
\]

表示禁止向上级电网外送有功功率。

末段启动前：

\[
P_{\mathrm{PCC},0}=-20\ \mathrm{kW}
\]

表示微电网当前仍从上级电网购入20 kW。

为便于算例，暂不额外扣除安全保留量，因此：

\[
M_0=0-(-20)=20\ \mathrm{kW}
\]

设目标EV当前正常充电功率：

\[
P_s=60\ \mathrm{kW}
\]

已有防逆流资源能够保证的有效同步补偿速度为：

\[
R_0=10\ \mathrm{kW/s}
\]

可用防逆流补偿容量：

\[
H_0=50\ \mathrm{kW}
\]

EV最低可控充电功率：

\[
P_{EV,\min}=0\ \mathrm{kW}
\]

---

## 6.2 实施条件检查

首先：

\[
P_s>M_0
\]

即：

\[
60>20
\]

因此需要末段整形。

速度：

\[
R_0=10>0
\]

满足条件。

容量需求：

\[
P_s-M_0=60-20=40\ \mathrm{kW}
\]

而：

\[
H_0=50\ \mathrm{kW}
\]

因此：

\[
H_0\ge P_s-M_0
\]

满足容量条件。

最低功率：

\[
P_{EV,\min}=0\le20=M_0
\]

满足末段下降条件。

# 7. 同步补偿下的PCC功率平衡验证

这是本轮最重要的数学闭环检查。

末段开始后，EV相对于初始状态释放的负荷为：

\[
P_s-P_{EV}(t)
\]

本算法同步要求已有防逆流资源形成：

\[
\Delta P_{AR}^{ff}(t)
=
P_s-P_{EV}(t)
\]

的降低净对外出力作用。

在理想执行条件下，末段过程中PCC功率变化可以写成：

\[
\Delta P_{\mathrm{PCC}}
=
\left(P_s-P_{EV}\right)
-
\Delta P_{AR}^{ff}
\]

代入：

\[
\Delta P_{AR}^{ff}
=
P_s-P_{EV}
\]

得到：

\[
\boxed{
\Delta P_{\mathrm{PCC}}=0
}
\]

因此末段逐步退出过程中：

\[
P_{\mathrm{PCC}}\approx-20\ \mathrm{kW}
\]

即原有瞬时安全余量不会因为计划内EV逐步减载而被同幅提前消耗。

# 8. 最终充电结束瞬间验证

在理想末段终点：

\[
P_{EV}=M_0=20\ \mathrm{kW}
\]

同步补偿已达到：

\[
\Delta P_{AR}^{ff}=60-20=40\ \mathrm{kW}
\]

此时EV完成充电：

\[
20\rightarrow0
\]

最后一次负荷减少量：

\[
20\ \mathrm{kW}
\]

因此PCC瞬时从：

\[
-20\ \mathrm{kW}
\]

变为：

\[
-20+20=0\ \mathrm{kW}
\]

即：

\[
\boxed{
P_{\mathrm{PCC,after}}=
P_{\mathrm{exp,lim}}
}
\]

在本算例理想条件下，最终正好到达禁止外送边界，而没有超过该边界。

实际实施时可以通过在 \(M_{\mathrm{raw}}\) 中扣除安全保留量，使最终结果保留一定工程裕度。

# 9. 用户充电时间影响验证

末段整形持续：

\[
4\ \mathrm{s}
\]

若始终保持60 kW完成同样的：

\[
0.04444\ \mathrm{kWh}
\]

所需时间：

\[
T_{\mathrm{const}}
=
\frac{
0.04444\times3600
}{
60
}
\approx2.667\ \mathrm{s}
\]

因此理论额外时间：

\[
4-2.667
=
1.333\ \mathrm{s}
\]

也与公式：

\[
\Delta T
=
\frac{
(P_s-M_0)^2
}{
2R_0P_s
}
\]

计算结果一致：

\[
\boxed{
\Delta T\approx1.333\ \mathrm{s}
}
\]

该数值仅作为算例说明本方案对完成时间的影响可以被明确计算。

# 16. 现有技术组合攻击测试

内部模拟最危险的创造性组合：

```text
CN119070379A
充电桩负荷骤降 + 光储充防逆流

        +

CN115207900A/B
PCC趋势 + 防逆流资源响应时间

        +

EP3718073A1
EV剩余电量 + 动态充电功率 + ramp-down

        +

US10139847B2
相关联等幅功率调整 + 外送约束
```

审查员理论上可能据此提出：

> 既然EV临近完成可以降功率、防逆流资源具有响应时间、外送约束下两个资源可以相关联调节，那么将EV末段降功率与防逆流补偿联合起来是否属于自然组合？

这是当前最主要的创造性风险。

我们的区别必须集中在：

\[
\boxed{
P_i^*
=
\sqrt{
M_0^2+7200R_0E_i^{rem}
}
}
\]

该关系不是简单把四类技术并列，而是同时满足：

1. EV剩余电量最终恰好被充完；
2. 在固定 \(M_0,R_0\) 条件下，末段目标功率变化率为 \(-R_0\)；
3. EV完成前目标功率趋近 \(M_0\)；
4. 配套同步补偿使计划内EV负荷释放不直接同幅消耗PCC安全余量；
5. 最终只留下受 \(M_0\) 限制的瞬时退出。

### 内部结论

**创造性风险：中等。**

不是“现有技术很干净”，也不是“已经被直接公开”。

当前仍达到继续撰写交底书的内部标准，但正式交底书不能把独立创新写成宽泛的：

> “EV末段降功率并由储能同步补偿。”

必须把核心状态关系和物理因果写进去。
