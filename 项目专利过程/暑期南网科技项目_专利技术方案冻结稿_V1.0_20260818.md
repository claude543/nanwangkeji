# 0. 当前结论与状态

当前暂定专利方向为：

> **针对光储充微电网中可控EV在完成充电时由较大充电功率快速退出、可能造成PCC外送功率突增的问题，根据EV剩余需充电电量、PCC当前防逆流瞬时负荷释放余量以及现有防逆流资源的有效跟随速度，形成EV充电末段功率轨迹；在EV功率逐步下降的同时，向现有PV/ESS等防逆流资源生成同步补偿需求，使EV负荷逐步退出，并把最终充电完成瞬间的剩余负荷突降控制在当前允许的防逆流余量范围内。**

# 1. 唯一技术问题

本件专利只解决一个问题：

在光储充微电网中，EV属于较大功率可控充电负荷。当EV完成充电并由较高充电功率快速下降至零时，微电网内部负荷会在短时间内明显减少，导致PCC有功功率向外送方向快速变化。

现有防逆流控制通常在PCC已经接近或超过外送限制后，再通过以下资源进行修正：

- ESS增加充电；
- PV降低发电；
- 其他柔性负荷增加用电。

但上述资源具有有限的功率变化速度和有限的可调容量。如果EV的负荷退出速度明显快于防逆流资源的跟随速度，则在现有资源完成修正之前，PCC可能短时出现不允许的反向潮流。

因此，本件专利不研究整个微电网优化调度，而只研究：

> **如何在EV充电结束之前，主动塑造EV末段充电功率下降过程，使其与微电网现有防逆流能力协调。**

这些可以作为系统已有功能、实施条件或替代方式出现，但不能重新扩张为本件专利的第二条创新主线。

主要实施环境采用光储充微电网，包括：

- 一个或多个PV；
- 一个或多个ESS；
- 一个或多个可控EV充电负荷；
- 微电网交流母线；
- PCC；
- 上级电网；
- PCC有功功率测量；

- PV1、PV2；

> **新算法负责EV完成充电前的主动预整形；现有S4防逆流负责PCC反馈监测和后备保护。**

二者不是相互替代关系。

# 4. 全文统一功率符号

## 4.1 PCC功率

全文统一：

\[
P_{\mathrm{PCC}}>0
\]

表示：

> 微电网通过PCC向上级电网送出有功功率。

\[
P_{\mathrm{PCC}}<0
\]

表示：

> 微电网通过PCC从上级电网购入有功功率。

后续所有正文、公式、实施例和附图必须使用这一套符号。

## 4.2 EV功率

为了避免EV充电为负值造成核心公式混乱，本算法内部统一使用EV充电功率幅值：

\[
P_i^{EV}\ge0
\]

例如：

\[
P_i^{EV}=60\ \mathrm{kW}
\]

表示第 \(i\) 台EV以60 kW功率充电。

如果设备接口仍使用“充电为负”的外部功率符号，则在输出接口处转换：

\[
P_{EV,i}^{grid}=-P_i^{EV}
\]

核心算法内部不使用负值充电功率。

# 6. 变量的严格定义

## 6.1 EV等效剩余需充电电量 \(E_i^{rem}\)

定义为：

> 从当前时刻至达到本次目标充电状态，还需要由充电设备交流侧向EV提供的等效电能。

采用单位：

\[
\mathrm{kWh}
\]

离散更新关系：

\[
\boxed{
E_i^{rem}(k+1)
=
\max
\left[
E_i^{rem}(k)
-
\frac{P_i^{EV}(k)T_s}{3600},
0
\right]
}
\]

若车辆或BMS提供的是电池侧剩余需充电电量，则在进入本算法前通过已有充电效率关系换算为交流侧等效剩余需充电电量。

## 6.2 基础防逆流瞬时负荷释放余量

根据PCC当前功率和允许最大外送功率：

\[
\boxed{
M_{\mathrm{raw}}
=
\left[
P_{\mathrm{exp,lim}}
-
P_{\mathrm{PCC}}
\right]_+
}
\]

其中：

\[
[x]_+=\max(x,0)
\]

例如禁止外送：

\[
P_{\mathrm{exp,lim}}=0
\]

且当前：

\[
P_{\mathrm{PCC}}=-20\ \mathrm{kW}
\]

则：

\[
M_{\mathrm{raw}}=20\ \mathrm{kW}
\]

表示在其他功率瞬间不变的条件下，当前约有20 kW负荷可以突然退出而不立即越过0 kW外送边界。

实际实施时可以从 \(M_{\mathrm{raw}}\) 中扣除预设安全保留量，得到：

\[
M_0
\]

安全保留量属于工程参数，不作为本发明创新点。

## 6.3 防逆流有效同步补偿速度 \(R_0\)

定义为：

> 在当前运行状态下，已有PV限发、ESS增加充电或其他可调资源能够保证用于抵消EV负荷下降的有效功率变化速度。

单位：

\[
\mathrm{kW/s}
\]

\(R_0\) 可以由已有设备能力参数、控制器当前有效能力或其他已知方式提供。

**如何估计 \(R_0\) 本身不是本发明的创新。**

## 6.4 防逆流可用补偿容量 \(H_0\)

定义为：

> 当前可参与本次EV末段协调的PV、ESS或其他资源，在降低微电网净对外有功功率方向上还能提供的总可用功率调节空间。

它回答的是：

> 防逆流资源“总共还能调多少”。

而 \(R_0\) 回答的是：

> 防逆流资源“能以多快的速度调”。

# 7. 核心物理机制

仅让EV慢慢降低充电功率并不足以保证防逆流安全。

假设末段控制开始时EV充电功率为：

\[
P_s
\]

当EV降低至：

\[
P_i^{EV}
\]

时，EV负荷已经减少：

\[
P_s-P_i^{EV}
\]

如果PV、ESS等资源完全不动作，这部分负荷减少本身会推动PCC向外送方向变化，从而提前消耗原有安全余量。

因此，本发明在EV末段功率下降的同时生成防逆流同步补偿需求：

\[
\boxed{
\Delta P_{AR}^{ff}
=
P_s-P_i^{EV}
}
\]

其含义为：

> EV相对于末段控制起始功率减少了多少，现有防逆流资源就形成相应幅值的降低净对外出力补偿。

所述补偿可以由：

- ESS增加充电；
- PV降低发电；
- 其他可增加用电或降低发电的资源；
- 上述资源组合；

实现。

具体资源分配算法不属于本发明核心。

# 8. 核心算法公式

## 8.1 EV末段功率轨迹

当本次末段控制启动时，锁定当前采用的：

\[
M_0,\quad R_0
\]

EV末段目标功率边界定义为：

\[
\boxed{
P_i^*
=
\sqrt{
M_0^2
+
7200R_0E_i^{rem}
}
}
\]

其中 \(E_i^{rem}\) 采用kWh，因此公式中包含 \(7200=2\times3600\)。

实际EV目标功率满足：

\[
\boxed{
P_i^{cmd}
=
\min
\left(
P_i^{normal},
P_i^*
\right)
}
\]

其中 \(P_i^{normal}\) 为车辆、充电设备或上层任务允许的正常充电功率。

本算法只提供一个额外的微电网防逆流功率上限，不突破车辆或充电设备自身限制。

## 8.2 功率下降速度的物理解释

当：

- \(M_0\)、\(R_0\) 在本次短时末段控制过程中保持不变；
- EV能够跟踪所述功率边界；

有：

\[
P_i^2=M_0^2+7200R_0E_i^{rem}
\]

以及：

\[
\frac{dE_i^{rem}}{dt}
=
-\frac{P_i}{3600}
\]

因此：

\[
\boxed{
\frac{dP_i}{dt}
=
-R_0
}
\]

即：

> 在理想跟踪条件下，EV末段负荷下降速度与本次选定的防逆流有效同步补偿速度相匹配。

该结论仅在上述条件下成立，正式正文不得扩大表述。

## 8.3 充电完成前的最终功率

当：

\[
E_i^{rem}\rightarrow0
\]

有：

\[
\boxed{
P_i^*\rightarrow M_0
}
\]

因此理想情况下，EV最终完成充电前的剩余充电功率趋近于：

\[
M_0
\]

随后EV由：

\[
M_0\rightarrow0
\]

完成最后断开。

# 9. 末段控制启动条件

若末段控制起始前EV正常充电功率为：

\[
P_s
\]

当：

\[
P_s\le M_0
\]

时：

\[
\boxed{\text{无需启动末段整形}}
\]

当：

\[
P_s>M_0
\]

时，对应的理论末段启动剩余能量为：

\[
\boxed{
E_{sw}
=
\frac{
P_s^2-M_0^2
}{
7200R_0
}
}
\]

当：

\[
E_i^{rem}\le E_{sw}
\]

且其他实施条件满足时，进入末段控制。

---

# 10. 必须满足的实施条件

## 10.1 防逆流速度条件

\[
R_0>0
\]

若当前没有能够跟随EV负荷下降的防逆流资源，则不启动完整末段整形。

## 10.2 防逆流容量条件

\[
\boxed{
H_0
\ge
P_s-M_0
}
\]

若不满足，则不能宣称本算法单独能够完成整个末段过程，应交由已有防逆流控制、充电任务管理或其他备用方式处理。

## 10.3 EV最低可控功率条件

若EV或充电桩最低稳定充电功率为：

\[
P_{EV,\min}
\]

主要实施方式要求：

\[
\boxed{
P_{EV,\min}\le M_0
}
\]

否则EV可能无法平滑下降到 \(M_0\)。

# 11. 末段持续时间和用户任务影响

理想情况下：

\[
\boxed{
T_{\mathrm{taper}}
=
\frac{
P_s-M_0
}{
R_0
}
}
\]

与始终保持 \(P_s\) 充电相比，由末段整形增加的理论充电完成时间为：

\[
\boxed{
\Delta T
=
\frac{
(P_s-M_0)^2
}{
2R_0P_s
}
}
\]

如果用户存在最晚离场时间或必须按时达到目标SOC的约束，可由上层充电任务管理模块判断是否允许启用本算法。

用户充电排程优化不属于本发明核心。

# 12. 末段过程中参数处理

主要实施方式：

1. 进入末段时取得并锁定 \(M_0\)、\(R_0\)、\(P_s\)；
2. 末段过程中继续监测PCC、防逆流资源有效性、EV实际功率和剩余需充电电量；
3. 不因参数瞬时变化而直接重新计算出一个突然更低的EV目标功率；
4. 若安全条件明显恶化，则暂停继续降低EV功率，或退出本末段整形，由已有防逆流反馈控制优先处理；
5. 条件变好时，不要求重新提高EV功率。

---

# 13. EV完成后的控制交接

当：

\[
E_i^{rem}=0
\]

EV充电功率置零。

末段过程中已经形成的防逆流同步补偿量：

\[
\Delta P_{AR}^{ff}
\]

**不能与EV断开同时瞬间清零。**

主要实施方式采用：

> EV完成充电后，将当前防逆流补偿状态平滑交由已有S4防逆流反馈控制继续管理，再由现有控制根据PCC状态逐步调整或释放。

---

# 14. 多EV处理原则

## 14.1 主要实施方式

当多台EV同时可能进入末段时：

> 选择预计完成时间最早的一台EV作为当前末段控制对象。

其他EV保持正常允许充电功率。

当前目标EV完成后，再重新计算下一台EV是否进入末段控制。

## 14.2 替代实施方式

如果允许多台EV同时进入末段，则需要分别分配：

\[
R_i,\quad H_i
\]

并至少满足：

\[
\sum_i R_i\le R_{AR}
\]

以及对应总补偿容量不超过当前可用防逆流容量。

该方式仅作为替代实施方式。

# 15. 与现有S4防逆流策略的关系

固定关系：

```text
EV正常充电
    ↓
检测到末段条件
    ↓
本专利计算EV末段功率轨迹
    ↓
EV逐步降低充电功率
    +
同步形成防逆流补偿需求
    ↓
现有PV/ESS等资源执行补偿
    ↓
EV最终完成充电
    ↓
补偿状态平滑交给已有S4防逆流反馈控制
```

同时：

```text
PCC始终持续监测
    ↓
若仍出现外送超限或异常风险
    ↓
已有S4防逆流反馈控制优先介入
```

# 16. 权利要求级核心技术特征 V1.0

## 特征1：取得关键状态

获取：

- EV剩余需充电电量；
- PCC当前功率和允许外送边界；
- 当前可用于防逆流的有效同步补偿速度；

并可进一步获取防逆流可用补偿容量作为实施条件。

## 特征2：形成当前防逆流瞬时负荷释放余量

根据PCC当前有功功率与允许最大外送功率之间的关系，确定本次EV完成充电事件允许的瞬时负荷退出余量 \(M_0\)。

## 特征3：形成EV末段动态功率边界

根据：

\[
E_i^{rem},\quad M_0,\quad R_0
\]

形成EV末段动态功率边界，主要实施关系为：

\[
\boxed{
P_i^*
=
\sqrt{
M_0^2
+
7200R_0E_i^{rem}
}
}
\]

并使用该边界限制EV末段充电功率。

## 特征4：同步生成防逆流补偿需求

根据：

\[
\boxed{
\Delta P_{AR}^{ff}
=
P_s-P_i^{EV}
}
\]

形成防逆流同步补偿需求，并交由现有PV、ESS或其他防逆流资源执行。

## 特征5：EV完成后与已有防逆流反馈闭环交接

EV完成充电后：

- EV功率置零；
- 已形成的防逆流补偿状态不瞬时清除；
- 由已有PCC防逆流反馈控制根据后续PCC状态逐步调整。

### 控制输入
