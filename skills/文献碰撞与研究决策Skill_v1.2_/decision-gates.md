# 研究决策门槛

用于判断论文方向、证据是否闭环、以及是否开启下一轮。

# 1. 方向锚点

在改变方向前先回看：
- 当前真正研究的问题；
- 当前项目/论文目标；
- 已有工程和实验基础；
- 主机制与辅助机制；
- 已明确不做的方向。

文献只能帮助修正方向，不能因为出现相似关键词就自动带偏。

# 2. 本轮必要性

新一轮必须能回答：

> 这一轮结束后，我们会据此决定什么？

答不出来就不要开启大范围检索。

# 3. 证据边界

用户侧统一显示：
- 已由全文确认
- 摘要支持
- 仅有基本信息
- 分析推断
- 现有材料无法判断

负面结论不能比证据更强。

# 4. 搜索饱和与全文闭环分开

## 搜索已饱和
说明不需要再扩张普通文献。

## 全文已闭环
说明决定性负面判断已有足够全文依据。

搜索饱和不自动等于全文闭环。

# 5. 重合强度看多层，而不是关键词

至少比较：
1. 研究问题
2. 系统对象
3. 状态/信息
4. 核心机制
5. 条件/扰动/场景
6. 验证环境

只重合一个算法名或应用词，不足以判定方向失去价值。

# 6. 具体机制的四种中文处理

## 已不能作为主要创新
已有工作明确覆盖该机制本身。

## 可以直接借鉴的成熟机制
已有成熟先例，可作为组件、基线或支撑方法。

## 当前仍值得重点研究
目前证据下仍应作为论文核心。

## 仍有文献风险，需要下一轮核查
当前值得保留，但相邻研究线可能形成更强碰撞。

# 7. 整篇论文的四种方向判断

## 保持当前方向
主线无须调整。

## 进一步收窄方向
大方向成立，但贡献边界要更加精确。
这是发现大量成熟邻近机制后的正常结果。

## 需要实质修改方向
核心机制高度重合，或新证据要求方法明显调整。

必须让用户确认后再改变方向锚点。

## 建议放弃当前方向
仅在高度同构已有工作、核心问题不成立或用户主动放弃时使用。

必须让用户确认。

# 8. 不自动冻结最终算法

文献检索可以决定：
- 问题还值不值得做；
- 哪些组件不用重新发明；
- 哪个方向风险最高；
- 下一步应验证什么。

但不能仅凭文献检索就自动冻结：
- 最终状态向量；
- 数学公式；
- 控制器结构；
- 参数；
- 实验工况；
- 工程版本改动。

这些必须回到具体模型、算法和实验验证。

# 9. 研究视角自校正

初次识别的研究类型只是暂定。

第一轮最接近论文出来后，如果真正竞争点不同，
必须修正研究视角和比较维度。

不要维护错误的第一次分类。

# 10. 反方审计

重要轮次结束前检查：

1. 搜索词是否只支持当前方向？
2. 有没有邻近术语可能暴露更强已有工作？
3. “没做”是否由全文确认？
4. 差异是否只是应用名称不同？
5. 审稿人最可能拿哪篇论文反驳？

如有真实缺口，只补一个窄检索。

# 11. 下一轮类型

每轮最后只能选一种：

- 停止；
- 只做一个领域内补检；
- 只做一个相邻理论补检；
- 后续在公式/实现阶段按需查询。

如果继续，必须写出唯一决策问题。

# 12. 全文下载提示

每轮必须明确：

## 是否需要你下载全文

- 不需要
- 需要

如果需要，只列1～3篇最关键文献：
标题 + 网站/数据库 + DOI。
