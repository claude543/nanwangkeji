# 检索协议

仅在开始或修正一轮文献检索时读取。

# 1. 先明确“这轮要决定什么”

任何检索先写清一个决策问题。

好的例子：
- “现有方法是否已经利用某类实时状态完成同类控制？”
- “当前候选机制是否已被高度同构工作覆盖？”
- “这一算法组件应继续自己设计，还是作为成熟方法借鉴？”

不好的例子：
- “多找点论文。”
- “看看有没有创新。”

没有明确决策，不开启大范围检索。

# 2. 先做通用研究画像，再决定检索重点

先检查八个维度：

1. 研究对象
2. 研究目标
3. 层级与时间尺度
4. 状态/信息/数据
5. 核心机制
6. 约束与假设
7. 扰动/不确定性/运行条件
8. 验证与证据

然后识别1个主要研究视角和最多2个辅助视角。

研究视角只用于避免漏项，不是硬分类。

# 3. 查询词按“概念簇”构造

不要只用一个超长检索式。

通常分成：

## 直接问题簇
对象 + 目标 + 最核心机制。

## 机制簇
暂时去掉应用名称，只搜真正方法。

## 邻近术语簇
寻找功能相同但叫法不同的研究。

## 场景级碰撞簇
对象 + 关键机制 + 约束/异常 + 验证。

第一轮结果出来后，根据最接近论文修正查询词。

# 4. 电气工程来源优先级

根据当前任务选择，不机械要求全部数据库。

通常优先：
- IEEE Xplore；
- IET；
- ScienceDirect / Elsevier；
- Springer / Wiley；
- Web of Science / Scopus用于发现和追踪；
- 高质量中文电气工程期刊、CNKI/万方；
- Google Scholar / Semantic Scholar / OpenAlex / Crossref用于补充发现和引文追踪；
- arXiv、作者主页、机构仓储用于补充全文或预印本。

如果用户明确说“优先IEEE”，就优先IEEE。

# 5. 中英文检索

国际论文默认以英文术语检索。

遇到：
- 国内电网工程实践；
- 中文标准；
- 国内示范项目；
- 中文高水平期刊；

再补充中文检索。

对关键术语考虑：
- 缩写和全称；
- 新旧叫法；
- 功能等价词；
- 相邻领域术语。

# 6. 文献筛选看“决策价值”

优先判断：
- 是否直接回答本轮问题；
- 场景是否接近；
- 状态/信息是否接近；
- 核心方法是否接近；
- 是否值得迁移；
- 是否会改变创新边界；
- 来源是否可靠。

高影响力期刊但与决策无关，不自动进入核心精读。

# 7. 阅读优先级

内部可分：
- 必须精读；
- 核心熟悉；
- 定向阅读；
- 背景了解；
- 排除。

对用户用中文解释，不要求记字母。

# 8. 去重

同一DOI视为同一文献。

无DOI时比较：
- 标题；
- 作者；
- 年份；
- 期刊/会议。

会议版与期刊扩展版、预印本与正式期刊版不要简单合并，
应标记“同一研究线/扩展版本”。

同一团队连续论文要标记，避免把同一研究路线误当成多个独立证据。

# 9. 全文门槛

摘要足够用于：
- 初筛；
- 判断是否值得下载；
- 粗略理解主题。

以下结论尽量要求全文：
- “没有使用某状态”
- “没有考虑某恢复机制”
- “没有某层控制”
- “没有某种实验”
- “与我们的核心高度重合/明显不重合”

# 10. 引文追踪

只对：
- 最接近的核心论文；
- 奠基性论文；
- 暴露出新术语/新研究线的论文；

做前向/后向追踪。

不要对所有候选论文无限追踪。

# 11. 文献反校正

第一轮检索后必须检查：

> 初始研究视角和重点比较维度，是否仍与真正最接近的论文一致？

如果不一致，修正研究视角和检索维度。

这一步比“第一次分类准确”更重要。

# 12. 搜索停止条件

停止扩张搜索，当：
- 本轮问题已基本可回答；
- 新论文开始重复同类机制；
- 最接近的1～3篇工作已知；
- 继续增加普通论文不再改变决策。

如果负面判断仍缺全文：
停止扩张，但进入关键全文闭环，不算本轮完全结束。
