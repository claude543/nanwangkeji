# 《Science Research Writing》独立再蒸馏吸收审计

## 结论

独立 cangjie 重跑确认：v1.0.0 的科研逻辑与证据主干无需重构；真正值得补充的是语言实现层。

## 已吸收或改造后吸收

- 句子删除测试：保留，但设置图表导航、逻辑连接、范围限定等例外。
- 方法/技术归属清晰：吸收核心目的，不采用固定“时态=归属”公式。
- 时态与语态：保留为信息功能与期刊风格工具，不赋予“真值”。
- 因果弱化：改造成证据强度—因果语言强度匹配。
- 情态表达：改造成证据/义务强度检查，不做固定词表公式。
- Results 数字表达：改造成关键数字需要比较基准、变化幅度或工程意义；拒绝“所有数字必须加评价词”。
- Results 详略：吸收“篇幅与核心论断重要性基本匹配”。
- Discussion 回访：吸收核心术语稳定、回访不新增事实。
- Abstract：吸收“从正文抽取并压缩”的工作流。
- Title：吸收研究问题转写、名词链歧义、介词关系和范围检查；强词触发证据审查而不是一律禁止。
- 引用位置：吸收引用应靠近真正被支持内容，避免技术归属混淆。
- 方法可信度：吸收“关键选择需要真实理由”；拒绝用 carefully/thoroughly 等副词制造严谨感。

## 明确不吸收

- 固定句数、词数、章节长度；
- 固定时态—功能一一对应表；
- “母语作者论文”作为范文标准；
- 把最佳结果包装成典型结果；
- 通过语言淡化局限；
- 用现在时、强评价词或情态词制造更高“真实性”；
- 为吸引未来引用而设计研究方向；
- 把 published-paper 常见写法自动升级为期刊规则。

## 优先级没有改变

技术事实与科研诚信
→ 论断—证据和适用边界
→ 电气工程技术正确性
→ 目标期刊当前官方要求
→ 目标期刊稳定写作惯例
→ 一般科研写作与英语实现
