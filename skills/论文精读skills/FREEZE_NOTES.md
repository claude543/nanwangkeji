# 长期冻结说明

版本：v1.2.0  
状态：长期冻结

## 本次为何解除过 v1.1.0 冻结

真实使用中确认了一个跨论文、长期存在的需求：

> 精读不仅要帮助理解科研内容，还需要在用户明确要求时，把优秀论文作为“论文组织范本”反向拆解，帮助学习如何从科研内容形成论文。

该需求不是单篇论文特例，因此以可选模块形式进入 v1.2.0。

## 冻结原则

后续不因为：
- 看到新的精读提示词；
- 遇到新的电气子领域；
- 发现新的 GitHub Skill；
- 想增加更多固定栏目；

就继续修改。

只有以下情况之一反复出现时才考虑升级：
1. 同一类精读错误多次出现；
2. 论文范本学习持续把成稿结构误当科研真实过程；
3. 中文输出规则持续失效；
4. 新能力能够解决多个真实论文中反复出现的问题；
5. ChatGPT Skill 机制发生重大变化。

## 使用原则

先长期使用 v1.2.0。

未来发现问题时先记录失败案例，累计同类问题后再决定是否升级。
