# 更新记录

## v1.2.0 — 长期冻结版

在 v1.1.0 深度科研精读稳定版基础上增加一个按需加载的“论文范本学习”模块。

主要变化：
- 保留标准精读与深度科研精读两档，不新增第三档；
- 增加可叠加的论文范本学习视角；
- 可反向拆解全文主线、章节功能、核心图表/验证作用和论文论断形成过程；
- 增加“值得学习 / 不能机械照搬 / 可迁移组织骨架”；
- 明确区分论文呈现顺序与作者真实科研/写作顺序；
- 没有明确证据时，不虚构作者“原本做过什么”；
- 范本学习默认不输出英文写作术语；
- 用户确实需要英文句式、词组或单词时才给英文；
- 用户可见的判断节点、分类和流程默认全部中文；
- 范本学习只在用户明确要求时加载，不增加普通精读负担；
- 与标准/深度科研精读复用已有结论，避免重复。
