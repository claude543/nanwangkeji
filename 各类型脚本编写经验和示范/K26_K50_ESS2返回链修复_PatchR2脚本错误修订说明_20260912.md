# K26_K50｜ESS2 返回链修复 Patch R2 脚本错误修订说明

日期：2026-09-12

## 1. R1 为什么“Actual/Expected 都空”却报错

专项审计结论没有错。

审计明确：

```text
Executor_Demux out1 = UNCONNECTED
```

R1 期望也是“无消费者”。

错误来自辅助断言使用：

```matlab
isequal(actual, expected)
```

直接比较 cell 数组。

空集合在 MATLAB 中可能表示为：

```text
0×0 cell
1×0 cell
0×1 cell
```

它们在“消费者集合”语义上都表示：

```text
EMPTY
```

但 `isequal` 会把数组形状也作为比较条件。

因此 R1 才出现：

```text
Actual:
Expected:
```

两边都空，却报 mismatch。

R1 在正式编辑之前退出，所以模型没有被修改。

## 2. R2 的处理

Patch 和 Verifier 中所有消费者集合比较统一改成：

```text
normalizeEndpointList
↓
统一转成1×N row-cell
↓
去掉空字符串
↓
排序
↓
比较元素数量
↓
逐项比较endpoint字符串
```

不再比较 cell 容器方向。

## 3. 新增纯自测

Patch 在任何模型访问之前测试：

```text
0×0 empty == 1×0 empty
0×1 empty == 1×0 empty
['b','a'] == ['a','b']
单元素相等
不同元素不相等
不同数量不相等
```

Verifier 也在加载模型前执行同类自测。

因此这类“验证框架自己的容器形状问题”不再等到真实模型 preflight 才暴露。
