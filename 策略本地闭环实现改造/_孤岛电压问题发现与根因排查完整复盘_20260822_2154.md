# 3. 第一处重要修正：`Ppcc≈0` 并不等于整个孤岛功率缺额≈0

此前我们为了排除“原来 -100 kW 工况太重”这个可能性，设计了：

```text
CFG_AA_tie_target_kW = 0
```

并验证：

```text
Ppcc ≈ 0 kW
```

当时的推断是：

> 离网前微电网与电网几乎没有有功交换，因此 J1 打开后不会突然少掉很大的有功支撑。

这个推断后来被证明是不完整的。

原因不是 `Ppcc` 数值错了，而是：

> **我们没有重新确认 `Ppcc` 测量边界与 J1 实际切断边界是否是同一个电气边界。**

也就是说：

```text
“一个测量值接近0”
≠
“这个断路器切开以后两侧实际交换功率接近0”
```

除非测量块和断路器严格位于同一联络线边界。

这是本轮第一个重要方法论教训。

# 4. 第二处重要修正：近零 P 也不等于孤岛负担很小

即使只考虑 DER 内部，我们此前近零 Pcc 工况中六台设备并不是都接近零功率。

大致存在：

```text
PV1 / PV2 大量发电
EV1 / EV2 大量充电
ESS1 / ESS2 少量调节
```

它们相互抵消以后，外部看起来：

```text
Ppcc ≈ 0
```

但岛内仍然可能存在很大的内部功率流和动态电流需求。

因此重新形成了一个更严谨的判断：

> “近零PCC”最多只能排除“大平均有功联络线缺额”这一种情况，不能排除：
>
> - 大无功；
> - 大内部功率交换；
> - 单台GFM瞬态电流能力不足；
> - 多台GFL对唯一GFM的动态压力。

这一点本来会把我们带到 P/Q、电流限幅、ModIndex 等内部诊断，但随后上传的最新模型给出了更大的突破。

# 11. 为什么以前看到2～4 kV低压振荡，反而支持这个根因

两个负荷都是：

```text
constant Z
恒阻抗
```

恒阻抗负荷满足近似：

\[
P \propto V^2
\]

所以如果900 kW额定负荷的电压掉到：

```text
0.35 pu ≈ 3.5 kV
```

则负荷大致会下降到：

\[
900 \times 0.35^2
\approx 110\ \text{kW}
\]

这已经接近单台100 kW级 ESS 的支撑能力。

如果电压掉到：

```text
0.25 pu ≈ 2.5 kV
```

则：

\[
900 \times 0.25^2
\approx 56\ \text{kW}
\]

这也解释了我们之前经常看到：

```text
2 kV
3 kV
4 kV
```

附近低压振荡或部分恢复，而不是始终严格归零。

也就是说：

> **电压掉下来以后，恒阻抗负荷自己因为 V² 关系“自动减载”，系统才在低电压区域获得暂时的功率平衡。**

这是“900 kW孤岛负担”假设与实际波形高度吻合的第二个强证据。

> “按照当前实际电气拓扑，真实tie-line power可能应该使用Pgrid。”

这是一个合理的临时判断，因为当时：

```text
PCC测量
≠
J1断路器
```

但在决定正式迁移 Load1/Load2 后，最终方案应当修正为：

```text
DER
→ Ppcc测量
→ J1
→ 外部负荷/Grid
```

此时：

> **`Ppcc` 才是最合适的项目主联络线功率。**

理由：

1. 它直接位于微电网边界；
2. 与J1物理边界一致；
3. 项目历史AGC、S2、S7、V5板端AGC全部建立在它上面；
4. 论文主线也是PCC/tie-line tracking；
5. 没必要为了一个可以通过拓扑统一解决的问题，推翻大量历史控制接口。

最终建议冻结：

```text
Ppcc
= 微电网PCC / tie-line active power
= AGC / S2 / S7 / 论文主控制变量

Pgrid
= Grid侧辅助测量
= 电网诊断/同步/物理核验信号
```

# 19. 负荷一定要600+300 kW吗

**不一定。**

900 kW只是老师原模型中的历史负荷参数，不是当前论文/板端方法必须保持的研究对象。

但当前为了避免一次改两个变量：

```text
拓扑位置
+
负荷数值
```

我们决定：

> **正式迁移后先恢复原600+300 kW，用于验证正常并网基线与老师旧模型一致。**

迁移到J1 Grid侧以后：

```text

→ Load1/2正常存在，由外部系统共同承担

J1 OPEN
→ Load1/2被隔离在Grid侧

```

因此这900 kW再大，也不会直接导致当前孤岛电压问题。

以后如果确认这两个负荷对最终项目没有研究意义，可以单独调整，但那是另一个独立决策。

所以 V2 同样在 preflight 阶段停止，没有修改模型。

# 34. 后续窗口接替时必须坚持的原则

1. **先完成当前手动迁移后的 Rebuild，不再改模型。**
2. Build成功以后，用同一模型一次Load做并网+AGC+孤岛回归。
3. 如果并网和孤岛都PASS，正式冻结新边界。
4. 如果孤岛仍有短时5～13 kV瞬态，再做高采样内部诊断；不要提前大调PI。
5. `Ppcc`继续作为主PCC/tie-line变量，前提是当前拓扑修正正式验证通过。
6. 岛内普通S7/PCC AGC HOLD 是后续必须补的系统语义，但不是本次长期塌压的首因。
7. 不要再用“Ppcc≈0”直接推导“J1两侧物理功率≈0”，除非边界已经验证一致。
8. 任何孤岛/黑启动/重同步实验之前，先检查：
   - 断路器两侧节点；
   - 内外负荷归属；
   - 资源容量；
   - P/Q平衡；
   - 测量边界。
9. 当前新的最大工程认知是：**实时模型的控制逻辑正确，不代表其边界语义自动适合新的运行模式。**
