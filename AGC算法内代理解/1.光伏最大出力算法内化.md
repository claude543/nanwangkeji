# 光伏最大出力算法内化

> 第一项内化任务正式开始：光伏最大可用出力算法

**方法：六层内化法**

```text
定位功能
→ 拆解输入输出
→ 逐行理解代码
→ 建立物理含义
→ 完成手算与边界分析
→ 脱离代码反向讲解
```

---

## 一、模块在整个系统中的位置

代码函数：

```matlab
function [Ppv_max1_kW, Ppv_max2_kW] = ...
    PV_Profile_Curve(time_s, P_unit_kW, PV_time_s, PV_profile_pu)
```

**任务**：根据当前仿真时间，在预设光伏出力曲线上查出当前标幺值，再换算为两台光伏当前时刻的最大可用有功功率。

**位置**：链路最前端

```text
时间和光照变化
→ 光伏最大可用出力   ← 本模块
→ AGC获得光伏功率上限
→ AGC生成光伏功率指令
→ 光伏本地控制器跟踪指令
```

**三个关键量的区分**：

| 量 | 含义 |
|---|---|
| **光伏最大可用出力** Ppv_max | 当前自然条件下最多能发多少 |
| **光伏功率指令** Ppv_ref | AGC希望光伏发多少 |
| **光伏实际功率** Ppv_actual | 光伏设备最后实际发出多少 |

三者关系：

```text
0 ≤ Ppv_ref ≤ Ppv_max
Ppv_actual 尽量跟踪 Ppv_ref
```

> Ppv_max ≠ 光伏当前实际功率。

---

## 二、输入输出逐一理解

### 1. time_s

| 项目 | 内容 |
|---|---|
| 含义 | 当前仿真时间 |
| 单位 | s（秒） |
| 作用 | 决定从光伏曲线的哪个位置取值 |

示例：`time_s = 3600` 表示仿真运行到第 3600 秒。

---

### 2. P_unit_kW

| 项目 | 内容 |
|---|---|
| 含义 | 单台光伏的功率基准值 / 额定功率 |
| 单位 | kW |

用于将标幺值转换为实际功率：

```text
实际功率 = 标幺值 × 功率基准值
```

示例：

```text
P_unit_kW = 100 kW
当前光伏曲线值 = 0.75 pu
→ 最大可用出力 = 100 × 0.75 = 75 kW
```

---

### 3. PV_time_s

光伏曲线的时间坐标数组。

```matlab
PV_time_s = [0, 10, 20, 30];
```

表示曲线在 0s、10s、20s、30s 设置了四个关键点。

---

### 4. PV_profile_pu

与 `PV_time_s` 一一对应的光伏标幺值数组。

```matlab
PV_profile_pu = [0.2, 0.6, 1.0, 0.5];
```

对应关系：

| 时间 | 光伏标幺值 |
|:---:|:--------:|
| 0 s | 0.2 pu |
| 10 s | 0.6 pu |
| 20 s | 1.0 pu |
| 30 s | 0.5 pu |

两个数组必须：

- 长度相同
- 位置一一对应
- 时间通常按升序排列

---

### 5. Ppv_max1_kW 和 Ppv_max2_kW

| 输出 | 含义 | 单位 |
|---|---|---|
| Ppv_max1_kW | PV1 当前最大可用出力 | kW |
| Ppv_max2_kW | PV2 当前最大可用出力 | kW |

当前代码中两者完全相同：

```matlab
Ppv_max1_kW = pmax;
Ppv_max2_kW = pmax;
```

**当前模型假设**：

- 两台光伏额定容量相同
- 使用同一条光照/出力曲线
- 当前最大可用出力相同

这是一种建模简化，不代表真实工程中两台光伏一定完全相同。

---

## 三、主函数逐行拆解

主函数核心四步：

```matlab
pu = interp_profile(time_s, PV_time_s, PV_profile_pu);
pmax = max(P_unit_kW, 0.0) * max(pu, 0.0);
Ppv_max1_kW = pmax;
Ppv_max2_kW = pmax;
```

---

### 第一步：查出当前曲线标幺值

```matlab
pu = interp_profile(time_s, PV_time_s, PV_profile_pu);
```

调用子函数 `interp_profile`（interp = interpolation 插值，profile = 曲线）。

> 根据当前时间，在离散光伏曲线点之间做插值，计算当前时刻的光伏标幺值。

| 输入 | 含义 |
|---|---|
| time_s | 当前时间 t |
| PV_time_s | 时间坐标 x |
| PV_profile_pu | 对应曲线值 v |
| **输出 pu** | **当前时刻对应的标幺值 y** |

---

### 第二步：标幺值转换为 kW

```matlab
pmax = max(P_unit_kW, 0.0) * max(pu, 0.0);
```

**`max(P_unit_kW, 0.0)`** — 防止额定功率出现负值。

```text
P_unit_kW = -100 → max(-100, 0) = 0
```

**`max(pu, 0.0)`** — 防止曲线标幺值出现负数。

```text
pu = -0.1 → max(-0.1, 0) = 0
```

**最终乘法**：

```text
pmax = 非负功率基准 × 非负标幺值
```

保证 `Ppv_max ≥ 0`。

---

### 第三、四步：两台光伏使用同一最大出力

```matlab
Ppv_max1_kW = pmax;
Ppv_max2_kW = pmax;
```

PV1 最大可用出力 = PV2 最大可用出力。这是当前模型的设定，不是算法必然要求。

未来若两台光伏容量或光照不同，可能需要改为各自独立的 `P_unit` 和 `profile`，但当前内化以实际代码为准。

---

## 四、插值子函数详解

```matlab
function y = interp_profile(t, x, v)
```

| 参数 | 含义 |
|---|---|
| t | 当前时间 |
| x | 时间数组 |
| v | 曲线值数组 |
| y | 插值得到的当前值 |

---

### 获取曲线点数量

```matlab
n = numel(x);
```

示例：`x = [0, 10, 20, 30]` → `n = 4`

---

### 默认输出第一个曲线值

```matlab
y = v(1);
```

先给输出一个初始值，避免没有赋值。

---

### 当前时间早于第一个点

```matlab
if t <= x(1)
    return;
end
```

由于前面已设置 `y = v(1)`，当 `t ≤ 第一个时间点`，直接返回第一个曲线值。

示例：`x(1)=0, v(1)=0.2, t=-5` → `y = 0.2`

这相当于曲线左侧采用**端点保持**。

---

### 寻找当前时间所在区间

```matlab
for k = 1:n-1
    if t <= x(k+1)
```

从第一个区间开始逐段搜索。

示例：`x = [0, 10, 20, 30], t = 16`

```text
16 ≤ 10？否
16 ≤ 20？是 → 区间为 10～20 秒
```

---

### 计算区间宽度

```matlab
dx = max(x(k+1) - x(k), 1e-9);
```

正常情况下 `dx = 后一个时间点 - 前一个时间点`。

`1e-9` 防止两个时间点完全相同导致除以零，是一种数值保护。

---

### 计算当前位置比例

```matlab
a = (t - x(k)) / dx;
```

`a` 表示当前时间位于区间内的相对位置。

示例：区间 10～20s，当前 15s → `a = (15-10)/10 = 0.5`（区间正中间）
示例：t=12s → `a = (12-10)/10 = 0.2`（走过区间 20%）

---

### 线性插值

```matlab
y = v(k) + a * (v(k+1) - v(k));
```

```text
当前值 = 左端点值 + 区间位置比例 × (右端点值 - 左端点值)
```

示例：10s: 0.6 pu, 20s: 1.0 pu, 15s（中点）

```text
y = 0.6 + 0.5 × (1.0 - 0.6) = 0.8 pu
```

---

### 当前时间超过最后一个点

循环结束后执行：

```matlab
y = v(n);
```

超出最后一个曲线时间则保持最后一个曲线值（右侧端点保持）。

示例：最后时间 30s, 最后值 0.5, 当前 50s → `y = 0.5`

## 五、完整手算示例

**给定**：

```matlab
P_unit_kW = 100;
PV_time_s = [0, 10, 20, 30];
PV_profile_pu = [0.2, 0.6, 1.0, 0.5];
time_s = 15;
```

**第一步：找到时间区间**

```text
15 位于 10～20 秒之间
左端点：x(k)=10, v(k)=0.6
右端点：x(k+1)=20, v(k+1)=1.0
```

**第二步：计算区间比例**

```text
a = (15-10) / (20-10) = 0.5
```

**第三步：计算当前标幺值**

```text
pu = 0.6 + 0.5 × (1.0 - 0.6) = 0.8
```

**第四步：换算最大可用出力**

```text
pmax = 100 × 0.8 = 80 kW
```

**最终输出**：

```text
Ppv_max1_kW = 80 kW
Ppv_max2_kW = 80 kW
```

这意味着当前时刻两台光伏各自最多可发 80 kW，但不意味着 AGC 一定命令它们发 80 kW。AGC 可能根据 PCC 目标只要求 PV1=50 kW, PV2=50 kW，只要不超过 80 kW 即可。

## 六、输出如何进入 AGC

在 `AGC_Controller` 中，两个光伏最大出力进入：

```matlab
Ppvmax1_kW
Ppvmax2_kW
```

先限制到合法范围：

```matlab
pvmax = [
    clamp(Ppvmax1_kW, 0.0, P_UNIT);
    clamp(Ppvmax2_kW, 0.0, P_UNIT)
];
```

AGC 实际采用的光伏上限再限制为 `0 ≤ Ppvmax ≤ P_UNIT`。

当 AGC 需要增加微电网净出力时：

```matlab
[Ppv, used] = alloc_up(Ppv, pvmax, rem);
```

含义：在不超过 `Ppvmax` 的前提下优先增加光伏功率。

**完整关系**：

```text
PV曲线决定自然资源上限
→ AGC决定实际分配多少
→ 光伏本地控制执行AGC指令
```

---

## 七、必须掌握的边界情况

| 情况 | 处理 |
|---|---|
| 当前时间早于曲线起点 | 输出第一个曲线值 |
| 当前时间晚于曲线终点 | 输出最后一个曲线值 |
| 曲线值为负 | `max(pu, 0)` 变为 0 |
| P_unit 为负 | `max(P_unit, 0)` 变为 0 |
| 曲线值 > 1 | PV 函数本身不限制，进入 AGC 后 `clamp` 到 `P_UNIT` |

**两级保护**：

```text
PV曲线模块：限制下界 ≥ 0
AGC 模块：进一步限制在 0 ~ P_UNIT 之间
```

## 八、这个模块对论文的意义

虽然它本身只是一个简单的曲线模块，但后续很多论文场景都依赖它：

**可构造的场景**：

- 光伏最大可用出力快速上升
- 光伏最大可用出力快速下降
- 随机波动
- 云层遮挡导致的功率骤降

**角色定位**：

```text
实验扰动源
光伏波动场景发生器
储能平滑控制的输入
通信延时实验中的变化信号
```

**论文创新不在"线性插值"**，而在：

> 当 Ppv_max 变化时，控制系统如何更好地跟踪、平滑、预测或补偿

---

## 九、五个核心认识

**第一**：Ppv_max 是当前自然条件允许的最大值，不是实际功率，也不是 AGC 最终指令。

**第二**：光伏曲线使用离散时间点描述，点与点之间通过线性插值得到连续值。

**第三**：当前两台光伏使用同一条曲线和同一个功率基准，因此最大可用出力相同。

**第四**：PV 函数保证最大可用出力不小于 0；AGC 内部又进一步保证它不超过设备基准功率。

**第五**：AGC 增加功率时，光伏只能在当前值与 Ppv_max 之间增加，这个差值就是光伏的向上可调裕度。

## 十、第一轮内化检验

请自己回答以下五个问题（不看上面的解释）：

1. **Ppv_max、Ppv_ref 和 Ppv_actual** 分别是什么？三者有什么区别？
2. 当前时间位于两个曲线点之间时，代码怎样计算当前标幺值？
3. 为什么当前代码中 PV1 和 PV2 的最大可用出力始终相同？
4. 当曲线值为负数或大于 1 时，代码分别怎样处理？
5. **Ppv_max** 进入 AGC 以后，对 AGC 的功率分配起什么作用？

---

### 参考解答

#### 第 1 题

| 量 | 含义 |
|---|---|
| **Ppv_max** | 当前自然条件下光伏最多能发出的功率，是自然上限 |
| **Ppv_ref** | AGC 下发给光伏的功率指令，是控制目标 |
| **Ppv_actual** | 光伏设备实际发出的功率，是实际运行值 |

三者关系：`0 ≤ Ppv_ref ≤ Ppv_max`，Ppv_actual 尽量跟踪 Ppv_ref。

---

#### 第 2 题

代码调用 `interp_profile(time_s, PV_time_s, PV_profile_pu)` 做**线性插值**：

1. 找到当前时间 t 所在的区间 `[x(k), x(k+1)]`
2. 计算区间内比例 `a = (t - x(k)) / (x(k+1) - x(k))`
3. 计算当前标幺值 `y = v(k) + a × (v(k+1) - v(k))`

---

#### 第 3 题

因为当前代码写死了：

```matlab
Ppv_max1_kW = pmax;
Ppv_max2_kW = pmax;
```

且 `pmax` 来自同一条曲线 `PV_profile_pu` 和同一个功率基准 `P_unit_kW`，所以两台光伏计算结果完全相同。这是建模简化，不是算法必然。

---

#### 第 4 题

**曲线值为负数**：`max(pu, 0.0)` 将负数截断为 0。

```text
pu = -0.2 → max(-0.2, 0) = 0 → Ppv_max = 0
```

**曲线值大于 1**：PV_Profile_Curve 本身不做上限限制。例如 `pu = 1.2, P_unit = 100 kW` → `pmax = 120 kW`。但进入 AGC 后经 `clamp(Ppvmax_kW, 0.0, P_UNIT)` 限制，最终不超过 `P_UNIT`。

**两级保护**：

```text
PV 曲线模块：限制下界 ≥ 0
AGC 模块：限制在 0 ~ P_UNIT
```

---

#### 第 5 题

Ppv_max 进入 AGC 后起三个作用：

1. **限制光伏指令上限**：光伏在任何时刻的功率指令不能超过 Ppv_max
2. **计算光伏向上调节裕度**：`向上裕度 = Ppv_max - 当前光伏指令`
3. **决定分配比例**：两台光伏按各自剩余裕度比例分担调节量

示例：当系统需要增加净出力时，AGC 调用 `alloc_up(Ppv, pvmax, rem)`，光伏在不超过各自 Ppv_max 的前提下按裕度比例增发。若光伏裕度不足，剩余调节量才传给储能和充电负荷。

> Ppv_max 不是直接等于光伏指令，而是限制光伏指令上限、计算向上调节裕度、决定两台光伏分配比例的依据。
